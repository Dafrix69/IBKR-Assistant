## 0. 开始前

- 关掉 Electron 版(两个引擎不能同时盯一个交易库;Qt 版检测到 Electron 在跑会拒绝起引擎)。
- **备份真库**:退出所有版本后,自己拷一份 `~/Library/Application Support/dafrix`。C++ 版默认连真配置、真库。
- TWS 切到**纸面账户**(7497),勾「启用 ActiveX 与套接字客户端」。配置里只放纸面账户。
- 编译(Terminal 面板):

```bash
sh native/tools/rebuild-workspace.sh
```

## 1. 先不碰券商

1. `Datrix --engine none`:界面能开,16 页都能点开,深浅色各看一眼。
2. 命令行:`ibkr-engine selftest --config <配置>`、`validate`、`records`——只读、不连券商。
3. `Datrix --engine native`,**TWS 先别开**:状态条应显示未连接,不崩、不刷错。

## 2. 连纸面账户(只看,不发单)

1. 开 TWS 纸面,再起 `--engine native`。接入页应显示已连接;核对账号(遮过的)、持仓、净值、当日盈亏和 TWS 一致。
2. 行情页:K 线、盘前盘后与夜盘、SPX 盘外按 ES 推算。
3. 订阅持仓行情,平掉的会撤订阅。
4. 断开 TWS 再恢复:应自动重连;**断线期间下单/改单/撤单会直接报错(不排队,这是有意的改动)**。

## 3. 纸面发单(小额,逐项)

对照 Electron 版,同一操作看结果是否一致:
1. 手动页「7840 7845 bear call」这类无价速记 → 本地解析成 AUTO_MID。
2. 下一张小单:确认框弹出、内容与实际一致;成交回报落库;订单看板更新。
3. 撤单、改单。
4. 持仓追踪:建一条带止盈/止损/到点平仓的追踪,看托管单发出与触发。标的止损价、日内剧本同理。
5. `ibkr-engine run`(必须带确认参数,且 `auto_execute=true` 才发)、`parse`(永远只校验不发单)。
6. 熔断/halt:撤单失败时仍应清理。

**不要在真实账户上做以上任何一项。**

## 5. 有意与 TS 不同的几处(你可否决)

- 断线下单/改单/撤单报错而非排队(TS 也已改,你批准的)。
- 跟单发出一张单后,后面记录步骤出错,不再记为「被拒绝」。
- 引擎重建时软件条件单交接给新引擎;`firePending` 每笔发单前重查熔断;`halt` 撤单失败仍清理。
- 富途整块不搬。
- 已知未修:`domain/positions.cpp` 中,某条腿 `avg_cost` 为无穷时 `withCombos` 的组合成本与 TS 不同(券商不会报这种值,仅记录)。
