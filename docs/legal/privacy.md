# 隐私说明

版本:2026-09-28

一句话:**你的交易数据留在你自己的电脑上。我们没有服务器,不收集、不上传你的账户、持仓、订单与交易记录。**

下面逐项说明哪些数据存在哪里、哪些数据会离开你的电脑、发给谁。

## 存在你电脑上的

| 内容 | 位置 |
|---|---|
| 交易记录、成交、审计日志、持仓追踪设置、想法备忘、板块与提醒 | 本机的交易库文件及其备份 |
| 设置(含账户别名与账号的对应关系) | 本机的配置文件 |
| 大模型 API Key、富途交易解锁密码 | 操作系统的凭证库(macOS 钥匙串 / Windows 凭据管理器) |
| 运行日志 | 本机的日志文件。写入前会抹掉账号、密钥与家目录里的用户名 |
| 期权行情的记录(时刻、指数现价、行权价、买卖价、隐含波动率;用于校准蝴蝶测算,可以关掉) | 交易库旁边的 `fly-iv` 目录。里面没有账号、持仓与订单 |

交易库、它的备份,以及你用「交易记录 → 导出」另存的文件里,账号是完整的;界面、日志与诊断信息里的是打了码的。

卸载软件不会自动删除这些文件。交易库与备份不一定在软件的数据目录里,凭证库里的条目也要单独删;
逐项的位置与做法见使用指南的「数据、备份与恢复」第 8 节。

## 会离开你电脑的

| 发给谁 | 发什么 | 什么时候 |
|---|---|---|
| 你配置的大模型服务商(Anthropic,或你填写的 OpenAI 兼容端点) | 你输入的指令原文、账户**别名**(不是账号)、你设置的代码别名表与限额;使用「想法分析」「AI 选股」「行情解读」「回测条件解析」时,还有对应的文字与行情数值 | 你点「解析并校验」「发送到IBKR」或使用这些功能时 |
| 你的券商软件(TWS / IB Gateway / 富途 OpenD,运行在本机) | 订单、行情请求、账户查询 | 连接券商之后 |
| 公开行情数据源(Yahoo Finance、Cboe) | 要查询的指数 / 代码 | 顶栏行情带与指数现价刷新时 |
| GitHub | 一个不带任何账户信息的版本查询请求 | 检查更新时(可在「关于」页关闭自动检查) |

真实账号不会出现在发给大模型的内容里,这一点由代码检查保证。请不要在指令或想法里自己写入账号、密码等敏感信息——你写进去的文字会原样发给大模型。

## 我们不做的事

- 不做用户行为统计,不嵌入任何分析或广告组件。
- 不自动上传崩溃报告或日志。「导出诊断信息」只在你点击时生成一份文件,保存到你指定的位置,发不发、发给谁由你决定。
- 不读取与本软件无关的文件。

## 第三方的隐私政策

大模型服务商、券商、数据源如何处理收到的数据,以它们各自的隐私政策为准。
