# Discord 跟单

这一页讲怎么让软件自动跟别人在 Discord 频道里发的蝴蝶单:要准备什么、怎么配、怎么先只看不发、每条信号的下场怎么读。
设计与口径在 [功能文档:Discord 跟单](../features/follow.md)。

> **先读这一条。** 打开自动跟单之后,你信任的那个人每发一张单,软件都不再问你,直接发到券商。
> 他发错一条、写错一个数、Discord 账号被盗,都会变成你账户里的订单。软件只跟开仓,不跟他的平仓。
> 请先「只观察」几天,再在纸面账户上打开,最后才考虑实盘。

## 1. 它跟什么,不跟什么

| 跟 | 不跟 |
|---|---|
| 你信任的发送者,在你指定的那一个频道里发的消息 | 别的频道、别的人,哪怕写的是一模一样的单 |
| 写明了价格的买入蝴蝶,如 `1.8 挂15蝴蝶 15CM`、`7770蝴蝶 20CM 4块钱试试` | 没写价格的(对方把价格放在下一条消息里时,软件不把两条拼起来) |
| 写明了方向与价格的贷方价差,如 `7770 7775 bear call 挂个-2-2.5`、`00 95 bull put 试下 -2 -2.5` | 没写 bull put / bear call 的价差(只提醒你);借方价差 |
| 消息里带 `@everyone` 之类的提及没有关系 | 带止损、条件、平仓、两张单拼在一起的消息;图片里的单子;股票与单腿期权 |
| 有单子的样子的消息 | 只是提到「蝴蝶」的评论(「蝴蝶先走一下」),不提醒也不记录 |
| 刚发出来的消息 | 发出超过上限秒数的旧消息(断线之后补到的) |
| 开仓 | 对方的平仓、改价、撤单;对方编辑或删除消息 |

速记的写法和你自己在「交易指令」页敲的一样,见 [02-日常使用](02-日常使用.md) 第 2 节「默认值与速记规则」。
跟单不经过大模型:接不住的只提醒你,不会交给模型去猜。

## 2. 准备:一个 bot,和一个 bot 看得到的频道

软件通过你自己建的 Discord bot 读消息。**不要用你个人账号的 token**:用个人账号跑自动化违反 Discord 的条款,会被封号。

- 打开 Discord Developer Portal,New Application;左侧 Bot → Reset Token,把那一整段复制下来。
- 同一页往下,Privileged Gateway Intents → 打开 **Message Content Intent**。不开的话 bot 看不到消息正文。
- 左侧 OAuth2 → URL Generator,勾 `bot`,权限只要 View Channels 与 Read Message History;打开生成的链接,把 bot 拉进**你能管理的服务器**。

bot 只能读它所在服务器里的频道。对方的服务器你拉不进 bot 时,让单子出现在你自己的服务器里:

| 情况 | 做法 |
|---|---|
| 对方的频道是公告频道(频道名旁边有喇叭图标) | 点频道顶上的「关注」,选你服务器里的一个频道。对方每次「发布」消息,都会转到你这边 |
| 不是公告频道 | 请对方同时在你的服务器里发一份;或者请那边的管理员把你的 bot 拉进去 |

## 3. 在软件里配置

「接入 → Discord 跟单」:

- **1 · Bot 与连接**:粘贴 bot token,点「保存 token」。它只存在系统凭证库里。下面那一行写着连接状态;
  在 Developer Portal 改过设置之后点「重新连接」。
- **2 · 听哪个频道、信任谁**:在 Discord 的「设置 → 高级」里打开开发者模式,右键频道 →「复制频道 ID」,填进来并保存。
  等频道里有人说话,「频道里最近看到的消息」会列出来,在对方那一条上点「信任」。也可以右键对方头像 →「复制用户 ID」手动添加。
  关注过来的公告频道,发送者显示的是源频道的名字——信任它,等于信任所有能在源频道发公告的人。
- **3 · 发到哪、最多亏多少**:

| 项 | 含义 | 默认 |
|---|---|---|
| 发到这些账户 | 一个都不勾 = 默认账户;勾两个就每单各发一份 | 默认账户 |
| 每单最坏亏损上限 | 蝴蝶:张数 × 100 × 权利金;贷方价差:张数 × 100 ×(宽度 − 收到的权利金) | 300 美元 |
| 每天最多跟几单 | 按美东的一天算 | 3 |
| 消息多旧就不跟 | 秒 | 30 |

这三个默认值只是保守的起点,请按你亏得起的数改。它们是多加的一道:「设置」里的限额、保护规则、熔断照常生效。

## 4. 先只观察

「自动跟单」开关关着时,软件照样连着、照样解析、照样把每一条记在「最近的信号」里,标着「只观察」,一张单都不发。
用它确认三件事:对方的写法软件接得住;解析出来的行权价、方向、张数和你理解的一样;上限设得合适。

## 5. 打开

把「自动跟单」拨到开,点「保存」。系统会弹出确认框,上面写着频道、信任的发送者、发到哪些账户(纸面还是实盘)、三个上限——
读完再点。之后这些情况会再弹一次:换频道、多信任一个人、换账户、调大上限。关掉与往紧了改不用确认,当场生效。

跟单要发得出去,还得满足手动发单本来就要满足的条件:「设置 → 允许自动执行」开着、连着 TWS、没有熔断;
发到实盘账户还要「允许实盘账户下单」开着。

## 6. 每条信号的下场

每一条都会发系统通知,并记在面板最下面:

| 标签 | 意思 | 怎么办 |
|---|---|---|
| 已跟单 | 发到券商了(或进了软件盯盘队列) | 到「订单看板」看成交;自己设持仓追踪 |
| 只观察 | 能发,但开关关着 | — |
| 太旧 | 消息发出超过了上限秒数 | 多半是断线后补到的;经常出现就查网络,或看本机时钟是不是偏快 |
| 没接住 | 有单子的样子,但速记没有完整接住、没写价格、价差没写方向,或者拿不到现价。说明里写着差的是哪一样 | 想跟就自己到「交易指令」页下 |
| 超上限 | 超了单笔亏损上限或每日单数 | 觉得上限太紧就调大(要确认) |
| 闸门关着 | 熔断、「允许自动执行」没开、没连券商、账户别名不存在 | 按说明处理 |
| 没有发出 | 过了校验但被保护规则拦下 | 见 [02-日常使用](02-日常使用.md) 第 8 节 |
| 被拒 | 校验或券商拒了(超限额、重复单、休市……) | 看说明里的原因 |

## 7. 要知道的几件事

- **「N蝴蝶」写在百位边上不跟。** 「00蝴蝶」是现价的百位加 0:现价 7650 以上、7700 以下时它算成 7600,可对方多半指 7700。
  软件算出来的中心离现价 50 点或更远就不跟,面板里标「没接住」并写明原因;对方写完整的中心(「7700蝴蝶」)就没有这个问题。
- **没写价格的不跟。** 对方先发「20蝴蝶 20CM」、再发「3.6」时,第一条没有价格,软件标「没接住」;第二条只有一个数,不算单子。想跟就自己到「交易指令」页下。
- **贷方价差的风险和蝴蝶不一样。** 蝴蝶最多亏掉付出的权利金;贷方价差是先收钱,到期时价格穿过两个行权价,亏的是「宽度 − 收到的权利金」(宽 5 点、收 2.5 就是每张 250 美元)。
  对方写「-2 -2.5」时软件按收 2.5 挂单,成交不了就一直挂到收盘。
- **单笔上限要够。** 默认 300 美元:贷方价差(宽 5 点)过得去,权利金 3 块以上的蝴蝶过不去,会标「超上限」。要跟就按你亏得起的数调大(要确认)。
- **你的成交和对方的不一样。** 价格、张数、有没有成交都可能不同。
- **跟进来的持仓没有自动的止盈止损。** 要保护就自己到「持仓追踪」里设,或者在券商端设。
- 连不上 Discord 而且不会自己好的时候(token 不对、没开 Message Content Intent),软件会发一条通知并停下来,改好之后点「重新连接」。
- 软件不走代理:你的网络连不上 Discord 时,它也连不上。
- 不再用了:关掉开关、把频道 ID 清空并保存(软件就不再连 Discord),再到 Developer Portal 重置 token 或删掉那个应用。

## 8. 对方的频道拉不进 bot:本地收件

对方的频道是私密的、不是公告频道、那边的管理员也不肯拉 bot 时,可以用「本地收件」:一个你自己运行的小脚本读**你屏幕上**的 Discord 窗口,
把当前频道里新出现的消息抄进一个本机文件,软件读这个文件。它不用任何 token、不碰 Discord 的接口,Discord 那边什么都收不到。

代价要先知道:

- Discord 要一直开着、停在那个频道;电脑不能锁屏、不能睡。
- 软件按**显示名**认人,不是按账号。频道里别人把昵称改成和对方一样,软件分不出来——只在你信得过所有成员的私密小群里用。
- 消息从发出到软件看到约 1 到 3 秒。

怎么用:

1. 退出 Discord,在终端里用 `open -a Discord --args --force-renderer-accessibility` 重新打开(不带这个参数,窗口里的消息读不到)。切到那个频道。
2. 系统设置 → 隐私与安全性 → 辅助功能,把你运行脚本用的终端加进去。
3. 在「接入 → Discord 跟单」里打开「本地收件」并保存;下面那一行显示收件文件的路径。
4. 运行脚本(在软件的源码仓库里):`swift desktop/tools/discord-window-follow.swift --channel 频道名 --out 收件文件路径`。它每 1.5 秒看一次窗口,
   抄到新消息就在终端里打一行。切到别的频道它会停,切回来继续。
5. 对方发一条之后,在「频道里最近看到的消息」里点「信任」(条目写成 `local:显示名`),保存。打开自动跟单的那一步和第 5 节一样,确认框会写明消息来自本地收件。

只观察、三个上限、每条信号的下场都和 bot 那条路一样。
