# IBKR-Assistant 用户手册

这份手册写给使用 IBKR-Assistant 的人:怎么装、怎么配、每天怎么用、数据在哪、出了问题怎么办。
它只讲操作;每个功能背后的设计与口径在 [docs/features](../features) 里,手册在用得到的地方给出链接。

## 这个软件是什么,不是什么

IBKR-Assistant 是一个装在你自己电脑上的下单工具。你写一句话(比如"买入 AAPL 100 股 limit 230"),大模型把它翻译成结构化订单,
限额、方向、账户、时段、重复单由代码逐条校验,通过之后经你自己登录的 TWS / IB Gateway 发到你自己的 Interactive Brokers 账户。
围绕下单,它还带持仓追踪(到价自动平仓)、订单看板、交易记录,以及行情、板块、扫描、回测、复盘这些研究页面。

它不是投资顾问,不是券商,不持有也不接触你的资金。软件里的分析、评分、筛选、提醒、回测、复盘和模型给出的解读都只是计算结果或文字生成,
不构成投资建议,也不保证正确。每一笔交易都是你自己的决定,盈亏由你自己承担。

## 适合谁

| 适合 | 不适合 |
|---|---|
| 有 IBKR 账户,能在自己的电脑上安装并登录 TWS 或 IB Gateway | 希望软件替你做交易决定 |
| 愿意自备一个大模型 API Key(Anthropic,或任意 OpenAI 兼容端点,如 DeepSeek),费用自理 | 不想让指令原文发给任何大模型服务商 |
| 用 Apple Silicon 的 Mac(macOS 12 以上)或 64 位 Windows 电脑 | 用 Intel Mac(没有对应的安装包) |
| 愿意先在模拟账户上把常用的写法跑一遍 | 想通过富途下单(富途通道目前只有检测与诊断,下单桥还不可用) |

## 先读这三条

> **1. 先用纸面(模拟)账户。** 大模型可能把方向、数量、行权价、到期日、账户解析错,校验层拦得下一部分,拦不下全部。
> 先在模拟账户上确认软件对你常用的写法理解无误,再考虑实盘。「允许自动执行」「允许实盘账户下单」两个开关默认都是关的。
>
> **2. 软件侧的止盈止损,软件必须开着才有效。** 持仓追踪的盯盘在你的电脑上进行:软件退出、电脑睡眠或关机、断网、与券商断连时,它不会触发。
> 要在这些时候也有保护,只能用「托管到券商」,或者在券商端另设保护。
>
> **3. 备份要自己另存一份。** 软件会自动备份交易库,但备份和交易库在同一块硬盘上。硬盘损坏、误删、重装系统时两样会一起丢,
> 请定期把备份目录拷到别处。

## 本手册的写法

- 「」里的字是界面上的原文。「接入 → 账户」表示「接入」页里的「账户」页签;「关于 → 支持」表示「关于」页里的「支持」一节。
- "纸面账户""模拟账户"是一回事,指 IBKR 的 Paper Trading 账户;"实盘账户"指用真钱的账户。
- 快捷键在 macOS 上写作 ⌘,Windows 上对应 Ctrl。
- 手册里出现的账号 `DU1234567`、`U1234567` 都是示例,不是真实账号。
- 软件的行为以你手上这一版为准。手册与界面不一致时,请以界面上的说明为准,并告诉我们。
