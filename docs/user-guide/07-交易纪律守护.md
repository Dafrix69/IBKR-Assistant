# 07 交易纪律守护

交易纪律守护(guard)管两件事:**开仓前先写下止损**,**股票仓位必须有止损单**。它不给建议、不出信号。
设计与口径见 [docs/features/guard.md](../features/guard.md)。

> 这个功能还没在纸面账户上跑过。打开之前,请先在纸面账户上按本页最后一节试一遍。

## 打开

它默认关着,没有界面开关。在应用数据目录的 `settings.json` 里(位置见 [03 数据、备份与恢复](03-数据、备份与恢复.md))加一段,存盘后重启 Datrix:

```json
"guard": { "enabled": true }
```

其余几项不写就用默认值:补录期 60 秒、单笔最坏亏损上限为净值的 2%、止损距离超过 8% 时股数减半、默认止损按 8% 与前 10 日最低价算。

## 写交易意图

在交易库所在的文件夹里(默认 `~/Library/Application Support/dafri/`)找到 `guard/intents.jsonl`,没有就新建。
一行写一份,存盘后几秒内会被收走,结果追加到同一个文件夹的 `intents.log.jsonl`,并弹通知告诉你收下了还是为什么没收。

股票:

```json
{"symbol":"BE","side":"BUY","qty":20,"entry_price":195,"stop_price":186,"stop_reason":"13周低点","thesis":"电力需求","invalidation":"跌破 13 周低点"}
```

期权组合(不拦开仓;持仓里认得出这只组合时,按规则盯出场):

```json
{"symbol":"QQQ","structure":"QQQ 660/670/680 call fly","expiry":"2026-11-09","cost_usd":157,"exit_rules":{"take_profit":"中间价 >= 成本 × 2.5","stop_loss":"中间价 <= 成本 × 0.4","time_stop":"到期日 15:00 ET"}}
```

不是默认账户的,加 `"account":"账户别名"`。
期权组合的出场规则要写得出数:止盈、止损写成「成本 × 几」,几点平写成「15:00」,写不出数的不收下;收权利金的贷方组合暂不支持。

文件一存盘就会被收走。用编辑器写时,每次存完就关掉这个文件再写下一份;一直开着同一个窗口反复保存,后写的那一份可能落进已经被收走的旧文件里而丢掉。
最稳的是在终端里追加一行:

```bash
echo '{"symbol":"BE","side":"BUY","qty":20,"entry_price":195,"stop_price":186,"stop_reason":"13周低点"}' >> ~/Library/Application\ Support/dafri/guard/intents.jsonl
```最坏亏损超过净值 2% 的意图不收下,通知里会写明这个止损下最多能买多少股。

## 关掉意图

```json
{"close":"BE","reason":"判断作废,改为观望"}
```

不写理由不收。仓位平掉之后,对应的股票意图会自动关掉。

## 打开之后会发生什么

- **写了意图再买股票**:几秒内 Datrix 在券商按意图的止损价挂一张止损单(「持仓追踪」页能看到,备注「guard 意图止损」)。
  - 你在「持仓追踪」页把这条止损改松、停用或关掉托管,下一轮会被改回去,并记一笔违规。收紧可以。
  - 你在 TWS 里撤掉这张止损单,约一分钟后会重新挂上,并记一笔违规。
  - 要真的放开止损,只能写一行关掉意图(带理由)。
  - 在配置里加 `"trail_r": true`:盈利过 1 倍止损距离时止损抬到成本价,过 2 倍抬到成本 + 1 倍,只升不降。
- **写了意图的期权组合**:持仓里认得出这只组合时,Datrix 盯它的中间价,到止盈价、止损价或标的止损线就用限价单平掉(最多让 10%,不改市价),
  到期日当天到你写的钟点无条件平。同一到期日的几只组合交错持有(比如 660/670/680 和 664/674/684 两只蝶)时认不出来,只提醒一次,出场要你自己盯。

- **在交易指令页发股票开仓单**:没有对应意图、方向不对或股数超过意图的,单子不发,记录显示「纪律拦下」。只解析不拦,平仓不拦。
- **在 TWS 里手动开了股票仓位、没写意图**:马上收到通知;60 秒内没补录,Datrix 会在券商挂一张止损单(在「持仓追踪」页能看到这条追踪,备注写着「guard 默认止损」)。
  止损价取「入场价 × 0.92」与「前 10 个交易日最低价」中更近的那条;卖空的对称。
- **价格已经跌过默认止损价**:不替你平仓,每五分钟提醒一次,请自己处理。
- 普通止损单在盘前盘后不触发,开盘才止损。

## 推到手机

照 `guard/DEPLOY.md` 第 2 节配好 Telegram 或 Pushover,token 存进钥匙串。之后这些会推到手机:IBKR 断开超过 2 分钟(恢复时再推一条)、
Datrix 或交易引擎异常退出后重新起来、止损或止盈触发、拦下一张开仓单、每一笔违规。同一句话 10 分钟内只推一次。
网断了推不出去的,网回来后补推,正文写明晚了几分钟。

想试一下通不通,在终端里:

```bash
echo '{"push_test": true}' >> ~/Library/Application\ Support/dafri/guard/intents.jsonl
```

交易库旁边的 `guard/heartbeat.json` 每 5 分钟更新一次:连没连着、几份持仓、几条在管的止损、推送有没有积压。

## 每日报告

每个交易日美东 16:15(北京时间早上 5:15,冬令时)推一份到手机,也写进交易库旁边的 `guard/reports/<日期>.txt`:净值和上一份比涨跌多少、
今天开了什么仓(有没有意图)、哪些止损触发了、有哪些违规、下一个交易日到期的期权、连接是否正常。周五多一段:本周违规几次、止损触发几次、
每笔做完的交易赚了几个 R(没止损的那几笔写「无止损」)。那个时刻 Datrix 没开着的,当天晚些时候开起来再补发。TWS 那时没登着(它每天北京 23:45 自动登出),报告会等你登回去再发;
到美东 20:00(北京早上 9 点)还没登回去,就发一份注明「TWS 断开」的。

## 先在纸面账户上试

1. 用纸面账户登录 TWS,Datrix 连上它,打开 guard。
2. 在 TWS 里手动买 10 股任意股票,不写意图:应当马上收到通知,60 秒后 TWS 里出现一张止损单。
3. 写一份最坏亏损超过净值 2% 的意图:应当收到「没收下」的通知,`intents.log.jsonl` 里写着原因。
4. 先写好意图再买 10 股:几秒内 TWS 里出现止损单。在 TWS 里撤掉它:约一分钟后重新出现。
5. 开一只纸面蝶,写一份止损倍数贴近现价的意图:看到它被平掉。
6. 退出 TWS 3 分钟:手机收到「IBKR 断开」,重新登录后收到「IBKR 已恢复」。
7. 照 `guard/DEPLOY.md` 第 4 节装好 launchd 任务后,在终端 `pkill -9 -x Datrix`:十几秒内 Datrix 重新打开,手机收到「Datrix重启了」。
8. 让 Datrix 在一个交易日的 16:15(美东)开着:手机收到每日报告,`guard/reports/` 里有同样的一份。
