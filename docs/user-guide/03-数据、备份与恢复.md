# 数据、备份与恢复

你的交易数据只存在你自己的电脑上,软件没有服务器替你保管。这一页讲清楚每样数据放在哪、软件自动做了哪些备份、
怎么从备份恢复、怎么搬到新电脑,以及卸载之后怎么把数据删干净。

## 1. 数据放在哪

软件用到两个位置:**应用数据目录**(配置、同意记录,Windows 上还有日志)和**交易库所在的目录**(交易库、备份)。两者不一定在同一个文件夹里。
macOS 上日志按系统的惯例另放在 `~/Library/Logs/` 下。

应用数据目录:

| 系统 | 位置 |
|---|---|
| macOS | `~/Library/Application Support/IBKR-Assistant/` |
| Windows | `%APPDATA%\IBKR-Assistant\` |

各样数据:

| 内容 | 文件 | 位置 |
|---|---|---|
| 设置(限额、闸门、保护规则、连接、账户别名与账号的对应关系) | `settings.json` | 应用数据目录 |
| 上一份设置(每次从界面改设置之前留下的) | `settings.json.bak` | 应用数据目录 |
| 交易记录、成交、审计日志、持仓追踪设置、想法备忘、板块与提醒 | 交易库 `trades.db` | macOS 默认 `~/Library/Application Support/dafri/trades.db`;Windows 新安装时是 `%APPDATA%\IBKR-Assistant\data\trades.db` |
| 交易库的备份 | `trades-年月日-时分秒-原因.db` | 交易库旁边的 `backups/` 目录 |
| 熔断状态 | `breaker.json` | 交易库旁边 |
| 当日到期期权的 IV 记录(只有行情:时刻、现价、行权价、盘口、IV;没有账号与持仓) | `年-月-日.jsonl`,一天一个 | 交易库旁边的 `fly-iv/` 目录。留最近 400 天 |
| 运行日志 | `main.log` | macOS `~/Library/Logs/IBKR-Assistant/`;Windows 应用数据目录下的 `logs\`。单份最多 4 MB,另留一份旧的。写入前会抹掉账号、密钥与家目录里的用户名 |
| 条款同意记录 | `consent.json` | 应用数据目录 |
| 大模型 API Key、富途交易解锁密码 | — | 操作系统的凭证库(macOS 钥匙串 / Windows 凭据管理器),不在任何文件里 |

**以软件里显示的路径为准。** 交易库的位置由 `settings.json` 里的 `storage.db_path` 决定,你手上的可能和上表不同:

| 想找什么 | 去哪看 |
|---|---|
| 配置文件、日志文件的完整路径 | 「关于」页的「配置文件」「日志文件」两行 |
| 打开它们所在的文件夹 | 「关于 → 支持」的「打开配置文件所在位置」「打开日志所在位置」 |
| 交易库的完整路径 | 「设置 → 数据与备份」的「交易库」一行 |
| 打开备份目录 | 「设置 → 数据与备份」的「打开备份目录」 |

如果你是从改名之前的老版本(那时叫 Dafri Trading)一路升级上来的,应用数据目录可能仍是旧名字的那个文件夹,同样以「关于」页显示的为准。

## 2. 自动备份

| 种类 | 什么时候留 | 保留几份 |
|---|---|---|
| 每日自动 | 每天第一次打开软件时(两份之间至少隔 20 小时) | 最新的 7 份 |
| 升级前 | 新版本需要改动交易库的结构时,在改之前 | 最新的 3 份 |
| 手动 | 你点「立即备份」时;从备份恢复之前,软件也会先自动留一份 | 最新的 5 份 |

- 超出份数的旧备份会自动清掉。
- 备份是交易库在那一刻的完整快照,不用停软件。
- 文件名里的时间是 UTC 时间,和界面上显示的本地时间差着时区,属于正常。
- 自动备份是在软件打开交易库的时候做的。软件连续开着好几天不退出时,不要指望它每天到点自己留一份,想留就点「立即备份」。
- 备份没有成功(比如磁盘满了)不会挡住软件使用,只在日志里记一句。所以请偶尔到「设置 → 数据与备份」看一眼最新一份是哪天的。

> **备份和交易库在同一块硬盘上。** 硬盘损坏、误删整个文件夹、重装系统时,两样会一起丢。
> 请定期点「打开备份目录」,把里面的文件拷到别处(移动硬盘、另一台电脑、你信任的网盘)。备份里有你的完整交易记录,请像保管对账单一样保管。

## 3. 「设置 → 数据与备份」

| 控件 | 作用 |
|---|---|
| 「立即备份」 | 现在留一份手动备份。适合在升级、换电脑、大改设置之前点一下 |
| 「打开备份目录」 | 打开备份所在的文件夹 |
| 列表里每一行 | 一份备份:时间、种类(「每日自动」「升级前」「手动」)、大小 |
| 「恢复到这一份…」 | 用这一份换掉现在的交易库,见下一节 |

这一节要交易引擎在运行时才读得到。显示「读不到备份清单」时,先到「关于」页最下面点「重启交易引擎」。

## 4. 从备份恢复

### 步骤

1. 「设置 → 数据与备份」,在要恢复的那一份后面点「恢复到这一份…」。
2. 系统弹出「从备份恢复交易库」确认框,写着这份备份的时间、种类和大小。确认无误点「恢复这一份」。
3. 软件依次做这几件事:给现在的库再留一份备份 → 停下交易引擎 → 把现在的库改名挪到一边 → 把备份放到库的位置 → 重新启动引擎。
4. 看到「交易库已恢复,交易引擎正在重启。请核对追踪与挂单状态。」之后,按下面的清单核对。

### 恢复会做什么,不会做什么

| 会 | 不会 |
|---|---|
| 把交易库换成备份那一刻的样子 | 不会找回备份之后的内容:那之后产生的交易记录、成交、追踪设置、想法,在恢复后的库里都没有 |
| 恢复前先给现在的库留一份备份 | 不会删掉现在的库:它被改名为 `trades.db.before-restore-时间戳`,留在原来的文件夹里 |
| 重启交易引擎:持仓追踪停几秒,券商连接会重连 | 不会影响已经挂在券商那边的单,也不会改变你在券商的持仓 |
| 保留备份本身,之后还能再恢复一次 | 不会改动设置(`settings.json`)与 API Key |

### 恢复之后要核对的

- **「持仓追踪」**:追踪设置回到了备份那一刻。备份之后新建的追踪没有了,需要的话重新建;备份之后删掉的追踪又回来了,不需要的话再删一次。
  哪条追踪已经触发过也记在库里:备份之后才触发的追踪,恢复后是还没触发的样子,请对着实际持仓逐条看,该删的删、该暂停的暂停。
- **TWS 里的挂单**:券商那边的单不受恢复影响。备份之后才挂出去的托管单,在恢复后的库里没有对应的追踪,请到 TWS 里核对,不要的自己撤掉。
- **「订单看板」「交易记录」**:备份之后发出的订单在记录里没有,以券商的记录为准。

恢复错了可以退回去:再恢复一次,选恢复之前软件自动留的那份「手动」备份。

交易库本身打不开(损坏、被占用等)时,软件启动时会弹出「交易库打不开」对话框,从那里也能恢复,见 [04-常见问题与排障](04-常见问题与排障.md)。

## 5. 配置文件的备份

每次从界面改设置(包括在「接入 → 账户」里改账户)之前,软件会把改之前的那一份存成 `settings.json.bak`。只留最近的一份。

它的用处是:配置文件坏了、引擎起不来时,「配置文件有问题」对话框里的「恢复上一份可用的配置」用的就是它。
恢复出来的配置里「允许自动执行」「允许实盘账户下单」一律是关的,需要时自己重新打开;坏的那份会改名留在旁边,不会删。
完整说明见 [04-常见问题与排障](04-常见问题与排障.md)。

手改 `settings.json` 之前,建议自己先复制一份。

## 6. 换电脑

### 在旧电脑上

1. 处理好持仓追踪:本机盯盘的追踪在你关掉旧电脑之后就不再盯了;托管到券商的单会留在券商那边。
2. 「设置 → 数据与备份」点「立即备份」。
3. 退出软件(macOS 用 ⌘Q;Windows 关掉窗口)。**先退出再拷文件**,运行中拷出来的交易库可能不完整。
4. 拷走三样东西:

   | 拷什么 | 在哪 |
   |---|---|
   | `settings.json` | 应用数据目录 |
   | 交易库文件 `trades.db` | 「设置 → 数据与备份」显示的位置。旁边如果有 `trades.db-wal`、`trades.db-shm`,一起拷 |
   | `backups` 文件夹 | 交易库旁边 |

### 在新电脑上

1. 安装软件,打开一次,确认条款,然后退出。这一步会把应用数据目录建出来。
2. 用拷来的 `settings.json` 替换应用数据目录里的那一份。
3. 打开 `settings.json` 看 `storage.db_path`。把 `trades.db` 和 `backups` 文件夹放到它指的那个文件夹里。
   用户名不同、或者从 macOS 换到 Windows(反过来也一样)时,原来的路径在新电脑上不对,请先把 `storage.db_path` 改成新电脑上的实际位置。
   那个文件夹里如果已经有第一次打开时建的空库,用拷来的替换它,并把旁边多余的 `trades.db-wal`、`trades.db-shm` 删掉。
4. 打开软件,然后逐项做:

   | 要做的 | 为什么 |
   |---|---|
   | 「接入 → 大模型」重新填 API Key | Key 在旧电脑的系统凭证库里,不会跟着文件走 |
   | 新电脑的 TWS / IB Gateway 里重新打开 API | 这是 TWS 自己的设置,见 [01-安装与首次配置](01-安装与首次配置.md) 第 5 节 |
   | 「接入 → TWS」点「检测连接」,确认每个别名都「对得上」 | 账户与连接是跟着 `settings.json` 过来的,要确认在新环境里仍然正确 |
   | 「设置」里核对限额与两个闸门 | 闸门的开关状态也跟着 `settings.json` 过来了。建议先关掉,在新电脑上用模拟账户试过再打开 |
   | 「设置 → 数据与备份」确认「交易库」的路径和备份列表 | 确认软件读的是你拷过来的那个库 |
   | 「持仓追踪」逐条核对 | 追踪设置在交易库里,也跟着过来了 |

5. 旧电脑上不再使用时,记得退出那边的 TWS。同一个 IBKR 用户名在别处登录着,新电脑这边会拿不到行情。

## 7. 导出交易记录(JSON)

「交易记录」页右上角点「导出」,在「导出全部交易数据」对话框里选保存位置(默认文件名 `dafri-trades.json`)。

| 文件里有 | 文件里没有 |
|---|---|
| `exported_at`:导出时间 | 持仓追踪设置 |
| `records`:全部交易记录,每条带着指令原文、解析出的订单、状态时间线、成交与佣金 | 想法备忘、板块与价位提醒 |
| `audit_log`:审计日志 | 设置、API Key |

注意两点:

- **它不是备份。** 恢复只认备份目录里的备份文件,这份 JSON 不能用来恢复交易库。它的用处是留档、对账、拿到别的工具里分析。
- **里面有真实账号。** 界面上显示的账号是打了码的,但导出的记录里是库里的原样。这份文件请自己保管,不要直接发给别人。
  需要把现场发给支持时,用「导出诊断信息…」,那一份不含交易记录,账号已打码。

## 8. 卸载与彻底删除数据

卸载软件**不会**删除你的数据。

### 卸载之前

- 到「持仓追踪」处理掉不再需要的追踪。托管到券商的单在卸载之后仍然挂在券商那边,不要的请到 TWS 里撤掉。
- 需要留底的话,先把备份目录和导出的 JSON 拷到别处。

### 卸载

| 系统 | 做法 |
|---|---|
| macOS | 先 ⌘Q 退出,再把「应用程序」里的 IBKR-Assistant 移到废纸篓 |
| Windows | 用系统的卸载功能卸载 IBKR-Assistant。卸载程序会先请正在运行的软件退出 |

### 手动删除全部数据

卸载之后按下表逐项删除。删除之前请确认路径(卸载前在「关于」页和「设置 → 数据与备份」里记下来)。

| 删什么 | 在哪 |
|---|---|
| 应用数据目录(设置、同意记录,Windows 上还有日志) | macOS `~/Library/Application Support/IBKR-Assistant/`;Windows `%APPDATA%\IBKR-Assistant\` |
| 日志(macOS) | `~/Library/Logs/IBKR-Assistant/` |
| 交易库、备份、熔断状态、IV 记录(`fly-iv/`) | 交易库所在的文件夹。macOS 默认是 `~/Library/Application Support/dafri/`,它**不在**应用数据目录里,要单独删 |
| 大模型 API Key | macOS「钥匙串访问」/ Windows「凭据管理器」里,名称带 `dafri-llm-api-key` 的条目 |
| 富途交易解锁密码(存过才有) | 同上,名称带 `dafri-futu-unlock` 的条目 |
| Discord bot token(存过才有) | 同上,名称带 `dafri-discord-bot` 的条目。不再用这个 bot 的话,到 Discord Developer Portal 把它的 token 重置或把应用删掉 |
| 你自己另存的东西 | 拷到别处的备份、导出的 JSON、导出的诊断信息 |

如果你用过很早的 Windows 版本,`%LOCALAPPDATA%\dafri\credentials.dpapi.json` 里可能还留着旧格式的加密凭证,一并删除。

删除之后,不再使用的 API Key 建议到服务商那边作废。
