# 日常使用

每天用得到的操作:怎么写指令、解析与发送的区别、顶栏上每一项是什么意思、怎么一键停下、去哪看订单与记录、怎么给持仓设止盈止损。
每个功能只讲到"会用"为止,设计细节在各节末尾链接的功能文档里。

## 2. 写指令

在「交易指令」页的输入框里用一句话写,中英文可以混着写。认得的品种:美股正股、单腿期权、垂直价差、蝴蝶、铁鹰,以及带价格条件的条件单。

| 想做的事 | 可以这样写 |
|---|---|
| 限价买正股,并记下理由 | `买入 AAPL 100 股 limit 230,理由:回调到位` |
| 条件触发后开价差 | `spx到7500时,开一张今天的 7520 7550 call spread。理由:突破 7500 整数关口后追动能` |
| 蝴蝶(中心 + 翼宽) | `7520的20cm蝴蝶` |
| 蝴蝶速记(本地解析,不经过大模型) | `1.8 挂15蝴蝶 15CM` |
| 铁鹰 | `卖出 7200/7250/7650/7700 铁鹰` |
| 指定账户 | 句子里写明别名,如"用模拟账户买…" |

输入框下面有一排可以点的词(「call spread」「卖出铁鹰」「权利金上限」「补理由」等),点一下就把对应的片段插进输入框。

### 默认值与速记规则

下面这些规则在页面上「速记规则、默认值与发送条件」里也写着:

- 期权与组合没写张数时默认 1 张,没写到期日时默认当日到期,组合没写标的时默认 SPX,蝴蝶默认买入。**用到默认值时结果里会带「提示」,发送前核对。**
- `N cm` 表示翼宽 N 点;句末孤立的数字是净权利金上限;蝴蝶没写看涨 / 看跌时按现价推断。
- 固定行话在本地解析:「1.8 挂15蝴蝶 15CM」里「挂」是当日限价,「N蝴蝶」是现价的百位加 N(现价 6907 → 6915)。
- 「蝴蝶」二字可以省:`spx明天 7850 40cm 2.3` 是明日 7810/7850/7890 蝴蝶挂 2.3。

### 一定要写清楚的

- **正股必须写数量。** 软件不猜数量,"清仓""全部卖出"也不行——解析时不看你的持仓,请写具体股数。
- **限价单必须写价格。** 没写价格又没明说"市价"会被拒,软件不会擅自改成市价单。
- **期权要写全**:标的、到期日、行权价、看涨还是看跌(上面说的默认值除外)。
- **盘前盘后要成交**,指令里加「盘外」或「隔夜」,并且必须是限价单。
- 休市时,按默认策略市价单会被拒,限价单会挂到下一个交易时段,条件单进入等待队列。

### 同时发到两个账户

配置了两个以上账户时,输入框下面有一排「发单账户」。勾一个发一个;勾两个,每笔订单各发一份,各自校验、各自记录。
指令里点了名的账户不复制,照你写的发。勾了实盘账户而实盘闸门没开时,下面会直接提示发到这个账户的那一份会被拦下。
账户减到只剩一个时这排勾选会藏起来,订单就发到这一个账户;勾过的账户都不在了(改了别名、换了券商)时,回到默认账户。
细节见 [同时向两个账户发单](../features/dual-account.md)。

## 3. 「解析并校验」与「发送到IBKR」

| 按钮 | 做什么 | 会不会发单 |
|---|---|---|
| 「解析并校验」 | 把指令翻译成订单并过一遍校验,结果摆在右边 | 不会 |
| 「发送到IBKR」 | 先弹确认框,确认后解析、校验,通过的订单直接发到券商 | 会 |

「发送到IBKR」在下面任何一条不满足时是灰的,鼠标停在上面会说缺哪一条:

- 「设置」里打开了「允许自动执行」;
- 已连接 TWS;
- 没有熔断。

发到实盘账户还需要「设置」里打开「允许实盘账户下单」,否则那一份订单会在校验时被拦下。

保护规则暂停中时按钮照常可点,输入框下面会多一行提示:新开仓的单会被拦下、停在「仅校验未发送」;
在减已有持仓的平仓单照发(见第 8 节)。

### 确认框

点「发送到IBKR」后,系统会弹出「发送真实订单」确认框,上面写着:指令原文、发到哪些账户、每个账户是纸面还是实盘。
含实盘账户时,最上面那一行会写成「发送真实订单(含实盘账户)」。核对无误点「我确认,发送」;默认选中的是「取消」。

**确认之后没有第二次确认。** 这句话解析成什么订单,通过校验的就直接发出。所以没把握的写法,先点「解析并校验」看一遍。

### 结果卡片

| 卡片 | 含义 |
|---|---|
| 「已提交 · …」 | 已经发到券商,带订单号 |
| 「排队等待触发 · …」 | 条件单。写着「软件盯盘(AUTO_MID)」的由本软件盯着,**软件必须保持运行,否则条件不会触发**;其余的已经带着触发条件发到了券商 |
| 「已通过校验(未发送)· …」 | 只解析没发送 |
| 红色拒绝卡片 | 谁拒的(「模型拒绝」「校验拒绝」「引擎拦下」「券商错误」)、为什么。常见原因见 [04](04-常见问题与排障.md) |
| 「提示」 | 用到的默认值和其他提醒 |
| 「本次解析」 | 模型、提示词版本、耗时。本地速记解析的会写「本地秒解(未经大模型)」 |

### 开仓之前先算一算:蝴蝶测算

右栏顶上有两个标签:「解析结果」和「蝴蝶测算」。后一个回答的是:**按现在的现价开这只蝶,标的几点走到哪儿,它值多少、赚多少**。
只算不下单。

填三样就能算:

| 填什么 | 说明 |
|---|---|
| 中心行权价、翼宽 | 例:7750、25 = 7725 / 7750 / 7775 |
| 预计走到(点位) | 你认为标的会走到哪儿 |
| 预计几点到 | **美东时间**,24 小时制。旁边有「30 分钟后」「1 小时后」「2 小时后」「15:45」 |

其余的留空就行:方向按中心在现价上方还是下方定;成本按此刻的盘口中间价;现价、三条腿的盘口与 IV 从 TWS 取;当日到期。
**成本建议填上你打算挂的价**——中间价多半成交不了,算出来的盈利会偏高。

结果里依次是:

| 这一块 | 怎么读 |
|---|---|
| 「预计盈利」 | 目标时刻到目标点位时赚多少(全部张数,美元) |
| 「半数情况下」 | 到时的 IV 估不准。按历史上估错的幅度,有一半的情况盈亏落在这个区间里——另一半在外面 |
| 「要是 IV 不变」 | 同一处,IV 按不变算。和上面差得多,说明结果很吃 IV 的假设 |
| 「到期时停在目标」 | 到期那一刻标的停在目标点位 |
| 走势那一行 | 这一段走了全天波动的几倍;按这段时间算是几个标准差(「平缓」「偏急」「很急」) |
| 「盈亏曲线」 | 蓝线 = 目标时刻到;橙色虚线 = 现在就到;灰线 = 到期。虚线(成本)以上是赚 |
| 「IV 变了会怎样」 | 到时的 IV 是别的样子时各赚多少。标出来的那一行是主结果用的 |
| 「早到晚到」 | 同一个目标点位,不同时刻到达各值多少 |

**IV 是会变的,这里的数是估计,不是承诺。**

- 标的跌,IV 升;标的涨,IV 降。跌一个"全天波动"大约升 12%,涨一个大约降 8%。
- 当日到期的期权,一天里的波动不是匀速走完的(上午重),IV 这个数也跟着有自己的走法。

默认的「自动」把这两样都估了进去,结果里写着各占多少(如「时段 +1%、走势 −7%」)。
估的依据是历史数据:两年多的标普 ETF 与短期波动率指数,看标的走了一段之后 IV 实际怎么变。
拿没参与估计的那段数据检验,它说得准 IV 变化的三成左右——**剩下的估不出来**,所以旁边摆着「半数情况下」的区间。
结果最下面写着校准用的是哪一段数据。

要知道的两点:

- 区间只算了"IV 估不准"这一份。**标的会不会在那个时刻走到那个点位,不在里面**,那是你自己的判断。
- 校准用的是波动率指数,不是你这三条腿自己的 IV。当日到期的期权在急跌时反应可能更大。
  软件会自己把当日到期期权的 IV 记下来(连着 TWS、在常规交易时段里每五分钟一笔),攒够 40 个交易日之后重新校准,
  估出来更准就改用它。开关和已经攒了多少在「更多」的最下面;记的只有行情,文件在交易库旁边的 `fly-iv` 目录里。

不想用自动:点开「更多」,「到时的 IV」选「不变」或「自己填」。

其他:

- 「跟着行情刷新」:每 10 秒按最新的现价与 IV 重算一次。离开这一页就停;取不到行情时会自己关掉,并留着上一次的结果。
- 「写进指令」:把这只蝶写成一句指令放进左边的输入框(如 `SPX 7750蝴蝶 25cm 看涨 2张 1.85`)。**它只填字,不发单**;
  接下来照常点「解析并校验」核对,再决定发不发。
- 没连 TWS、休市时也能算:点开「更多」,把「现价」和「IV」都手动填上。
- 不计佣金。
- 开仓之后想盯着"标的到了就走",用「持仓追踪」里的标的目标价(见第 7 节):那边每秒按最新的行情重算。

## 4. 顶栏各项的含义

| 位置 | 显示 | 含义 |
|---|---|---|
| 应用图标上的圆点 | 绿 / 红 | 交易引擎在运行 / 无响应 |
| 连接 | 「TWS 已连接」 | 引擎与 TWS 的长连接正常 |
| | 「TWS 未连接」 | 只能解析,不能下单,也拿不到行情 |
| | 「TWS 上游中断」 | 本机连得上 TWS,但 TWS 与 IBKR 服务器断了。等它自动重连,或检查网络 |
| | 「TWS 状态未知」 | 引擎没有回应,连接状态读不到 |
| 模式 | 「仅解析」 | 自动执行没打开,校验通过也不发单 |
| | 「自动执行(仅纸面)」 | 会发单;指向实盘账户的会被拦下 |
| | 「自动执行(含实盘)」 | 会发单,实盘账户也不拦 |
| | 「保护暂停」 | 保护规则触发了,新单暂停;鼠标停上去看原因。平仓不受影响 |
| | 「已熔断」 | 自动执行全部暂停,解除后恢复 |
| 实盘 | 「实盘已放开」(红点) | 发到实盘账户的订单不会被拦下,会用真钱成交 |
| | 「仅纸面」 | 发到实盘账户的订单会被拦下,或者没有配置实盘账户 |
| 时钟 | 「盘前 / 盘中 / 盘后 / 休市」加美东时间 | 美股正股的交易时段 |
| 模型 | 模型名 | 解析用的大模型 |

右侧的按钮:有新版本时出现「新版本 x.y.z」;「连接 TWS」/「断开 TWS」;「暂停自动执行」/「解除熔断」。

## 5. 熔断:「暂停自动执行」

发现任何不对劲,先按它,再查原因。四个入口效果相同:

- 顶栏的「暂停自动执行」;
- 快捷键 ⌘ Shift H(Windows:Ctrl+Shift+H);
- macOS 菜单栏「交易 → 暂停全部自动执行(熔断)」;
- macOS 上右键点 Dock 图标,「暂停全部自动执行(熔断)」。窗口藏着的时候这是最快的入口。

熔断有两种,对已有的保护处置不同:

| | 手动熔断(你按的) | 自动熔断(解析或下单连续失败,默认 3 次) |
|---|---|---|
| 新指令、条件单 | 不发 | 不发 |
| 券商侧的未成交单(含托管的止盈止损单) | **全部撤掉** | 原样保留,不再挂新的、不再改价 |
| 软件止损、追价平仓、「立即平仓」 | **不发** | 照发(那是在减仓) |

也就是说,手动熔断之后持仓上不再有本软件提供的任何保护,需要你自己到 TWS 里处理。
按下之后,「订单看板」的「通知」里会多一条「已熔断 · 撤销未成交单 N 笔」。TWS 没有回应时撤单可能没有完成,请到 TWS 里确认挂单确实撤掉了。

恢复:点顶栏的「解除熔断」。自动熔断时会弹通知说明原因,先弄清原因再解除。

## 6. 订单看板与交易记录

**「订单看板」** 左边是「排队等待触发」(由软件盯着、还没触发的条件单),右边是「已提交 / 近期」,下面是「通知」。

**「交易记录」** 是全部记录。可以按状态筛、按标的 / 原因 / 指令内容搜;点一行看详情(状态时间线、成交、佣金),Esc 收起。
记录只增不改:软件里没有修改或删除记录的功能。右上角的「导出」见 [03](03-数据、备份与恢复.md)。

| 状态 | 含义 |
|---|---|
| 「仅校验未发送」 | 通过了校验但没有发出去(只解析,或被保护规则拦下) |
| 「已受理」「已挂单」 | 在券商那边,还没成交 |
| 「已成交」「部分成交」「已撤单」 | 券商回报的结果 |
| 「当日未触发」 | 当日有效的条件单到收盘没触发,已失效 |
| 「校验拒绝」「模型拒绝」「券商报错」「熔断拦下」 | 没发出去,或被券商拒了 |
| 「去向不明(券商侧查无此单)」(黄色) | 对账时券商那边没有这张单,当天的成交也没有填满它。只成交了一部分的,提醒里会写明成交了多少、剩下多少,已成交的部分已补进记录。软件只陈述事实,不替你作废。**先到 TWS 里核对,再决定要不要重下(或只补下剩下的部分)** |

重启软件或重连券商之后,引擎每分钟会把券商侧的在途单与本地记录对一遍。由软件盯盘的条件单在软件重启后不再被盯,要继续请重新提交。
细节见 [执行对账](../features/reconcile.md)。

## 7. 持仓追踪

「持仓追踪」页给账户里的实际持仓设止盈止损。**这一页会真的发单。**

### 设置一条追踪

1. 在「账户持仓」里找到持仓(只列配置里有别名的账户的实际持仓),点「设置追踪」。
2. 填目标,可以只填其中几项:

   | 栏 | 含义 |
   |---|---|
   | 「标的目标价」 | 标的走到哪儿就走。填了它,止盈价由引擎按当前波动率每秒现算,下面会显示预计价位与预估收益 |
   | 「止盈价」「止损价」 | 这份持仓自己的价格到多少就平 |
   | 「跟踪止损 %(按价格)」 | 价格从最有利的位置回落 N% 就平 |
   | 「利润回撤 %(按利润)」 | 利润从峰值缩水 N% 就平。「利润回撤起算门槛 %」是浮盈到过成本的 N% 才开始算,新建时默认 10 |
   | 「分档利润回撤(蝶式 40/30/20)」 | 给蝴蝶用的分档回撤,勾上就不看上面那个固定百分比 |
   | 「触发后平仓比例 %」 | 默认 100 全平 |

3. 选择触发后做什么:

   | 开关 | 关着 | 开着 |
   |---|---|---|
   | 「到价自动平仓」 | 只提醒(卡片上写「仅提醒」) | 到价即自动发平仓单,不再询问。「允许自动执行」开着时默认就是开的 |
   | 「止盈/止损托管到券商(IBKR)」 | 由本机盯盘 | 把止盈止损作为 GTC 单挂到券商服务器上。要先打开「到价自动平仓」,只开托管不开它会被拒绝 |

4. 点「开始追踪」。打开了自动平仓或托管时,系统会弹确认框,确认后才生效。

### 本机盯盘与托管到券商的区别

| | 本机盯盘 | 托管到券商 |
|---|---|---|
| 在哪判断 | 你的电脑,每秒一轮 | 券商服务器 |
| 软件退出、电脑睡眠或关机、断网时 | **不触发** | 仍然有效,但价格停在最后一次调整的位置 |
| 组合(蝴蝶、价差) | 支持 | 只托管一张限价止盈单,而且要先填「标的目标价」;止损类仍由本机盯 |

**合上笔记本的盖子,macOS 会直接睡眠**,插着电源也一样。睡着之后本机盯盘全停。

- **有追踪在盯时,软件会弹一个 macOS 的授权框**,问能不能在盯盘期间阻止合盖睡眠。点允许、输入你的登录密码之后,合上盖子也照常盯
  (屏幕关掉,电脑接着跑:别放进包里,用电池时电会耗光)。没有追踪在盯满 10 分钟、或退出软件时,会再弹一次授权框把合盖睡眠恢复。
- 不想要这一项,在菜单「交易 → 盯盘时合盖不睡」里去掉勾。授权框点了取消,这一段盯盘期间不再问,合盖照样会睡。
- 电脑关机、断网、TWS 需要重新登录时,本机盯盘照样会停。重要的持仓请在券商端另设保护。

睡着的时候,软件会把这件事告诉你:

- **拔掉电源时**,如果有追踪在本机盯着,会弹一条提醒:合盖睡眠没关掉时是「正在用电池:合上盖子,本机盯盘就停了」,
  关掉了是「正在用电池:电耗光,本机盯盘就停了」。一段用电池的时间里只提醒一次。
- **醒来之后**,等电脑真正醒稳(连续一分钟没再睡)会弹一条通知,写明睡了多久(美东几点到几点)、哪几条追踪这段时间没人盯。
  请照着核对持仓与挂单:睡着期间到价的,软件没有平。
- **醒来头 20 秒不判断**:醒来那一刻 TWS 给的报价可能还是睡前的,紧接着 TWS 往往会断线重连。软件等与 TWS 的连接连续稳住 20 秒
  再恢复判断(连接一直不稳,最多等 2 分钟)。这段时间里追踪卡片与「正在追踪」下面那一行写着「电脑刚醒,先不判断…」。

### 自动平仓还要过哪些闸

- 「允许自动执行」已打开;
- 实盘账户还要「允许实盘账户下单」。组合(蝴蝶、价差)和单腿一样,没有别的开关;它的平仓单还没有在实盘上成交过,第一次到价时请在 TWS 里看一眼成交;
- 手动熔断期间不发;
- 合约当前时段能交易。盘前、盘后也会平,市价平仓会自动转成限价单。

到价了却发不出去时,追踪卡片上会出现「到价了但没有平仓」并写明被什么拦住。提醒只发一次,不会反复弹。

### 正在追踪

每张卡片上有「暂停」/「恢复」、「立即平仓」、「删除」。「立即平仓」有确认框,确认后马上发平仓单;「删除」只删追踪设置,不影响持仓本身。
「立即平仓」记作「手动平仓」:卡片上显示「已手动平仓」,不算止损,不会让「止损护栏」暂停自动执行。

触发后期权与组合走"追价平仓":平仓单先挂在立刻成交的价上,头两秒不动,之后每秒再让一跳,让到上限(默认 10%,表单里的「追价最多让价 %」)为止。
为了成交而让价,成交价可能明显劣于触发时的报价。卡片上会显示「追价第 N 秒…」。

「正在追踪」标题下面那一行是盯盘的心跳。它变成警告色时的含义见 [04](04-常见问题与排障.md)。完整口径见 [持仓追踪](../features/tracker.md)。

## 8. 保护规则

熔断管的是软件出了毛病,保护规则管的是"今天不顺"。四条规则在「设置 → 保护规则」里,**默认全关**,打开某一条才展开它的参数。

| 规则 | 什么时候触发 | 触发后 |
|---|---|---|
| 「止损护栏」 | 一段时间内止损平仓够次数(止盈、手动「立即平仓」不算) | 暂停新单一段时间 |
| 「回撤护栏」 | 一段时间内已实现盈亏从峰值回落够多 | 暂停新单一段时间 |
| 「同标的冷却」 | 一只标的刚平过仓 | 这只标的一段时间内不下新单 |
| 「日内亏损上限」 | 当天(美东)已实现盈亏净亏到线 | 当天不再下新单,第二天美东零点自己解除 |

- **只挡新单,永远不挡平仓。** 持仓追踪的平仓照发。
- 被挡下的单停在「仅校验未发送」,保护期过了原样再发一次就行。排队中的条件单继续排着,触发那一刻再查一次。
- 到点自己解除,不用人工。顶栏在暂停期间显示「保护暂停」。
- 开着的规则必须填大于 0 的参数,否则不让保存。
- 保护期内手写的平仓指令,只有在每条腿都是减仓、数量不超过持仓时才被认作平仓、照发;认不准的一律当新单挡。
  所以暂停期间「发送」按钮不灰,由引擎逐张判。

另有一条和保护规则开没开无关的限制:手写"卖出持有的看涨期权""卖出持有的蝴蝶"这类平仓指令,会在校验时被当成新开仓拒掉。
这类平仓请用持仓追踪的「立即平仓」,或直接在 TWS 里平。

「设置 → 单笔风险预算」是另一回事:它只在订单卡片上多一句提醒,不拦单,见 [单笔风险预算](../features/risk-budget.md)。保护规则的完整口径见 [保护规则](../features/protections.md)。

## 9. 超时之后的「结果未知」

发送指令、建立或修改追踪、立即平仓时,如果引擎 2 分钟内没有回话,界面显示的不是"失败",而是:

> 结果未知:引擎 2 分钟内没有回话,这次操作可能已经执行(订单可能已经发出)。请先到「订单看板」和券商端核对,不要直接重发;引擎回话后这里会再通知一次。

这时订单可能还在排队,随后照样发出去。请按这个顺序做:

1. **不要重发。**
2. 到「订单看板」看有没有这张单;再到 TWS 里看挂单与成交。以券商的记录为准。
3. 等通知。引擎回话之后会补一条「「发送指令」有结果了」,写明这次操作最终是已经执行,还是没有成功。
4. 确认没有发出去之后,再决定要不要重新提交。
