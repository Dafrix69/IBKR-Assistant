# 安装与首次配置

从下载安装包到第一次解析指令的全过程:装软件、确认条款、在 TWS 里打开 API、填账户、填大模型的 API Key、核对限额。
照着做完,你会停在"只解析、不发单"的状态——要不要打开自动执行,是之后的另一个决定。

## 1. 开始之前要准备什么

| 项目 | 要求 |
|---|---|
| 电脑 | macOS 12 以上的 Apple Silicon Mac(Intel Mac 不支持),或 64 位(x64)Windows 电脑 |
| 券商软件 | 已安装 Interactive Brokers 的 TWS 或 IB Gateway,并且能登录 |
| IBKR 账户 | 建议先只用模拟(Paper Trading)账户 |
| 大模型 API Key | Anthropic 的,或任意 OpenAI 兼容端点的(如 DeepSeek)。Key 由你自己申请,调用费用由你自己承担 |
| 其他 | 不需要安装 Node 或 Python,交易引擎打在安装包里 |

本软件不接触你的 IBKR 账号密码。登录始终在 TWS / IB Gateway 自己的窗口里完成。

## 2. 安装

安装包在[发布页](https://github.com/Dafrix69/IBKR-Assistant/releases)。

### macOS

1. 下载 `IBKR-Assistant-<版本>-mac-arm64.dmg` 并打开。
2. 直接从磁盘映像里运行时,软件会问「要把 IBKR-Assistant 移到「应用程序」文件夹吗?」。选「移动到「应用程序」并打开」:
   它会把自己复制到「应用程序」、打开新副本、退出映像里的这一份。也可以自己把应用拖进「应用程序」再打开。
3. 如果系统提示无法验证开发者、不让打开:到「系统设置 → 隐私与安全性」点「仍要打开」。
   也可以在终端执行 `xattr -dr com.apple.quarantine "/Applications/IBKR-Assistant.app"` 之后再打开。

### Windows

1. 下载 `IBKR-Assistant-<版本>-win-x64.exe` 并运行。
2. 如果 SmartScreen 拦下来:点「更多信息 → 仍要运行」。
3. 安装器不是一键安装,可以改安装目录。装好后用名为「IBKR-Assistant」的快捷方式打开。

### 升级

软件不会自动下载和安装新版本,只会告诉你有新版并给出下载链接(见 [04-常见问题与排障](04-常见问题与排障.md) 的「怎么检查新版本」)。
下载新的安装包装上去会替换旧版;配置与交易记录都在用户目录里,不受影响。

升级之前先退出旧版(macOS 用 ⌘Q)。忘了退出也不要紧:

- Windows 的安装器会先请正在运行的旧版自己退出,等 6 秒,还没退才强制结束。
- macOS 上旧版会弹出「检测到另一个 IBKR-Assistant 正在尝试启动」,点「退出此版本」后再打开新版本。

新版本需要改动交易库的结构时,改之前会先留一份备份(见 [03-数据、备份与恢复](03-数据、备份与恢复.md))。

## 3. 第一次启动:条款确认

第一次打开会先出现「开始之前:请阅读并确认」,里面有三个页签:「风险揭示」「使用条款」「隐私说明」。

1. 三个页签都要点开看过,下面的勾选框才能勾(之前它写的是「三份文本都点开看过之后才能勾选」)。
2. 勾上「我已阅读并理解风险揭示、使用条款与隐私说明」。
3. 点「同意并继续」。点「不同意,退出」会退出软件。

同意之前,整个界面被这个窗口挡着,不能使用。发单、授权自动平仓、打开自动执行与实盘这几件事,软件内部还会另外再挡一道。
条款改版之后,下次启动会要求重新确认。之后想重看:「关于 → 支持 → 查看条款」。

## 4. 「还差 N 步才能开始」

进入软件后停在「交易指令」页。必要的配置没做完时,页面上方有一张「还差 N 步才能开始」的卡片,缺哪一步就写哪一步,右侧的按钮直接带你过去:

| 步骤 | 按钮 | 去哪 | 对应本页 |
|---|---|---|---|
| 「配置大模型 API Key」 | 「去配置」 | 「接入 → 大模型」 | 第 8 节 |
| 「填上你的券商账号」 | 「去填写」 | 「接入 → 账户」 | 第 7 节 |
| 「连接TWS」 | 「去连接」 | 「接入 → TWS」 | 第 5、6 节 |
| 「打开自动执行」 | 「去设置」 | 「设置」 | 第 9 节。这一步不计入 N,不打开也能解析 |

前三步都完成后卡片会自己收起。下面按实际操作的先后顺序讲。

## 5. 在 TWS / IB Gateway 里打开 API

这一步在 IBKR 的程序里做,不在本软件里做。

1. **启动 TWS 或 IB Gateway 并登录。** 停在登录界面时 API 不会响应。
2. **打开 API 开关。** TWS:Configure(齿轮)→ API → Settings,勾选「Enable ActiveX and Socket Clients」。
   IB Gateway:Configure → Settings → API → Settings。
3. **核对 Socket port。** 同一页的「Socket port」要和本软件配置里的端口一致。IBKR 的默认值:

   | 程序 | 模拟 | 实盘 |
   |---|---|---|
   | TWS | 7497 | 7496 |
   | IB Gateway | 4002 | 4001 |

   本软件新装时的配置是:模拟连接 `paper` 用 7497,实盘连接 `live` 用 7496。
4. **只信任本机。** 同一页的「Trusted IPs」只留 `127.0.0.1`。API 端口不要暴露到局域网。
5. **第一次连接时点「Yes」。** 本软件第一次连上来时,TWS 会弹出「Accept incoming connection attempt?」,点 Yes。不点的话,本软件这边会一直显示握手超时。

### 端口对不上怎么办

两条路,任选其一:

- 在 TWS / IB Gateway 里把「Socket port」改成本软件配置的端口(比如把 IB Gateway 模拟盘的 4002 改成 7497)。
- 改本软件的配置文件。连接(端口、client id)目前不能从界面改,只能手改 `settings.json`:
  1. 「关于 → 支持 → 打开配置文件所在位置」,用文本编辑器打开 `settings.json`。
  2. 找到 `connections` 一段,改对应连接的 `port`(提示 client id 被占用时改 `client_id`):

     ```json
     "connections": {
       "paper": { "broker": "ibkr", "host": "127.0.0.1", "port": 7497, "client_id": 11 },
       "live":  { "broker": "ibkr", "host": "127.0.0.1", "port": 7496, "client_id": 12 }
     }
     ```
  3. 保存后到「关于」页最下面点「重启交易引擎」。

  手改时注意逗号和引号。改坏了引擎起不来,会弹出「配置文件有问题」的对话框,处理办法见 [04-常见问题与排障](04-常见问题与排障.md)。

## 6. 「接入 → TWS」:检测与连接

页面从上到下是一条检查链:

| 分区 | 看什么 |
|---|---|
| 「1 · 程序」 | TWS / IB Gateway 装没装、在不在运行。装了没开的有一个「启动 …」按钮;启动后请在它自己的窗口里登录 |
| 「2 · API 端口」 | 7496 / 7497 / 4001 / 4002 以及配置里的端口是否开放,每个端口配置成了模拟还是实盘 |
| 「3 · 握手与账户」 | 点「检测连接」之后的结果:握手是否成功、服务器版本、每个账户别名是「对得上」还是「不在可管账户里」 |
| 「4 · 连接引擎」 | 「连接交易引擎」/「断开交易引擎」。这才是下单用的长连接 |
| 「连不上时照着做」 | 6 步指引,内容就是上面第 5 节,端口号按你的实际配置显示 |

操作顺序:

1. 点「重新检测」,确认程序在运行、端口是开放的。
2. 点「检测连接」。这是一次只读握手,读回账户列表,连完即断,不会下单。
3. 握手成功后点「连接交易引擎」(顶栏右侧的「连接 TWS」是同一个动作)。连上后顶栏显示「TWS 已连接」。

之后不用每次手动连:引擎启动时会自己连接券商,连不上的每 30 秒再试一次;TWS 比本软件晚开也没关系。
你点过「断开」之后,它就不再自动连。连接的细节见 [TWS 连接](../features/tws-connection.md)。

此时「握手与账户」里的别名多半还对不上,因为账户还没填。填完账户(下一节)再回来点一次「检测连接」。

## 7. 「接入 → 账户」:填上你的账户

指令里说的「模拟」「主账户」是账户的**别名**。发给大模型的只有别名,账号留在本机。

新装的软件带着三个示例账户(「模拟」「主账户」「富途模拟」),账号都是全零的占位,页面上会提示「还有账户用的是示例里的占位账号」。
用占位账号可以解析指令,但订单发不到你的账户上。

**改成你自己的账号:**

1. 在要用的那一行点「修改」(新加一个就点「添加账户」)。
2. 填表:

   | 栏 | 怎么填 |
   |---|---|
   | 「别名」 | 指令里怎么称呼它,最多 24 个字。修改已有账户时别名不能改;`DEFAULT` 是保留字,不能用 |
   | 「账号」 | IBKR 的账号是 U 或 DU 开头加数字(在 TWS 右上角、或「账户」窗口里看得到),如 `DU1234567`。修改时要重新填一遍 |
   | 「类别」 | 「纸面(模拟)」或「实盘」。请如实选:它决定这份订单要不要过「允许实盘账户下单」这道闸 |
   | 「连接」 | 经哪条连接下单。模拟账户选 `paper`,实盘账户选 `live` |
   | 「默认账户」 | 指令里没点名账户时发到它 |

3. 点「保存…」。系统会弹出一个确认框,上面列出将要写进配置的每一项:别名、**完整的账号**、类别、连接、是否默认账户。
   请对着 TWS 里显示的账号逐位核对,再点「保存」。
4. 保存后交易引擎会重启(几秒钟),券商连接会重连。

几条规矩:

- IBKR 的模拟账号以 D 开头。账号不是 D 开头的,不能标成「纸面(模拟)」——标错了,实盘闸门对它就不起作用,所以软件直接不让存。
- 同一个账号不能配给两个别名。
- 用不到的示例账户请点「删除」(同样有确认框)。删除只改本机的配置,不影响券商那边的账户与持仓;用这个别名建的追踪会失效。
- 富途通道目前只有检测与诊断,下单桥还不可用,不用配置富途账户。

填完回到「接入 → TWS」点「检测连接」,确认每个别名后面都是「对得上」。这一步很重要:账号写错时 IBKR 不一定报错,
所以软件在连接时拿 TWS 给出的真实账户列表逐个比对。

## 8. 「接入 → 大模型」:API Key 与测试

1. 「供应商」选「Anthropic(Claude)」或「OpenAI 兼容端点」。
2. 「模型」从下拉里选,或在「自定义模型」里填模型标识(如 `deepseek-chat`)。
3. 选了「OpenAI 兼容端点」时要填「Base URL」,用服务商给你的地址,通常以 `/v1` 结尾。必须是 https(只有本机 `127.0.0.1` 上的端点可以用 http)。
4. 在「API Key」里粘贴你的 Key,点「保存」。「当前供应商 Key」会变成「已配置(存于 Keychain)」。
   Key 存在操作系统的凭证库里(macOS 钥匙串 / Windows 凭据管理器),按供应商分开存,不写进配置文件,不进日志;界面只显示有没有配置,不会把 Key 再显示出来。
5. 点「测试连接」。它会真的发一次最小请求(会产生很少的调用费用),成功时显示「连通 · 模型名」、延迟与 token 用量。
6. 点「保存配置」。

「调用参数」(max_tokens、超时等)一般不用改。

如果测试结果里写着「端点不支持 json_schema,已降级为 json_object…」,说明这个端点的结构化输出能力较弱,指令被拒的比例可能升高。
换了 Base URL 之后直接点「测试连接」,需要把 Key 再填一次,或者先保存再测。细节见 [接入外部大模型](../features/llm-providers.md)。

## 9. 「设置」:核对限额与两个闸门

### 执行闸门

| 开关 | 新装时 | 含义 |
|---|---|---|
| 「允许自动执行」 | 关 | 关着时只解析、只校验,永不发单 |
| 「允许实盘账户下单」 | 关 | 关着时,指向实盘账户的订单一律被拦下;纸面账户不受它限制 |
| 「触发方向必须有现价」 | 开 | 拿不到现价就拒绝条件单 |

现在两个闸门都请保持关闭。关是当场生效的;开要点「保存设置」,并且在系统确认框里再确认一次。
打开之前要核对什么,见 [05-安全与隐私须知](05-安全与隐私须知.md)。

### 风控限额

每一笔订单都要过这些限额,它们是最后一道闸。请改成你能承受的数。

| 项 | 新装时 |
|---|---|
| 「单笔名义金额上限」 | 5000 USD |
| 「期权 / 价差单笔上限」 | 5 张 |
| 「市价单股数上限」 | 200 |
| 「AUTO_MID 滑点上限」 | 0.1 美元 / 张 |
| 「重复防抖窗口」 | 10 分钟 |

改完点「保存设置」。往松了改(比如调大金额上限)会弹出「放宽风控限额」确认框,列出每一项从多少改到多少;往紧了改不用确认。
格子不能空着:空着的话软件不让保存,并告诉你是哪一项。

「保护规则」和「单笔风险预算」默认全关,用法见 [02-日常使用](02-日常使用.md)。「数据与备份」见 [03-数据、备份与恢复](03-数据、备份与恢复.md)。

## 10. 第一次试运行:只解析,不发单

1. 回到「交易指令」页,在输入框里写一句:

   ```
   买入 AAPL 100 股 limit 230,理由:回调到位
   ```

2. 点「解析并校验」(快捷键 ⌘↩,Windows 上是 Ctrl+Enter)。**这个按钮不会发单。**
3. 看右边的「解析结果」:

   | 卡片 | 含义 |
   |---|---|
   | 「已通过校验(未发送)· …」 | 这句话被理解成了什么订单:标的、方向、数量、价格、账户、估算的敞口。逐项核对是不是你的本意 |
   | 红色的拒绝卡片,如「校验拒绝 · 超出风控限额」 | 谁拒的、为什么。下面一行是具体原因 |
   | 「提示」 | 解析时用到的默认值与其他提醒。发送前要看 |
   | 「本次解析」 | 用的模型、提示词版本、耗时与 token 用量 |

4. 把你平时会写的几种指令都这样试一遍,看软件的理解是否和你一致。

通过校验的订单会在「交易记录」里留下一条记录,状态是「仅校验未发送」。没有连接券商时也能解析,只是拿不到行情。
