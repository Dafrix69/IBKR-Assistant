# 常见问题与排障

按"现象 → 原因 → 怎么办"排的问题清单。先在下表里找到你看到的那句话或那个现象,再翻到对应编号的条目。
解决不了的,按最后一节导出诊断信息,连同问题描述一起发给支持。

|---|---|
| 连接 | Q1 连不上 TWS · Q2 别名显示「不在可管账户里」 · Q3 连接反复断开 · Q4 行情、K 线拿不到 |
| 启动 | Q5 「配置文件有问题」 · Q6 「交易库打不开」 · Q7 装不上或打不开 |

## 连接

### Q1 连不上 TWS

先到「接入 → TWS」点「重新检测」和「检测连接」,看「握手与账户」卡片上的原因,再对照下表。页面最下面的「连不上时照着做」是同样的 6 步,端口号按你的实际配置显示。

| 步骤 | 检查什么 |
|---|---|
| 1 | TWS 或 IB Gateway 已启动,并且**已经登录完**。停在登录界面时 API 不会响应 |
| 2 | API 开关已打开。TWS:Configure(齿轮)→ API → Settings,勾选「Enable ActiveX and Socket Clients」;IB Gateway:Configure → Settings → API → Settings |
| 3 | 同一页的「Socket port」和本软件配置的端口一致。IBKR 默认:TWS 实盘 7496 / 模拟 7497,Gateway 实盘 4001 / 模拟 4002 |
| 4 | 同一页的「Trusted IPs」只留 `127.0.0.1` |
| 5 | TWS 弹出的「Accept incoming connection attempt?」已经点了 Yes |
| 6 | 回到「接入 → TWS」点「检测连接」 |

| 卡片上写着 | 多半是 | 怎么办 |
|---|---|---|
| 端口 … 拒绝连接 | TWS 没在运行,或它的 API 端口不是这个 | 第 1、3 步 |
| 端口开着,但握手超时 | 「Enable ActiveX and Socket Clients」没勾,或 TWS 正弹着确认框等你点 Yes | 第 2、5 步 |
| 连接超时 | TWS 还停在登录界面 | 第 1 步 |
| clientId 已被占用(326) | 另一个程序在用同一个 client id | 关掉那个程序,或改 `settings.json` 里这条连接的 `client_id`,见 [01](01-安装与首次配置.md) 第 5 节 |
| 无法连接到 TWS(502) | API 没启用,或端口不一致 | 第 2、3 步 |
| 未连接(504) | TWS 没有完成登录 | 第 1 步 |

模拟盘的 TWS 没开时,实盘那条连接照常可用;没连上的那条引擎会在后台每 30 秒重试一次。

### Q2 别名显示「不在可管账户里」

- **原因**:这个别名填的账号,不在这条连接登录的 TWS 能管的账户里。常见的是账号填错了一位,或者账户挂错了连接(模拟账户挂到了 `live`)。
- **怎么办**:「接入 → 账户」点「修改」,对着 TWS 里显示的账号重新填,并核对「连接」选得对不对。保存后回来再点「检测连接」,直到显示「对得上」。
- 对不上的时候不要发单。

### Q3 连接反复断开,或显示「TWS 上游中断」

- 「TWS 上游中断」:本机连得上 TWS,但 TWS 与 IBKR 服务器之间断了。IBKR 每晚的服务器重置会造成短暂中断,属于正常。等它自动重连,或检查网络。
- 下单时报「TWS 与 IBKR 服务器的连接已中断(错误 1100)」(或 2110)是同一件事,这时单还没发出去。TWS 与本机都会自己重连,连回来再发。
- 单次掉线、连回,软件都会当场提醒,并且自己重连。
- 提示反复断开时,常见原因有三个:TWS 自动重启后在等你重新登录;TWS 弹出了 API 连接确认框;同一个 client id 被别的程序占用。到 TWS 的窗口里看一眼。
- **断开期间持仓追踪读不到持仓与报价,不判断也不发单。** TWS 需要重新登录时软件帮不上忙,只能你自己去登录。

### Q4 行情、K 线拿不到

- **原因**:最常见的是同一个 IBKR 用户名在别处登录着(比如另一台电脑上的 TWS)。行情会跟着那边走,本机拿不到。
- **怎么办**:先在别处登出,再回到本机。
- 行情订阅是按用户名算的,不是按账户。TWS 界面里看得到报价,不代表 API 这一路也有。
- 用了一阵之后**所有**报价突然都拿不到,报错里带着 101(IBKR):行情线路用完了。IBKR 同时能订的行情大约 100 条,
  持仓的每条期权腿、每只正股各占一条;平掉的持仓下一轮读持仓时就会让出线路,所以正常用不会占满。
  真遇到了,点顶栏的「断开 TWS」再点「连接 TWS」,订阅会全部清掉重来(断开的这几秒持仓追踪不判断、不发单)。

## 启动

### Q5 弹出「配置文件有问题」

- **原因**:`settings.json` 不见了、格式坏了(手改时少了逗号或引号),或者里面有一项不合规。对话框里会写明是哪一种、具体哪里不对。
- 这时交易引擎没有启动,**持仓追踪的止盈止损不在盯盘**。

| 按钮 | 做什么 |
|---|---|
| 「恢复上一份可用的配置」 | 用 `settings.json.bak` 换回来。坏的那份改名留在旁边,不会删。恢复出来的配置里「允许自动执行」「允许实盘账户下单」**一律是关的**,需要时到「设置」里重新打开。只有存在可用的备份、并且它和现在这份不一样时,才有这个按钮 |
| 「打开配置文件所在位置」 | 打开文件夹,让你自己改。对话框会再出来一次,改完好点重试 |
| 「我改好了,重试」 | 重新启动交易引擎 |
| 「退出」 | 退出软件 |

恢复之后,备份之后才做的改动(比如刚加的账户)需要重新做一遍。

### Q6 弹出「交易库打不开」

这时交易引擎同样没有启动,持仓追踪不在盯盘。对话框第一行会说明是哪一种:

| 对话框写着 | 原因 | 怎么办 |
|---|---|---|
| 交易库文件损坏了 | 文件读不出来,或没有通过完整性检查 | 点「用最近的备份恢复」。坏掉的那份会改名留在旁边;这份备份之后的记录不在恢复后的库里。没有备份时没有这个按钮 |
| 交易库被另一个程序占着 | 多半是另一个 IBKR-Assistant 还没退干净 | 先退出它,再点「重试」 |
| 交易库所在的位置写不进去 | 文件夹权限不对,或磁盘满了 | 点「打开数据所在位置」检查权限与剩余空间,处理后点「重试」 |
| 交易库是更新版本的软件写的 | 这个库被更新版本的软件用过,现在这一版不认识它的结构(比如装回了旧版本) | 升级到最新版本再打开。这种情况对话框里没有恢复备份的按钮 |

恢复之后要核对什么,见 [03-数据、备份与恢复](03-数据、备份与恢复.md) 第 4 节。

### Q7 装不上或打不开

| 现象 | 怎么办 |
|---|---|
| macOS 提示无法验证开发者 | 「系统设置 → 隐私与安全性」点「仍要打开」,见 [01](01-安装与首次配置.md) 第 2 节 |
| Windows SmartScreen 拦截 | 「更多信息 → 仍要运行」 |
| 弹出「检测到另一个 IBKR-Assistant 正在尝试启动」 | 同一时间只能运行一个。在升级的话点「退出此版本」,再打开新版本 |
| 弹出「IBKR-Assistant 无法启动」,说写不进配置文件 | 检查对话框里那个文件夹的权限与磁盘剩余空间 |
| Intel Mac | 没有对应的安装包 |

## 指令

### Q8 指令被拒绝了

原因写在「交易指令」页右边的红色卡片上。标题是"谁拒的 · 为什么",下面一行是具体说明。之后在「交易记录」里点开那条记录也能看到。

| 谁拒的 | 含义 |
|---|---|
| 「模型拒绝」 | 指令本身没写清楚,大模型不肯猜 |
| 「校验拒绝」 | 指令读懂了,但过不了代码的校验 |
| 「引擎拦下」 | 熔断、模型调用失败等 |
| 「券商错误」 | 发出去了,被券商拒了 |

| 卡片上的原因 | 是什么意思 | 怎么办 |
|---|---|---|
| 「没写数量」 | 正股没写股数,或写了"清仓""全部卖出" | 写明具体数量。解析时不看你的持仓 |
| 「没写价格」 | 没给价格,也没明说市价 | 写上限价,或明说"市价" |
| 「期权要素不全」 | 标的、到期日、行权价、看涨 / 看跌缺了一项,或蝴蝶没给翼宽 | 补全 |
| 「指令读不清」 | 有歧义或自相矛盾,卡片上会指出矛盾点 | 改写得更直接 |
| 「解析把握不够」 | 模型对自己的解析没把握 | 把指令写得更明确后重试 |
| 「账户别名不认识」 | 指令里的账户不在别名表里,卡片上列出了可用的别名 | 改用已有的别名,或到「接入 → 账户」添加 |
| 「未允许实盘下单」 | 见 Q9 | |
| 「超出风控限额」 | 金额、张数、股数或一次输入的订单数超了,卡片上有具体数字 | 改小,或到「设置」里调整限额 |
| 「当前时段不能交易」 | 休市时下了市价单 | 改成限价单 |
| 「疑似重复下单」 | 防抖窗口内(默认 10 分钟)已经提交过高度相似的订单 | 确实要再下一笔,等窗口结束或改变数量 |
| 「暂不支持这种单」 | 不支持的品种或下法,如卖出蝴蝶、日历价差、跨式,或盘外的市价单 | 换一种下法 |
| 「模型调用失败」 | 网络、API Key 或服务商的问题 | 到「接入 → 大模型」点「测试连接」,看它报什么 |

卡片上的原因如果是一串英文,说明这个代码还没有对应的中文说明,请把它连同下面那行说明一起发给支持。

提示「要发给大模型的内容里出现了真实账号…」时,把账号从文字里删掉再试,见 [05-安全与隐私须知](05-安全与隐私须知.md)。

### Q9 发到实盘账户的单被拦下

- **现象**:卡片写「校验拒绝 · 未允许实盘下单」;或者勾选实盘账户时,输入框下面提示这个账户是实盘账户、当前没有允许实盘下单。
- **原因**:「设置」里的「允许实盘账户下单」是关的。这是默认状态,是在保护你。
- **怎么办**:确认要用实盘之后,按 [05-安全与隐私须知](05-安全与隐私须知.md) 核对一遍,再到「设置」里打开并保存。
- 如果这个账户其实是模拟账户:到「接入 → 账户」看它的「类别」是不是标成了「实盘」。手改过配置文件的话,没写 `is_paper` 的账户一律按实盘处理。

### Q10 「发送到IBKR」是灰的,或提示要先确认

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 按钮是灰的 | 鼠标停在按钮上会列出原因:自动执行未打开、未连接 TWS、已熔断 | 逐条处理 |
| 按钮能点,发出去的单却停在「仅校验未发送」 | 保护规则暂停中(输入框下面有一行提示):新开仓的单被拦下,平仓照发 | 等暂停到点自己解除,再原样发一次 |
| 提示「这一步要先在确认框里点确认…」 | 确认已经过期(一分钟),或者确认之后内容变了 | 重新操作一遍,在确认框出现后一分钟内完成,中间不要改动内容 |
| 提示还没有同意条款 | 没有确认现行条款(条款改版之后也要重新确认) | 重启软件,在出现的条款窗口里确认 |

### Q11 提示「结果未知」

引擎 2 分钟没有回话。这张单可能已经发出去了。**不要重发**,先到「订单看板」和 TWS 里核对,等软件补发的那条结果通知。
完整做法见 [02-日常使用](02-日常使用.md) 第 9 节。

## 追踪

### Q12 「持仓追踪」页出现「盯盘节拍器…」的警告

「正在追踪」标题下面那一行是盯盘的心跳。正常时写的是「盯盘:引擎每 1 秒一轮 · 上一轮 … ms」。

| 写着 | 含义 | 怎么办 |
|---|---|---|
| 「盯盘节拍器:等第一轮结果…」 | 刚连上,还没跑完第一轮 | 等几秒 |
| 「盯盘节拍器没在跑:追踪止盈与托管调价都停了」 | 盯盘循环没有运行。它是连上券商之后才启动的 | 看顶栏是不是「TWS 已连接」。没连上先解决连接(Q1);连着却仍然这样,到「关于」页点「重启交易引擎」 |
| 「盯盘这一轮没做成:…」 | 这一轮读持仓或报价失败了,后面写着原因。这一轮不判断、不发单 | 多半是 TWS 断线或正在重连,见 Q3。连回来的第一轮会照常判断 |
| 「盯盘节拍器已经 N 秒没跳了」 | 引擎被占住了,超过 3 秒没有新的一轮 | 持续不恢复时见 Q15 |
| 「电脑刚醒,先不判断:…」 | 电脑刚从睡眠里醒来。醒来那一刻的报价可能还是睡前的,软件等与 TWS 的连接稳住 20 秒再判断 | 等一等,最多 2 分钟自己恢复。睡了多久、哪些追踪没人盯,醒稳之后会有一条通知 |
| 「读不到盯盘结果:…」 | 界面读不到引擎的结果,下面的价格与状态停在最后一次读到的时候 | 见 Q15 |

出现这些警告时,本机盯盘的止盈止损可能没有在工作。托管到券商的单不受影响,但价格不会再调整。重要的持仓请到 TWS 里看着。

### Q13 到价了但没有平仓,或托管单没挂出去

- 追踪卡片上的「到价了但没有平仓」后面写着被什么拦住了:自动执行没打开、实盘闸门没开、正在熔断、合约此刻休市、拿不到现价等。处理掉那一项;需要马上平的,点卡片上的「立即平仓」或直接在 TWS 里平。
- 刚给这只持仓加过仓,或开了一只和它共用行权价的相邻组合(IBKR):下单定价用完会撤掉共用那几条腿的行情,盯盘要重新订一次,这一两秒里这只持仓拿不到现价、不判断,随后自己恢复。一直不恢复才需要处理,见 Q4。
- 断线重连之后(IBKR):如果 TWS 迟迟不重新给报价,盘中过 30 秒(盘前 / 盘后 2 分钟)软件会自己重新订一次,这之前这只持仓拿不到现价、不判断。
  反复重订还是没有价,多半是 TWS 与 IBKR 服务器之间断着,看 TWS 窗口右下角的连接状态。
- 电脑合过盖、睡过一觉:睡着的那段时间里本机盯盘不跑,到价了也不会平;醒来头 20 秒(连接不稳时最长 2 分钟)也先不判断。
  醒稳之后的那条「电脑睡了 … 本机盯盘没有运行」通知写着是哪一段、哪几条追踪。见 [02-日常使用](02-日常使用.md)「本机盯盘与托管到券商的区别」。
- 卡片显示「仅提醒」:这条追踪没有打开「到价自动平仓」,到价只会提醒。
- 卡片显示「托管单尚未挂出…」:正在对账,或被闸门拦住,看卡片下方的提示;没连接券商时,连上之后会自动挂出。
- 实盘账户上的组合(蝴蝶、价差)默认只提醒、不发单,见 [02-日常使用](02-日常使用.md) 第 7 节。

### Q14 记录显示「去向不明」

- **含义**:对账时券商那边没有这张单,当天的成交也没有填满它。它可能已经被撤了,也可能是更早成交了而软件没拿到回报。软件不替你下结论。
  只成交了一部分的,提醒里会写「只找到 40(共 100)」这样的数:那 40 已经补进记录,说不清的是剩下的 60。
- **怎么办**:到 TWS 里查这张单的实际结果,以券商的记录为准。**核对之前不要照原样重下**,否则可能变成双倍仓位;
  部分成交的,要补也只补剩下的部分。
- 软件重启后,原来由软件盯盘的条件单不再被盯,也会出现在这里。要继续请重新提交。

## 应用

### Q15 通知说交易引擎没有回应,或已退出

| 通知 | 含义 | 怎么办 |
|---|---|---|
| 「交易引擎没有回应」 | 引擎 30 秒没有回话。持仓追踪的止盈止损暂时停了 | 看屏幕上有没有钥匙串 / 凭据的弹窗在等你处理,有就先处理 |
| 「交易引擎无响应,已强制重启」 | 连续 3 分钟没有回话,软件已经把引擎重启了 | 重启后会自动连回券商。到「持仓追踪」和「订单看板」核对状态 |
| 「交易引擎已恢复响应」 | 恢复了 | 不用处理 |
| 横幅「交易引擎已退出:…。正在自动重启…」 | 引擎意外退出。软件会自动重启它,间隔从 3 秒起逐次加倍,最长 60 秒 | 等它起来;也可以到「关于」页点「重启交易引擎」 |

引擎停着的时候本机盯盘不工作。反复出现时请导出诊断信息(Q18)。

### Q16 macOS 上关了窗口,软件还在运行

- 这是有意的。在 macOS 上点红色关闭按钮或按 ⌘W 只是把窗口藏起来,追踪、提醒与自动执行照常在后台工作。第一次这样做时会有一条通知「IBKR-Assistant 仍在运行」。
- 叫回窗口:点 Dock 图标,或菜单栏「窗口 → 主窗口」(⌘0)。
- **真正退出用 ⌘Q。** 退出后本机盯盘就停了。
- 窗口藏着时要熔断:右键点 Dock 图标,选「暂停全部自动执行(熔断)」。
- Windows 上关掉窗口就是退出软件。

### Q17 某一页显示「这一页出错了」

- 只有出错的那一页换成了说明卡。其他页面、顶栏的「暂停自动执行」不受影响,持仓追踪在交易引擎里照常运行。
- 先点「重试这一页」,不行再点「重新载入界面」。反复出现时点「导出诊断信息…」。
- 通知「界面意外退出,正在重新载入」也是同一类:界面会自己重新载入,持仓追踪不受影响,价位提醒在界面恢复后继续。

## 支持

### Q18 怎么导出诊断信息

1. 「关于 → 支持」点「导出诊断信息…」。macOS 上也可以用菜单栏「帮助 → 导出诊断信息…」。
2. 选保存位置。导出后软件会在文件夹里选中这份文件。
3. 发出去之前建议自己先看一遍,再连同问题描述(做了什么、看到了什么、大概几点)一起发给支持。

| 里面有 | 里面没有 |
|---|---|
| 软件版本与系统信息 | 交易记录、成交、持仓 |
| 交易引擎的状态与自检结果 | API Key |
| 脱敏后的配置(账号已打码) | 完整的账号 |
| 备份清单、条款同意状态、上次检查更新的结果 | 想法备忘的原文 |
| 最近的日志(写入前已抹掉账号、密钥与家目录里的用户名) | |

只想贴几行到聊天窗口里,用旁边的「拷贝概要」:版本、系统、引擎与券商连接状态。

### Q19 怎么检查新版本

- 「关于 → 更新」点「检查更新」。有新版本时会显示「下载 x.y.z」和「发布页」,顶栏也会出现「新版本 x.y.z」。
- 软件**不会**自动下载或安装。下载安装包装上去会替换旧版,配置与交易记录不受影响。
- 「自动检查更新」开着时,软件启动后查一次,之后每 12 小时一次;不想让它自己联网可以关掉,关了只有手动点才查。
- 某一版不想升:点「忽略这一版」。更新的版本出来时照样会提示。
- 检查失败不影响任何交易功能,原因写在「更新」那一行里。
