# 安全与隐私须知

这一页讲几件实际的事:哪些数据会离开你的电脑、确认框到底保证了什么、账号为什么总是打着码,以及打开「允许自动执行」和「允许实盘账户下单」之前要核对什么。
正式的约定在三份条款文本里,链接在本页末尾;这里不重复条款,只讲怎么做。

## 1. 什么会离开你的电脑

你的交易数据留在你自己的电脑上。软件没有自己的服务器,不收集、不上传你的账户、持仓、订单与交易记录。会发到外面去的只有下面这几样:

| 发给谁 | 发什么 | 什么时候 |
|---|---|---|
| 你配置的大模型服务商(Anthropic,或你填写的 OpenAI 兼容端点) | 你输入的指令原文、账户**别名**(不是账号)、你设置的代码别名表与限额;使用「想法分析」「AI 选股」「行情解读」「回测条件解析」时,还有对应的文字与行情数值 | 你点「解析并校验」「发送到IBKR」或使用这些功能时 |
| 你的券商软件(TWS / IB Gateway / 富途 OpenD,运行在本机) | 订单、行情请求、账户查询 | 连接券商之后 |
| 公开行情数据源(Yahoo Finance、Cboe) | 要查询的指数 / 代码 | 顶栏行情带与指数现价刷新时 |
| GitHub | 一个不带任何账户信息的版本查询请求 | 检查更新时。可在「关于 → 更新」里关掉「自动检查更新」 |
| Discord(配置了「Discord 跟单」才有) | 你自己建的 bot 的 token,用来登录。软件只接收消息,不向 Discord 发送任何消息 | 填了频道 ID 并保存了 bot token 之后,软件开着时一直连着 |

另外几点:

- 本地速记解析(如 `1.8 挂15蝴蝶 15CM`)不经过大模型,结果卡片上会写「本地秒解(未经大模型)」。
- 软件不做用户行为统计,不嵌入分析或广告组件,不自动上传崩溃报告或日志。
- 「导出诊断信息…」只在你点击时生成一份文件,存到你指定的位置。发不发、发给谁由你决定。
- 大模型服务商、券商、数据源收到数据之后怎么处理,以它们各自的隐私政策为准。

哪些数据存在本机的什么位置,见 [03-数据、备份与恢复](03-数据、备份与恢复.md)。

## 2. 不要把账号、密码写进指令或想法

你在「交易指令」和「想法」里写的文字,会**原样**发给大模型服务商。

- 指账户请用别名(「模拟」「主账户」),不要写账号。
- 软件会在每一次外发之前检查:文字里出现了**配置里的账号**时,这一次不发,并提示
  「要发给大模型的内容里出现了真实账号…为保护隐私没有发出。请把账号从文字里删掉后再试。」
- 这道检查只认得配置里写着的账号。密码、身份证件号、别的账户的账号、银行卡号,它认不出来——写进去就发出去了。请自己把住这一关。
- 本软件任何地方都不需要你的 IBKR 登录密码。登录只在 TWS / IB Gateway 自己的窗口里完成。

## 3. 确认框保证什么

会动钱或放松保护的操作,都要先过一个系统原生的确认框:

| 操作 | 确认框 |
|---|---|
| 「发送到IBKR」 | 「发送真实订单」,写着指令原文、发到哪些账户、每个账户是纸面还是实盘 |
| 持仓追踪里打开「到价自动平仓」或托管 | 「授权软件自动平仓」 |
| 追踪卡片上的「立即平仓」 | 「立即平仓」 |
| 打开「允许自动执行」 | 「打开自动执行」 |
| 打开「允许实盘账户下单」 | 「允许实盘账户下单」 |
| 把风控限额往松了改 | 「放宽风控限额」,列出每一项从多少改到多少 |
| 打开 Discord 自动跟单,或开着时换频道、多信任一个人、换账户、调大上限 | 「打开 Discord 自动跟单」,写着频道、信任的发送者、发到哪些账户(纸面还是实盘)、三个上限 |
| 添加、修改、删除账户 | 列出将要写进配置的每一项,账号完整显示 |
| 从备份恢复交易库 | 「从备份恢复交易库」,写着这份备份的时间、种类和大小 |

它保证的是:

- **没有你点的那一下,这些操作不会执行。** 放行的凭据只在你点了确认之后才发出,界面自己造不出来。
- **你确认的就是将要执行的。** 凭据绑着这一次的内容(指令原文、账户、追踪参数、限额)。确认之后内容变了,不放行。
- **一次确认只管一次。** 用过作废;一分钟之内没用也作废。
- **确认框上最显眼的那一行由软件的主进程写**,不是由页面写;发单的确认框里,账户是纸面还是实盘是去问交易引擎得来的。
- 往安全的方向改不用确认:关闭两个闸门、把限额往紧了改、关掉或收紧跟单,都是当场生效。
- **自动跟单只在打开时确认一次。** 之后信任的发送者每发一张单都不再问你——这正是它的用途,也是它的风险,见 [06-Discord 跟单](06-Discord跟单.md)。

它**不**保证的是:

- 不保证大模型把你的话理解对了。确认框给你看的是指令原文,不是解析出来的订单。发送之前没有"看一眼解析结果再确认"这一步——
  想先看解析结果,请先点「解析并校验」。
- 不替你核对账号填得对不对。添加账户时请对着 TWS 里显示的账号逐位核对。

所以:确认框上的每一行都请读完再点。默认选中的按钮是「取消」。

## 4. 账号为什么总是打着码

界面、日志和诊断信息里,账号显示成 `DU***567` 这样(只留开头的字母和最后三位)。原因是这些内容经常会被截图、被发给别人:

| 地方 | 账号的样子 |
|---|---|
| 界面上的账户列表、交易记录 | 打码(很多地方只显示别名) |
| 日志文件 | 写入前抹掉账号、API Key、家目录里的用户名 |
| 「导出诊断信息…」的文件 | 打码;配置是脱敏后的 |
| 「关于」页的引擎日志 | 打码 |
| 添加 / 修改账户时的确认框 | **完整显示**,为了让你核对 |
| `settings.json` | **完整**。这是软件知道你账号的地方 |
| 交易库与它的备份、「交易记录 → 导出」的 JSON | **完整** |

由此得出两条规矩:

- 要把现场发给别人时,发「导出诊断信息…」的那一份,发之前自己先看一遍。
- `settings.json`、交易库、备份、导出的 JSON 不要直接发给别人,也不要放在公开的位置。

## 5. 保管好电脑本身

本软件把 API Key 存在操作系统的凭证库里,把闸门和限额存在配置文件里。**电脑本身被别人控制时,这些保护都不起作用。**

- 给系统账户设密码,离开时锁屏。不要和别人共用同一个系统账户。
- TWS 的 API 设置里,「Trusted IPs」只留 `127.0.0.1`,不要把 API 端口暴露到局域网。
- 只从发布页下载安装包。
- 备份拷到别处时,选你信得过的位置。备份里有完整的交易记录和账号。
- API Key 疑似泄露时,到服务商那边作废并换一把新的,再到「接入 → 大模型」重新保存。
- 不再使用这台电脑时,按 [03-数据、备份与恢复](03-数据、备份与恢复.md) 第 8 节把数据删干净。

## 6. 打开「允许自动执行」之前

打开之后,点「发送到IBKR」并确认,解析通过的订单就会直接发到券商;持仓追踪里打开了「到价自动平仓」的追踪,到价时也会自己发单。请逐条核对:

- [ ] 三份条款文本读过了,尤其是《风险揭示》里"自动执行的风险"一节。
- [ ] 「接入 → TWS」的「握手与账户」里,每个要用的别名都是「对得上」。
- [ ] 「接入 → 账户」里每个账户的类别(纸面 / 实盘)标得对,默认账户是你想要的那一个。
- [ ] 「设置」里的风控限额是你能承受的数。限额是最后一道闸。
- [ ] 你平时会写的每一种指令,都先用「解析并校验」试过,解析结果和你的本意一致。
- [ ] 知道「暂停自动执行」在哪(顶栏右侧),记得快捷键 ⌘ Shift H(Windows:Ctrl+Shift+H)。
- [ ] 考虑过要不要打开保护规则(日内亏损上限等)。它们默认是关的。
- [ ] 「允许实盘账户下单」还关着,顶栏显示「仅纸面」。先只在模拟账户上跑。

打开的方法:「设置 → 执行闸门」打开开关,点「保存设置」,在确认框里点「我明白,打开」。要关的时候直接关,当场生效,不用保存。

## 7. 打开「允许实盘账户下单」之前

打开之后,发到实盘账户的订单不再被拦下,会用真钱成交。顶栏会一直显示红点的「实盘已放开」。

- [ ] 在模拟账户上完整走过一遍:发单与确认框、立即平仓、托管单、重启引擎后的对账、从备份恢复。
- [ ] 读过 [更新记录](../../CHANGELOG.md) 里"已知的限制":有一部分功能只做过离线测试,还没有在真实账户上逐项核对。
- [ ] 风控限额按实盘账户的资金重新看过一遍。
- [ ] 重要的持仓在券商端另设了保护,不只靠本软件的止损。
- [ ] 清楚本机盯盘在软件退出、电脑睡眠或关机、断网、TWS 需要重新登录时不会触发。
- [ ] 备份目录已经另存了一份。
- [ ] 知道实盘账户上的组合(蝴蝶、价差)打开「到价自动平仓」就会自动发平仓单;这张平仓单还没有在实盘上成交过,第一次到价时请在 TWS 里核对成交。

打开之后的习惯:

- 每次发送前看一眼确认框里账户后面写的是「纸面」还是「实盘」。
- 不需要实盘的时候把它关掉。关是当场生效的。
- 定期在券商端核对持仓与挂单,以券商的记录为准。
- 配置文件从备份恢复之后,两个闸门会是关的,这是有意的。
