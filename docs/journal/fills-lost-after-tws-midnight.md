# 「同步成交」点了也没有:成交过了 TWS 的午夜就要不回来(2026-10-07,实盘 TWS,打包版)

起因是「交易分析」页的一张截图(北京时间 10-08 01:50 前后):下拉框里只有一笔 TTWO,右上角「已连 TWS · 库内成交 5 笔」,
当晚买的那张 SPX 蝴蝶不在,点「同步成交」也不出来。

**根因:成交只在打开交易分析 / 绩效体检时才向 TWS 要,而 TWS 只给它自己那个"当天"的成交。** 这台机器的 TWS 时区是
`Asia/Shanghai`(`~/Jts/jts.ini`),"当天"在北京时间 0 点翻篇——正落在美股盘中。蝴蝶是 0 点前 54 秒成交的,第一次同步在 0 点之后。

## 经过

时间是北京时间(`main.log` 的时间),括号里是美东。

| 北京时间 | 事 |
|---|---|
| 10-07 21:50:23(09:50) | TTWO 买 20 股,分 5 股、15 股两笔成交。之后某次打开页面时同步进了库 |
| 23:23–23:58 | 电脑睡了 36 分钟(`main.log`「系统醒来,睡了 36 分钟」) |
| 23:59:06(11:59:06) | SPX 7750/7770/7790 看跌蝴蝶成交:三条腿 8.58 / 2.55 × 2 / 0.77,净 4.25。不是应用发的单(库里当晚没有对应的交易记录),所以也没有实时成交回报 |
| 23:59:35 | 在应用里给这张蝴蝶加了追踪(审计 `tracker_add`) |
| 10-08 00:00:00 | TWS 的"当天"翻篇 |
| 00:34–00:36 | 在看行情页 |
| 01:47–01:50 | 打开交易分析、点「同步成交」。没有 `fills_failed` 审计:同步是成功的,只是 TWS 回的"当天"里已经没有昨晚那四行 |

券商侧的成交记录里这张蝴蝶好好的;本地 `broker_fills` 只有 5 行:10-01 那张到期蝴蝶的三条腿(价格 0 的到期行)和 TTWO 两行。
做了几个星期蝴蝶、库里一张都没有,是同一个原因:每一张都得赶在北京时间 0 点之前打开过一次交易分析才留得下来。

## 为什么以前没发现

- 文档和界面都写着「TWS 只给当天的成交」,但默认了"当天"就是交易日。它是 TWS 登录时区的日历日。
- 应用发出去的单有实时回报,落在交易记录里,看起来成交都在;`broker_fills` 是另一张表,只有同步才写。
- 列表不空的时候(这次有 TTWO),下拉框里那句「TWS 只给当天的」不显示;被 15 秒节流挡掉的那一次点击,右上角只写「已连 TWS」。

## 改了什么

- `services/fillSync.ts`:引擎连着 TWS 时自己同步。持仓指纹一变就去要(成交必然改持仓,几秒内落库),没变也每 5 分钟一次,
  重连回来先要一次;页面按钮走同一个入口、同一道 15 秒节流;券商 10 秒不答就作罢,不堵后面的。口径在
  [交易分析](../features/tradereview.md)「成交从哪来」。
- 交易分析页的按钮提示与说明写明"当天"按 TWS 的时区算、漏掉的怎么补;用户手册排障加了 Q21。

## 还没有在真机上核对的

- 01:50 那次 TWS 到底回了什么没有直接看到,是从"同步没报错、库里没多出行"推出来的。
- 「在 TWS 的交易日志里勾上前几天,`reqExecutions` 就连那几天一起回(最多 7 天)」取自 IBKR 的 API 文档,这台机器的 TWS 10.50 上还没试。
- 后台同步只有离线测试(`fill-sync.spec.ts`,其中一条照这次的时间线写的),没有接过真 TWS。

## 后来

- 带后台同步的那一版装上时(成交之后 11 个小时),那张蝴蝶已经不在 TWS 的"当天"里:后台同步防得住以后,补不回已经丢的。
  用户再点「同步成交」仍然没有它。
- 那三笔开仓成交先照券商侧的记录手工补进了库(成交号、方向、数量、价格取自券商;各条腿是哪张合约,取自库里同一批合约的到期记录)。
- 随后给成交同步加了"往回要 7 天":另开一条只读连接,用接口 200 版起才有的带天数的请求(`ibExecHistory.ts`)。
  在这台机器的 TWS 10.50 上试过:前两天的成交全回来了,手工补的三条腿和 TWS 回的逐项一致,另多出一条组合行。
- 「交易日志里勾上前几天」那条路没有再试:有了带天数的请求,它只剩给老版本 TWS 兜底。

## 补不回来的情形

成交那一刻应用没开、电脑睡着、或和 TWS 断着,而且之后 7 天里应用都没有连上过 TWS(或者 TWS 太老,不支持带天数的请求)。把 TWS 的登录时区改成美东,
翻篇就挪到北京时间中午(美股休市的时候),这个窗口小得多——那是 TWS 里的设置,由用户决定。
