# 蝴蝶测算

开仓之前回答一个问题:标的在某个时刻走到某个价位时,这只蝶值多少、赚多少。按各腿的 IV 定价,并估计到那一刻 IV 会怎么变。
只计算,不下单。界面在「交易指令」页右栏的「蝴蝶测算」,RPC 是 `options.fly_plan`(读道)。

持仓追踪的「标的目标价」问的是持仓之后"标的**现在**到 X 值多少";这里多一维时间:7718 开的 7750/25 点蝶,
14:30 到 7745 和 10:45 到 7745 是两个数。

## 定价

与持仓追踪的 `ibkr` 档是同一套定价:

- 点数制 Bachelier,每条腿用自己的 IV,按 +1 / −2 / +1 加权(`flyexit.legValue`)。
- 年化 IV 换成点数:σ_点 = 现价 × IV × √剩余年数(`ivPricing.ibkrLegSigmas`),剩余时间按日历时间 / 365。
- 目标时刻就是此刻时,测算与持仓追踪的试算给出同一个数(`fly-plan.spec` 拿 `tracker.spotTarget` 对照)。

**IV 的来源**,整只蝶用同一档:

| 来源 | 什么时候用 | 锚定盘口 |
|---|---|---|
| `input` | 用户手动填了 IV(三条腿共用) | 不锚:填 IV 就是要看"IV 是这个数时值多少" |
| `ibkr` | 三条腿都有 IBKR 推送的模型 IV | 锚 |
| `quote` | 缺模型 IV、三条腿都有盘口:各腿按自己的中间价反解 | 不用锚:此刻的模型价就是中间价 |

缺一条腿就整档不用,不拿别的腿的 IV 去填。三档都不成时报错,提示手动填 IV。IV 只收 0 到 500%。

**锚定。** IBKR 的模型价和盘口中间价常有差距。模型只负责"变多少",水平锚在盘口上。这段差距属于时间价值,
按 √(目标时刻的剩余时间 / 此刻的剩余时间) 收敛,到期归零。差距超过 0.3 点、又超过中间价的 25% 时照样锚定,同时提醒:
那时模型对"变多少"的估计也要打折扣。

**成本。** 填了就用填的,必须小于翼宽。没填用盘口中间价,同时给出现在立刻买得到的价(两翼按卖价、中心按买价);
盘口也没有时用模型价并注明。盈亏按取整之后的净价计算,界面上"值 11.88、成本 2"旁边就是 +$988。

## IV 会变

目标时刻各腿 IV 的乘数 = **时段乘数 × 走势乘数**,合计限制在 [1/3, 3]。这是「自动」档,也是默认;
用户可以改选「不变」或「自己填」,和历史上的通常情况差十个百分点以上时提醒一句。
两份乘数的参数都由历史数据估计(见下文「校准」),写在 `flyIvModel.ts`。

### 时段乘数:日内方差分布

每天的平方收益先除以当天开盘时的隐含方差(VIX1D²)再求和、求份额,避免几个暴跌日主导结果。

| 半小时 | 份额 | 这一段开始时还剩 |
|---|---|---|
| 09:30 | 15.1% | 100% |
| 10:00 | 11.8% | 84.9% |
| 10:30 | 9.5% | 73.2% |
| 11:00 | 8.1% | 63.7% |
| 11:30 | 6.0% | 55.6% |
| 12:00 | 5.2% | 49.7% |
| 12:30 | 6.0% | 44.5% |
| 13:00 | 5.1% | 38.5% |
| 13:30 | 6.0% | 33.4% |
| 14:00 | 6.2% | 27.5% |
| 14:30 | 6.1% | 21.3% |
| 15:00 | 5.2% | 15.2% |
| 15:30 | 10.0% | 10.0% |

年化 IV 不变,意味着剩余波动随钟点匀速减少;实际的减少方式是上表。两者之比就是时段乘数:

```
时段乘数 = √[(那时还剩几成 / 此刻还剩几成) ÷ (那时的剩余时间 / 此刻的剩余时间)]
```

从 10:00 算起:11:00 约 0.95,13:00 约 0.95,14:30 约 1.00,15:00 约 1.04,15:30 之后约 1.19。

只用于**当日到期、16:00 正常收盘**的蝶。隔日到期、提前收盘日的时段乘数是 1。

### 走势乘数:IV 对走了多远的反应

```
ln(IV 乘数) = a + b·u + c·u²        u = (目标点位 − 现价) ÷ 全天标准差,跌为负,限制在 ±4
a = −0.0105    b = −0.0969    c = 0.0253
```

| u | −3 | −2 | −1.5 | −1 | −0.5 | 0 | 0.5 | 1 | 1.5 | 2 | 3 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| IV 乘数 | 1.66 | 1.33 | 1.21 | 1.12 | 1.05 | 0.99 | 0.95 | 0.92 | 0.91 | 0.90 | 0.93 |

- 决定 IV 变化的是走了多远(全天标准差的几倍),同样的距离一小时走完与四小时走完,IV 的变化相近。
- u = 0 时乘数略小于 1:没怎么动的时段,IV 平均微降。
- **全天标准差**:当日到期的,用期权自己的 IV 折回全天(剩余波动 ÷ √此刻还剩几成);其它期限用年化 IV × √(0.83 / 252)。
  这里假定期权隐含的剩余波动就是市场对实际波动的预期,不另算风险溢价。
- **期限**:VIX9D 的系数 a = −0.0053、b = −0.0641、c = 0.0129,反应比 1 天期弱三分之一。非当日到期的蝶在两者之间按 ln(期限) 插值;
  1 天以内一律用 1 天期的,9 天以上用 9 天期的。

### 半数情况下的区间

残差的标准差:

```
sd = 0.158 × √(这一段占全天方差的份额) × (0.823 + 0.265·|u|)
```

到时的 IV 取主结果的乘数 × exp(∓0.6745·sd),两头各算一次蝶价,和主结果一起取最小最大(蝶价对 IV 不单调,翼内翼外方向相反)。
这个区间在样本里实际覆盖了 52.5%。它只包含 IV 估不准的那一份,标的会不会在那个时刻走到那个价位不在其中,那是用户自己的判断。

## 校准

**数据**(来自公开行情接口,原始数据不进仓库,进仓库的只有估出来的参数):

| 数据 | 用来估什么 | 样本 |
|---|---|---|
| SPY 小时线 | 标的走势、日内方差的小时份额 | 2023-12-11 至 2026-09-25,692 个交易日 |
| SPY 5 分钟线 | 每个小时内前后半小时的分配 | 最近 60 个交易日(公开分钟线只给这么多) |
| VIX1D 小时线 | 1 天期 IV 怎么变;每天开盘时的隐含水平 | 692 天 |
| VIX9D 小时线 | 期限长一档时反应弱多少 | 692 天 |

- 标的用 SPY:SPX 指数 09:30 那一笔用昨收拼接,隔夜缺口会在开盘几分钟里"走"出来,夸大第一个小时的方差。
- 小时线只用收盘价:IV 指数的小时线除第一根外,开盘价七成对不上 5 分钟线,收盘价都对得上。

**走势的估计方法。** 小时网格(09:30、10:30 … 15:30、16:00)上每天取所有 i < j 的窗口,共 28 个;
y = ln(VIX1D_j / VIX1D_i) 减去 VIX1D 自己的日内平均走法;u = ln(S_j / S_i) ÷ 全天标准差,
全天标准差 = √(0.83 / 252) × VIX1D_i(VIX1D_i 同样先去掉它自己的日内平均走法),0.83 = 实际常规时段方差 ÷ (开盘 VIX1D² / 252)。
最小二乘拟合 u 的二次式。

**检验。** 前 484 个交易日(2023-12-11 至 2025-11-19)拟合,后 208 个(2025-11-20 至 2026-09-25)检验,两段不重叠:

| 拿什么预测 IV 的变化 | 检验段 R² |
|---|---|
| IV 不变 | −0.007 |
| 校准的模型 | **0.322** |

模型解释得了 IV 变化的三成,其余七成估计不出来,所以结果里同时给区间。

**分段稳定性。** 三段各自估计:

| 区间 | 09:30 | 10:30 | 11:30 | 12:30 | 13:30 | 14:30 | 15:30 | b | c |
|---|---|---|---|---|---|---|---|---|---|
| 2023-12 至 2024-11 | 22% | 14% | 9% | 10% | 17% | 14% | 14% | −0.076 | 0.029 |
| 2024-11 至 2025-10 | 27% | 17% | 10% | 14% | 11% | 11% | 10% | −0.114 | 0.020 |
| 2025-10 至 2026-09 | 31% | 22% | 14% | 10% | 8% | 9% | 6% | −0.101 | 0.029 |

走势系数的方向与量级稳定,斜率有三成出入;日内分布在往上午集中。参数用全部样本,不追最近一段,所以要定期重新校准
(建议每季度一次,或行情明显变样之后)。

**重新校准:**

```
cd engine-ts
npm run build && npm run calibrate:fly -- --fetch            # 取数据、校准、出报告,不改文件
npm run calibrate:fly -- --fetch --write                     # 同上,并写进 src/flyIvModel.ts
npm run build && npx vitest run fly-
```

`fly-calibration.spec` 对写进去的参数有几条底线:样本至少一年、样本外 R² 明显为正且好过"IV 不变"、区间覆盖率在一半上下、
b < 0 且 c > 0。不满足就不能进定价。`fly-plan.spec` 用一份固定的模型测试"参数怎么用",重新校准不影响它。

**局限:**

- IV 的变化用 VIX1D 估计,当日到期期权自己的 IV 没有历史数据。VIX1D 是恒定 1 天期的:上午主要反映当天到期的那一批,越到下午越偏向次日到期的。
  当日到期期权对走势的反应多半更强,尤其在尾盘。IBKR 不给过期期权的历史行情,所以要靠软件自己积攒(下一节)。
- 隐含的日内分布当成和实际的一样。
- 5 分钟线只有 60 天,小时内前后半小时的分配样本短。
- 隔日到期的蝶没有时段那一份,"这一段占全天方差的份额"按钟点算,夜里与白天一样重。
- IV 偏斜固定在行权价上,不随现价移动。
- 公开行情接口的商用条款未定(见商用化报告);校准只在开发时运行,运行时顶栏行情带也在用它。
- IBKR 推送的当日到期模型 IV 用什么剩余时间约定,还没在真机上核对(`npm run probe -- --steps ivcheck`)。
  锚定挡住了水平上的偏差,挡不住"变多少"上的偏差。

## 自己积攒 IV

`services/ivRecorder.ts` 在引擎里按节拍运行,不靠界面驱动:

| 项 | 规则 |
|---|---|
| 什么时候记 | 连着 IBKR、在常规交易时段里(休市日、提前收盘日按日历),每 5 分钟一笔 |
| 记什么 | SPX 当日到期(SPXW):开盘后第一笔现价取整作锚,取锚 −75 / −50 / −25 / −10 / 0 / +10 / +25 / +50 / +75;锚以下记看跌、以上记看涨、锚上两样都记(都取虚值一侧)。每条腿记买价、卖价、IBKR 模型 IV,外加当时的现价 |
| 行权价 | 一整天不换,引擎重启也沿用当天的锚;标的离锚 20 点以上时,再添一对跟着现价的平值 |
| 测算顺带记 | 测算读到行情时也记一笔(那三条腿);同一只蝶一分钟最多一笔;现价是手动给的、不是当日到期、三条腿都没有 IV 时不记 |
| 要有盘口 | 循环记的那一笔,至少一条腿有卖价才记。只有模型 IV、一条盘口都没有的不记:那不是行情,电脑睡着时 TWS 给过一模一样的三笔 |
| 存放 | 交易库旁边的 `fly-iv/年-月-日.jsonl`,一行一笔,只追加;保留最近 400 个记录日,换日后第一笔时清理 |
| 内容 | 只有行情,没有账号、别名、持仓、订单(`iv-recorder.spec` 检查键的清单) |
| 开关 | 默认开,在测算面板「更多」的最下面,存在库的偏好表里;关掉后不订任何行情,已记的不删 |

- 行情用测算那批自己的流(`optionMarks.ts`),碰不到盯盘的流;一轮十条腿上下。
- 样本单独存放,不进交易库:坏了、删了都碰不到订单与追踪,库的结构版本也不用动。
- 不记的时候说得出原因(`options.iv_recorder` 的 `idle_reason`):没连券商、期权行情只从 IBKR 取、不在常规交易时段、已关闭、
  配置里没有 SPX 这个指数、拿不到现价、行情订阅被拒(带 TWS 原话)、这一轮只有模型 IV 没有盘口、这一轮一条行情都没来、上一轮出错。
  出错记下来,循环不停。

**用积攒的样本校准:**

```
cd engine-ts
npm run build && npm run calibrate:fly -- --fetch --samples auto            # 只出报告
npm run calibrate:fly -- --fetch --samples auto --write                     # 过得了两道关才写进去
```

`fitFromSamples` 估计的两样与指数那一路相同,量法贴着测算自己:

- y = 同一条腿(同一行权价)的 IV 对数变化,只看起点时离现价一个全天标准差以内的腿;
- u 的分母 = 期权自己的剩余波动折回全天(平值 IV × √剩余年数 ÷ √还剩几成);
- IV 自己的日内走法:10:00 起每半小时一个点到 15:30,累加半小时一步的平均变化,测算的时段乘数直接用它;
- 半小时网格,每个点取前后四分钟内最近的一笔;前七成交易日拟合,后三成检验。

两道关:样本不够时 `fitFromSamples` 直接报错(一天有六个半小时点以上的至少 40 天、至少 1,000 个窗口、检验段至少 30 个窗口);
`ownIsBetter` 要求检验段上自己这一份的 R² 大于 0.1,且不输指数那一份在同一批窗口上的 R²。过了,模型里多一个 `own`,当日到期的蝶的时段、走势、区间宽度改用它,
结果底部注明"用的是软件自己积攒的当日到期期权 IV";隔日到期的仍用指数那一份。
估计方法已用已知答案的合成样本验证过;还没有用真实样本校准,第一次带 `--samples` 时只出报告,先看数字说不说得通。

## 止盈策略共用这份日内分布

`flyexit.VARIANCE_WEIGHTS` 就是校准出来的 `variance_weights`。止盈策略的阶段切换、持仓追踪 `clock` 档的 σ、
交易分析回放里没有真实蝶价时的模型价都用它。当前的切换时刻(EM 36):

| 时刻 | 还剩几成 | 剩余 σ(点) | 翼宽 25 的阶段 |
|---|---|---|---|
| 10:30 | 73% | 30.8 | A |
| 12:07 | 48% | 25.1 | A |
| 13:30 | 33% | 20.8 | A |
| 15:00 | 15% | 14.0 | C |
| 15:30 | 10% | 11.4 | C |

| 翼宽 / EM | σ_剩余降到 W / 1.6 的时刻(阶段 C 的起点) |
|---|---|
| 25 / 36 | 14:43 |
| 25 / 50 | 15:31 |
| 40 / 36 | 12:09(阶段 A 持续到 14:00,所以 14:00 直接从 A 进入 C) |
| 20 / 36 | 15:19 |
| 10 / 36 | 15:51 |

重新校准会连它一起改:写进 `flyIvModel.ts` 之后 `golden-flyexit` 变红,核对过再 `npm run golden:update -- golden-flyexit`。
EM 与 `switch_k` 由用户定,分布由数据定。

## 日程

| 没给 | 默认 |
|---|---|
| 目标日期 | 今天;今天不是交易日或已收盘,就是下一个交易日(并说明) |
| 到期日 | 目标那一天(当日到期);可以晚于目标那一天 |
| 交易类 | 指数用配置里的日到期类(SPX → SPXW,收盘结算),和本地速记开的是同一张合约 |
| 标的 / 张数 | SPX / 1 张 |
| 看涨 / 看跌 | 中心 ≥ 现价取看涨,并提醒 |

- 提前收盘日的当日到期按 13:00 到期。持仓追踪的到期时刻(`ivPricing.expiryEpochMs`)按 16:00(AM 结算的月度合约按 09:30),
  提前收盘日没有特殊处理,这是那一侧的已知缺口。
- 目标时刻不在常规时段里照样计算,但提醒那时指数不报价。目标时刻已经过去、或在到期之后:拒绝。

## 取行情(`optionMarks.ts`)

测算的腿很可能正好是持仓的腿(加仓、相邻的蝶共用行权价),而行情流按「合约 + generic ticks」缓存、没有引用计数,
所以测算用自己的流:

- 带自己的 generic tick `106` 订阅,撤销时只点名撤这一条。
- 订上之后保留:空闲至少 60 秒才撤(每 30 秒检查一次),最多保留 24 条(行情线路有配额)。
- 读取一次一个;换了会话、流被拒、或者连接还在却超过时限一笔盘口都没来(断线重连后库重订了、TWS 却不给),读之前撤掉重订。
  时限由调用方按正股表的时段给(`heldStreams.silenceLimitMs`:盘中 30 秒,盘前 / 盘后 2 分钟,休市不判),这一层不认识交易时段。
- 只管着纸面账户的会话切到行情类型 3 订阅(有实时给实时,没有给延迟),订完切回 1;管着实盘账户的会话不切。
- 盘口最多等 4 秒,合约确认最多等 12 秒;盘口齐了之后再等模型 IV 最多 1.5 秒(休市时它根本不来)。
- 拿不到的给 null。退不退到手动 IV 由上一层决定。
- 现价:指数走 `router.indexPrice`(夜盘按期货推算,来源注明)。推算失败、拿到的是昨收时不计算,请用户手动给。

**手动输入与离线。** 现价与 IV 都手动给、且没连 IBKR 时,一条行情都不取,可以在休市时按"假如现价是 X"推演。
连着 IBKR 时照样订三条腿的盘口(用于成本与买卖价)。只给了其中一样,另一样照旧向券商取。富途连接下不取期权行情,IV 必须手动给。

## 界面

在「交易指令」页的右栏,和「解析结果」是同一栏的两面(分段控件切换);点「解析并校验」或「发送」自动切回解析结果。

- 主结果旁边是「半数情况下」的盈亏区间和「要是 IV 不变」的数。
- 「IV 变了会怎样」一张表:−25% / 不变 / +25% / +50% / +100%,加上主结果用的那一档(标出来,按它自己的乘数计算,和主结果是同一个数)。
- 提醒里把合计拆开:"到时的 IV 按 −5.5% 算(时段 +1.3%,走势 −6.7%);历史上同样的走势之后,半数情况落在 −13% ~ +3% 之间"。
- 结果底部写明校准用的数据、时间段、样本外 R²,以及"VIX1D 是恒定 1 天期的指数,不是这三条腿自己的 IV"。
- 盈亏曲线上每个价位用它自己的乘数;时间线上每一行用那一刻的时段乘数;「现在就到」按 IV 不变计算,和持仓追踪的试算一致。
- **「写进指令」只填字**:把这只蝶写成一句话放进左边输入框(有字就另起一行),发不发还是那两个按钮与确认框的事。
  当日与下一个工作日到期的写成本地速记认得的样子(`SPX 7750蝴蝶 25cm 看涨 2张 1.85`),其它到期日写明日期、交给大模型;
  权利金用测算时的成本。`desktop-fly-plan-form.spec` 把写出的句子交给本地速记解析,结果必须是测算的那一只。
- **「跟着行情刷新」**:十秒一次,只在面板看得见时运行(循环在 `store/flyPlan`);失败一次就自动关掉,留着上一次的结果并说明。
- 表单改过之后结果仍显示,但压暗并标出"这是改之前的",「写进指令」变灰。
- 时刻一律用美东时间,结果里另给本地时间。

## 实时现价与关口提醒

面板顶上一行:SPX 的实时现价、现价上下最近的两个关口(25 的整数倍)与各自的距离、「到 25 的整数倍时提醒」的开关。
蝶的中心落在这些位置上;点关口就是把它填进「中心行权价」。

**现价**(`options.spot`,读道)和测算用的是同一路,所以面板上的数就是测算会用的数:

| 来源 | 什么时候 | 界面 |
|---|---|---|
| `quote` | 常规时段:券商的指数现价 | 数字后面一个绿点 |
| `futures` | 常规时段之外:期货现价 − 基差(见 [持仓追踪](tracker.md)「夜盘的指数现价」) | 绿点,标「期货推算」,悬停看怎么推的 |
| `stale` | 期货推算失败时退回的上一个收盘价;TWS 与 IBKR 服务器断开时的最后一笔 | 压暗,标「不是现价」,不显示关口,不提醒 |
| `none` | 没连券商、券商没给价 | 一句原因 |

- 不用顶栏行情带的那一格:它读的是指数流的最新价,常规时段之外停在收盘价上。
- 取不到价不是 RPC 报错,是 `price: null` 的回执:这是两秒一次的轮询,不该每两秒弹一条错误。
- 只认配置里的指数。每问一个标的就是一条常驻行情,界面递不进别的代码。
- 引擎读的是常驻行情流里的那一笔(`indexPrice`),不另订行情。

**提醒**(`lib/spotLevels.ts` 的 `stepLevelWatch`,纯函数):这一笔相对上一笔穿过了关口就报一次。

| 规则 | 理由 |
|---|---|
| 碰到就算:上行是「上一笔 < 关口 ≤ 这一笔」,下行反过来 | 7724 → 7725.00 报上穿;接着回落到 7724 不是下破 |
| 报过的关口静音,直到价格离开它 12.5 点(半个步长) | 离得比这更远,最近的关口已经是另一个,再回来才是"又到了";在关口上来回蹭只报一次 |
| 第一笔只登记 | 一打开不把现价旁边的关口报一遍 |
| 两笔隔了 30 秒以上,后一笔只登记 | 电脑睡过、断线重连:中间走过哪儿没人看见 |
| 换了来源的那一笔只登记 | 09:30 从期货推算换回官方指数,两种量法之间的差不是行情 |
| `stale` / `none` 不拿来判断 | 不会动的价穿不过任何关口,但它和前后两笔的差是假的 |
| 一笔跳过几个关口只报最后一个,正文写越过了几个 | 开盘跳空时不连弹三条 |

- 轮询在 `store/spot`,应用启动就开始,与当前在哪一页无关:走到关口正是该回来测算的时候。连着券商、开关开着就两秒问一次;
  开关关着时只在面板看得见的时候问。
- 常规时段之外照样提醒,用的是期货推算的价,正文标明「按期货推算」。
- 提醒走价位提醒的那扇置顶弹窗与提示音,受板块页「提醒方式」两个开关管;弹窗关着或没收下时发系统通知。
  弹窗的「查看」跳回这块面板。
- 开关记在本机(`dafri-spot-level-alert`),默认开;静音状态只在内存里,重启后第一笔只登记。
- 步长 25 是 SPX 蝶中心的间距,写在 `lib/spotLevels.ts`,不是可调参数。

## 契约

- `options.fly_plan`:入参与返回在 `contract/options.ts`。schema 是 strict 的、数值只认数字,键名写错当场拒绝。
  不发单、不改配置,不在 `SENSITIVE_METHODS` 里,不需要确认凭据。错误码:入参与规则上的错 −32602;取不到现价或行情 −32017。
- `options.iv_recorder`(状态)与 `options.iv_recorder_set`(开关)在本地道。
- `options.spot`(读道):入参只有可选的 `symbol`(缺省 SPX),strict。不是配置里的指数 −32602;取不到价是 `price: null` 的回执。

## 真机核对

目前全部是离线测试。连着 TWS 时要看的:

1. 盘中对一只蝶点「测算」:三条腿的盘口与 IV 都出得来;「现在就到」那一行和持仓追踪的试算是同一个数。
2. 手里有这只蝶时点「测算」、打开「跟着行情刷新」放几分钟:持仓追踪的价照常在跳。
3. 开仓时记下测算的数,到目标时刻和实际蝶价比较,这是核对 IV 模型在真实期权上准不准的唯一办法。
4. 盘中连着 TWS 放半小时:`fly-iv/` 里当天的文件每五分钟多一行,十条腿都有 IV;期间持仓追踪的价照常在跳。
5. 盘中看面板顶上的 SPX:和 TWS 里的指数是同一个数、两秒一跳;走过一个 25 的整数倍时弹窗一次,在关口上来回蹭不再弹;
   切到别的页照样弹,「查看」跳回这块面板。夜盘标着「期货推算」,数字跟着 ES 走。
