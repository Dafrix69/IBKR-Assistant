# 顶栏宏观行情带

形状在引擎契约里(`engine-ts/src/contract/macro.ts`),界面从 `bridge.ts` 拿同一份。

七格常驻行情,**双来源混合**,界面上分得清哪格是哪个:

| 来源 | 走哪些 | 刷新 | 界面标记 |
|---|---|---|---|
| **TWS 流式** | 标普500·SPY、纳指100·QQQ、黄金·GLD、布油·BNO、比特币·PAXOS 现货 | **2 秒** | 数值后一个绿点,小字标出实际标的 |
| 公开数据源 | VIX、美债10Y,以及上面任何一格拿不到实时数据时 | 10 秒(已连 TWS)/ 60 秒 | 无绿点 |

为什么指数要换成 ETF:SPX / NDX / VIX 指数值和 GC / BZ 商品期货在 IBKR 都要**单独订阅**,
多数账户没有;而对应 ETF 属于普通美股,只要有 US Equity Streaming 就是实时的。ETF 的涨跌幅
贴近指数,但**绝对价位可能差一个量级**(GLD 几百美元 vs 黄金期货几千美元),所以每格都标出实际
读的是哪个标的——不标的话那个数字会让人以为行情崩了。原油这格是**布伦特**(BZ=F / BNO),不是 WTI。

**VIX 与美债10Y 永远走公开源,不给 ETF 替身。** 这是刻意的:VIXY 有 contango 损耗、长期偏离
VIX;TLT 是价格,和收益率**反向**——换上去会让人把「利率下行」读成「利率上行」。宁可慢一格,
不可错一格。有测试钉着这条(`test_vix_and_10y_never_get_an_etf_stand_in`)。

**比特币同样不给 IBIT 替身**:这格要看的是币价本身(几万美元),IBIT 几十美元差一个量级。连着 TWS 时
读的是 IBKR 挂在 PAXOS 上的 BTC 现货(`secType CRYPTO`,行情**免订阅**,2026-09-08 真机实测两秒内到价);
断开时公开源 BTC-USD 兜底。富途通道见到加密标记直接跳过——它没有这个市场,混进批量订阅会把整批拖垮。

秒级只在连了 TWS 时才开:那时走的是**常驻订阅**,读一次几乎不花时间。没连 TWS 时七格全走
公开端点,而那个端点本身就不是逐笔更新的——刷快了只是反复拿同一个值,还会把自己的 IP 打进限流。

**券商那一路出任何岔子,这一轮就当没有流式报价**:七格降级到公开源,下一轮再试,`macro.board` 本身不报错。
`macroBoard` 对 router 抛异常早有护栏;2026-09-20 迁契约时照出 RPC 这一层漏了一处——handler 为了把异步的 `streamQuotes`
摊平成同步面,在 `macroBoard` 外面先 `await` 了一次,那一次没包:行情线路一抛,整条 RPC 报错,界面上的表现是行情带不再更新。
现在包上了,`tests/market-rpc.spec.ts` 钉着。
