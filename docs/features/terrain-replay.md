# 地形记录与离线回放

第一阶段记录 SPX 日内剧本每次期权墙刷新所观察到的 GEX 地形。沿用现有 TWS 连接、当日到期链与五分钟刷新流程;不增加行情订阅,不产生订单。

## 底账

交易数据库同目录的 `terrain/YYYY-MM-DD.jsonl`,按收到结果时的美东日期分文件。成功为 `observed`,刷新失败为 `refresh_failed`;失败行不携带旧墙。关闭日内剧本后不再采集。未采集的时段不能补造。记录永久保留,由用户备份或清理。

字段包括 schema_version=1、model_version=oi-gex-v1、symbol=SPX、requested_at、received_at、status、wall。wall 白名单保存现价、到期日、每档 OI/成交量/GEX、墙、翻转位、覆盖范围与 OI 缺失数。只记录允许的数值和枚举;账户、订单、原始报错文本和任意额外字段不会落盘。文件新建权限为 0600。记录失败在日内剧本备注显示,不阻断现有剧本计算。

requested_at 是开始请求墙的本机时间,received_at 是获得结果后的本机时间;不是交易所成交时间。缓存命中也可形成一次观察,不能因此认为行情更新了。market_at、market_data_type 暂为 null:当前 wallFor 返回值未传播逐合约实际行情类型与各字段更新时刻。一次实测为实时不能证明往后所有帧实时。Greeks、OI 与价格可能异步更新,帧收到得晚不代表所有字段都新。

这是按 OI 与 Call 正/Put 负假设计算的 GEX,不是 EHG。成交量缺失在上游可能已降为零,单档净 GEX 也可能因缺输入为零;这些记录不能证明零成交或真实中性,不能作为自动开仓授权。第一阶段保存聚合观察值,不支持更换模型后从原始期权腿重算。实际数据类型、逐字段时间和原始腿的存储是后续采集层扩展。

## 图形回放

在 Qt 应用「交易指令」页点击「地形回放」,选择已有记录的美东日期。拖动时间轴查看该时刻之前最后收到的地形,也可按上一帧/下一帧切换。日期加载后拖动在本地完成,不需要连接 TWS;当日新增记录用「刷新记录」读取。

每档净 GEX 用点和正负色柱显示,竖线表示该帧 SPX 现价;鼠标悬停查看数值。横纵轴按整日记录固定范围,便于比较变化;这是复盘展示范围,不是当时可用的交易信号。时间轴不插值,未采集的行权价不连线。刷新失败显示空图,超过五分钟的观察显示帧龄提醒,损坏记录显示日志不完整。

## 命令行回放

构建得到独立开发工具 `terrain-replay`,只链接本地数据模块,不读取交易配置、不连接 TWS。它不包含在安装包中。

```
terrain-replay --dir /path/to/terrain --date 2026-10-22
terrain-replay --dir /path/to/terrain --date 2026-10-22 --at 2026-10-22T14:00:00Z --max-age-ms 300000
```

不传 at 输出完整日内时间线;传 at 时必须带时区,且属于指定的美东日期。按 received_at 排序,只选择不晚于 at 的最后一条,同一毫秒按写入顺序取最后一条。支持任意跳转和重启后重复读取。max-age-ms 默认五分钟,只是观察帧龄门槛,可显式更改,不是经过验证的交易阈值。

状态:

- no_data:截至指定时刻没有记录。
- refresh_failed:最后一次观察失败,不会回退到之前成功的墙。
- stale:最后成功帧的观察年龄超过门槛。
- observed_market_age_unknown:帧龄未超门槛,但行情真实年龄仍未知。
- incomplete_log:文件有坏行、未知版本或错误日期的记录。保留最后可读记录供检查,不宣称回放完整。rejected_records 是整个文件的诊断计数,不是当时市场可见信息。

断电半行被跳过并计数;再次写入会先补换行,不会吞掉下一条完整记录。读取失败与空文件分开处理。命令行工具输出 JSON 时间线或某时刻快照;图形界面提供手动回放,不提供盈亏回测或自动交易信号。

## 代码与验证

`native/engine/domain/terrain_log.*` 管落盘、白名单、校验与 as-of 读取;`native/engine/orchestrate/services/playbook_service.cpp` 在刷新结束后记录;`native/tools/terrain_replay.cpp` 提供离线入口。`tst_terrain_log` 验证未来帧不可见、失败帧不回退、过期、重启、损坏尾行恢复、数据白名单与 CLI 参数。

记录和回放用离线测试验证;TWS 单独只读探测核对过字段可用性,不等于完整应用采集链路已经实盘验收。

Qt 回放由 `options.terrain` 只读接口、`TerrainController` 和 `TerrainReplay.qml` 组成。日期受本地日志校验约束,目录由引擎配置确定。控制器测试覆盖异步旧响应、销毁后的回调、空记录、失败帧和时间跳转;QML 测试实际拖动时间轴并检查渲染告警。
