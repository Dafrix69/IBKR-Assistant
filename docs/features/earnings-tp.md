# 财报止盈

持有正股过财报:财报出来之后,价比**财报前最后一个收盘价**有利到设定的百分比,就在盘后、夜盘或次日盘前把它平掉。
它是 [持仓追踪](tracker.md) 的一个目标(`targets.earnings_tp`),触发之后走追踪原来那条平仓路:同一套平仓条件、先落闩再发单、一条追踪只发一次。
界面在新建追踪表单的「更多出场规则」里,入参是 `tracker.add` / `tracker.update` 的 `earnings_tp_pct`、`earnings_date`、`earnings_timing`。

只给正股。期权在盘后与夜盘不交易,到价了也平不掉;期权与组合填了当场拒。

## 窗口与基准

| 发布时段 | 基准日(取它的收盘价) | 反应日 | 窗口 |
|---|---|---|---|
| 盘后(`AFTER MARKET`) | 财报日当天 | 下一个交易日 | 基准日收盘 → 反应日收盘 |
| 盘前(`BEFORE MARKET`) | 财报日的上一个交易日 | 财报日当天 | 同上 |

- 窗口从基准日的常规时段收盘开始(提前收盘日是 13:00),盘后、夜盘、次日盘前、反应日的常规时段都判,到反应日收盘为止(`analysis::etp::planWindow`)。
  窗口开始之前不判——财报前的涨幅不是「财报止盈」;反应日收盘还没到价,这一项**作废**(`lapsed`),提醒一次,追踪上别的止盈止损照常。
- 盘中发布、时段未知的排不出窗口:分不出哪一个收盘价是「财报前收盘」。财报日不是交易日的同样排不出。
- 止盈价 = 基准收盘价 × (1 ± 百分比 / 100),多头向上、空头向下(`targetPrice`)。百分比由人填,范围 0–500 只挡手误。

**财报日期从哪来。** 不填 `earnings_date` 就照 IBKR 的财报日历(Wall Street Horizon,和 [板块财报](sector-earnings.md) 同一路 `wshe_ed`):
取窗口还没结束的第一场,只认已确认(`CONFIRMED`)且盘前或盘后的。开窗之前每 6 小时核对一次,日期变了跟着改并提醒一次。
日历读不到(没有权限、超时)、日期没确认、没有下一场时**不上膛**:卡片照实写原因,提醒一次,每分钟再查。
手填 `earnings_date`(美东 `YYYY-MM-DD`)与 `earnings_timing`(`after` / `before`)的不查日历,建追踪时当场排窗口,排不出当场拒;两样要一起填。

**基准收盘价。** 基准日收盘满 60 秒之后取那一天的日线收盘(`dailyBars`,IBKR `ADJUSTED_LAST` 日线),取到就落进 `targets.earnings_tp.ref_close`,
重启不再取;取不到每分钟再试,这段时间不判。等 60 秒是让收盘竞价那一笔进日线,这个数没有数据依据,只是不取 16:00:00 那一刻还在变的那根。

财报日历与日线都在后台取:WSH 一次请求可以等十几秒,盯盘一秒一轮,不等它,取到了下一轮用(`orchestrate/earnings_watch`)。

## 拿什么价判

**拿此刻立刻能成交的价判**:多头(要卖)看买价,空头(要买回)看卖价(`executable`)。不看最新成交价——盘后与夜盘成交稀,
最新一笔可能是几分钟前的,也可能是一笔很小的单;买价到了止盈价,说明这一刻真有人按这个价接。

- 买卖价来自一条常驻订阅(`BrokerRouter::stockBook`):盘前、盘中、盘后订 SMART,夜盘订 IBKR 的 `OVERNIGHT` 交易所(SMART 那条流夜里不跳)。
- 买价或卖价缺一边、不是正数、倒挂:这一轮不判,卡片写「拿不到买卖价」。订阅被拒(没有夜盘行情)的隔 60 秒再订,不让盯盘每一轮等首笔报价。
- 止损类(止损、跟踪止损、利润回撤)同一轮也触发的,听止损的;固定止盈价同时到了的,记财报止盈的原因。
- 时段:正股日历的盘前 / 盘中 / 盘后之外,美东 20:00–03:50、所属交易日开市的那一段算夜盘(`stockSession`;周日晚归周一,周五晚与假日前夜不算)。
  其余时间休市,不判。

## 平仓单

| 时段 | 单子 |
|---|---|
| 盘中 | 照追踪的 `order_type`:市价就是市价单,限价是买价(卖价)朝成交方向让 `slippage_pct` |
| 盘前 / 盘后 | 一律限价 + `outsideRth`,SMART,价同上 |
| 夜盘 | 一律限价 + `outsideRth`,合约的交易所换成 `OVERNIGHT`,当日有效(夜盘 03:50 收盘时失效) |

**限价单发出去之后追价**(别的正股平仓单不追):每一轮拿最新的买价(卖价)重算立刻成交价,走 [追价平仓](tracker.md#追价平仓) 的同一套——
前 3 轮停在首单的价上,之后每轮多让一跳(0.01),上限 `chase_max_pct`;改的始终是同一张单;追 30 轮没成交提醒一次。
单被撤、被拒、到时段结束失效时,换回「止盈已触发」并提醒持仓可能还在,不重发。
财报止盈按整条追踪的 `close_fraction_pct` 平,不占分批止盈的档。

**托管到券商的追踪。** 到价时不另发组外的单:把同一个 OCA 组里的止盈单改到(没有就挂一张)立刻成交的价去追,和别的触发同一条路。
托管单是 SMART 的 GTC,不进夜盘交易所,所以**托管的追踪夜盘那一段不判**,04:00 盘前接着盯;要夜盘也能平,就别托管。
正股日历说休市时,同一条追踪上别的目标(固定止盈、止损)照旧不发——进夜盘的只有财报止盈。

## 落库的样子

`targets.earnings_tp`(设了才有这个键):`pct`、`manual`、`date`、`timing`、`ref_date`、`react_date`、`start_ms`、`end_ms`、`ref_close`、`lapsed`。
`tracker.update` 改目标而财报止盈没换场次的,排好的窗口与取到的基准收盘价留着。盯盘行的 `earnings_tp` 在这份之上多 `phase`
(`resolving` / `unresolved` / `waiting` / `armed` / `hit` / `lapsed` / `idle`)、`target`、`session`、`price`(这一轮的买价或卖价)、`reason`(卡片上那一行)。
