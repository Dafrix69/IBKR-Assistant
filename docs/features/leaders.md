# 强势股筛选:把实盘比赛优胜者的选股规则变成代码检查

[绩效体检](performance.md)管的是"做完之后",这一节管"做之前":实盘比赛的优胜者都公开过自己怎么挑股票,
而且规则写得足够具体,可以逐条变成代码。代码在 [`engine-ts/src/leaders.ts`](../../engine-ts/src/leaders.ts),
RPC 是 `screener.leaders`(读道),界面在「研究 → 扫描」表格下面的「强势股筛选」一节,和上面那张 RS / 背离表
用同一个股票池、同一个基准、同一条日线缓存。**只用券商日线,不调模型;只陈述规则过没过,不给买卖建议。**

## 规则从哪来

| 规则 | 出处 | 在这里怎么算 |
|---|---|---|
| 趋势模板 8 条 | Mark Minervini(美国投资锦标赛 1997 年冠军、2021 年以 334.8% 再夺冠),《股票魔法师》《像冠军一样交易》 | 见下表,8 条全过 = 第二阶段上升趋势 |
| VCP 波动收缩形态 | Minervini | 基底里回撤一次比一次浅、最后一次缩量,放量越过枢轴 |
| RS 评级 | William O'Neil / IBD;David Ryan 用 CAN SLIM 三连冠美国投资锦标赛 | 近 3 个月 40%、前三个季度各 20% 的加权涨幅,池内排百分位 |
| 放量新高 | CAN SLIM 的 N(新高)与 S(供需) | 收盘创 52 周新高且量 ≥ 50 日均量 1.5 倍 |
| 大盘方向 | CAN SLIM 的 M;IBD 的派发日 | 基准在不在 50 / 200 日线上、近 25 个交易日的派发日 |

**CAN SLIM 里没算的**:C(当季盈利增长)、A(年度盈利增长)、I(机构持仓)要财报与持仓数据,
券商日线给不了。表下面的 notes 每次都写明,不拿别的东西冒充。

## 趋势模板

| # | 条件 | 口径 |
|---|---|---|
| 1 | 价在 150 日线与 200 日线之上 | 简单均线,最后一根收盘 |
| 2 | 150 日线在 200 日线之上 | |
| 3 | 200 日线上行至少 1 个月 | 与 22 个交易日前比;另外数出连续上行了几个月(最多数 5),Minervini 说最好 4–5 个月 |
| 4 | 50 日线在 150 与 200 日线之上 | |
| 5 | 价在 50 日线之上 | |
| 6 | 比 52 周低点高 30% 以上 | 《股票魔法师》的口径;新书放宽到 25%,这里取严的 |
| 7 | 离 52 周高点 25% 以内 | 52 周 = 最近 252 根的最高价 / 最低价 |
| 8 | RS 评级 ≥ 70 且跑赢基准 | 池子不到 10 只时只看加权涨幅有没有跑赢基准 |

**数据不够的那条是「判断不了」**(日线不够 200 根算不出 200 日线、不够 253 根算不出 RS),界面画成空心点,
不算过也不算没过;但第二阶段要求 8 条**全部是过**,所以新股永远进不了第二阶段——这是规则本意,不是缺陷。

**RS 评级是池内百分位**,不是 IBD 的全市场排名:扫 8 只股时第一名就是 99。池子越大越接近原意,
所以不到 10 只时第 8 条退成"跑赢基准"。

## VCP

1. 从最近 130 根里找最高点当基底起点;最高点离现在不到 6 根 = "还贴着新高,没有形成基底"。
2. 起点之后的摆动高点(左右各 3 根都不比它高)依次切段,每段的最低点算一次回撤深度。
3. 并段:后一个高点不低于前一个时,前一段只是基底里的一截,并掉;比 1.5% 还浅的回撤当噪音并掉。
4. **成形** = 至少两次回撤、一次比一次浅、第一次不超过 50%、最后一次不超过 15%。
5. **枢轴** = 最后一次回撤开始时的高点。**缩量** = 最后一次回撤里的均量低于 50 日均量的 80%。
6. 状态:收盘越过枢轴且量 ≥ 50 日均量 1.4 倍 = 放量突破;越过但量不够 = 突破量不足;
   在枢轴下方 5% 以内 = 临近枢轴;更远 = 收缩中。

**两处判断**,在真实日线上核对过(2026-09-23,NVDA / PLTR 最近约 200 根,数据来自行情接口、没进仓库):

- **后一个高点更高就并段**,是为了把"从低点反弹途中的小停顿"并进同一次收缩。代价是基底右侧的一次真回撤也会被并掉:
  NVDA 5 月高点 236.5 → 7 月 190(19.8%)→ 8 月 227.9 → 207(约 9%)→ 9 月 234.8 → 209(11%),因为 9 月的高点高过 8 月,
  读成 19.8% → 11%、枢轴 234.76、临近枢轴。更严的读法是 20 → 9 → 11、不算收紧。两种读法都说得通;这里取前一种,
  并把回撤序列、枢轴摆在悬停里给人核对。PLTR 读成"只有一次回撤"(8 月底高点之后 12.6%),与图一致。
- **缩量不是成形的必要条件**:Minervini 要最后一次收缩缩量,但缩量的判断(低于 50 日均量 80%)很粗,硬卡会漏掉;
  所以没缩量的照样列出,结论里直接写「最后一次收缩没缩量」。NVDA 就是这种。

均线、摆动点都是自己写的几行代码(CLAUDE.md:不引技术指标库)。这是对一个看图形态的**机械近似**,
测试里用折线造的教科书形态钉住(三次收缩 20.8% → 11.1% → 5.7%)。真实 K 线上会有它认不出、或认错的基底,
所以界面上每一格悬停都给出回撤序列与枢轴,人自己看图核对。

## 大盘方向

- **派发日**:基准跌 ≥ 0.2% 且量比前一天大。25 个交易日后过期;之后收盘比那天涨回 5% 以上的也作废(IBD 的口径)。
- **调整中**:跌破 200 日线,或派发日 ≥ 6 个且离一年高点 6% 以上。
- **承压**:派发日 ≥ 4 个,或跌破 50 日线。
- 其余是**上升趋势**。
- 基准是 SPY / QQQ 这两只 ETF 的日线与成交量,是 IBD 看指数本身的近似,notes 里写明。

O'Neil 的统计是"四只股票里有三只跟着大盘走",Minervini 在大盘调整时把仓位降到很低甚至空仓——
所以大盘状态放在表的最上面,而不是最后一列。

## 排序

8 条过了几条 → VCP 状态(放量突破 > 临近枢轴 > 突破量不足 > 收缩中 > 不成形)→ RS 评级。拉不到日线的那一只自己带着错沉底,不拖累别的。
