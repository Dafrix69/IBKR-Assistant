# 强势股筛选

把实盘比赛优胜者公开过的选股规则逐条变成代码检查。RPC 是 `screener.leaders`(读道),界面在「扫描」页表格下面的「强势股筛选」,
和上面的 RS / 背离表用同一个股票池、同一个基准、同一份日线缓存。只用券商日线,不调模型;只陈述规则过没过,不给买卖建议。

## 规则从哪来

| 规则 | 出处 | 在这里怎么算 |
|---|---|---|
| 趋势模板 8 条 | Mark Minervini(美国投资锦标赛 1997 年冠军、2021 年以 334.8% 再夺冠) | 见下表,8 条全过 = 第二阶段上升趋势 |
| VCP 波动收缩形态 | Minervini | 基底里回撤一次比一次浅、最后一次缩量,放量越过枢轴 |
| RS 评级 | William O'Neil / IBD;David Ryan 用 CAN SLIM 三次获得美国投资锦标赛冠军 | 0.4 × 近 63 日涨幅 + 0.2 × 近 126 / 189 / 252 日涨幅,池内排百分位 |
| 放量新高 | CAN SLIM 的 N(新高)与 S(供需) | 收盘创 52 周新高且量 ≥ 50 日均量 1.5 倍 |
| 大盘方向 | CAN SLIM 的 M;IBD 的派发日 | 基准在不在 50 / 200 日线上、近 25 个交易日的派发日 |

CAN SLIM 的 C(当季盈利增长)、A(年度盈利增长)、I(机构持仓)要财报与持仓数据,券商日线给不了;表下面的说明每次写明。

## 趋势模板

| # | 条件 | 算法 |
|---|---|---|
| 1 | 价在 150 日线与 200 日线之上 | 简单均线,最后一根收盘 |
| 2 | 150 日线在 200 日线之上 | |
| 3 | 200 日线上行至少 1 个月 | 与 22 个交易日前比;另数出连续上行了几个月(最多数 5),Minervini 说最好 4–5 个月 |
| 4 | 50 日线在 150 与 200 日线之上 | |
| 5 | 价在 50 日线之上 | |
| 6 | 比 52 周低点高 30% 以上 | 取《股票魔法师》的口径(新书放宽到 25%) |
| 7 | 离 52 周高点 25% 以内 | 52 周 = 最近 252 根的最高价 / 最低价 |
| 8 | RS 评级 ≥ 70 且跑赢基准 | 有 RS 评级的成员不到 10 只时,只看加权涨幅有没有跑赢基准 |

- 数据不够的那条是「判断不了」(不够 200 根算不出 200 日线、不够 253 根算不出 RS),界面画成空心点,不算过也不算没过;
  第二阶段要求 8 条全部是过,所以新股进不了第二阶段,这是规则本意。
- RS 评级是**池内百分位**,IBD 用的是全市场排名:扫 8 只股时第一名就是 99,池子越大越接近原意。

## VCP

1. 从最近 130 根里找最高点当基底起点;最高点离现在不到 6 根 = 还贴着新高,没有形成基底。不到 60 根日线不判定。
2. 起点之后的摆动高点(左右各 3 根都不比它高)依次切段,每段的最低点算一次回撤深度。
3. 并段:后一个高点不低于前一个时,前一段只是基底里的一截,并掉;比 1.5% 还浅的回撤当噪音并掉。
4. **成形** = 至少两次回撤、一次比一次浅、第一次不超过 50%、最后一次不超过 15%。
5. **枢轴** = 最后一次回撤开始时的高点。**缩量** = 最后一次回撤的均量低于 50 日均量的 80%。
6. 状态:收盘越过枢轴且量 ≥ 50 日均量 1.4 倍 = 放量突破;越过但量不够 = 突破量不足;在枢轴下方 5% 以内 = 临近枢轴;更远 = 收缩中。

- 后一个高点更高就并段,是为了把从低点反弹途中的小停顿并进同一次收缩;代价是基底右侧的一次真回撤也会被并掉
  (例如 20% → 9% → 11% 会读成 20% → 11%)。回撤序列与枢轴放在悬停提示里给人核对。
- 缩量不影响是否成形:缩量的判断很粗,硬卡会漏掉,没缩量的照样列出,结论里写「最后一次收缩没缩量」。
- 均线、摆动点都是自己写的几行代码。这是对看图形态的机械近似,真实 K 线上会有认不出或认错的基底,所以界面每一格悬停都给出回撤序列与枢轴。

## 大盘方向

- **派发日**:基准跌 ≥ 0.2% 且量比前一天大。25 个交易日后过期;之后收盘比那天涨回 5% 以上的也作废。
- **调整中**:跌破 200 日线,或派发日 ≥ 6 个且离一年高点 6% 以上。
- **承压**:派发日 ≥ 4 个,或跌破 50 日线。
- 其余是**上升趋势**。
- 基准用 SPY / QQQ 两只 ETF 的日线,是 IBD 看指数本身的近似,说明里写明。大盘状态放在表的最上面:O'Neil 统计四只股票里有三只跟着大盘走,
  Minervini 在大盘调整时把仓位降到很低。

## 成交量从哪来

四条规则要看量:缩量(最后一次收缩的均量低于 50 日均量的 80%)、放量突破(≥ 1.4 倍)、放量新高(≥ 1.5 倍)、派发日(量比前一天大)。
日线走 `MarketDataService.dailyHistory` → 券商的 `historicalBars`,每根都带当天的成交量:

- **IBKR**:股票与 ETF 取 `ADJUSTED_LAST` 日线,`@stoqey/ib` 给的每根 K 线里的 `volume` 原样带出来。
- **富途**:`K_DAY` 历史 K 线的 `volume` 列。
- **指数没有成交量**:IBKR 对指数的日线回 −1,记成 0。量是 0 时缩量是「判断不了」,越过枢轴只算「突破量不足」,放量新高与派发日都不成立。

量只拿同一只股自己的日线互相比较(对 50 日均量、对前一天),券商报的是股数还是手数不影响结论。
盘中最后一根是当天还没走完的那根,量只算到此刻,却和完整交易日的 50 日均量比较,所以收盘之前放量突破、放量新高、派发日都偏保守;
日线缓存 10 分钟。缩量只看最后一根之前的那些,不受影响。
IBKR 的 `ADJUSTED_LAST` 日线是否带量还没在真机上核对:盘中运行 `npm run probe -- --steps bars`,看报告里带量的日线根数大于 0、最后一根是当天。

## 排序

8 条过了几条 → VCP 状态(放量突破 > 临近枢轴 > 突破量不足 > 收缩中 > 不成形)→ RS 评级。拉不到日线的那一只带着错误沉底,不拖累别的。
