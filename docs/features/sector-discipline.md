# 板块提醒中的交易纪律

板块联动、个股异动、开盘后复核与09:25时段提醒描述观测事实,同时提示确认、退出计划与风险预算。板块页的「提醒后的交易纪律」可展开查看六项说明及固定历史样本的适用范围。个股异动的弹窗、系统通知退路与订单看板通知流共用简短纪律提示,原始异动记录保持观测内容。

## 提醒口径

- 原板块联动的涨跌阈值、占比、最低只数、频率及通知开关不变。提醒线只代表观察条件,不预测开盘反转,不推断消息是利好或利空。
- 当前输入是相对昨收的价格快照。正文明确未作5分钟收盘确认;不把一次触及或当前仍有涨幅写成连续守住。
- 盘前集体上涨和下跌都记录最近一次触发时的板块中位,保存实际参与该中位数的去重成分股。美东10:00—10:30同组股票均有新鲜行情时复核一次;缺任意一只则等待,超过窗口不补报。不能用缺失部分成分股后的中位数替代原组。
- 上涨侧当前中位≤盘前中位的一半为「已回吐至少一半」,否则「当前仍保留过半盘前涨幅」;下跌侧当前中位≥盘前中位的一半为「已收回至少一半」,否则「当前仍保留过半盘前跌幅」。零或非有限基准不能判断。
- 两次快照比较并不代表5分钟收盘确认、持续10分钟守住或可以按该价成交,也不是对利好消息反应的归因。

## 六条纪律

1. 涨跌幅只作观察条件,股票、主题与时段分别判断。
2. 长影线只算触及;恢复程度用已完成K线核查。确认后入场的收益未验证。
3. 入场前明确目标、失效价、最迟退出时间;不因浮盈消失或亏损延长计划。
4. 夜盘、盘前、正盘分别评估,跨09:30重新审查原假设。
5. 先定计划损失预算再估仓位,同板块合并风险,亏损后不增加总风险。
6. 核对价差、可成交量与费用,优先限价并接受未成交,不把历史最高价触及视为自己的成交。

纪律为提示文字,没有开仓、平仓、修改订单或调整风控限额的路径,也没有可勾选的「已确认」状态。没有新增行情订阅;当前板块监控未计算夜盘自身涨跌、5分钟收盘或10分钟连续守住。价格阈值与50%复核都是观察分类,不是定价参数、预测概率或自动退出线。

## 研究依据与局限

固定TWS历史价格样本覆盖2025-03-25至2026-10-23:28只主题股、396个交易日、11,054个股日,不是完整两年,也没有严格按历史市值筛选小盘股。股票池事后选择且存在存活者偏差。

夜盘跌≥3%且盘前终点有效的205个股日中,161次曾触及收回一半跌幅(78.5%),52次在盘前结束仍达到目标(25.4%)。四项总体方向统计的按日期聚类95%区间均覆盖50%;同日多股不是独立事件。固定历史个股比例不作为实时板块联动的条件概率,没有新闻标签,也没有成交成本后的盈利验证。

原始行情与完整研究保留在项目`data/tws-extended-hours/`,不打包、不提交原始行情。复核出处为`reports/2026-10-27-cached-analysis/summary.json`和`reproducibility.json`;应用只含固定摘要与纪律文字,不依赖该本地报告文件才能显示。

延长交易时段的价差与成交限制参考[SEC说明](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-42)。

## 代码与验证

`shell/event_rules`保存摘要、纪律与对称复核纯函数;`shell/events_store`记录同组快照并沿用现有提醒通道;`shell/feed_stores`为个股异动附加简短纪律;`shell/sectors_controller`以CONSTANT属性提供固定纪律模型,`app/pages/SectorsPage.qml`展示折叠说明,行情刷新不重建说明列表。

`tst_event_rules`验证上涨/下跌对称边界、无效基准和观察口径;`tst_events_store`通过假引擎验证缺失成分股不误判、恢复行情后只报一次;`tst_shell`使用隔离用户目录与预览引擎检查板块页折叠与展开两种状态。相关7组离线测试通过,应用目标在Windows Debug下可编译;全量工程验证仍有其他模块的编译错误、测试失败及缺失可执行文件。测试不连接券商;尚未在实时板块行情上验证。

事件文案基线采用事实与纪律口径,复核标题标明当前快照及一半边界,不含未经验证的「利好大概率回吐」因果判断。
