# 界面

侧栏三组、13 项,按"多久用一次"分层:

- **工作区**(每天要点的)
  - **交易指令** — 输入框(⌘Enter 解析)与解析结果并排;「解析并校验(不下单)」/「发送到 IBKR / 富途」两个按钮,
    结果卡片含通过 / 排队 / 拒绝 / 警告与本次调用的模型、耗时、token 用量
  - **订单看板** — 「排队等待触发」与「已提交」分列(§8.2b),下方是实时通知流;侧栏项带排队数徽标
  - **交易记录** — 可筛选列表与完整详情、数据导出
  - **持仓追踪** — 券商账户里的实际持仓,按仓位配止盈 / 止损 / 跟踪 / 利润回撤,到价自动平仓;这一页会真的发单
- **研究**
  - **行情** — 一页三个子页:**K线 PA**(实时 K 线 + 价格行为读盘,判断由代码算、权重公开,见专门一节)、
    **订单簿**(深度梯子,只读)
  - **想法** / **板块** — 随手记与 AI 分析;自定义板块与 AI 选股(每只股带一个**业务标签**,如"芯片""数据中心",
    AI 选股自动给,行上点胶囊可改)。**价位提醒**住在板块页里:盯了的股在成分股行下面
    画一条价位条(期权墙、20 / 60 / 120 / 200 日线、52 周位、整数关口与现价摆在一条横线上),穿越时响铃 + 系统通知
  - **扫描** — 对股票池(板块成分股)做批量复盘,一页三个子页,数字全由引擎纯函数算(`screener.ts`,黄金对拍):
    **RS 强度**(1 周 / 1 月 / 1 季 / 半年 / 1 年五个区间对 SPY 或 QQQ 的相对强度,再按业务标签汇总中位数与跑赢家数)、
    **拐点筛选**(周线 / 日线 / 1 小时 / 30 分 / 15 分上找左侧 **CD 背离**——CD 指 MACD 快线 DIF,价格新低而 DIF 抬高为底背离、
    反之顶背离,可选右侧均线确认:背离后收盘穿过指定均线且站稳才算「已确认」)、
    **极值偏离**(逐只翻看:每根 K 线的**修正版买卖压力**——收盘在含前收盘的真实区间里的位置、按相对量加权、EMA 平滑——
    与**偏离程度**——收盘相对均线的百分比折成近段历史的 z 分数,|z| ≥ 2 标为极值)。只读研究,不下单
  - **回测** / **交易分析** — 日线策略回测;蝴蝶成交复盘与止盈策略回放
- **应用**(沉底)
  - **接入** — 一页三个子页:TWS、富途 OpenD、大模型
  - **设置** / **关于**

顶栏常驻:美东时间、市场状态、模型、网关连接状态(按生效的券商显示 `TWS` 或 `OpenD`)、
当前模式,以及**「暂停全部自动执行」熔断按钮(⌘⇧H)**——§9.7 要求的那个总闸。

界面结构参照 Apple Design Resources 的 macOS UI Kit 应用模板:**统一工具栏 + 源列表侧栏 +
内容区**。选中项为强调色填充(窗口失焦退灰),图标是按 SF Symbols 几何手绘的内联 SVG
(描边 1.4,`currentColor`,不引外部字体,CSP 依旧只允许 'self');窗口窄于 1000px 时侧栏收成图标栏。

## 视觉底子:按 macOS HIG 来

- **系统字体与字号层级**(正文 13px / 说明 11px),不自造字号
- **系统语义色**(systemBlue/Red/Green/Orange),浅色 `#007AFF`、深色 `#0A84FF`
- **跟随系统深浅色**——桌面应用不该强制一种外观
- **材质**:窗口开 `vibrancy`,界面用半透明底让模糊透出来;工具栏 `hiddenInset` + 拖拽区
- **AppKit 风格控件**:胶囊分段控件、开关(不是复选框)、System Settings 那种内嵌分组列表
- 0.5px 发丝分隔线、10px 圆角、克制的阴影

半透明只是装饰,不是可读性的前提:**macOS 打开「减弱透明度」辅助功能、或在 Windows 上没有
vibrancy 底材时,自动切换成实底**(`prefers-reduced-transparency` + 非 darwin 平台的
`data-vibrancy="off"`)。这一条是实测发现的——在没有底材的环境里,半透明面板背后是空的,
文字对比度会直接塌掉。

## 两个平台各按各的规矩

原来这套界面是照 macOS HIG 一路做下来的,跑在 Windows 上就露了馅。搭了个
[界面预览台](../../desktop/tools/README.md)之后才看得见问题——之前根本没法给 Electron
窗口截图,UI 只能盲改。

**被量出来的一个真 bug**:`.shell` 写的是 `height: calc(100% - 52px)`,把工具栏高度
硬编码了,而工具栏下面还有一条宏观行情带。于是壳层比可用高度多出 27px,**侧栏最底下
那一项和内容区底部被裁掉**——窗口越矮越明显。现在改成 body 竖向 flex + `flex: 1`,
高度由布局自己算。

**窗口按钮在哪一侧,两个平台正好相反。** macOS 的红绿灯在左上,所以工具栏左边留了
88px;Windows 的最小化/最大化/关闭在右上,那 88px 就成了纯浪费,而右边的按钮会被系统
按钮压住。现在 macOS 继续 `hiddenInset`,Windows 改用 `titleBarStyle: 'hidden'` +
`titleBarOverlay`——把系统按钮直接画在应用自己的工具栏右侧,省掉一整条原生标题栏,
也没有"一个应用两条栏"的割裂感(VS Code、Teams、Edge 都是这个做法)。叠加层的配色
跟着深浅色重画,否则浅色主题下会画出一组看不见的白色按钮。

**字体栈原来在 Windows 上会一路 fallback 到 Arial**:`-apple-system` → `SF Pro Text`
→ `PingFang SC` 全都解析不到,中文再退到另一套字库,字重和西文对不上。补上
`Segoe UI Variable Text`(Win11)/ `Segoe UI`(Win10)和 `Microsoft YaHei UI`。

**`cursor: default` 是 macOS 的规矩**,Windows 用户看到不变的箭头会以为点不动——
非 darwin 平台给按钮、导航项、记录行换回 `pointer`。

**快捷键要显示这个平台上真实存在的键。** 界面上原来画的是 `⌘⏎`,Windows 键盘上没有
这个键;现在按平台渲染成 `Ctrl+Enter`。监听端本来就是 `metaKey || ctrlKey` 和
`CommandOrControl`,功能一直是对的,错的只是标签。

## 界面上的券商名也跟着切

和引擎侧那次"文案平替"是同一类问题,只是这次在按钮上:切到富途之后,主按钮还写着
**「发送到 IBKR」**,而单子实际会发到富途——这种不一致在下单界面上是会出事的。现在
按钮、快捷键提示、执行条件说明、二次确认弹窗里的券商名都跟着 `broker_provider` 走。

顺带修掉:交易记录里的在途状态原样显示券商的英文枚举(`Submitted` / `PreSubmitted`),
终态翻了、在途没翻,同一列中英夹杂——而这恰恰是最常扫的一列。

## 密度与层次

- **卡片和页面原来是同一个背景色**,只靠一条 0.5px 边框区分,深色下几乎看不出来。
  拆出 `--bg-elevated`,卡片真的浮起来一层。
- **页头吸顶**:列表一长,标题和旁边的「导出 / 清空」就滚没了,想点还得先滚回去。
- **顶栏状态条不再换行**:栏高写死 52px,一换行第二行直接被裁掉,显示成半个词。
  改成不换行,窄窗口下按重要性**整颗**丢弃(时间和模型可以没有,连接状态和模式不能)。
- **数字用等宽字形**:价格、数量、时间竖着排要能对上位。
- **列表时间收紧**成 `08-21 21:41`(当天只显示时分),完整时间放 tooltip——年份在
  列表里没有信息量,却挤掉了后面的账户标签。

## 键盘与读屏

侧栏原来是一排普通 `<button>`,读屏软件只会念出"八个按钮",既说不出这是导航,也说
不出当前停在哪一项。补上 `role="tablist"` / `aria-selected`,并让**方向键**在项之间
走(Home / End 跳到首尾)——这是所有成熟应用侧栏的标准行为。焦点环原来只有开关有,
现在所有可交互元素都有;另外尊重「减弱动态效果」。

## 第二轮:去掉"后台感"

第一轮把 token 建对了(系统字号、语义色、发丝线、圆角),但实际渲染出来仍像一个深色的网页后台。
对着 Notes / Mail / Finder / System Settings 并排看,差的不是 token,是几条用法:

- **颜色只落在一个点上。** 顶栏状态原来是三颗彩色填充胶囊(绿「已连接」、橙「仅纸面」、绿「盘中」),
  现在是 8px 圆点 + 常规文字,颜色只在圆点上;记录列表的「已成交 / 被拒」和「买入 / 卖出」也从填充胶囊
  改成只着色文字;提示条不再整块染色。Apple 的工具栏和列表里没有彩色填充块——三种颜色并排抢焦点,
  正是"后台管理系统"的观感来源。
- **卡片没有彩色左边条。** ok / warn / bad 改成标题前一枚 16px 圆标(✓ / ! / ×),和 System Settings 一致;
  「还差 N 步」块去掉橙条,成为内嵌分组列表。
- **层次靠亮度阶梯。** Windows 没有 vibrancy,原来侧栏(#1e1e20)与内容区(#222225)几乎同色,糊成一片。
  深色实底改为窗口底 #2b2b2e / 内容区 #1e1e20 / 卡片 #2f2f33,参照 Notes 深色侧栏≈#2c2c2e、正文≈#1e1e1e。
- **源列表度量。** 侧栏项行高 28、左右内缩 10、圆角 5(Finder / Notes),不再贴着侧栏边。
- **分段控件按内容宽,且只有一种。** 记录页的状态筛选原来是一排独立胶囊、密度切换是两个普通按钮,
  现在和设置页的「跟随系统 / 浅色 / 深色」同款。
- **涨跌色成对做成 token**(`--up` / `--down`),图表里 54 处硬编码的深色十六进制全部改走它——浅色模式下
  `#30D158` 在白底上本来就对比度不足。顺带做了「涨跌配色」设置(绿涨红跌 / 红涨绿跌),是显示偏好,记在本地。
- **焦点环只有一种**(3.5px、强调色 30%,AppKit 的样子)。顺带发现 `--accent` 从未被定义,引用它的焦点环
  和悬停色一直是失效的。

宏观行情带全部无数据时整条收起;「暂停自动执行」常态是普通按钮,已熔断时才红——常红会被读成"一直在告警"。
这些决定与截图对比记录在 `docs/reports/desktop-optimization-report.md`。

## 第三轮:把"成熟产品"差的那几毫米补上

前两轮之后,壳和图表已经对了;再对着 Mail / Stocks / System Settings 并排看,剩下的差距都在"用法的一致性"上,
每一条单看都小,加起来就是"像不像"的分水岭:

- **元数据是文字,不是胶囊。** 卡片底下那行"时间 · 账户 · 金额"原来每一项都是一颗灰色圆角胶囊,
  一页几十颗——这是继彩色胶囊、左边色条之后"后台感"的第三个来源。Apple 的列表里这些都是直接写出来的
  二级色文字,现在也是;`.status`(已成交 / 已挂单 / 校验拒绝)一并收成着色文字,不再有底。
- **文字着色用"可访问"变体。** systemGreen / Red / Orange 是给圆点、开关、图表用的,直接当 11px 文字放在白底上
  对比度只有 2–3:1,浅色模式下"已成交"几乎看不清。Apple 自己为此备了一套变体(#248A3D / #D70015 / #C93400),
  现在做成 `--green-text / --red-text / --orange-text` 与 `--up-text / --down-text`,规矩是:**文字一律用 `*-text`,
  基础色只用于面和图**。顺带修掉:盈亏数字原来钉死绿红,没有跟随「涨跌配色」——设置页的说明写的是"统一跟随"。
- **颜色只留给要一眼看见的东西。** 纸面账户标签原来是绿色等宽字——纸面是常态,不该发光;现在是二级色文字,
  只有实盘账户、券商托管、自动平仓已开这类"会动真钱"的标签用橙色。
- **界面文案里不出现配置键名。** 「发送条件:`auto_execute` 已开 … 实盘另需 `allow_live_trading`」这种话是给
  写配置的人看的,用户看到的是"自动执行已打开 · 已连接 OpenD · 未熔断;实盘账户还需在「设置」里允许实盘下单";
  看板里的 `BUY 2 NVDA` / `SPY >= 775` 也翻成"买入 2 NVDA" / "SPY ≥ 775"。
- **说明文字有行长。** 11px 的说明一行跑满 1100px 是一百个汉字,回行时眼睛会丢行;现在收在 760px 以内。
  内嵌分组列表里的说明行(回测的策略描述)补了和其他行一样的内边距——它原来贴着左边框。
- **同一件事只有一种控件。** 想法页的「进行中 / 全部」原来是两个普通按钮靠 ghost 样式区分,
  现在和记录页、设置页一样是分段控件;速记片段从 999px 胶囊改成 6px 圆角的填充 token(Mail 收件人那种);
  列表行悬停只提亮底色,不再描蓝边。
- **第一眼只看到要操作的东西。** 每一页开头原来都有一段两到六行的 11px 说明(数据从哪来、规则是什么、
  不接下单链路……),它们对第一次来的人有用,对每天来的人是每次都要跳过的一堵墙,而且把输入框和主按钮
  往下挤。现在这些说明收成一行三级色的折叠项(「数据来源与判断方式」「价位从哪来、什么时候报」……),
  和已有的「读盘常识」「连不上时照着做」同一机制,点开的状态按页记住。交易指令页同理:速记片段常驻一行
  (不展开也能点),规则、默认值和发送条件收进默认折叠的说明;「这一页会真的发单」这种安全警告不收。
- **侧栏按"多久用一次"分三层。** 原来 16 项分四组平铺,"研究"组塞了 8 项,持仓追踪这种会真发单的页混在研究里,
  TWS / 富途 / 大模型三个配一次就不常来的页各占一个常驻位。现在是 12 项三组:**工作区**(交易指令、订单看板、
  交易记录、持仓追踪)、**研究**(行情、想法、板块、回测、交易分析)、**应用**(接入、设置、关于,沉底)。
  三个盯行情的工具(K线 PA、订单簿、期权墙)合成「行情」一页,三个接入页合成「接入」一页,进去后在页头的
  分段控件里切子页,上次看的那个子页记住。组标题可折叠;快捷键或就绪清单跳到折叠组里的页时自动展开。
  16 个页面一个没删,`tab-<id>` 与页内所有 id 不变,`.tab[data-tab="tws"]` 这样的跳转照旧能用——子页按钮和侧栏项
  是同一种 `.tab`。
- **持仓追踪的表单默认收起。** 十个字段(止盈、止损、两种跟踪、分档、比例、方式、托管…)原来摊在每张持仓卡片里,
  两只持仓就是两屏表单。现在卡片只有持仓与盈亏,点「设置追踪」才展开,一次只展开一张——设置的对象就在眼前这张卡上。
- **K线 PA 的结论从九行散文变成两列。** 引擎的 readout 本来就是"结构:…／最近结构事件:…／确认条件:…"这样的字段句,
  界面把它们拼成了一段话;现在拆成左列字段名(二级色)、右列结论,和记录详情那张"单据"同一做法。首句总括和拆不开的行原样保留,
  界面不替引擎改写结论。
- **价位提醒住进板块页,价位条摆在成分股行下面。** 期权墙提醒原来是一个独立页,盯的股和板块里的股是两份清单;
  现在提醒的管理(盯谁、响不响、最近触发)是板块页底部的一节,成分股行右侧一个「盯」,盯了的股在行下面画一条
  **价位条**:期权墙(持仓墙 / 成交墙 / 最大痛点 / Gamma 翻转)、20 / 60 / 120 / 200 日线、52 周位、整数关口和现价
  摆在一条横线上,阻力在上、支撑在下,离现价多远一眼可见。标签按真实像素量宽度后分层(最多三层),卡片再窄也不叠。
  20 日线是这次加到引擎里的(`DEFAULT_MA_PERIODS` 两侧同步为 20/60/120/200,黄金基线重生成)。
- **数字键切页、窄窗口图标栏、失焦退灰。** Ctrl/⌘ + 1…9 按侧栏顺序切页;窗口窄于 1000px 时侧栏收成 56px 的图标栏
  (最小窗宽从 1080 放到 900);窗口失焦时侧栏选中项从强调色退成灰(主进程转发 focus / blur,和 AppKit 源列表一致)。
  顺带:交易分析不再和回测共用图标;接入页端口卡片上的 `配置:live` 改成"配置为实盘";K 线均线降到 70% 透明。
- **图区近黑。** 深色下蜡烛图的底色原来就是卡片的灰(#2f2f33),蜡烛和网格都浮在灰上没有对比;
  iOS「股市」和富途夜间的图区都比周围暗得多。现在图区是 `--chart-bg`(#0b0b0d),8px 圆角嵌在卡片里,浅色下是白。
- **三处从未生效的样式。** 持仓追踪的"离触发还有多远"量表条引用的 `--line / --ok / --warn / --bad` 从未定义过,
  条一直是透明的;速记区的 `--text-secondary / --text-primary` 同样不存在;「发单账户」那行的 `display:flex`
  盖掉了 `[hidden]`,单账户时本该整行消失却一直露着一个标签。这类问题截图看不出"有什么",只看得出"少了什么",
  所以又跑了一遍交互态(紧凑列表、记录详情、追踪卡片)的截图。

## 按可用性启发式过了一遍

有了[预览台](../../desktop/tools/README.md)之后又做了一轮,这次不是看好不好看,而是逐条对
Nielsen 那十条可用性启发式。另外配了一份**首次启动的数据源**(`tools/mock-bridge-empty.js`)
——什么都没配、什么都没连、一条记录都没有。这是新用户唯一会看到的状态,也是开发时最少
看到的状态:手上有数据的时候一切都好看,空的时候才知道哪里缺引导。

**「还差 N 步才能开始」。** 新用户打开软件落在「交易指令」页,而这一页在没配 API Key、
没连券商之前什么也做不了——原来唯一的线索是按钮下面一行灰色小字。现在缺什么列什么,
每条直接跳到能解决它的那一页;必要条件都满足就整块消失。它是状态,不是唠叨,所以刻意
**没做成可以永久关掉的横幅**——关掉只会让人更找不到问题在哪。

同理,「发送」按钮为什么点不动,鼠标停上去说得出来了(未打开自动执行 / 未连接 / 已熔断)。
禁用而不说明原因是最招人烦的一种交互。

**记录详情原来是一坨 JSON。** `JSON.stringify(record, null, 2)` 是开发者视图。而记录是
这个软件的核心产物(§6 每一笔从提交到终态都落库),用户想知道的是:发了什么、走到哪一步、
成交在什么价、模型花了多少钱。现在是一张单据:这笔单 / 合约 / 订单 / 成交 / 模型 /
**状态时间线** / **成交明细表**。原始 JSON 没删,收进折叠区——这个项目在意可审计性,
那份原文要留得住。

**内部枚举不再漏给用户。** `OPT` / `BUY` / `LMT` / `EXPLICIT` / `DAY` / `Submitted` 这些
是协议里的取值,不是给人看的词。现在统一翻译,翻不过来的原样显示——露一个英文,好过编
一个错的中文。买卖方向另外着色,那是扫列表时最先看的字段。到期日从 `20260821` 变成
`2026-08-21`。

**回测参数原来叫「参数 fast」「参数 buy_below」。** 用户得自己猜 buy_below 是买入线还是
买入下限。参数名是策略定义的一部分,所以中文名加在引擎侧的 `STRATEGIES` 里和策略写在
一起,界面认不出就退回原名——而不是散到界面里去维护一份会和引擎失配的表。

**交易记录能按状态筛了。** 翻记录时最常问的是"哪些成了、哪些还挂着、哪些被拒了",而原来
只有一个关键词框——想看被拒的单得先记住"校验拒绝"这四个字。每一档带条数,空的档位直接
禁用,省掉一次白点。

**长操作会转圈。** 解析一条指令要 2 到 60 秒,握手诊断 8 秒。原来只是把按钮置灰、换一行
文字,用户分不清"在跑"和"卡死"。

**横幅会自己消失。** 提示类 6 秒后走,错误类留着等人看,两者都点得掉。永远挂在那里的
横幅,过几分钟就没人再看它一眼。

**键盘。** `Esc` 收起打开的记录详情——打开了一个面板却没法用键盘关掉,是最基础的一条
"用户控制权"缺失。注册在案的快捷键有四个,界面上原来只提过一个,现在「关于」页有完整
一览,按平台渲染真实键名。

**读屏与标签。** 18 个输入框看着有标签,但那个 `<label>` 没有 `for`——读屏软件只会念
"一个数字输入框",点标签也不会聚焦到输入框(所有原生表单都有的行为,少了会让人觉得
这个界面"怪怪的")。这类问题人眼一页页看很容易漏,所以写了
[`tools/audit_ui.js`](../../desktop/tools/audit_ui.js) 让机器扫:无名按钮、无标签输入、
引用了不存在的 DOM id、界面文案里漏出来的内部枚举。

**交易记录给了密度切换。** 之前在"卡片流"和"密集表格"之间纠结过:表格扫得快,但塞不下
`intent_summary` 和 `reason`,而那两段恰恰是这个软件区别于普通下单终端的地方(自然语言
交易)。答案不是二选一——**舒适**保留意图和理由,适合回看"我当时在想什么";**紧凑**
一行 28 像素、时间/标的/方向/意图/状态列对列,适合扫"哪笔出了问题"。选择记在本地。

(实现上有个坑值得记:紧凑模式用 grid 排版时,DOM 顺序和列顺序不一致会让 grid 的自动
排布把靠后的元素甩到第二行——行高从 28 变回 100,"紧凑"就白做了。所以行列都写死。)

**顶栏按"要不要马上处理"重排。** 工具栏的位置很贵,只该留会变、且变了要处理的东西:

* **时间和市场时段合成一格**——时间之所以要看,正是因为它决定了现在是盘前还是盘中;
  拆成两格既占位又要读两遍。只留时分,秒在这里没有决策价值却让这格每秒都在跳。
* **模型名是配置不是状态**,一个月不变一次却占着最宽一格。降级成背景色小字,完整名进
  tooltip,窄屏第一个丢的就是它。
* **券商连接和执行模式挪到最左**——前者会断,后者是安全闸门,它们才是要盯的。

**参考资料按需展开。** 三块常驻的教学内容(「读盘常识」和两处「连不上时照着做」)第一次
来的时候是救命的,连上之后就成了每次都要滚过去的一堵墙。处理原则不是"藏起来",而是
**需要它的那一刻自动展开**:没连上时指引默认打开、连上就收起;订单簿还没关注标的时常识
默认打开、加了标的就让路。手动点过一次之后就记住用户的选择,不再自动改——自动化可以
帮忙猜第一次,但不该反复推翻用户的手动操作。

**开机即可打字。** 主输入框是整个软件唯一的入口,原来每次都要先用鼠标点一下。现在启动时
和切回该页时都自动聚焦。

**列表里的时间统一成紧凑格式**(`08-21 21:41`,当天只显示时分),完整时间进 tooltip。
详情页的「提交时间」和状态时间线保留完整格式——那里正是要看准确时刻的地方。

**残缺负载不该让整页塌掉。** 设置页原来是 `settings.policies.auto_execute` 直接点进去,
少一个字段就整页空白 + 一句 JS 报错。现在缺什么空着那一格,其余照常可用。
