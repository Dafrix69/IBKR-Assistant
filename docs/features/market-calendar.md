# 内置休市日历

2026-09-28 加的。`engine-ts/src/marketCalendar.ts`,纯函数,零依赖,不读时钟。

## 为什么要有

配置里的 `market_holidays` / `early_close_days` 是一张手写的表,示例只写到 2026 年。表里没有的年份,
每个工作日都算交易日——从 2027 年元旦起,这几处会在每一个假日悄悄错一次:

- 「休市不发市价单」的策略(`closed_market_policy`);
- 期权到期日是不是交易日的校验;
- 顶栏的市场状态、提前收盘日的收盘时刻(盯异动按它算时段进度、价位提醒按它算收盘);
- 碰均线的"前一个交易日"。

卖出去的软件不能靠用户每年记得去补一张表。

## 口径

休市日 / 提前收盘日 = **配置里写的 ∪ 内置日历**。

| 项 | 取值 | 为什么 |
|---|---|---|
| 规则算得出来的十个假日 | 元旦、马丁·路德·金日、华盛顿诞辰、耶稣受难日、阵亡将士纪念日、六月节、独立日、劳动节、感恩节、圣诞节 | NYSE 的规则 |
| 周末的假日 | 周六提前到周五,周日顺延到周一 | 同上 |
| 元旦落在周六 | **不补休** | 周五是上一年的最后一个交易日(NYSE Rule 7.2)。2022、2028 年都是这样 |
| 六月节 | 2022 年起 | 那一年才成为交易所假日 |
| 提前收盘(美东 13:00) | 感恩节次日;平安夜(12 月 24 日是交易日时);7 月 3 日(落在周一到周四时) | 同上 |
| 已经发生过的临时休市 | 一张写死的表(9·11、国葬、飓风桑迪) | 规则算不出来;只影响复盘里的历史日期 |
| 以后的临时休市 | 写进配置 | 规则算不出来,配置里写的永远算数 |
| 覆盖年份 | 2000–2060 | 早于它的只在复盘里出现 |
| `"market_calendar": "config_only"` | 退回只认配置 | 交易所改了规则、而软件还没更新时的出路 |

为什么是并集而不是"配置里有这一年就只认配置":用户为 2027 年补一个临时休市日,不该让那一年别的假日全部失效。

并集是在加载配置时算好、直接放进 `settings.market_holidays` / `early_close_days` 的。
钱路径上的代码(`broker.ts`、`validator.ts`)读的还是那两个数组,一行没动。

## 对黄金基线的影响

没有。基线的配置里只写了 `2026-09-07` 与 `2026-11-27`,并上内置日历之后 2026 年多出九个假日——
全套基线跑下来没有一处变化(那些日期上没有用例)。

## 钉住它的测试

`tests/market-calendar.spec.ts`。对的是交易所公布过的日历,不是对着实现抄一遍规则:2026 年那一张就是示例配置里
手写的那张(逐日相同);2022–2025 是已经过完的年份;2027、2028 是示例没写到的。另有一条遍历 2000–2060:
休市日都落在工作日、一年八到十三个、既休市又提前收盘的一个没有。
