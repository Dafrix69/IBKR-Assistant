# 内置休市日历

美股的休市日与提前收盘日按交易所规则计算(`engine-ts/src/marketCalendar.ts`,纯函数、零依赖、不读时钟),和配置里手写的
`market_holidays` / `early_close_days` 取并集。用户不用每年去补一张表。

用到它的地方:休市不发市价单的策略(`closed_market_policy`)、期权到期日是不是交易日的校验、顶栏的市场状态、提前收盘日的收盘时刻
(盯异动按它算时段进度、价位提醒按它算收盘)、碰均线的"前一个交易日"、蝴蝶测算与 IV 记录的日程。

## 规则

| 项 | 取值 |
|---|---|
| 规则算得出的十个假日 | 元旦、马丁·路德·金日、华盛顿诞辰、耶稣受难日、阵亡将士纪念日、六月节(2022 年起)、独立日、劳动节、感恩节、圣诞节 |
| 落在周末的假日 | 周六提前到周五,周日顺延到周一 |
| 元旦落在周六 | 不补休:周五是上一年的最后一个交易日(NYSE Rule 7.2),例如 2022、2028 年 |
| 提前收盘(美东 13:00) | 感恩节次日;平安夜(12 月 24 日是交易日时);7 月 3 日(落在周一到周四时) |
| 已经发生过的临时休市 | 写死的一张表(9·11、国葬、飓风桑迪),只影响复盘里的历史日期 |
| 以后的临时休市 | 写进配置,配置里写的永远算数 |
| 覆盖年份 | 2000–2060 |
| `"market_calendar": "config_only"` | 只认配置;交易所改了规则、软件还没更新时用 |

取并集:用户为某一年补一个临时休市日,那一年别的假日照样有效。并集在加载配置时算好,直接放进 `settings.market_holidays` / `early_close_days`,
读这两个数组的代码(包括 `broker.ts`、`validator.ts`)不用改。黄金基线的配置只写了两个日期,并上内置日历之后基线没有变化(那些日期上没有用例)。

## 测试

`tests/market-calendar.spec.ts` 对照交易所公布过的日历:2026 年与示例配置里手写的那张逐日相同;2022–2025 是已经过完的年份;2027、2028 是示例没写到的。
另有一条遍历 2000–2060:休市日都落在工作日、一年八到十三个、没有一天既休市又提前收盘。
