# 富途 OpenD

IBKR 用不了时的备用券商通道。`FutuRouter`(`engine-ts/src/futuBroker.ts`)与 `BrokerRouter` 接口一致;
提示词、别名表、限额、校验、记录格式都不变,只换出口。配置里 `"broker": { "provider": "futu" }` 切换。

## 现状:适配桥在真机核对之前不可用

- `futuBridge.ts` 的 `loadFutuBridge()` 一律抛 `FutuUnavailable`(`bridge_unverified`)。所以握手诊断、连接引擎、交易解锁都会失败;
  能用的只有程序检测与端口探测。
- npm 的 `futu-api` 在引擎的 `devDependencies` 里,不随安装包发出去(它依赖的 protobufjs 6 有没有修复版本的安全通告)。
  装好的应用里富途面板显示「这个版本没有带富途的接口库」。
- 下文的差异处理都已在 `futuBroker.ts` 实现,有对着假桥的离线测试(`tests/broker-futu.spec.ts`);其中的真机结论来自已经删除的 Python 引擎
  (Python SDK 10.10),TS 这一侧从没连过真的 OpenD。
- **启用的步骤**:连着本机 OpenD,把 npm `futu-api` 的接口签名、返回列名、枚举取值逐一核对,先只读、不碰下单;核对完把 `futu-api` 挪回
  `dependencies`,在 `futuBridge.ts` 里接上。SDK 的日志只能写到 stderr:stdout 只传 RPC 协议,一行非协议输出就会让界面的解析出错。

## 切换

- 同一时刻只连一家。「接入 → 富途 OpenD」顶部切换,切换先把选择写进配置、再断开现有连接;顶栏的连接标识跟着从 `TWS` 变成 `OpenD`。
- 连接只能手改配置文件。面板从 `broker.catalog` 拿到该抄的配置片段并直接显示;切到一家没配连接的券商会被拒绝(−32006),报错里带着那段片段。
- 富途账号是一串数字,`U` / `DU` 开头的 IBKR 账号在下单、读持仓、同步订单时拒绝(`accId()`);连接时它只是不出现在会话的账户列表里。
- 按 `provider` 构造 router 的地方有两处:`cli.ts` 的 `buildRouter()` 与 `services/brokerLink.ts` 的 `makeRouter()`。
  盘口流动性等纯函数直接复用 `broker.ts` 的实现。

## 面板

| 分区 | 做什么 |
|---|---|
| 0 · 券商接入 | IBKR / 富途之间切换 |
| 1 · 程序 | 检测 OpenD 是否安装、是否在运行(富途版 `FutuOpenD`、海外版 `moomooOpenD` 都认);装了没开的可以一键启动 |
| 2 · API 端口 | 探测 11111 / 22222 与配置里的自定义端口,纯 TCP,不发协议帧 |
| 3 · 握手与账户 | 读回 OpenD 版本、行情与交易是否已登录、账户列表,核对别名是否对得上真实账号,逐行显示并标红 `is_paper` 与富途 `trd_env` 不一致的账户 |
| 4 · 连接引擎 | 建立引擎下单用的长连接 |
| 5 · 交易解锁 | 只有实盘需要 |
| 连不上时照着做 | 8 步指引,按实际配置显示端口,写明富途做不到的几件事 |

登录在 OpenD 自己的窗口里完成,本软件不接触富途账号密码。实盘的交易解锁密码只存系统凭证库,而且只存 md5:
界面填的明文在引擎里算完 md5 就丢,不进配置、不进日志,审计里只记服务名。

## 和 IBKR 的差异

| 差异 | 处理 |
|---|---|
| 没有组合单 | 价差 / 蝴蝶 / 铁鹰直接拒绝,不拆成单腿分别发:一条腿成交另一条没成交,就是裸头寸 |
| 没有原生条件单 | `SUPPORTS_NATIVE_CONDITIONS = false`,所有条件单进软件盯盘队列,软件必须开着 |
| 回报靠拉取 | `pollOrderUpdates()` 由 `pending.poll`(`Engine.syncBrokerOrders()`)拉订单与成交,包成和 IBKR 同形的对象走同一套入库;富途下界面与主进程在没有排队单时也发 `pending.poll` |
| 模拟盘不支持成交查询 | 按订单行的 `dealt_qty` / `dealt_avg_price` 增量合成成交,`exec_id` 标「(合成)」,不能用来做滑点归因;实盘走逐笔成交 |
| `is_paper` 要和 `trd_env` 一致 | 连接时读回每个账号的 `trd_env`,诊断里标红不一致的,下单前再核对,对不上拒绝;`is_paper` 是实盘闸门的输入 |
| 没有 2 分钟 K 线 | 最小 1 分钟,往上 5 / 15 / 30 / 60 分钟与日线;缺的周期拒绝,不用 1 分钟线合成 |
| 没有美股指数 | `quoteCapability()` 闸门:涉及 SPX / NDX / VIX / RUT 的报价、K 线当场拒绝,条件单在进队列之前拒绝,并给出可选替代(SPY / QQQ / IWM / VIXY),软件不替用户换标的;`symbol_map` 映射成 ETF 也绕不过去(闸门认配置里的 `index_symbols`)。期权链不挡 |
| 行情带的连续期货、指数、加密货币 | 一律跳过,七格走公开源 |
| 托管到券商 | 富途账户不能开 |
| 异动监控 | 只支持 IBKR |

**代码换算。** 普通美股按 `US.<代码>`。指数先看 `broker.futu.symbol_map` 的显式映射,没有就去富途的证券列表里查一次并缓存
(美股指数代码是双点的 `US..SPX`)。期权合约用期权链按到期日、行权价、看涨看跌反查代码,不自己拼。

## 期权墙在富途下怎么算

- 富途的美股期权行情是一份独立于股票行情的权限,没有它连期权链的到期日列表都取不到;引擎把这条错误单独说明,不笼统地说"没有行情权限"。
- 指数的期权链支持,缺的只是指数现价。现价由看跌看涨平价关系从链上反推:同一到期日所有行权价都满足 C − P = S − K·D(D 是折现因子),
  在行权价网格上取样,把 (C − P) 对 K 做最小二乘直线拟合,截距是现价 S,斜率的相反数是 D,利率和到期时间一起拟合出来。
  只看一个平值行权价、把 D 当成 1 会有几十点的系统偏差。
- 残差大(报价稀疏、深度虚值、混进别的到期日)、或 D 落在合理区间外时拒绝,不给一个看起来像样的错价。
- 反推的现价带 `spot_source: "parity"` 到界面,显示为「现价由期权链反推」。黄金用例(`baseline/golden/broker.json`,`golden-brokerpure.spec.ts`)
  覆盖干净报价、脏报价、样本不足、行权价全相同四种。

## 额度

富途的行情按额度计:订阅额度(按资产等级,常见 100 条)——期权链、盘口这类一次性订阅用完立刻退订;历史 K 线额度(按标的数)——用完时的报错明确说是额度问题。
