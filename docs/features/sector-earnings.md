# 板块财报与历史反应

每个成分股行内显示下一财报的美东日期、发布时段、距今天数及确认状态。展开后显示历史财报的开盘跳空、首日收盘及第5个交易日收盘涨跌。仅页面内提示，不发送订单。

## 数据来源

只使用现有 IBKR TWS 会话。`sectors.earnings {symbol}` 是只读 RPC，确认股票 conId 后依次请求 WSH metadata 和 `wshe_ed` 日历。协议版本需173以上，日期窗口为过去2年至未来120天，最多1000条。权限、覆盖和历史范围取决于实际返回，不保证完整。错误、空数据、无未来日期和缺历史分别展示；没有返回不等于没有财报，也不推断用户未订阅。

同会话最多一路 WSH 请求，元数据与事件请求各12秒超时并撤销。板块行情刷新后串行读取标的，同标的五分钟内复用；行内可手动刷新。回包绑定 QObject 生命周期。线协议参考现有 MIT 依赖 @stoqey/ib，未引入依赖或复制 IB GPL 源码。

字段依据 [IBKR WSH 字段说明](https://www.interactivebrokers.com/campus/wp-content/uploads/sites/2/2023/09/WSHEclassesandfieldsforIBAPI2022-12-23.pdf)。

## 计算口径

只认 `earnings_date` 为财报日期，不以确认公告日期、电话会议日期或财季截止日替代。仅 CONFIRMED 且 BEFORE MARKET / AFTER MARKET 计算：盘前归当天交易日，盘后归下一交易日，按内置 NYSE 假日和周末顺延。

百分比都相对反应日的前一交易日收盘；第5日包含反应首日。缺基准价或目标日行情则该格为空，第5日还要求期间日线齐全。未完成的当天日线不参加计算；盘中或时段未知无法用日线隔离反应，全部为空。

日线复用 IBKR `dailyHistory(symbol,760)` 缓存。涨跌未校正同期市场、拆股及分红影响，不归因于财报，也不是预测。历史以返回记录为限。

当前使用离线合成日期、行情和假 TWS 验证假日顺延、缺日线、未知时段、预估日期，以及 WSH 成功、错误、超时和生命周期。未在线验证本账户 WSH 权限。
