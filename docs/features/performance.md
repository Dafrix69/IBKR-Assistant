# 绩效体检:冠军交易员天天盯的那几个数

交易分析页一次看**一笔**;这一页看**全部**:把已了结的交易摊成一本美元账,算出实盘比赛优胜者和他们的教练
反复强调的那几个数,再用写死的规则挑出行为上的毛病。代码在
[`engine-ts/src/performance.ts`](../../engine-ts/src/performance.ts),RPC 是 `review.performance`(读道),
界面是侧栏「研究 → 绩效体检」。**不调模型、不外发**:这里出的是金额,只在本机算、只给界面看。

## 为什么是这几个数

实盘比赛的赢家各有各的方法,但在"怎么知道自己有没有优势、怎么活下来"这件事上说的是同一套话。
这一页把那套话变成可以对照的数字,每一条结论都写明借鉴自谁:

| 来源 | 在这里变成了什么 |
|---|---|
| Van Tharp(交易员教练) | 期望值、R 倍数、SQN 系统质量分 |
| Mark Minervini(美国投资锦标赛 1997 年冠军;2021 年以 334.8% 再夺冠) | 平均亏损要远小于平均盈利、小亏就走、渐进式仓位(赚钱时加、亏钱时减) |
| Larry Williams(1987 年 World Cup 期货冠军,一年 11,376%) | 资金管理决定能不能活下来;凯利 / optimal f 只当上限参照 |
| Andrea Unger(World Cup 期货组四届冠军:2008、2009、2010、2012) | 时间过滤:优势只在某些时段,其余时段少做 |
| Kevin Davey(World Cup 期货组 2005–2007 三年回报都过 100%,2006 年第一) | 样本够多才谈得上优势,几十笔之前的结论只当提示 |
| 国内期货实盘大赛 | 综合排名收益与回撤一起看 → 恢复因子、最大回撤 |
| 职业交易员 / 自营公司 | 日亏上限(见[保护规则](protections.md)的 `daily_loss`) |
| Mark Douglas、Brett Steenbarger(交易心理) | 报复性交易、过度交易 |
| Jesse Livermore / William O'Neil | 截断亏损、让利润奔跑 → 持有时长的处置效应 |

## 账本:哪些交易、怎么算钱

同一批交易、同一套去重,和知识总结、下单页「历史相似交易」共用 `services/tradeHistory.ts`:

| 来源 | 一笔是什么 | 盈亏 | 风险(R 的分母) |
|---|---|---|---|
| 券商成交合成的蝴蝶 | 开仓那张 + 配上的平仓单;没平的过了到期日按到期日收盘结算 | (平仓价 − 开仓价)× 乘数 × 张数,扣两边成交回报里的佣金 | 买蝶 = 权利金;卖蝶 = 翼宽 − 收的权利金(不对称的不算) |
| 股票持仓段 | 从空仓到空仓一段 | 已实现盈亏 − 佣金 | 建仓时计划的止损:\|进场均价 − 止损\| × 峰值股数(见下);没设过止损的没有 |
| Flex 期权仓位 | 一个仓位的完整生命周期 | Flex 的已实现盈亏(已扣佣金) | 蝴蝶 / 垂直价差 / 单腿的借方开仓 = 权利金;贷方、比例蝶、日历不算 |
| 按结构整理的期权出场事件 | 一次出场一笔 | 导出里的已实现盈亏(已扣佣金) | 没有;也没有开仓时刻 |

**不进账本的**,在账本下面分三类数出来,不编:持仓中、结果不明(到期结算价取不到——没连 TWS 时取不到日线)、
成本不明(建仓早于已同步的成交)。回报里没有佣金的笔数写进 notes。

## 口径

- **持平**:|盈亏| < 1 美元。不算进胜率,也不打断连胜连亏。
- **胜率**只数输赢;**盈亏比** = 平均盈利 / |平均亏损|;**保本胜率** = 1 / (1 + 盈亏比)。
- **期望值** = 净盈亏 / 笔数(持平也算一笔)。
- **SQN** = √min(N, 100) × 平均 R / R 的标准差,只数风险固定的交易,不到 10 笔不算。N 封顶 100 是 Tharp 的口径。
  档位:< 1.6 差、1.6–2 一般、2–2.5 好、2.5–3 很好、≥ 3 极好。
- **平仓权益曲线**按了结时刻累计;峰值从 0 起步,一路亏就是亏多少算回撤多少——与回撤护栏同一个口径。
  图的横轴是第几笔,不是时间:同一分钟平两笔不会挤在一起,而冠军看资金曲线本来也是按笔看。
- **凯利比例** f = W − (1 − W) / 盈亏比,输赢不到 8 笔不算。只当上限参照,界面写明冠军实际的单笔风险在 0.5%–2%。
- **时段**按美东开仓时刻:开盘 30 分钟 / 上午 / 午盘 / 下午 / 尾盘 30 分钟 / 盘外。

## 行为规则

阈值写死,样本不够就不说。先说最要紧的(期望值),再说风险,最后说行为。

| id | 什么时候说 | 语气 |
|---|---|---|
| `sample` | 不到 30 笔 | 提示 |
| `expectancy` | 输赢 ≥ 5 笔:期望为正 / 为负 | 好 / 坏 |
| `payoff` | 盈亏比 < 1 且胜率离保本线不到 5 个百分点 | 留意 |
| `sqn` | 风险固定的交易 ≥ 10 笔 | 按档位 |
| `kelly` | 输赢 ≥ 8 笔;≤ 0 时说"没有下注优势" | 提示 / 留意 |
| `recent` | 至少 20 笔:最近 10 笔为负而全部为正(该缩仓),或最近更好 | 留意 / 好 |
| `tail_loss` | 亏损 ≥ 5 笔且最大一笔超过平均亏损 3 倍;或亏损 ≥ 10 笔且最大 3 笔占总亏损一半以上 | 坏 |
| `drawdown` | ≥ 10 笔:恢复因子 ≥ 2 为好,否则留意 | 好 / 留意 |
| `worst_day` | ≥ 5 个交易日,最差一天 ≥ 亏钱日平均的 3 倍 | 留意,指向日亏上限 |
| `overtrading` | 单日笔数 ≥ max(4, 中位数 × 2) 的日子 ≥ 3 天,且那些天每笔为负、比其余更差 | 留意 |
| `disposition` | 输赢各 ≥ 5 笔有持有时长:亏的中位数 > 赚的 × 1.5(坏),反过来(好) | 坏 / 好 |
| `revenge` | 亏完 30 分钟内开的仓 ≥ 5 笔、其余 ≥ 5 笔,前者每笔为负且更差 | 坏,指向止损护栏与冷却 |
| `size_after_loss` | 亏损后下一笔 ≥ 5 次,其中 ≥ 30% 占用放大到**同品种**中位数 1.5 倍以上,且比赢后高 10 个百分点以上 | 坏 |
| `session` | 两个时段各 ≥ 8 笔,一个赚一个亏 | 提示 |

两处阈值是被反例逼出来的:

- **`tail_loss` 的集中度要 10 笔亏损起步**:5 笔一样大的亏损,最大 3 笔就占 60%——"占一半"在笔数少时是必然的,不是信号。
  写测试时的反例抓出来的。
- **`size_after_loss` 按同品种的中位数比,且要比赢后明显高**:第一版拿一个中位数比全部交易,股票的名义金额(几千上万)
  和蝶的权利金(几百)混在一起,股票笔笔都像"放大"。股票与期权混着做的账本上,亏后与赢后"放大"的比例会差不多高——
  只是仓位本来就忽大忽小,却报成了"亏后加码"。改成各品种各算中位数、再要求差 10 个百分点以上,它就不再误报。

结论只描述已经发生的事与一条可以对照的规矩,**不给买卖建议、不给具体仓位**;仓位计算器要人自己填比例。

### 股票的 R:建仓时计划的止损(2026-09-26)

止损不在成交里,可建追踪时填了。R 的分母要的是**初始风险**(Van Tharp),所以只认这段持仓期间**最早**建的那条追踪的
`stop_loss`,之后改过、上移过的都不算。来源是 `audit_log` 里界面写的 `tracker_add`(`store.plannedStops`):追踪行会被删、
止损会被改,这条痕只增。配法(`performance.plannedStopFor`):同标的;痕里有账户别名的还要同账户(2026-09-26 起才记,
更早的只按标的配);建追踪的时刻落在开仓与平仓之间;止损在保护一侧(做多低于进场均价、做空高于),否则不是止损、不算。
加过仓的按**峰值股数**算,分母偏大、R 偏小——宁可说保守了。

## 执行损耗:按中间价触发,实际卖在哪(2026-09-26)

追价平仓每轮都知道模型价、自然价、挂的价,可以前一样都没落下。现在两条平仓痕(`auto_close` 到价平仓、`hosted_sweep`
托管单改成追价平仓)多记一个 `mark`:**触发那一刻的持仓现价**(中间价口径);`hosted_sweep` 还记下托管止盈单的记录 id。
`execQuality.ts` 把它和那张单的成交均价(组合只认 BAG 行,同 `foldEvents`)对上:

- **让出** = 平多头卖低了(mark − 成交)、平空头买高了(成交 − mark),× 成交份数 × 乘数。成交比触发价好是负的,照实记。
- 汇总给合计、每笔平均、占触发价的中位数与平均,再按合约类型分。**中位数是回测「每次成交成本」该填的数**。
- 范围、天数与账本同一套筛法;品种按合约类型对:股票 = STK,蝴蝶 = BAG(本仓库的组合几乎全是蝶),期权 = OPT / FOP。
- **算不出的数成 `missing`,不猜**:2026-09-26 之前的痕没有 mark、单子没成交、找不到那张单。
- 手动下的单不在里面:限价单成交只会比限价好,拿它比没有意义;市价单下单时没留参照价。这里只量"软件替你平"的那一段。

## 保护规则建议(2026-09-26)

体检指到「设置 → 保护规则」时,以前只说"那里可以设",不带数。现在 `performance.protectionAdvice` 按这本账给参数,界面
「按建议填入」确认后发一次 `settings.patch`,**只带那一条规则的那一段**。引擎不自己改设置。

| 规则 | 什么时候建议 | 建议值 |
|---|---|---|
| `daily_loss` | 亏钱日 ≥ 5 天,且至少有一天越过建议线 | 亏钱日平均的 2 倍,向上取整到 10 美元 |
| `stoploss_guard` | 最长连亏 ≥ 4 笔,或「报复性交易」那条成立 | 120 分钟内 3 次 → 暂停 60 分钟 |
| `cooldown` | 同一只标的亏完 30 分钟内又开的 ≥ 5 笔,平均为负且比其余差 | 30 分钟 |

只在那条规则**关着、或开着但比建议松**时给——已经比建议严的,不劝人放松。**回撤护栏不给**:它和日亏上限切的是同一类坏日子,
两条一起按数据填会互相打架,人自己挑一条更清楚。止损护栏的建议写明"只数持仓追踪发出的止损类平仓"。

## 仓位计算器

固定风险比例:先定这一笔最多亏账户的百分之几,再倒推做几份。几个乘除法,算法在界面的 `lib/sizing.ts`,
权益与比例记在本机 localStorage(只为下次不用重填)。每份最大亏损的起手值取账本里蝴蝶风险的中位数。
另给一个"照这个比例连亏历史最长连亏那么多笔,累计回撤多少"(复利口径),单笔风险超过 2% 时卡片转成留意。
**只算不下单。**
