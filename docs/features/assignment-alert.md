# 到期日空头腿的指派提醒

个股与 ETF 的期权是实物交割的:到期日收盘时还在实值里的空头腿会被指派,账户里多出或少掉正股。贷方价差只有空头腿在实值里时,
多头腿作废、空头腿照样被指派——周一醒来多一手正股,就是这么来的。软件在收盘前提醒一次,**只提醒,不发单**。

## 规则

| 项 | 口径 | 理由 |
|---|---|---|
| 看哪些腿 | 账户里今天(美东)到期、`sec_type = OPT`、标的不在配置的指数表(`index_symbols`)里的期权腿 | 指数期权现金结算,到期只结一笔现金,没有正股进出;期货期权不在这里 |
| 什么时候看 | 收盘前 30 分钟起,每分钟一次,到收盘为止;提前收盘日按 13:00 收 | 再早,标的还会走,拿一个还会变的价来吵没有用。30 分钟是提醒的时点,不进任何价格与盈亏 |
| 什么算实值 | 看涨:正股现价 > 行权价;看跌:现价 < 行权价。正好等于不算 | 交易所对到期自动行权的门槛是实值 0.01 美元 |
| 提醒谁 | 每个账户、每只标的一条:列出在实值里的空头腿,以及**按现在的价到期后这只标的的正股净变动** | 净变动把同一天到期、也在实值里的多头腿算进去(它们会自动行权):两条腿都在实值里的价差净变动是 0,提醒里照实写 |
| 说几次 | 同一条腿一天一次。先是虚值、后来进了实值,进去的那一轮说 | |
| 拿不到正股现价 | 说一次「今天到期的空头腿:…,拿不到现价,自己看一眼」;之后拿到了、在实值里,再说一次 | 判断不了不等于没事 |

正股现价取券商的常驻报价流(`streamQuotes`,和顶栏行情带同一路);这只标的此前没订过的话,第一次会订上并留着(一只标的一条行情线路)。

## 不做的事

- **不自动平仓。** 平掉一条空头腿可能把一个价差拆成裸腿,而两条腿都在实值里的价差本来就不需要动。要到点自己走,在这份持仓的追踪上填「到点平仓」([持仓追踪](tracker.md))。
- 不估"收盘时会不会还在实值里",不看盘后:提醒里只有此刻的价。收盘后正股继续走、对手方在盘后选择行权(或放弃)的情形软件不知道。
- 不看提前指派(到期日之前、除息日前后)。
- 富途通道不起作用:它的持仓行不分期权与正股,认不出哪些是今天到期的期权腿。

## 状态

只在内存里:引擎重建之后,同一条腿在时段里会再说一次。审计日志记 `assignment_risk`(账户别名、标的、现价、各腿、净变动)。
只有离线测试,**没有在真机上核对过**:真实持仓里到期日字段的写法、时段里 `streamQuotes` 给不给得出个股现价。
