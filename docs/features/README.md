# 功能文档

每份文档写一个功能现在的设计:它做什么、按什么规则计算、边界在哪、代码与测试在哪。
操作步骤在 [用户手册](../user-guide/README.md),事故经过在 [journal](../journal/),改动历史看 git 提交记录。
