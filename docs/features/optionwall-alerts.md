# 期权墙与价位警告

选好标的 → 算当天期权墙 + 日线趋势位 → 在这些位置和整数关口上设警报,价格穿过时报一次。

**价位的三个来源:**

| 来源 | 具体是什么 |
|---|---|
| 期权墙 | 持仓量墙(OI 最大的行权价)、成交量墙、最大痛点、Gamma 翻转位 |
| 趋势位 | 日线 **60/120/200 日均线** 与 **52 周高低点**(前复权日 K,历史 K 线走券商) |
| 整数关口 | 现价上下最近的步长整数倍。IREN 41 块、步长 5 → **40 和 45** |

趋势位是"历史低位"的全市场标尺:跌到年线、创 52 周新低,都是大量资金的决策触发点。
几条纪律:均线凑不满周期的不算(拿 30 根算"60日均线"是撒谎);高低点用最高/最低价而非
收盘价(衡量"到过哪儿"要用真实摸到的价格);历史不足 52 周时降级为"上市以来高低点",
标签跟着改。均线每天都在动,但**价位只在「重算」时更新**——想让 60 日线跟上,开盘前点
一次重算(和期权墙同一个按钮)。

墙落在整数关口上是常事(它们本来就互相吸引),会**合并成一个**价位,标签两个都留着——
同一个位报两次,和报错在使用上是一回事。合并时以更可信的一方为准:墙压过整数关口,
**当天到期时成交墙压过持仓墙**。

**三个口径含义完全不同,界面上分开摆:**

- **OI 是隔夜存量** —— OCC 每天开盘前公布一次,盘中看到的不含当天的流
- **成交量墙**才是今天真正的流向。0DTE 合约绝大多数当天开当天平,**OI 墙基本没有参考价值**
- **GEX 的符号是一个假设,不是事实** —— 这里用最主流的那个(做市商多头 call、空头 put)。
  真实持仓没人看得到,换个假设结论可能反过来。它适合判断波动会被压住还是放大,不适合判断方向

最大痛点只是个统计量;「到期会被拉到那儿」这个因果**没有可靠证据**,当参考位看,别当预言。

## 不刷屏是这个模块最难的部分

价格在 40 附近来回蹭一分钟,朴素实现能报几十次——**报到第三次人就不看了,警告也就废了**。
所以每个价位有独立的状态机:

```
穿过 → 报一次 → 落防 → 价格离开 band 之外 且 过了冷却 → 重新上膛
```

外加两条:第一次取价**只登记不报警**(否则一打开页面就把现价附近的位全报一遍);
价位重算后,老价位的状态会被丢掉,不会越攒越多。状态存在 SQLite 里,重启不会重报。

## 挑哪条期权链

同一个标的在 IBKR 会返回**多条链**,挑错了整条链一个合约都 qualify 不出来。两个坑
(2026-09-09 对着真机核过):

- **调整期权类**:AAPL 的交易类是 `2AAPL` 和 `AAPL`。`2AAPL` 是拆股/分红调整过的旧合约,
  通常只有一个到期日。按字母序取第一个正好取到它。
- **指数月度记在周四**:SPX 的 AM 结算月度(交易类 `SPX`)在 IBKR 里的
  `lastTradeDateOrContractMonth` 是**第三个周五的前一个交易日**(20260917、20261015、
  20261119…),第三个周五当天(20260918)只存在于日到期链 `SPXW`。

所以挑链的顺序是:**先看这个到期日在不在这条链上**,再按 标的同名 → 配置里的月度/日到期类
→ 到期日最多的一条。同名优先不是审美问题:月度那天两条链都在,`SPX` 是 AM 结算、`SPXW`
是 PM 结算,挑错等于替用户换了结算方式。行权价网格也按挑中的那条取——SPXW 比 SPX 密,
用并集选出来的价位可能在这条链上根本不存在。

校验层(离线,不问券商)用同一条日期规则复核 `tradingClass`,见 `validator.ts`
的 `isIndexMonthlyExpiry`。

## 历史日线的一个硬约束

IBKR **不接受 `ADJUSTED_LAST` 配非空 `endDateTime`**(错误 321)。所以想要结束日在过去的
前复权日线,只能一路拉到今天再本地切片;换成 `TRADES` 虽然能带 `endDateTime`,但那是
不复权价,区间里有一次拆股就会看到一根凭空的跳空。「今天」一律用**美东日期**:引擎其它
地方传的 `end` 都是美东口径,这里若用 UTC,美东 20:00 之后两者差一天,"拉到今天" 会被
误判成 "结束日在过去",于是傍晚之后所有日线请求全挂。回测与 RS 强度扫描共用这条路径。

## 降级

期权墙和趋势位都是加分项:标的没有期权、链拿不到、行情没权限、历史 K 线额度用完都可能
失败。这时候**整数关口照样能用**(它什么都不依赖),但失败原因会明确显示出来——降级可以,
不能悄悄降级。日线历史带 10 分钟缓存:富途的历史 K 线是 30 天 100 只标的的**额度制**,
别把额度烧在重复请求上。

警告轮询是全项目唯一**不看当前在哪一页**的:切走了还得报,不然就没用了。
