# 历史相似交易

交易指令页解析出一张订单(提交的、排队的、只过了校验的都算),订单卡片下面列出历史里相似的交易:几笔、赚几亏几、按出场方式(提前平仓 / 持有到期 / 拆腿)
分开的胜负、最像的几笔,再带上提到这个标的的复盘想法。RPC 是 `ideas.similar_trades`(读道),打分是 `tradeSimilar.ts`(纯函数)。

## 边界

- **只读、只展示。** 不拦单、不改单、不进校验,也不回流到任何下单决策。[保护规则](protections.md)是规则挡单,这里是把历史摆到眼前。
- **不用嵌入、不调模型。** 规则打分,本地出结果。成交是精确数据,近似检索的错答案不会提示"我不确定"(见 [想法检索](idea-retrieval.md)「边界」)。
- **历史就是知识总结附带的那一批**(`services/tradeHistory.ts`,见 [想法备忘](ideas.md)「交易结果」):券商成交合成的蝴蝶与股票持仓段、Flex 期权仓位、
  按结构整理的期权出场事件。成败的算法、「结果不明」、同一段时间以 Flex 仓位为准,都一样。

## 怎么算相似

| 订单 | 先要满足 | 每多一项相近 +1 |
|---|---|---|
| 蝴蝶(`BUTTERFLY`,或 1:2:1 三腿) | 同标的、同为蝴蝶;底分 2 | 同看涨 / 看跌;翼宽差 ≤ 20%;同一到期档(当日 / 一周内 / 更远);同一美东时段开仓;权利金 / 翼宽差 ≤ 0.05;中心离现价(以翼宽计)差 ≤ 0.5 |
| 垂直价差 / 单腿期权 | 同标的、同结构;底分 2 | 同一到期档;同一美东时段开仓 |
| 股票 | 同标的,底分 2;同自定义板块的别的股票,底分 1 | 同方向(做多 / 做空);在近 20 日区间的同一档(低位 / 中间 / 高位)进场 |

- 美东时段:开盘半小时(09:30–10:00)、上午(至 12:00)、午后(至 15:00)、尾盘一小时(至 16:00)、盘外。订单按现在算,历史按开仓时刻算。
- Flex 期权仓位有行权价,和券商成交合成的蝴蝶一样逐项比较(结构名照导出:蝴蝶 / 垂直价差 / 单腿……,破翼与比例蝴蝶不算蝴蝶);出场方式多一档「逐腿平仓」,
  「拆腿后到期」归「拆腿」。
- 按结构整理的期权没有行权价,只能按"同标的同结构"粗配,底分 1,每条写明「只能粗配」;导出里的「多个仓位同时结算」大概率是蝴蝶,只在蝴蝶单下带上并写明。
  Flex 仓位覆盖的日子里它们已经不出现。
- 股票的卖出单一律按做空比较,平掉多头的卖单会和做空的持仓段对照。同标的与同板块别的股票的历史共用 200 笔的上限,同板块的多时会挤掉这只自己更早的交易。
- **同板块的股票只列出来,不算进胜负**(`primary: false`):别的股票赚了不说明这只会赚。
- 分数只用来排序。排序:算胜负的在前 → 分高在前 → 新的在前。引擎给 8 笔,卡片放 5 笔,悬停看为什么相似。

## 要行情的两项(`services/similarContext.ts`)

尽力而为:取不到就不给,那一项不比较、也不扣分,不让整个请求失败。没连券商时拿不到这一单的现价,这两项实际不参与比较。

- **蝴蝶中心离现价**:(中心 − 标的价)/ 翼宽,正数表示中心在上方。这一单用现价(`MarketDataService.spotOf`,指数夜盘用期货推算);
  历史每一只用开仓那一分钟的标的价:按开仓的美东日取那天的 1 分钟线(`BrokerRouter.intradayBars` 带 `endDay`,常规时段),取"该分钟或之前最后一根"的收盘。
  取一次就存进 `trade_entry_context`(历史不会变)。一张卡片当场最多补 3 个交易日、新的优先,剩下的由后台每 8 秒补一天(`backfillGapMs`,
  IBKR 的历史数据有频率限制);券商断了就停,下次打开卡片接着补。只有 IBKR 能按日子取历史分钟线,别的券商只用库里已有的。
- **股票进场位置**:进场价在进场之前 20 根日线高低区间里的位置(0 = 区间最低、1 = 最高,突破可以出界),分低位 / 中间 / 高位三档;
  这一单用现价对今天之前的 20 根。日线走 `dailyHistory`(10 分钟缓存),只算同标的的。日线是前复权价,拆股这类大跳会把位置算歪。

## 已知的不够

Flex 仓位导出之后的新交易,只有 TWS 当天同步进 `broker_fills` 的那些,而那套配对认不出拆腿(见 [交易分析](tradereview.md));定期再导一次 Flex 仓位,
新的日子就以仓位为准。
