# 回测:成交口径、统计、期权估价与参数扫描

「回测」页:买入持有、均线交叉、RSI 超卖、N 日突破、自定义多条件五种策略,日线、全仓进出、只做多,只作研究。
`backtest.run` 跑一次,`backtest.sweep` 扫一批参数(参数网格 × 样本内外 × 滚动前推 × 多只标的)。全是纯计算
(`backtest.ts`、`backtestLab.ts`),不经过模型、不接下单链路。回执里的 `notes` 是这一次结果的口径与已知偏差,界面原样摆在「注意」里。

## 成交口径

**收盘出信号,下一根开盘成交。** 指标用到当根收盘为止,所以信号最早在收盘后才有;同一根收盘价成交等于先看到收盘价再按它买卖,
隔夜的跳空全被算成了自己的利润。

| 情形 | 怎么算 |
|---|---|
| 持仓 | 第 i 根收盘时手里有没有仓 = 第 i−1 根收盘的信号(`heldAfterOpen`)。第 0 根一定空仓 |
| 一天的涨跌 | 隔夜那一段(前收 → 开盘)看前一根的持仓,开盘之后(开盘 → 收盘)看这一根的持仓 |
| 成交价 | 买、卖都是那一根的开盘价;区间结束时还开着的那笔按最后一根收盘价计浮盈 |
| 最后一根的信号 | 没有下一根,不成交;`notes` 第一条写明"某日收盘出了买入 / 卖出信号,不在这次的结果里" |
| 买入持有基准 | 同一个口径:第 0 根收盘决定、第 1 根开盘买进,之后一直拿着,不扣成本。「买入持有」策略不扣成本时和它逐位相同 |
| 没有有效开盘价 / 收盘价的日线 | 整次回测拒掉并指出是哪一天,不拿收盘价顶 |

- 日线是券商给的前复权价(指数是原始价)。指数的开盘价是成分股陆续开盘时算出来的,贴近前收,拿指数回测本来就只是近似。
- 切出来的一截(扫描的样本内 / 样本外 / 每一折)从起点那一根的收盘算起,净值 = 1;那一刻已经持有的,按起点的收盘价建仓并付一次成本,
  之后照常在开盘换仓。这一截的基准同理,从起点的收盘价拿起。

## 统计

全部由引擎从**逐日全量**净值算出;回执里的 `curve` 最多抽 300 个点,只给图用。

| 字段 | 口径 |
|---|---|
| `total_return_pct` / `buy_hold_return_pct` / `excess_return_pct` | 策略、基准、两者之差(百分点)。差由引擎减,界面不自己算 |
| `annualized_pct` | (期末净值)^(365 ÷ 首尾日历天数) − 1 |
| `max_drawdown_pct` | 逐日收盘净值从前高回落的最大幅度 |
| `volatility_pct` | 日收益的样本标准差 × √252 |
| `sharpe` | 日收益均值 ÷ 标准差 × √252。无风险利率按 0(空仓那些天收益是 0,不计利息);净值一动没动是 null |
| `sortino` | 日收益均值 ÷ 下行偏差 × √252。目标收益 0,下行偏差的分母是全部天数;没有下跌的日子是 null |
| `held_days` / `held_day_move_pct` | 在场的天数(相对上一根的涨跌里带着仓位的日线根数),与那些天净值单日变动的均方根:在场时一个典型的单日波动。扫描拿 单日波动 × √在场天数 当回撤的下限 |
| `trades` / `closed_trades` | 总笔数(含没平的那一笔)/ 已平仓笔数 |
| `win_rate_pct` `avg_win_pct` `avg_loss_pct` `payoff_ratio` `profit_factor` `expectancy_pct` | **只数已平仓的**:还开着的那一笔没有结果,算进去等于拿浮盈充数 |

- 盈亏比 = 平均盈利 ÷ \|平均亏损\|;盈利因子 = 盈利合计 ÷ \|亏损合计\|,按每笔的收益率算(相当于每笔下同样大的注);期望 = 每笔的平均收益率。
  缺一边(没有盈利的笔或没有亏损的笔)时对应的项是 null,不给无穷大。期权品种的每笔收益率是对投入的权利金而言。
- **多长才有意义。** "年化"的单位是一年:首尾不满 365 天时,年化收益、年化波动、Sharpe、Sortino、Calmar 都是把这一段外推到一年,
  回执带 `days`,`notes` 写明"不满一年,只作参考"。Calmar 的惯常口径是 36 个月;窗口越短,见过的最大回撤越小(随机游走下大致按 √时长 增长),
  年化又把短期收益按指数放大,两头都把它往高处推。Sharpe 的抽样误差约为 √(252 ÷ 日线根数):一年的日线,误差就在 1 上下。

## 成交成本

`cost_pct` 是**每一边**(买进一次、卖出一次)的成本占成交额的百分比,佣金与滑点一起算,0–10,默认 0。

| 品种 | 怎么扣 |
|---|---|
| 正股 | 开盘换仓的那一根乘一次 (1 − cost)。单笔收益 = 毛收益 × (1 − cost)²,还开着的那笔只扣进场一次 |
| 期权 | 开仓按权利金多付 cost、平仓(含到期)少收 cost;持有中的净值按"现在平掉能拿到多少"算 |

- `backtest.run` 在成本为 0 时回执里没有 `cost_pct` 这个键、`notes` 里有一条"没扣成交成本";大于 0 时才有这个键。`backtest.sweep` 的回执总带 `cost_pct`。
- **填多少。** 正股:每边 ≈ 佣金 ÷ 成交额 + 半个买卖价差 ÷ 股价,按自己常做的标的量。期权品种的成本是对权利金而言:期权的买卖价差占权利金的比例
  远大于正股的价差占股价的比例,不能沿用正股的数。
- [绩效体检](performance.md)「执行损耗」的占比是对持仓现价而言(蝴蝶、期权即权利金),只量了软件自动平仓那一边,是滑点、不含佣金。拿它当这里的成本,
  只能同品种对同品种:正股回测只看「股票」那一组的中位数,再加上佣金占成交额的比例;标着「样本少」的先别用。
  几种合约混着时那一页不给合计的中位数——股票的占股价、组合的占权利金,不是一个量。

## 期权品种

信号还是标的日线上的信号,执行换成买入看涨 / 看跌、借方价差或蝴蝶。每笔投入净值的 `risk_pct`,到期或信号消失时了结,到期后信号还在就在下一根开盘按新的行权价再开。

| 环节 | 口径 |
|---|---|
| 定价 | Black-Scholes,r = 0,无股息,各腿同一个波动率 |
| 波动率 | 近 20 日已实现波动率(收盘对收盘的对数收益,样本标准差 × √252),**逐日重估**:建仓用上一根收盘为止的值,持有中每天收盘用当天的值,信号平仓用上一根收盘为止的值 |
| 历史不够 | 凑不满 20 个日收益的位置没有波动率,**不估价、不开仓**,`notes` 写明有几根想持仓却没开成;整段一个值都算不出(不到 21 根)时整次回测拒掉。不拿默认波动率顶 |
| 行权价 | 贴到美股标准挂牌间隔:价位 ≤ 25 美元 2.5、≤ 200 美元 5、再往上 10(`strikeStep`);价差与蝴蝶的宽度同样贴档,不足一档按一档。每笔的 `strikes` 是贴档后的行权价 |
| 到期日 | 建仓日 + `dte` 天;落在周末、假日就往前挪到最近的一个交易日 |
| 时间 | **按交易日计**:到到期那一根还剩几根日线 ÷ 252,和波动率是同一个口径(波动率量的是"每个交易日一份方差")。到期那天收盘按内在价值结算。到期日在数据结束之后的(只可能是最后那笔没平的),数据之后那一段按这段日线自己"每个日历日折几个交易日"的比例折 |
| 开盘成交那一天 | 只剩开盘到收盘那一段:它占一个交易日方差的多少,拿到上一根为止的 20 根日线量,Σ ln(收 ÷ 开)² ÷ Σ ln(收 ÷ 前收)²(`trailingSessionShare`)。不按钟点折:隔夜十七个半小时的波动远没有盘中六个半小时大 |
| 太便宜的 | 整个结构的理论价不到 0.01 美元(期权的最小报价单位)不开仓,`notes` 写明根数。那个价挂不出买单;照它"买进",一笔就是几十万倍的假收益 |
| 搭不出来 | 贴档之后有腿的行权价 ≤ 0:不开仓,`notes` 写明根数 |

**这套估价往哪边偏,结果里直说,不靠调参数抹平:**

- **已实现波动率不是隐含波动率。** 市场上的隐含波动率通常高于随后的已实现波动率(方差风险溢价),所以这里的权利金偏低:单腿买方被算便宜了,收益偏乐观。
  价差与蝴蝶同时有买有卖,偏向取决于行权价的位置,不一定。不给波动率乘一个"溢价系数":这个系数因标的、期限、行情阶段而异,没有那只标的自己的
  隐含波动率历史就估不出来;蝴蝶测算里校准出的 `realized_to_implied` 量的是 SPX 一天期、常规时段方差对 VIX1D 的比值,搬不到别的标的和期限上。
- **每个交易日当作波动一样大,周末与假日不计。** 时间要是按日历天 ÷ 365 算,一两天到期的期权拿到的 σ²T 只有波动率那个数自己所说的一半上下,
  1 天期平值期权的买方凭空多赚四成多,所以按交易日算;代价是事件不进模型:财报、数据公布前后,和跨长假的期权,市场上比这里贵。
- **波动率与开盘占比都只用 20 根日线估,有抽样误差。** 在每个交易日方差相同、波动恒定的模拟行情上(年化 15%,四分之一的方差在隔夜,标的 5000,
  每档 600 条路径),按模型价买进持有到期:平值跨式的平均盈亏是权利金的 +0.8% ~ +1.6%(1 ~ 30 天期,标准误 0.3% ~ 0.5%),来自样本标准差偏低;
  窄的平值蝴蝶是 −3.4% ~ −4.9%(标准误 0.7% ~ 1.0%),来自蝴蝶的价对波动率是凸的。把真实的波动率与开盘占比直接交给模型,偏差是 0(±0.2%);
  只把占比换成 20 根日线估的,1 ~ 3 天期的跨式贵 0.5% 上下(这个比值的估计略偏高)。也就是说剩下的是估计误差,不是时间口径。
  真实行情的波动会聚集,这些数只说明量级与方向。
- **r = 0、无股息。** 利率为正时看涨偏便宜、看跌偏贵;分红的标的反过来再抵掉一部分。
- **没有偏斜。** 各腿用同一个波动率:虚值看跌实际更贵,虚值看涨实际更便宜。
- **没有期权自己的买卖价差。** 只能靠每边成本补。
- **行权价的档是规则上最粗的那一档,最小报价单位按 0.01 美元。** 实际挂牌往往更密(1 美元档、周期权);日线是前复权价,区间里拆过股的标的在拆股之前价位偏低,
  贴出来的档相对更粗,一分钱的门槛相对更高。
- **到期日不贴周五。** 除了避开非交易日,不要求那天真有期权到期。

## 参数扫描:`backtest.sweep`

| 入参 | 规则 |
|---|---|
| `symbols` | 1–8 只。多只时只用大家都有的交易日,每组参数的得分取各只的平均 |
| `strategy` + `grid` | 预置策略(均线交叉、RSI、N 日突破)的参数名 → 要试的取值;每个参数最多 20 个值,组合 ≤ 200,组合 × 标的 ≤ 800 |
| `split_pct` | 样本内占比,50–90,默认 70 |
| `folds` | 滚动前推的折数,2–6;默认 0 = 不做 |
| `objective` | `return`(总收益)或 `calmar`(收益回撤比,见下) |
| `instrument` / `cost_pct` | 同 `backtest.run` |

- **信号、持仓、期权用的波动率与开盘占比都在整段上算一次,再按下标切。** 指标只看当根及以前,这样切只多了指标的预热,不多看未来;否则样本外的前几十根会因为
  慢线没预热而全是空仓,期权品种还会因为波动率没预热而开不了仓。样本外那一段从样本内最后一根起结算(见「成交口径」)。
- 不合法的组合(快线 ≥ 慢线、RSI 买入线 ≥ 卖出线)跳过并写明原因,不进排名。回执只列排名前 20 的组合;`ranked` 是进了排名的组数,名次的分母是它。
- 每段至少 20 根日线才评。

### 按什么排

`return` 按样本内总收益。`calmar` 按 `return_over_dd`:

> 总收益 ÷ max(\|最大回撤\|, 回撤下限),回撤下限 = `held_day_move_pct` × √`held_days`(在场时的单日波动 × √在场天数,也就是在场那些天单日变动的平方和开根号)

- **不年化。** 同一段里各组的天数相同,年化只是同一个换算;而把二十几根日线外推成一年,会把收益高的组放大得不成比例。`SegmentStats.calmar`
  (年化 ÷ \|最大回撤\|,回撤为 0 时是 null)仍然给出,只作展示,不参与排名。
- **回撤有下限,所以总有定义,排名里只有一种量纲。** 没见过回撤不等于没有风险:这么大的日波动、在场这么多天,净值本来就该有这个量级的起落。
  下限和最大回撤量的是同一段时间里的起落;只拿"一天的波动"当下限,是拿一天去比多天的回撤,进场一两次、恰好都涨的组会排到有真实回撤记录的组前面。
  一直空仓的组得 0 分:比亏钱的强,比赚钱的差。多只标的时先逐只算再取平均。
- **下限经常起作用,它不是警报。** 没有大跌的行情里,样本内的赢家往往正是回撤比这个量级小的那些,`dd_floored`(下限顶替了实际回撤)在它们身上多半是 true;
  下限起作用时,得分就是 总收益 ÷ (单日波动 × √在场天数),相当于一个类似 Sharpe 的量。真跌过的行情里回撤通常比下限大,排的就是 总收益 ÷ 最大回撤。
- **进场很少的组仍然可能排第一,这条规则只是压低它,压不掉。** 在场 N 天、天天上涨的组,得分最高到 √N;三五天的连涨并不罕见,而有真实记录的组得分往往也就是这个量级。
  这是样本内任何"收益 ÷ 风险"都有的毛病,只能靠样本外来验。所以另有一个标记 `dd_under_one_day`:观察到的回撤还不到在场时**一天**的典型波动,
  基本没经历过回撤。样本内第一名如此时 `notes` 直说"这个名次不可靠",结果表与每折的表里那一组后面标「几乎没回撤过」。
- **滚动前推每一折用的是同一个得分。** 每一折带 `dd_floored` 与 `dd_under_one_day`,说的是那一折挑出来的那组在训练段的样子(按总收益挑时恒为 false);
  `notes` 数出有几折靠的是下限、其中几折几乎没经历过回撤。

### 挑出来的那一组可不可信

一次试了几十上百组、挑其中最好的,它在样本内好看是必然的。这里不做多重检验的校正(那需要知道这些组合里有几个是相互独立的,估不出来),
也不设"相关低于多少不可信"的线;只把算得准的摆出来,`notes` 用同样的数写成话:

| 字段 | 含义 |
|---|---|
| `best.oos_rank` / `ranked` | 样本内第一名在样本外排第几:1 + 样本外得分比它高的组数,同分同名次 |
| `pick_p` | 随手挑一组,样本外得分不比它差的概率 = 样本外得分 ≥ 它的组数 ÷ `ranked`。越接近 1,样本内的"第一"越不值钱 |
| `oos_median_return_pct` | 全部合法组合样本外收益的中位数:不挑、随便拿一组的水平。第一名的样本外收益该和它比,不是和 0 比 |
| `rank_corr` | 全部组合样本内与样本外得分的 Spearman 秩相关 |
| `rank_corr_p` | 它的单侧 p 值(置换检验:把样本外的次序随机打乱 9,999 次,相关不低于实际值的占比)。读法:两边的排名要是毫无关系,碰巧得到这么高或更高的相关的概率。最小是 1/10000,说明与界面写成"不到 0.1%" / "< 0.001",不印成 0 |
| `walk_forward.total_return_pct` | 滚动前推的连乘收益,见下 |

- p 值不是"策略有效的概率"。相邻参数的结果彼此高度相关,一个贯穿两段的因素(比如这段行情一路上涨,持仓越多越好)就能让排名延续;
  它只回答"排名延续了没有",不回答"策略有没有用"。置换用固定种子,同一次扫描重跑 p 值不变。
- 界面的结果卡不亮绿灯;只在两件不用划线的事上亮黄:秩相关不为正,或第一名的样本外收益不如中位数。
- **滚动前推**:区间按根数等分成 折数 + 1 段,第 j 折用前 j 段挑参数、运行第 j+1 段,各折测试段的收益连乘;训练段或测试段不到 20 根的那一折跳过。
  这是整张表里唯一每一步都只用了当时已有数据的数,和同期买入持有并排摆着。
- 样本内或样本外不满一年时,`notes` 写明两段各多少天、年化与 Calmar 是外推的。

## 偏差

- **幸存者偏差。** 代码是今天挑的:它活到了现在,退市、被并购、跌没了的不会被拿来回测。只跑一只也一样,`backtest.run` 与 `backtest.sweep` 的 `notes` 每次都写。
- **日线看不到盘中。** 止损、盘中突破这类规则表达不了;一天之内先到哪个价也不知道。
- 沿用现值、没有重新估过的参数:波动率与开盘占比的窗口 20 根日线、每段至少 20 根日线。

## 刻意不做的

| 不做 | 原因 |
|---|---|
| 保留"同一根收盘价成交"的选项 | 那是偷看;没有别的模块依赖它 |
| 给期权的波动率乘溢价系数、加偏斜 | 没有标的自己的隐含波动率历史,任何系数都是猜的;偏差写在结果里 |
| 多重检验校正、"过拟合概率"一类的单一结论 | 需要独立试验的个数或大量再抽样;给出名次、中位数与置换 p 值,让人自己判断 |
| 自定义条件、买入持有的扫描 | 前者没有数值参数可扫,后者没有参数 |
| 自动把最优参数填回表单 | 挑参数这件事正是要人看了样本外再决定 |
