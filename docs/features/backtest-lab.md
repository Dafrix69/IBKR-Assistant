# 回测成本与参数扫描

「回测」页:买入持有、均线交叉、RSI 超卖、N 日突破、自定义多条件五种策略,日线、收盘成交、全仓进出,只作研究。
单次回测(`backtest.run`)有两处会让人高估策略:不扣成本,以及参数是看着结果挑的。所以另有每边成交成本与 `backtest.sweep`
(参数网格 × 样本内外 × 滚动前推 × 多只标的)。全是纯计算(`backtest.ts`、`backtestLab.ts`),不经过模型、不接下单链路。

## 成交成本

`cost_pct` 是**每一边**(买进一次、卖出一次)的成本占成交额的百分比,佣金与滑点一起算,0–10。

| 品种 | 怎么扣 |
|---|---|
| 正股 | 这根日线的持仓和上一根不同就乘一次 (1 − cost);第 0 根就持有也算一次买进。单笔收益 = 毛收益 × (1 − cost)²,还开着的那笔只扣进场一次 |
| 期权 | 开仓按权利金多付 cost、平仓少收 cost;持有中的净值按"现在平掉能拿到多少"算 |

- 默认 0,结果与不扣成本逐位相同。`backtest.run` 在成本为 0 时回执里没有 `cost_pct` 这个键,大于 0 时才有,结果卡写明"已扣每边成交成本";
  `backtest.sweep` 的回执总带 `cost_pct`。
- 填多少:[绩效体检](performance.md)「执行损耗」的中位数就是实测值(那是"软件替你平"那一段的口径,手动下的限价单一般更少)。

## 参数扫描:`backtest.sweep`

| 入参 | 规则 |
|---|---|
| `symbols` | 1–8 只。多只时只用大家都有的交易日,每组参数的得分取各只的平均 |
| `strategy` + `grid` | 预置策略(均线交叉、RSI、N 日突破)的参数名 → 要试的取值;每个参数最多 20 个值,组合 ≤ 200,组合 × 标的 ≤ 800 |
| `split_pct` | 样本内占比,50–90,默认 70 |
| `folds` | 滚动前推的折数,2–6;默认 0 = 不做 |
| `objective` | `return`(总收益)或 `calmar`(年化 ÷ \|最大回撤\|;没有回撤时用年化) |
| `instrument` / `cost_pct` | 同 `backtest.run` |

- **信号在整段上算一次,再按日期切。** 指标只看当根及以前,这样切只多了指标的预热,不多看未来;否则样本外的前几十根会因为慢线没预热而全是空仓。
  样本外那一段从样本内最后一根起结算:那一根的持仓决定样本外第一天算不算涨跌(已持有就按那一刻买进付一次成本)。
- 不合法的组合(快线 ≥ 慢线、RSI 买入线 ≥ 卖出线)跳过并写明原因,不进排名。回执只列排名前 20 的组合。

要看的三样:

- **样本内第一名在样本外排第几**(`best.oos_rank`):排在后面,说明样本内的第一靠的是那段行情。
- **样本内外排名的秩相关**(`rank_corr`,Spearman):低于 0.3 时说明里直说"挑参数基本等于挑运气"。
- **滚动前推的连乘收益**(`walk_forward.total_return_pct`):区间按根数等分成 折数 + 1 段,第 j 折用前 j 段挑参数、运行第 j+1 段,各折测试段的收益连乘;
  训练段或测试段不到 20 根的那一折跳过。这是整张表里唯一每一步都只用了当时已有数据的数,和同期买入持有并排摆着。

## 刻意不做的

| 不做 | 原因 |
|---|---|
| 夏普 | 结算函数只交出抽样后的净值曲线(最多 300 点),拿它算日收益的标准差不准;Calmar 用的年化与最大回撤都是全量算的 |
| 自定义条件、买入持有的扫描 | 前者没有数值参数可扫,后者没有参数 |
| 自动把最优参数填回表单 | 挑参数这件事正是要人看了样本外再决定 |
| 按历史成分股回测股票池 | 券商日线只有现在还在交易的代码;多只一起扫时说明里写明幸存者偏差 |

## 测试

`backtest-lab.spec.ts`:成本为 0 时逐位相同且没有 `cost_pct` 键、正股与期权按规则扣、超范围拒绝;网格展开与不合法组合跳过、按样本内得分排序、
切分日在 70% 处、多只标的只用共同的交易日、滚动前推连乘、Calmar 用年化代替、入参报人话、秩相关的边界。`backtest-rpc.spec.ts`:RPC 的载荷形状、逐只取日线与报错码。
`golden-backtest.spec.ts`:净值曲线的黄金基线(容差 1e-9)。
