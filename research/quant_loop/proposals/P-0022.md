# P-0022 小盘股 5 日大涨后卖当周虚值 put（每日 delta 对冲）
范围: B
提案人: 主会话（不是 quant-proposer agent），研究目录 `research/call_spread_edge/`，2026-11-06
状态: 第 1–6 节在测试期任何对冲 / 条件化结果之前写定；测试期由验证人独立实现、只跑一次。

## 0. 已经看过什么（申报）
同 P-0021 第 0 节：测试期只看过**不对冲卖 call 价差**的盈亏（知道这批股票测试期还在涨）；没看过 put 侧、没看过对冲后的任何东西。训练期约 250 个格子里挑出来，**变体数按 250 计**。

## 1. 机制
仍是“卖方”思路，但换到被抬价的那一侧。小盘炒作股大涨之后，持有浮盈的散户和机构买 put 保护、做市商在“现货涨 + 波动率涨”（spot-up vol-up）的行情里同时抬高 put 的隐含；接下来一周向下的已实现波动没有定价的那么大。
训练期按 5 日涨幅分三档，只有最高档（> +9.48%）里对冲后卖周 put 稳定为正；同条件下卖 call 约为 0，所以不是“整体波动率都贵”，而是 put 侧在大涨后贵。
做成 put 价差（卖 −0.25 买 −0.10）会把两边的溢价对消，所以是单腿卖 put + 每日对冲。

## 2. 信号 / 入场
- 标的与 WOLF 剔除规则同 P-0021。每个 ISO 周第一个交易日收盘。
- ret5 = S0 / S(往前第 5 个交易日收盘) − 1 > **0.0948**（训练期全部（股票，入场日）的 2/3 分位，冻结）。
- 到期：同一 ISO 周内的最后一个到期日，且 DTE（自然日）在 [2, 6]；没有则不做。
- 行权价：put，按中间价反推 BS IV（r = 4.3%）、算 delta；分别取 delta 最接近 −0.25 和最接近 −0.10 的一档（各自 |差| ≤ 0.05，bid > 0，ask ≥ bid），**各算一笔**。

## 3. 结构与出场
- 卖 1 份 put（每 1 股名义），价格 = mid − k × 半点差，权利金按 r 计息。
- 每天收盘按当天该合约中间价反推的 IV 算 BS put delta Δp_t（负数），持有 Δp_t 股（即空 |Δp_t| 股；对持股者 = 少持 |Δp_t| 股），
  对冲盈亏 = Σ Δp_t·(S_{t+1} − S_t − r·S_t·Δt)；报价缺失或无法反推时沿用前一天 IV。
- 正股调仓按成交额 5 bp（含建仓与到期平仓）。持到到期，按内在价值结算。

## 5. 预先声明的预期（测试期 ≥ 2025-11-01）
| 量 | 预期 | 失败线 |
|---|---|---|
| 两档合并、k 0.5 每笔均值 | +0.05 ~ +0.35%（中心 +0.15） | ≤ 0 |
| 同上，周块 bootstrap 95% | 不含 0 | 含 0 → 不过关 |
| k 1.0 均值 | > 0 | ≤ 0 |
| 对照：同周、ret5 ≤ 0.0948 的卖 put（k 0.5） | 低于信号组 | 不低于 → 机制（大涨后 put 贵）不成立 |
| 为正的股票数 | ≥ 8/14 | ≤ 6 |
PASS = 前三行满足且 Bonferroni（2 个提案，97.5%）仍不含 0，第四行方向正确。

**推断单位（两个提案共用，验证人不得更改）**：按周块 bootstrap（平均块长 8 周，10000 次），每次重抽后用「抽到的各周全部交易的盈亏合计 ÷ 交易笔数」（按笔加权）求均值，取 2.5% / 97.5%（Bonferroni 另报 1.25% / 98.75%）。不用「各周平均值的平均」。

**检验力**：信号约三分之一的周触发，测试期约 12 个月，最多约 350 笔；训练期 k 0.5 的区间已经碰到 0。
所以写死：**均值 > 0 但区间含 0 = 「没证明」，不等于否定机制**；均值 ≤ 0 才算否定。

## 6. ETF 盲检
SPY / QQQ / IWM 上做同一规则（cut 用 ETF 自己训练期的 2/3 分位会是新参数——**不做**；直接用 0.0948 则几乎不触发）。所以 ETF 只报告「无条件卖周 put 对冲后」的结果作背景，不进 PASS。

## 7. 已知局限
幸存者偏差（这 15 只事后挑的、测试期没有崩盘的那种）对卖 put 有利，即使对冲后也是（没有向下大跳）；只有日收盘；美式 put 提前行权忽略（短期限影响小）；没有财报日历。
