# P-0014 整点入场的报价缺口：14:00 的四腿点差是否比两分钟后系统性更宽（只用价格判定的执行成本）
范围: A
状态: 第 1–6 节（机制、信号、规则、预先声明的预期、失败线 / 撤回闸门、变体计划）写于训练期回测之前（2026-11-01），跑数后没有改；第 7 节以后是跑完补写的。

## 1. 机制

### 1.1 主张
基准 A 在整点 14:00 下单。主张：**整点前后（14:00、14:01 两个分钟快照）0DTE 近平值腿的 NBBO 比几分钟前后系统性更宽**，原因是整点的订单流聚集：
1. 定时下单的参与者把单子放在整点（TWAP / VWAP 的分桶边界、“14:00 开 0DTE”这类日程化的系统性卖方与散户规则，基准 A 本身就是一个例子；人和调度器都偏爱整点）。
2. 流量集中到达时，做市商面对更高的库存风险与逆向选择（同一秒里大量同方向的跨式 / 铁蝶需求），对策是在整点附近加宽或撤掉一侧报价，流量过去后再收窄。
3. 所以在整点吃单的人（包括我们）付的是“拥挤时段”的点差；挪到整点之后一两分钟就避开了。

**谁在付钱**：在整点准时下单的拥挤订单流，付给做市商的是拥挤时段的风险补偿。**为什么没被套利掉**：这不是套利机会，是流动性的时段价格；做市商加宽是理性的，拥挤者因锚定 / 调度默认值不挪时间。任何一个小交易者挪两分钟就能避开，但这不会消除它。

### 1.2 美元上限（先写清，避免被误读为策略）
- 测试期 V-0013：铁蝶（P-0013 PASS 后的默认结构）14:00 每组 H ≈ 0.209 点，执行成本的点差项 k·H·100 ≈ 4.2 美元；费用 ≈ 6.2 美元（四腿各 1 美元最低佣金 + 交易所费），**费用这一半任何择时都动不了**。
- 跳价下限：SPXW 权利金 ≥ 3.00 跳价 0.10、< 3.00 跳价 0.05。14:00 平值两条腿通常 > 3（I 中位约 13），两条翅膀 < 3，所以铁蝶 H 的跳价下限 ≈ 0.05 + 0.05 + 0.025 + 0.025 = 0.15 点。**任何分钟选择能省下的点差上限 ≈ 0.2 × (0.21 − 0.15) × 100 ≈ 1.2 美元/天**，现实里只会是其中一小部分（几毛钱）。这不到基准 A 期望（+100 美元/天）的 1%。
- put 蝶（基准 A 字面结构）H ≈ 0.43，上限相应约 5 美元/天，只报告。

### 1.3 快照口径（决定性的不确定点）
`quote_1m` 的行时间戳为 hh:mm:00.000。我按 ThetaData 区间报价的通常口径理解为“该时刻（含之前最后一条）的 NBBO”，即 14:00 行是整点**之前一瞬间**的状态；做市商**预先**加宽会落在 14:00 行，**反应式**加宽（流量到达后）会落在 14:01 行。本地训练期只有 2 天逐笔，无法核实。所以把“整点窗口”预先定义为 {14:00, 14:01} 两行，替代入场分钟固定为 **14:02**（窗口之后第一分钟；按机制，整点流量在秒级完成，做市商在一分钟内收窄，14:02 是不依赖扫描的最早“过后”时点）。不扫描别的分钟去挑。

### 1.4 方向预言与反驳路径
- 预言符号：整点窗口**更宽**（残差 > 0）。如果训练期显示 14:00 更窄或无差，读法是“基准 A 已在最便宜的时点，没有边际”，撤回；**不翻转方向另立规则**。
- 机制可被单独反驳：整点聚集若是原因，同样的缺口应出现在 11:00、12:00、13:00、15:00（10:00 有经济数据发布、14:00 有 FOMC，都是事件而非日程流量，10:00 不用、FOMC 日剔除）。四个干净整点中少于 3 个同号 → 机制不成立，撤回。
- 安慰剂：每小时的 :37 分（任意非整点、非半点）做同样的残差，应 ≈ 0。

### 1.5 和账本的关系
- P-0002（训练期撤回）在 13:30–13:59 按 ATM 跨式涨幅 + 现货安静挑入场分钟，判的是盈亏 / 隐含回落；本提案只用 NBBO 宽度、只判执行成本，赔付变化（入场晚 2 分钟、K / w 可能不同）单独报告不进判定。
- P-0013（PASS）比的是同一时点不同结构；本提案是同一结构不同时点，与之正交，节省可叠加。
- P-0009 的教训：比较两个时点时不能按后一时点“有没有候选”配对。这里只要求两分钟**都**过点差上限且腿齐全（对称条件），并报告因此丢掉的天数及其在两个时点各自的 H。

## 2. 信号（入场那一分钟已知）
- 基准日：非半天、`spx_ret_prev` > −1%、有 0DTE；**FOMC 日剔除**（14:00 是事件；它们在 14:00 本来就被点差上限删光，但 14:02 可能不会，所以显式剔除）。另报含 FOMC。
- 时点 t 的选择（与基准 A / P-0013 相同）：S = `spot.parquet` 在 t 的值；K = 当分钟有报价的行权价中离 S 最近的一档；I = C(K).mid + P(K).mid；w = {20, 25, 30, 50, 75} 里 |w / I − 2| 最小，平局（容差 1e-9）取窄。
- 报价：chain 当分钟 NBBO，`flag_bad` 不用，ask > bid，bid ≥ 0；**点差上限**：任一腿 ask − bid > 2.0 点 → 该分钟丢弃；另报 1.0。
- 成本：k = 0.20，买 = mid + k·半点差、卖 = mid − k·半点差；费用 `max(佣金 × 张数, 1.00) + 张数 × (交易所 0.36/0.45 + 0.14 + 0.04028)`，佣金按权利金 < 0.05 → 0.25、< 0.10 → 0.50、其余 0.65。1 组 1 张。执行成本 E = k·H·100 + fee（美元）。

## 3. 统计量与规则

### 3.1 机制统计量 N（固定腿，去趋势）
对每个基准日、每个整点 h ∈ {11, 12, 13, 14, 15}（及安慰剂 h:37），在 h:00 选定 (K, w) 并**固定这四条铁蝶腿**，取它们在 h:00 − 5 … h:00 + 5 每分钟的 H（缺腿或超上限的分钟留空）。用 m ∈ {−5, −4, −3, −2, +2, +3, +4, +5} 的 H 对 m 做线性拟合（至少 6 个点），残差：
- N0 = H(h:00) − 拟合值(0)，N1 = H(h:01) − 拟合值(1)；N = (N0 + N1) / 2（点）。
- 美元：k · N · 100。
主统计量是 h = 14 的 N0（入场分钟本身）与 N，按天聚类 bootstrap（2,000 次）。

### 3.2 规则 R（判定用）
基准 A（铁蝶，见 P-0013）入场从 14:00 挪到 **14:02**，14:02 重新选 K、w。
- 判定量 G = E(14:00) − E(14:02)（美元/天，各自的 K、w；只含执行成本 k·H·100 + fee）。
- 单独报告、不进判定：Δmid = mid(14:02) − mid(14:00)（各自结构，点 × 100）；Δpayoff（按结算）；ΔPnL = 两者合计与 G 之和；K 或 w 改变的天数占比。
- put 蝶同口径只报告。

### 3.3 出场
持到结算（赔付按结算价），不提前离场。
