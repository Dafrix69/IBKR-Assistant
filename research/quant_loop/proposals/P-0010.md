## 机制

**命题 H1（主）**：SPX 期权在收盘时给“收盘 → 次日开盘”这一段定的风险中性方差，**高于**这一段的实际方差；日内段（开盘 → 结算）大体公平。所以 D 收盘买入次日到期的跨式（或卖出它），以“结算离 F 多远 / 跨式价”衡量的 ratio 系统性低于次日 09:35 入场的同一到期 0DTE 的 ratio。

文献：Muravyev & Ni（2020, *JFE*, “Why do option returns change sign from day to night?”）在 SPX 和个股期权上发现，Delta 对冲后的期权收益**隔夜显著为负、日内为正**，解释是隐含波动没有按“隔夜实际方差远小于日内”来降：收盘时的期权价格隐含了过多的隔夜方差。Jones & Shemesh（2018, *JF*, “Option mispricing around nontrading periods”）发现期权在非交易期（主要是周末）的收益显著更低，认为是对休市期间方差的错误处理而非风险补偿。两篇样本都在 0DTE / 每日到期出现之前；SPXW 每日到期（2022-05 起）后这一段是否还存在，是本提案要测的。

量化预言（先写）：预检里 s_imp ≈ 0.31（夜晚）/ 0.40（周末）。若日内段公平、隔夜实际方差只有隐含的 θ 倍，则 x_full ≈ √(1 − s_imp + s_imp·θ)。θ = 0.5 → 1 夜 0.92、周末 0.89；θ = 0.3 → 0.89 / 0.85。配对 P = x_full − x_day ≈ −0.05 ~ −0.10（若 x_day ≈ 1）。

**谁在付钱**：收盘买入次日到期期权的人——持有过夜头寸的保护买家（隔夜跳空不能在现货里止损）、收盘前买入次日彩票的散户，以及按“均匀时钟”插值隐含的报价惯例本身（做市商的期限结构在 1 天以内按日历或交易时间线性摊，收盘那一刻剩余时间里隔夜的权重偏大）。

**为什么没被套利掉**：(1) 要收这笔钱必须**过夜持有空 gamma**：隔夜跳空不能连续对冲（ES 夜盘薄，周末 ES 全休约 49 小时），保证金和跳跃风险让资本有限的卖方不愿放大；(2) 持到次日结算时，这笔溢价被次日整整一个交易日的噪声稀释——单笔盈亏标准差估计约 1500–2000 美元，单笔期望只有几十美元，任何一年都可能为负；(3) 16:00–16:15 的收盘段流动性小，大资金进不去。提前在次日开盘平仓才能“只收隔夜”，但开盘点差最宽，往返成本把它吃掉——这也是我不做提前离场的理由（默认持到结算，不需要另给理由）。

**能单独否定它的预言**：
1. P = mean(x_full − x_day) < 0（配对同一个 N）。
2. **归因到隔夜段**：实际隔夜方差份额 s_real = Σ(S_N,09:35 − F_D)² / Σ(settle_N − F_D)² **小于** 隐含份额 s_imp 的同口径值 Σ[(I_D)² − (I0_N)²]·(F/S 归一后) / Σ(I_D)²。如果 P < 0 但 s_real ≥ s_imp，那 P 来自日内段，不是隔夜机制，判失败。
3. 竞争解释“I 水平影子”：同一个 N 的配对已去掉日间 I 水平；再按 D 的 I_D/F 训练期三分位分层，要求三格中 ≥ 2 格 P < 0。
4. 竞争解释“下午 / 隔夜漂移”（V-0005）：结构对称（以 F 为中心），漂移不应偏向任一侧；仍按每天 settle_N − F_D 的符号分两半报告，两半都须 P < 0。
5. 竞争解释“报价源不同”：x_full 用 16:15 收盘 NBBO（EOD 文件），x_day 用 09:35 分钟中间价（chain）。若 EOD 收盘 NBBO 系统性偏宽 / 偏高，会人为压低 x_full。检验：用同一 EOD 文件里 ATM 两腿的点差 / 跨式比，报告 P 在“点差 / 跨式”低半与高半内是否同号；若 P 只在高半成立，判为报价伪影。

**命题 H2（次要，只报告，不进判定）**：周末 / 长周末（N − D ≥ 2 个日历天，以下统称“周末”）的 P 比 1 夜更负（Jones–Shemesh）。功效：周末约 130 天，x 单日标准差约 0.75，差值标准误约 0.08，只能分辨 ≥ 0.16 的差；预检显示周末只被多定价约 0.2 夜，我对 H2 的先验约 40%。

**安慰剂（唯一一种）**：周一夜（D = 周一）对 周二夜（D = 周二）的 P 差。两者都是普通 1 夜，机制预言差为 0；它给出“按星期切分”本身能制造多大的差，用来标定 H2 的周末差是否超出噪声。规则：|P_周一夜 − P_周二夜| ≥ |P_周末 − P_1夜| 时，H2 记为“分不出”。

## 信号（入场那一分钟已知）

- D：交易日，D 与 N 都非半天；N = calendar 里 D 的下一个交易日，且 D 日 greeks_eod 文件中存在 expiration = N 的 SPXW。
- F_D = 离 `underlying_price` 最近 5 个 C/P 双全行权价上 K + C_mid − P_mid 的中位数（16:15 收盘 NBBO，入场时已知）。
- K = 离 F_D 最近的 5 点行权价（平局取低）。I_D = K 档 C_mid + P_mid。
- 入场时刻 = D 日 16:00–16:15 收盘段，价格 = EOD 文件的收盘 bid / ask。
- 不用任何 D 日之后的数据；不用星期、事件、VIX 做过滤（星期只用于 H2 和安慰剂报告）。

## 结构

- **空铁蝶**（卖 K call、卖 K put，买 K + w call、买 K − w put），1 组 / 晚，持到 N 日结算（`calendar.settle[N]`），现金交割，无出场成本。
- 翅宽 w = 离 2 × I_D 最近的 5 点倍数（|w − 2I| 相等时取窄，比较加 1e-9 容差）；最小 10。
- 跳过：四腿任一缺档、bid ≤ 0（翅腿 bid = 0 允许，用 ask 买）、或任一腿 ask − bid > 2.0 点。
- 成交：每腿 px = mid ± k·(ask − bid)/2（买加卖减），k = 0.20；费用每腿 max(佣金, 1.00) + 交易所费 + 0.14 + 0.04028（config.yaml 校准值，与 P-0009 同实现）；乘数 100。另报 k 0 / k 0.5。
- 赔付：结算时欠 max(0, |settle − K| 内的空跨式内在值) − 翅膀补回，即标准铁蝶赔付。

## 主检验与判定口径

- x_full = |settle_N − F_D| / I_D；x_day = `edge_panel` 中 date = N、entry = 09:35 的 `ratio`（= |settle − S_09:35| / 09:35 ATM 跨式）。
- **P = mean(x_full − x_day)**，配对，日重抽样 95% 区间（10 000 次）。
- s_real 与 s_imp 如上（均值之比，日重抽样区间）。
- 交易：每晚盈亏（美元，k 0.20）、胜率、按年、最大回撤；与基准 A（N 日 14:00 的基准规则）日盈亏的相关，以及“基准 + 本规则”与“基准单独”的夏普。

### 判定：撤回

预声明闸门 7 条，触发 1 条：**闸门 7，铁蝶期望 k 0.20 = −51.8 美元 / 晚 ≤ 0**（2022 −230、2023 −25，只有 2024 为正；k 0 也是 −36，亏损不来自成本）。其余 6 条形式上通过，但都贴着零：P −0.025 只有预言中心的一半，区间跨零；s_real − s_imp −0.009，隐含隔夜份额 0.351 与实际 0.342 几乎相等；闸门 4 的 settle > F 半边 −0.005、闸门 6 的点差低半 −0.002，P 几乎全部来自“点差 / I 高”的那一半，报价伪影的嫌疑没有排除。

准确说法：**未证实（不是否定）**。点估计与 Muravyev–Ni 同向：收盘入场的 x_full 比次日 09:35 的 x_day 低 0.025；隔夜段实际 / 隐含（mean|S_09:35 − F| 对隐含隔夜跨式当量 √((I/F)² − (I0/S0)²)·F，582 晚隐含隔夜方差为正）为 0.955，中位 0.835。但幅度只有预言中心的一半，区间跨零；按方差份额算，做市商给隔夜的比例（35.1%）和实际（34.2%）几乎一样。P 的单晚标准差约 0.68、标准误 0.028；要在 2 个标准误上分辨 −0.05 需要约 4 倍样本（约 2,400 晚），这批数据（训练 + 测试约 1,100 晚）给不了。就算隔夜段真有这点溢价，**持到结算的空铁蝶也吃不到它**。拆开看（预声明结构的事后分解，不是变体）：空跨式在中间价的期望 +40.3 美元 / 晚，翅膀净成本（付出的翅价 − 结算补回）−70.2，费用 6.4，k 0 合计 −36.3；k 0.20 再加 15.5 美元点差成本，得 −51.8。翅膀把空跨式那点边际吃光还倒贴。换成不带翅膀的空跨式是另一个结构，须另立编号；它尾部无界，我不提。

**报价伪影没排除**：P 几乎全在“ATM 点差 / I”高的那半（−0.048 对 −0.002）。如果 16:15 收盘段做市商放宽报价、中间价偏高，P 的一半可能是伪影；本数据只有一个收盘快照，无法分辨。验证人若复核，先查 `nights.csv` 里 `atm_spr / I` 高半的天。

**周末格的观察（不翻转、不申请）**：周末 123 晚铁蝶 +308 美元、胜率 61.8%，x_full 0.835。拆开看：周一日内段 x_day 0.838（1 夜格的次日日内段 1.053），周末隔夜段 x_on 0.856（中位 0.666；1 夜格 0.982，中位 0.886）。**两段都实现得比隐含少**。所以 P_周末 = −0.003 ≈ 0 不是因为周末定价公平，而是周末隔夜段和周一日内段被同样高估了约 15%，x_full − x_day 的配对差测不出这种情况。空跨式在中间价的期望：周末 +463、1 夜 −69 美元 / 晚。

这条观察的污染要写清。mining `cross.md` 测过 `weekday`，但只在 13:00 / 14:00 入场：Mon@13:00 单变量过筛（训 +9.5pp / 测 +5.7pp），Mon@14:00 不成立，没有增量规则。**09:35 入场和“周五收盘 → 周一结算”从未有人测过，本轮已在训练期看过**：周一日内段 0.838 对其他 1.053，n 123 / 476，差 −0.215，按单晚标准差 0.70 / 0.81 约 2.8 个标准误。这个差比本提案要测的 P 大一个量级。它可能是 Jones–Shemesh 的周末错误定价在每日到期时代的样子（做市商把周末与周一当作一块定价，周五收盘与周一上午都偏贵），也可能是 2022–2024 的偶然；周末 +463 是否由少数平静周一主导，我没有查。后续提案若要追“周五收盘 / 周一上午做空 0DTE–1DTE 波动”，必须另立编号，申报本节是训练期已看过的结果，方向只能是这里的方向，判定只能用测试期一次，并先回答为什么 mining 里 Mon@14:00 不成立。
