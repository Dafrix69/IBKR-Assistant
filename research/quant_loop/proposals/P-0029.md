## §1 机制

**这笔交易是什么**：14:00 卖一个 15 点宽的 0DTE call 垂直价差，短腿选在中间价信用落在 3–4 点的位置（训练期短腿中位在现货上方 6.8 点，约 0.42 × I），持到结算。赚的是：**这一段 call 的风险中性价格（信用 / 15 ≈ 23 %）高于收盘落进这一段的实际赔付（训练期 21 %）**。

**谁在付钱**：买近价外 0DTE call 的人（零售的「彩票」型需求与收盘前的空头回补 / 上行保护），由做市商和卖方承接。证据很弱：AFH 2025 说「average OTM call returns are more negative than OTM put returns」「writing naked OTM calls is usually profitable in the 0DTE option market」，但只有图；有表的是 Table 1 的 VRP⁺ > VRP⁻（14:00：1.971 对 0.985）与 OA.3（2022 后上行溢价占比更高）。BBG 2023：零售是 0DTE 的净买方。

**为什么没被套利掉**：(1) 上行尾部（逼空日、政策日）一次赔掉约 3 次的信用；单日最坏 −1,246 美元 / 组（训练期）。(2) 每组每天十几美元，被单日约 530 美元的标准差淹没。(3) 两条腿的点差和费用约占毛边际的一半（k 0.5 时约 13 美元 / 组，毛边际约 27）。

**这个机制在 A-hist 上可能不成立的理由**：
- 外部数字：Vilkov 子期表（10:00、中间价、卖方，bp 标的）2020–21：卖 1.000C / 买 1.005C −0.77 bp ≈ −29 美元 / 组；卖 1.01C / 买 1.02C −0.24 bp（分册用两行之差算，无标准误）。**两行都为负，量级小**，并且都低于约 3 bp 的成本。分册的总判断：卖 OTM 信用价差「文献没有直接证据」。
- **漂移**：2020-04 → 2021-12 是持续的大牛市，bear call 站在漂移的反面；2020-03 与 2022-01…04 是下跌段。训练期 MWF 的「结算 − 14:00 现货」均值只有 +0.17 点，A-hist 的下午漂移若明显为正，这笔交易会亏，而那和溢价无关。§6 要求验证人单报这一项，以便区分「没有溢价」和「漂移帮倒忙」。
- 训练期本身就弱：MWF k 0.5 +16.9，95 % 区间 [−37, +68]，五年里两年为负（2023、2025）。

**可以单独反驳的预言（不含盈亏）**：若溢价存在，A-hist 上平均「信用 / 15」应高于平均「到期赔付 / 15」= mean(clip(结算 − K, 0, 15)) / 15（训练期 MWF 0.232 对 0.212）。若赔付 ≥ 信用，则这段 call 在那个年代没有被卖贵。

## §2 信号与结构（逐字可实现；验证人从原始文件重写）

**数据**、**可用报价**、**现货**、**结算**、**费用**：与 P-0028 §2 完全相同（`quote_1m_dte0` 14:00:00 行、`underlying_1m` 14:00:00 且 > 0、`greeks_eod` 第一行 `underlying_price > 0`；不可用 = 0/0、交叉、bid 0 且 ask > 1.00、点差 > 100 % mid；每腿 max(张数 × 佣金档, 1.00) + 张数 × (交易所费档 + 0.14 + 0.04028)，档位按腿的 mid）。

**每天的规则（每天至多 1 组，1 张）**：
1. 剔除半天（A-hist：2020-11-27、2020-12-24、2021-11-26；训练期 9 天）。**没有**前日收益过滤（那是蝶的规则；winrate_study：大跌次日 bear call 没有变差；用户的实际规格也没有）。
2. S = 14:00 现货；缺 → 不开，计数。
3. 候选短腿 K：5 点网格上满足 S − 30 ≤ K ≤ S + 80（`spread_credit_scan.py` 的扫描范围）、C(K) 与 C(K + 15) 都有可用报价、中间价信用 c = mid C(K) − mid C(K + 15) 满足 **3.00 < c ≤ 4.00**（c 先四舍五入到 6 位小数）。
   - 区间端点取 (3, 4] 是因为已发表的「74 % / +38 / +32」那一行来自 `by_credit.csv` 的 `pd.cut` 桶 (3.0, 4.0]；同一报告的分年表 `credit_3_4_by_year.csv` 用的是 [3, 4]（多 13 行）。见 §7.4。
4. 取 |c − 3.5| 最小的 K；**平局取较高的 K**（更远）。没有候选 → 不开，计数（训练期 31 %，见 §7）。
   - 这一步是本提案对报告规则唯一的补充：报告把每个满足条件的 (日, K) 都算一笔（一天可多笔），交易需要每天一笔。
   - **缺价的回退**：短腿或长腿不可用的 K 不是候选，规则自动落到其他满足条件的 K；不把长腿挪到 K + 20 等别的宽度。
5. 结构：卖 C(K)、买 C(K + 15)，各 1 张。
6. 盈亏（美元 / 组）= (c − k × (H_short + H_long) − min(max(0, 结算 − K), 15)) × 100 − 费用，H = (ask − bid)/2。k ∈ {0, 0.2, 0.5, 1}，**主判据 k 0.5**。

## §3 出场与结算

持到结算，无止损（`spread_stops.py`：提前离场压低期望；用户的实际规格表也是持到结算）。结算 = 当日 `greeks_eod.underlying_price`。没有结算价 → 不计，计数。

## §8 局限

- **年代不匹配**：同 P-0028（0DTE 份额约为 2024 年后的三分之一到一半、零售更少、只有 MWF 与月末到期）。另外，信用 3–4 点对应的位置随 SPX 点位和隐含移动：2020–21 的 SPX 在 2,200–4,800，同样 3–4 点的信用在低点位时离现货的百分比更远，**规格是按点数定的，不是按 delta 或 I 定的**。
- **选择效应**：规则只在「有一个 K 的信用落在 (3, 4]」的日子交易，被跳过的日子 I 偏低；A-hist 的跳过率和被跳过日子的构成会和训练期不同，验证人需报告。
- **费率**：2026 费率套用到 2020；两腿的费用 3.22 美元，当年费率差别在 0.5 美元以内。
- **k 的含义**：同 P-0028；垂直价差在 V-0020 里没有开平不对称，对称 k 合适，但 2020 年的 k 未知。
- **规则的幸存偏差**：15 宽、3–4 点是用户实际在做的规格；winrate_study 显示同宽度下 3–5 点「期望最高」，这是在 2022–26 上看过的。
- **功效**：约 4 %；能分辨的最小效应约 ±80 美元 / 天，远大于训练期的 +17。
- **结算来源**：同 P-0028。
