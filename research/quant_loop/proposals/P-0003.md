# P-0003 等风险仓位：每天按入场时已知的蝶最大亏损（成交借记）反比定组数，不改入场、结构、开不开

范围: A（SPX 0DTE 日内蝶式）

状态: 规格 v1。**机制、信号、结构、预期、失败线写于任何训练期盈亏数字之前。** 写这些之前我只看过一张不含结果的描述表：训练期基准日的翅宽分布（20/25/30/50/75 = 215/110/151/52/15 天；2022 年 50/75 宽 40 天，2023 年 11 天，2024 年 16 天）和各宽度借记中位数（11.4/13.7/15.6/27.9/40.5 点）。训练期证据一节在本节写定之后补入，预期一节跑完后不改。

## 这是一个二阶矩提案（先说清楚判据）

本规则**不改变每天开不开、几点开、开什么**，只改每天开几组。所以它**不可能改变胜率**（每天的盈亏符号和基准完全相同），也不以协议默认的“胜率 +3 个百分点”为目标。它要改进的是**同等总风险下的风险调整收益**：日盈亏的夏普（均值 / 标准差）和“均值 / 最大回撤”。验证人请按下面“预先声明的预期”里的主判据判，不按胜率判。

## 机制

谁在付钱：和基准 A 完全一样——买 0DTE ATM 期权的人付方差溢价（Step 2：14:00 实现 / 隐含 ≈ 0.92），蝶的买方（= 卖 ATM 跨式、买两翼）收它。本提案不声称有新的对手方。

本提案声称的是一个**分配上的缺陷**：基准每天固定 1 组，而按“翅宽 ≈ 2 × 隐含”选宽度之后，一组蝶的美元风险随当天的隐含成比例放大——训练期 20 宽一组借记约 1,140 美元、75 宽约 4,050 美元，差 3.5 倍。于是：

1. **异方差**：日盈亏的尺度 ≈ 借记 D_t（payoff 在 0 到翅宽之间，翅宽与借记同比例）。固定 1 组时，组合的方差几乎全由少数 50 / 75 宽的高波动日贡献。
2. **单位风险的边际不随尺度上升**：已有证据——五个挖掘族约 190 个因子在“翅宽按隐含选好”之后都不再有信息（SUMMARY.md），也就是说按隐含调过宽度后，“今天是大日子”并不预示更高的单位风险收益；而高波动日还有两个额外的结构性劣势：翅宽封顶 75 使极端日的 w/I 掉到 2 以下（winrate_study：w/I < 1.5 胜率明显下降），以及波动的波动在高隐含时更大（实现 / 隐含比更分散，尾部更肥）。基准自己的“跳过前日 ≤ −1%”就是这件事的一个粗糙的二值版本（高波动日减仓到 0），它在样本外站住了。本提案是它的连续版本，**增量必须在已经跳过前日大跌之后仍然出现**。
3. 在 μ_t ∝ D_t^a、σ_t ∝ D_t 的近似下，均值–方差最优的组数 x_t ∝ μ_t / σ_t² ∝ D_t^(a−2)。基准（x 恒定）只在 a = 2（单位风险边际随尺度线性上升）时最优；等风险（x ∝ 1/D）在 a = 1（单位风险边际与尺度无关）时最优。文献上这是 Moreira & Muir (2017) 的波动管理组合：方差变化没有被预期收益的同比例变化补偿时，反比于风险缩放能提高夏普。

为什么没被套利掉：这不是一个定价错误，是一个交易者自己的时间序列仓位选择；做市商和期权买方都不受它影响，不存在可以把它“套走”的对手方。它能不能成立只取决于 a 是否明显小于 2。

**机制可以被单独反驳**（只看基准自身的日盈亏序列，不需要跑规则）：

- G1（异方差存在）：按 D_t 训练期三分位分组，基准日盈亏标准差 高组 / 低组 ≥ 1.5。小于 1.5 → 风险尺度没有真的随借记变，缩放无从改善，放弃。
- G2（单位风险边际不随尺度上升）：Spearman(pnl_t / D_t, D_t) ≤ +0.05。大于 +0.05 → 大日子单位风险赚得更多（a 接近 2），反比缩放会损害期望，放弃。

## 信号

入场那一分钟（14:00）已知、且基准本来就要算的量：

- D_t = 基准当天那一组 put 蝶的**成交借记**（美元，按校准成交模型）= (腿中间价组合 + 0.20 × 半点差和) × 100 + 当组费用（含每腿最低 1 美元）。这就是这组蝶持到结算的最大亏损。
- c = 训练期基准日 D_t 的均值（一个常数，训练期定死，测试期不重估）。
- 组数 x_t = c / D_t。

## 结构

基准 A 一切不变（14:00、ATM put 蝶、翅宽在 20/25/30/50/75 里取 w / implied 最接近 2、中心 = 离现货最近的行权价、跳过 `spx_ret_prev ≤ −1%`、剔半天、持到结算）。只改组数：

- **V1（主判据）连续版**：组数 = x_t（允许小数，费用按组数线性缩放，1 组时的每腿最低佣金照算——对小数组是保守的）。这是对机制的直接检验。
- **V2（次要，用户实际可执行的整数版）**：预算 B = 2c，组数 n_t = clip(round(B / D_t), 0, 2)，和“每天固定 2 组”的基准比。按训练期借记中位数，20/25/30 宽 → 2 组，50/75 宽 → 1 组；只有 D_t > 4c 的极端日才会是 0 组（这一档等于按隐含跳过，是协议警告的“挑日子”，所以 V2 另报一个 clip 到 {1, 2}、永不为 0 的稳健性版本）。2 组时每条腿张数 ≥ 2，佣金 0.65 × 张数 ≥ 1.30，不触发每腿最低。
- 用户只做 20–30 宽时的映射（不另跑）：同一条规则，在 30 宽仍盖不住 2 × 隐含的日子组数自然变少；这是本规则的特例，不是新变体。

## 出场

持到结算（`calendar.settle`）。不提前离场：本提案只改仓位，不涉及路径。

## 成本

k 0.20（`config.yaml` 校准中位数）。用 P-0001 的换算：`pnl20 = pnl_k0 + (0.20/0.25)(pnl − pnl_k0) − 2 × (1.00 − 0.65)`（`winrate_panel` 的 `pnl` 是 k 0.25；put 蝶两条 1 张的腿补到每腿最低 1 美元）。借记 D_t 用同一套：`D_t = cost × 100 + 0.20 × H × 100 + fee + 0.70`，其中 0.25 × H × 100 = `pnl_k0 − pnl`，`fee = (payoff − cost) × 100 − pnl_k0`（这是从面板列反推入场时已知的费用，数值本身不依赖结果）。V2 的 2 组按每腿张数重算佣金（不补最低）。

## 比较口径（写死）

- 规则和基准**同一批日子**，同号日盈亏；只差每天的乘数。
- 夏普 = 日盈亏均值 / 日盈亏标准差（按天，不年化）。尺度无关，不需要归一化。
- 美元口径（均值、最大回撤）在**等总风险**下比较：把规则的日盈亏乘以 `mean(D_t) / c`（该期间基准平均借记 / c），使两者该期间的平均借记占用相同。训练期这个系数按定义 = 1；测试期由验证人按测试期 mean(D_t) 计算（这是事后的评估归一，不是交易决策）。
- 最大回撤 = 累计日盈亏的最大峰谷差。
- 区间：按天配对 bootstrap（2000 次，种子 20261030），重抽日子、同时算两边的统计量再相减。

## 预先声明的预期（写于任何盈亏数字之前）

依据：只用上面那张宽度分布表做的粗算——若单位风险边际恒定（a = 1），纯异方差带来的夏普倍数 ≈ sqrt(1 + CV(D)²)，训练期 CV(D) ≈ 0.4，约 +8%；若高波动日单位风险边际更差（a < 1），会更多。测试期除 2025 年春季外波动较低、50 / 75 宽的天数可能更少，收益相应更小。

机制闸门（训练期，先于规则盈亏；验证人测试期也照做）：

- G1：sd 高组 / 低组，预期 **2.0–3.5**；< 1.5 → 放弃。
- G2：Spearman(pnl/D, D)，预期 **−0.10 到 +0.03**；> +0.05 → 放弃。

训练期（V1 对基准，k 0.20）：

- 夏普倍数（规则 / 基准）：**1.05–1.30**。
- 等风险均值差：**−10 到 +25 美元/天**。
- 等风险最大回撤：规则比基准低 **10–40%**。
- 按年（2022 下半年 / 2023 / 2024 到 10 月）：夏普差三年都 ≥ 0；2022 贡献最大（50/75 宽集中）。任何一年夏普差 < 0 → 我视为不稳，降级为“未证实”，不申请测试期。

测试期（验证人判定用）：

- **主判据**：V1 夏普差（规则 − 基准）> 0，且配对 bootstrap 95% 区间下界 > 0。预期夏普倍数 **1.00–1.20**（中心约 1.07）。
- **副判据**：等风险最大回撤不高于基准（预期低 **5–35%**）；等风险均值差不低于 **−20 美元/天**（预期 −15 到 +20）。
- G1 ≥ 1.5、G2 ≤ +0.05 在测试期也要成立。
- 失败线（任一即 FAIL）：夏普差 ≤ 0 或区间下界 ≤ 0；等风险最大回撤高于基准；等风险均值差 < −20 美元/天；G1 < 1.5；G2 > +0.05；k 0.5 下夏普差翻负。
- 胜率：与基准**完全相同**（按构造），不作判据。
- 我预先承认的最可能失败方式：测试期 50 / 75 宽的日子很少，D_t 的离散度小，夏普倍数接近 1、区间下界碰 0。这应判 FAIL，不是 REVISE。
- V2（整数版）只作参考：预期它的夏普倍数在 V1 的 ±0.05 以内；它不是判据。

## 提案人结论

**撤回。** 机制要求的“单位风险边际不随尺度上升”在训练期被它自己预先登记的 G2 否定，规则的夏普、回撤、均值三项点估计全部比基准差。不申请测试期，也不以换归一量（翅宽 / 隐含）、换预算、换幂次的形式重交——那是同一机制的参数变体。建议账本记一行“训练期撤回”，并加进“已否定的机制”：

- 按入场借记反比定组数的等风险仓位（P-0003）：训练期 G2 = +0.065（大借记日单位风险收益反而更高，高三分位 +9.9% 对低三分位 +0.4%），规则夏普 ×0.76、等风险回撤 +10%。

顺带的事实（看过结果后才知道，**不是主张**，任何据此的提案都已被训练期数据污染）：

- 应以**年内** G2 为准：+0.105 / −0.028 / +0.098（2022 / 2023 / 2024）。上面合并的三分位表（+9.9% 对 +0.4%）**夸大了**效应：2023 年是基准唯一亏损的年份，又占了 215 个 20 宽日里的 122 个，而 2022 年占了 67 个 50 / 75 宽日里的 40 个——合并的“低借记组”很大程度上就是“2023”，“高借记组”就是“2022 + 2024”。
- 另一个平凡解释是 20 点的最小翅宽：安静日 w/I 被迫高于 2、单位借记收益偏低。事后检查（1 个事后诊断，计入变体数）：只留 1.5 ≤ w/I ≤ 2.5 的 512 天，Spearman(pnl/D, D) 仍是 +0.061（年内 +0.103 / −0.019 / +0.082）；w/I > 2.5 的只有 24 天。所以翅宽下限**不是**原因。
- 剩下的解释有两个，训练期分不开：（a）方差溢价按方差（σ²）而不是按波动（σ）定价，大波动日每单位风险收到的更多；（b）只是 2022 下半年和 2024 少数大日子的运气（高三分位期望 +203 的 sd 是 1,252，181 天的标准误约 93；2023 年方向相反）。反方向的规则（大日子加仓）在这里只能算看过数之后的猜测；要提只能作为新机制登记，并且要承认训练期已被看过——本地数据从 2022-05 开始，没有更早的干净样本，唯一干净的检验只剩测试期本身。

变体数（实际）：策略变体 3 个（V1；V2 clip 0–2 与 clip 1–2 在训练期完全重合——没有一天 D > 4c——实际只有 2 个不同的规则）；机制诊断 G1、G2 + 按年 3 切片 + k 0.5；**事后诊断 1 个**（w/I 1.5–2.5 子样本的 G2）。
