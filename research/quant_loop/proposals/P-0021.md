# P-0021 小盘股「正股换 call」：持股者把 Δ×100 股换成一张约 3 周、Δ≈0.35 的 call（静态对冲的买 call）

## 1. 机制
用户的原始做法（持股卖 call 价差）等于把右尾卖掉。训练期对冲后的诊断显示这 15 只的期权**整体不贵**：每日 delta 对冲后卖 call / 卖 put 几乎每一档都亏（按中间价也亏），中位数为正、均值被少数大跳拖负。
3 周期限上，**只在入场时对冲一次**（静态）的买 call 显著为正，而每日对冲的买 call 约为 0。差别来自 3 周内的趋势（收益的正自相关）和向上的大跳——在散户驱动的小盘股炒作行情里，期权按“随机游走 + 正常尾部”定价，低估了持续上冲。
付钱的人：卖 call 收租的持股者和做市商（他们的 IV 跟不上趋势行情的已实现路径）。

**反方证据（文献）**：Cao–Han 2013（高特质波动股票的期权对冲后收益更低 = 偏贵）、Boyer–Vorkink 2014（彩票型期权偏贵）。本提案与之相反，只能是“这批股票、这段炒作行情”的性质，**不是普遍的结构性溢价**。

## 2. 信号 / 入场（入场那一刻已知）
- 标的：ALAB APLD AXTI CLSK CRDO IREN LITE NBIS NVTS OKLO QBTS QUBT RKLB SNDK WOLF。
  **WOLF 数据缺陷**：入场早于 2025-10-13 且到期晚于 2025-09-26 的 WOLF 单子剔除（旧股 2025-09-26 停牌，2025-10-10 起为重组后新股，同一代码接上）。
- 每个 ISO 周的第一个交易日收盘（greeks_eod 的收盘 NBBO，`underlying_price` = 收盘价）。每周一笔，**允许重叠**（每周独立计一笔）。
- 到期：入场日 DTE（自然日）在 [14, 28] 内、最接近 21 天的那个（平局取早）；没有则这周不做。
- 行权价：该到期所有 call，用中间价按 BS（r = 4.3%，无股息）反推 IV、再算 delta；取 delta 最接近 0.35 且 |delta − 0.35| ≤ 0.05、bid > 0、ask ≥ bid 的那一档；没有则不做。

## 3. 结构
- 买 1 份 call（按每 1 股名义计），价格 = mid + k × 半点差；同时**卖出 h0 = delta 股**（= 少持 h0 股），持到到期不调整。
- 到期日收盘按内在价值结算。权利金按 r 计融资成本，卖股所得按 r 计利息。正股成交按成交额 5 bp（开、平各一次）。
- 盈亏 = (max(S_T − K, 0) − (mid + k·hs)·(1 + r·T)) − h0·(S_T − S0) + h0·Σ r·S_t·Δt − 5bp·h0·(S0 + S_T)，除以 S0，记为 %。
  （这就是“把 h0 股换成 1 份 call”相对“继续持有 h0 股”的盈亏。）

## 5. 预先声明的预期（测试期 ≥ 2025-11-01，到期 ≤ 数据末日）
| 量 | 预期 | 失败线 |
|---|---|---|
| Δ0.35、k 0.5 每笔均值 | +0.3 ~ +2.5%（中心 +1.0，按挑选打折） | ≤ 0 |
| 同上，周块 bootstrap 95% 区间 | 不含 0 | 含 0 → 不过关 |
| Δ0.35、k 1.0 均值 | > 0 | ≤ 0 |
| 为正的股票数（k 0.5） | ≥ 9/15 | ≤ 7/15 |
| 去两端 2% 均值（k 0.5） | > 0 | ≤ 0 → 写明“只靠尾部” |
| 相邻档 Δ0.25 / Δ0.50（k 0.5） | 同号 | 翻号 → 不稳健 |
PASS = 前三行全部满足，且按 2 个提案的 Bonferroni（97.5% 区间）仍不含 0；其余几行作稳健性报告。

**推断单位（两个提案共用，验证人不得更改）**：按周块 bootstrap（平均块长 8 周，10000 次），每次重抽后用「抽到的各周全部交易的盈亏合计 ÷ 交易笔数」（按笔加权）求均值，取 2.5% / 97.5%（Bonferroni 另报 1.25% / 98.75%）。不用「各周平均值的平均」。

**预先写定的解读（区分“期权便宜”和“股票接着涨”）**：同时报告**每日对冲**的同一规则（Δ0.35、k 0.5）。
若静态版 > 0 而每日对冲版 ≤ 0 或区间含 0，解读写死为：**收益来自这 15 只 3 周内的趋势延续（动量敞口），不是期权定价偏低**；
策略的边际就是动量，不是期权。只有两者都 > 0 且每日对冲版区间不含 0，才可以说“期权低估了向上的尾部”。

## 6. ETF 盲检
机制只属于小盘股炒作行情，**不预期**在 SPY / QQQ / IWM 上成立（指数期权公认偏贵 → 预期为负）。ETF 全历史（2023-01-27 起）结果**只报告**，不进 PASS。

## 7. 已知局限（验证人请核对并打折）
- **幸存者偏差**：这 15 只是 2026-10 事后按“涨得多的科技小盘”挑出来的，测试期它们仍在大涨。买 call 正是押这一点，所以测试期 PASS 也不能推到别的股票上。干净的检验要一个事前定义的小盘股池，需要另外下载。
- 只有日收盘报价；跨财报不剔除；美式 call 不派息时等同欧式。
