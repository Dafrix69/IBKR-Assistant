## 1. 机制

### 1.1 要测的价格事实
每一笔组合成交都有一个 Π 的买方和一个 Π 的卖方（Π 定义见 §3.1：持有 Π = 卖铁蝶 = 买 1:2:1 蝶，即“近平值短 gamma、长翅膀”的那一侧）。若组合成交价相对**独立的腿中间价参照**系统性偏高 D > 0，那么不论谁主动，Π 的买方平均比腿 mid 多付 D、Π 的卖方平均多收 D。这不需要给成交签号：D 是全部成交价相对参照的**水平**，与 P-0017 被签号噪声污染的问题无关（§1.4）。

### 1.2 谁在付钱、为什么没被套利掉
- **付钱的**：0DTE 近平值组合簿上的 Π 买方——卖铁蝶收权利金、买便宜的平值蝶赌钉住的终端用户（散户、系统化“14:00 开蝶”的程序，包括本项目的基准 A）。这类需求在 0DTE 上是单边的：P-0017 训练期里“成交价高于自带 mid 一跳以上”的笔数是“低于”的 2.3 倍（43% 对 19%），即主动方多半是 Π 买方。
- **收钱的**：组合簿（Cboe COB / COA）上的流动性提供者，持有的是 Π 的反面（买铁蝶 = 近平值长 gamma、短翅膀），承担到期前最后几小时的库存、钉住 / 跳空风险。按需求定价（Gârleanu, Pedersen & Poteshman 2009, RFS：终端用户净需求方向上的期权更贵，做市商要为无法完全对冲的库存收补偿），持续单边的净需求会让组合簿的清算价相对“无需求时的公允中心”向需求方偏移。
- **为什么腿 NBBO 不带这个偏移**：组合簿和腿簿是两本不同的簿；组合单的流动性提供者不必在腿簿上同时报价。把组合簿的偏移套利回腿簿，要在腿簿上逐腿成交——四腿半点差合计 H̄ ≈ 0.285 点 = 28.5 美元/组，比预期的 D（约 2 美元/组）大一个数量级，且 0DTE 腿间跳动快、腿险大。所以 D 可以长期留在腿点差的无套利带内而不被吃掉。
- **对谁有意义**：持到结算的用户每次开仓都是 Π 买方（基准 A 的 put 蝶 / P-0013 的空铁蝶都是），平仓（快速离场 / 止损 / 跟单止损）是 Π 卖方。对称 k 的成交模型会低估开仓成本、高估提前平仓成本。

### 1.3 可被单独反驳的地方
1. D ≤ 0，或日 bootstrap 区间含 0，或两段异号 → 组合成交价围绕腿 mid 对称，没有 Π 买方溢价，FAIL。
2. **安慰剂（唯一一种，§3.4）**：把同一时段、同样四 / 三条腿上的**单腿成交**相对 chain 插值的偏离按 Π 权重合成 D_single。Π 的权重之和为 0（铁蝶 +1−1−1+1、蝶 +1−2+1），所以单腿上“普遍买 / 普遍卖”的压力会相互抵消；如果 D 来自参照本身（chain mid 对这些行权价系统性偏离可成交价），或来自“翅膀单腿总被买、身体单腿总被卖”这类腿簿层面的倾斜，D_single 会和 D 同量级。组合簿机制预言 |D_single| 远小于 D。|D_single| ≥ D / 2 → 组合簿机制被否定，FAIL（即使 1 成立；见 §5）。
3. 只报告、不判：按单笔张数，散户需求机制预言 1–2 张的小单 D 不小于大单。

### 1.4 已知反证与为什么这次不同
- **P-0017（WITHDRAWN，不是 FAIL）**测的是成交**之后**的 mid 漂移（逆向选择），结论是独立参照下没有；它的判定口径被“签号与起点用同一份报价”污染。本提案测的是成交**那一刻**的价位相对独立参照的水平，**不签号**——每笔成交价只与一份报价（chain 插值）比较，成交价本身不是报价，不存在 P-0017 的选择偏差。签号分解（用自带 NBBO 签号、用 chain 插值量水平 = 两份独立报价）只作报告。
- P-0013（PASS）测的是绝对偏离 / 有效 k，不分方向；V-0013 的“同翅宽 put 蝶多偏离 2.4–3.2 美元/组”是绝对值，不是方向。
- 账本里没有 FAIL / 撤回的提案测过组合成交水平的方向。

### 1.5 考虑过、没有选的候选
- (a) 15:50–15:59 收盘前执行成本：它能给出的规则（“15:50 后触发的止损改持到结算”或“提前到 15:45 评估”）都改变赔付，A-tape 不许用结算价判；只按点差判，节省的 2–3 美元/组不足以授权一个改变赔付的规则，结论只能是“只报告”。本提案只在 §3.5 加一个 15:30–15:59 时段的报告行。

## 3. 测量

### 3.1 Π 与参照
- 铁蝶 g = (+1, −1, −1, +1) 对 (K−w P, K P, K C, K+w C)；蝶 g = (+1, −2, +1) 对同权利 (K−w, K, K+w)。Π_trade = Σ gᵢ·pxᵢ（点，每组）。
- **参照（主）**：chain 插值 mid。设 m = floor(t)，u = (t − m) / 60 秒 ∈ [0, 1)，Π_ref = (1 − u)·Σ gᵢ·mid_chain(m, Kᵢ, rᵢ) + u·Σ gᵢ·mid_chain(m + 1, Kᵢ, rᵢ)。chain 第 m 行 = m + 0~0.5 秒的 NBBO（V-0015 §1.4）。各腿两行都要有、非 `flag_bad`、bid > 0，否则该笔丢弃。用 m + 1 行是**测量参照**（同 V-0016 对“t 时 NBBO”的处理），不是信号；另报只用 m 行的参照。
- 每笔 Dᵢ = (Π_trade − Π_ref)·100（美元/组）。

### 3.2 主量
- 日值 D_d = 当日全部合格组合成交 Dᵢ 的 **10% 双侧截尾均值**（每笔等权，不按张数）。
- **主统计量 D = 日值的 10% 双侧截尾均值**（`scipy.stats.trim_mean(x, 0.10)`），区间 = 对日 bootstrap 10,000 次的截尾均值 2.5 / 97.5 分位（种子 18）。另报日值中位数与普通均值（只报告）。
- 分段：训练期段 1 = 2024-10-30 → 2025-04-30、段 2 = 2025-05-01 → 2025-10-31；测试期段 1 = 2025-11-01 → 2026-04-30、段 2 = 2026-05-01 → 结束。

### 3.3 换算成按方向的 k（交付物）
H̄ = 主样本全部合格成交的 Π 四 / 三腿半点差和（用 chain 插值同口径的 m 行，Σ|gᵢ|·(ask − bid)/2）的日级截尾均值。Π 买方 k_buy ≈ 0.20 + D / (100·H̄)，Π 卖方 k_sell ≈ 0.20 − D / (100·H̄)。注：用户自己的 0.20 来自以 Π 买方为主的成交，已部分含 D；这个换算只说明“对称 k 在两个方向上的误差量级”，不建议直接把两数写进 config，见 §5。

### 3.4 安慰剂（唯一一种）：单腿成交按 Π 权重合成
- 单腿成交 = 同一天逐笔里条件码**不在** 130/131/134/137/144 的成交（不按条件码再细分；报告各码占比），要求自带 bid > 0、ask > bid、price > 0。
- 每条单腿成交 j（行权价 k、权利 r、时刻 τ）：ℓ_j = price − mid_chain_interp(τ, k, r)（点；插值同 §3.1）。
- 对每笔合格组合成交 c（时刻 t、腿 i、权重 g）：ℓ̄_i = 腿 i 在 [floor15(t), floor15(t) + 15 分钟) 窗内全部单腿成交 ℓ_j 的均值；任一腿在窗内没有单腿成交 → 该笔不进安慰剂。D_single(c) = Σ gᵢ·ℓ̄ᵢ·100。
- 日值、截尾、bootstrap 与主量完全相同。判据：|D_single| < D / 2（点估计）。

### 3.5 只报告
- 结构：铁蝶 / call 蝶 / put 蝶各自的 D。
- 时段：09:45–12:00 / 12:00–14:00 / 14:00–15:30 / **15:30–15:59**（最后一分钟因无 16:00 行用 m 行参照）。
- 张数：1–2 张 / 3–9 张 / ≥ 10 张。
- 参照改为成交自带的四 / 三腿 NBBO mid（第二份报价，P-0017：与 chain 插值平均差 +0.04 美元/组）；参照改为只用 chain m 行。
- 签号分解：用自带 NBBO 签号（|Π_trade − Π_own| ≥ 0.05），水平用 chain 插值（两份独立报价）；报 s = +1 / −1 / 未签号三组的 D 与笔数占比。只用来描述“D 是靠哪一组成交的价位撑起来的”，不进判定。
- 基准 A 开仓日子集；去掉 2025-04-03 → 04-11；日值中位数、普通均值；H̄ 与 k_buy / k_sell。
- 不计算任何结算 / 盈亏量（A-tape 规则）。

## 5. 判定（测试期 2025-11-01 起，只跑一次）

PASS 需要同时满足：
1. D > 0 且日 bootstrap 95% 区间不含 0（美元/组）；
2. 测试期两段 D 都 > 0；
3. 安慰剂 |D_single| < D / 2。

任一不满足 = FAIL。**事先决定**：若 1、2 成立而 3 不成立，判 FAIL（组合簿机制被否定），账本记“Π 方向的价位偏移存在、但腿簿上也有，不是组合簿专有”，**不据此建议改 config**——因为那时偏移可能来自 chain mid 作为参照的系统误差，而不是用户真实多付的钱。

训练期撤回闸门（训练期跑完后我自己执行、不改）：训练期 1、2（两段 = 2024-10-30 → 2025-04-30、2025-05-01 → 2025-10-31）、3 任一不满足 → 不申请测试期。

**放弃这个想法的结果**：D 区间含 0 或两段异号（组合簿围绕腿 mid 对称）；或单腿合成的 D_single 和 D 同量级（偏移是参照或腿簿的性质）。

**PASS 的用处**：(i) 回测里 Π 买方（开仓）与 Π 卖方（提前平仓）用不同的 k，量级 ±D / (100·H̄)；(ii) Datrix 的快速离场 / 止损 / 跟单止损是 Π 卖方，按对称 k 估的平仓成本偏高，“提前离场普遍压低期望”的结论里平仓成本这一项略被高估（不改那条结论的方向，量级约 D 美元/组）。**即便 PASS 也不是边际**：预期约 2 美元/组，约基准 A 期望（+100 美元/天）的 2%。

局限（写在跑数之前）：
- D 是**成交了的**组合单的价位。用户 AUTO_MID 挂在腿 mid 买 Π，在 D > 0 的簿上是挂在清算中心的不利一侧，成交率会低于对称簿；成交率和未成交的机会成本无法从 tape 得到，只有用户自己的订单日志（含撤单）能给。所以“用户应把挂价锚在哪”这个操作问题本提案**不回答**；组合簿（COB）自己的报价不在数据里，无法比较“组合簿 mid”和“腿 mid”。
- chain 是腿 NBBO 的分钟快照；插值假设一分钟内 mid 线性移动。一分钟内的凸性在风险中性下期望为零，但若组合成交集中出现在 mid 单向移动的瞬间，会给 D 加上与方向相关的噪声；自带 NBBO 参照（第二份报价）用来检查这一点。
- 安慰剂假设单腿簿上“翅膀 / 身体”的买卖倾斜很小；若散户单腿买翅膀（彩票）远多于买身体，D_single 可以在没有组合簿偏移时也不为零（这是我最不确定的一点：它会让条件 3 偏严，而不是偏松）。
