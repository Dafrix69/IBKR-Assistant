## 1. 机制

### 1.1 价格事实
每笔两腿垂直价差组合成交有一个 V 卖方和一个 V 买方，V = 较值钱那条腿 − 较便宜那条腿（同权利、同张数；call 是低行权价 − 高行权价，put 是高 − 低），V ≥ 0。**V 卖方就是信用价差卖方**（卖近腿、买远腿 = bear call / bull put 开仓），V 买方是借方价差买方（bull call / bear put 开仓，或信用价差买回平仓）。
D_v = (V_ref − V_trade)·100：成交价比腿 mid 低多少，即卖方少收的信用（正 = 对卖方不利）。不签号，不判断谁主动，只量水平。

### 1.2 谁在付钱、为什么没被套利掉
- 预言 D_v > 0，与 P-0019 的 D 同族：卖铁蝶和卖信用价差都是**卖近平值 0DTE 权利金**（短 gamma，收权利金、有限风险）。若终端用户在组合簿上是持续的净权利金卖方（散户 0DTE 卖价差程序、"收 3–4 点"式的系统化开仓），组合簿流动性提供者接的是反面（买近腿 = 长 gamma、承担 0DTE 尾部与钉住风险），按需求定价（Gârleanu, Pedersen & Poteshman 2009）会把组合清算价压向卖方不利一侧。P-0019 的 Π 买方偏移（训练期 +2.45 美元/组、约 0.09·H）是同一需求在另一种结构上的读数。
- 没被套利掉：组合簿与腿簿是两本簿；把组合簿偏移套回腿簿要逐腿跨价，两腿半点差合计 H ≈ 0.10–0.15 点 = 10–15 美元/组，比预言的 D_v（约 1 美元）大一个数量级，且 0DTE 腿险大。偏移留在无套利带内。
- **这次为什么可能不成立（写在前面）**：垂直价差的对手方不全是做市商。借方价差（bull call / bear put）是散户最常用的方向单，与信用价差卖方在同一本簿上直接对冲；如果两类终端流量相当，净需求为零，D_v ≈ 0；如果借方方向单更多，D_v < 0。所以符号的先验只略偏正（见 §4）。
- 对谁有意义：用户开仓卖 bear call / bull put 是 V 卖方；止损 / 买回是 V 买方。用户校准的"借方 0.33 / 贷方 0.10"**主要是蝶的读数**（15/21），而蝶的"借方"= 买蝶 = Π 买方、"贷方"= 卖蝶平仓 = Π 卖方，与 P-0019 的方向一致；把它搬到信用价差上，"贷方"就变成了开仓那一侧——若 D_v > 0，贷方 0.10 对信用价差开仓是**乐观的**。这是本编号要回答的实际问题。

### 1.3 反驳链（同 P-0019，任一不成立 = 放弃）
D_v = D_own + F，D_own = (V_own − V_trade)·100（成交自带两腿 NBBO），F = (V_ref − V_own)·100。
1. D_v > 0，区间不含 0，两段同正。
2. 安慰剂 P_own（§3.3）：同一时段同一条腿的单腿成交价 − 自带 mid，按 V 权重合成并同号定向。若"卖方吃亏"是腿簿普遍的价位倾斜，P_own 与 D_own 同量级；组合簿机制预言 P_own ≈ 0。|P_own| < D_v/2。（已知它近 0 几乎是构造使然，见 V-0018 §4；它只排除"腿簿共有"。）
3. F：组合成交那一刻的自带 mid 与 chain 插值之差。|F| < D_v/4，否则 D_v 与报价抽样分不开。
P-0019 的 ±1 秒邻居检查不做：P-0019 训练期已显示组合成交不在腿报价瞬时偏移上（A −0.03），且对两腿结构没有新的理由；少一组变体。

## 3. 测量（美元/组 = 点 × 100）

### 3.1 V 与参照
V_trade = px_s − px_l；V_own = mid_s − mid_l（成交自带）；V_ref = (1 − u)·V_chain(m) + u·V_chain(m+1)，u = 秒/60。H_own = (ask_s − bid_s)/2 + (ask_l − bid_l)/2；H_ch 同式用 chain m 行与 m+1 行插值。

### 3.2 主量 D_v 与共报量
D_v,i = (V_ref − V_trade)·100。日值 = 当日 10% 双侧截尾均值；D_v = 日值的 10% 截尾均值；区间 = 对日 bootstrap 10,000 次（种子 20）的 2.5 / 97.5 分位。分段：训练 2024-10-30 → 2025-04-30 / 2025-05-01 → 2025-10-31；测试 2025-11-01 → 2026-04-30 / 2026-05-01 → 结束。共报 D_own、日中位。

### 3.3 安慰剂 P_own
单腿成交 = 条件码不在多腿集、自带 bid > 0、ask > bid、price > 0；ℓ_j = price − 自带 mid。每笔垂直成交：ℓ̄ 为该腿在同一 15 分钟窗内全部单腿 ℓ 的均值；P_own = −(ℓ̄_s − ℓ̄_l)·100（与 D_v 同号定向：正 = 单腿流也是"短腿卖在 mid 下、长腿买在 mid 上"）；任一腿窗内无单腿成交则不进。日值、截尾、bootstrap 同主量。判据 |P_own| < D_v/2。

### 3.4 F
F_i = (V_ref − V_own)·100，逐笔直接算，日级截尾同主量。判据 |F| < D_v/4。

### 3.5 有效 k（问题 1，不签号）
k_own,i = |V_trade − V_own| / H_own；k_ch,i = |V_trade − V_ref| / H_ch。各报：日级 10% 截尾均值（主）、逐笔中位、P25 / P75，按 §2 分层。另报 |滑点| 中位（点）与 H̄。

### 3.6 卖方签号 k 与用户校准对照（问题 3）
k_sell,i = (V_own − V_trade) / H_own（V 卖方的有效 k，正 = 卖方让价）；V 买方 k_buy,i = −k_sell,i。报 1 张单、10:00–14:00（贴近用户样本）与全部的中位 / 均值 / 分布（≤ 0、≤ 0.25、≤ 0.5、≤ 1 比例），与用户 credit 0.10 / debit 0.33 及 4 笔垂直价差（0.0、1.0 / 0.67、0.5）并列。只描述，不判；用户样本是挂 mid 且成交了的单，tape 是全体成交，两者的选择不同（§6）。

### 3.7 换算（交付物）
k_open_credit ≈ 0.20 + D_v/(100·H̄_own)，k_close_buyback ≈ 0.20 − D_v/(100·H̄_own)（同 P-0019 §3.7 的启发式：0.20 是 config 的对称基准，D_v 是方向修正）。另把 k_own 的测试期截尾均值作为"价差的不签号基准"并列，若它与 0.20 差 > 0.10 在注记中写明。

## 5. 判定

### 5.1 训练期撤回闸门（跑完自己执行，不改）
1. D_v > 0 且区间不含 0；2. 两段同正；3. |P_own| < D_v/2；4. |F| < D_v/4。任一不满足 → 不申请测试期；k（问题 1）与校准对照（问题 3）仍作为训练期描述交付。

### 5.2 测试期 PASS（只跑一次，四条同时成立）
同 5.1 四条，用测试期数据。任一不满足 = FAIL。事先决定：1、2 成立而 3 或 4 不成立 → FAIL，记"方向偏移存在但腿簿也有 / 与报价抽样分不开"，不出方向注记。

**放弃这个想法的结果**：D_v 区间含 0、两段异号，或为负（对卖方有利）；或 P_own、F 相对 D_v 过大。

### 5.3 PASS 后的交付物
`config.yaml` 成交模型的价差专用**注记**（写在账本行与 V-0020，不改文件）：近平值 0DTE 两腿垂直价差，开仓卖信用 k ≈ 0.20 + D_v/(100H̄)、买回 ≈ 0.20 − D_v/(100H̄)，按测试期重算；并写明用户 21 笔的"贷方 0.10"不适用于信用价差开仓。量级预期约 1 美元/组，远小于信用价差每笔期望的不确定性；不是边际。

## 8. 结论（提案人）

**训练期撤回（闸门 4）。不申请测试期。**

- 方向水平：垂直价差组合成交相对腿 mid 向信用价差卖方不利的偏移，chain 插值口径 +0.07、自带 NBBO 口径 +0.28 美元/组，两者之差 F −0.22 是 D_v 的 3 倍，按预注册不能把 D_v 与参照误差分开。更根本的是**量级可以忽略**：最大的口径也只有 0.025·H̄，不足 1 张价差一条腿最低佣金的三分之一。与 P-0019 的蝶不同，垂直价差的组合簿在训练期近乎对称（k_sell 中位 0、均值 +0.04）。
- 不签号有效 k（问题 1 的答案，训练期描述，不需要测试期判定）：**k_own ≈ 0.25**（两段 0.27 / 0.24，按宽度、时段、权利、张数各层 0.20–0.29），平均 |滑点| 约 2.8 美元/组；chain 插值口径 0.71 是参照噪声，不要拿分钟快照估价差的 k。
- 给 `config.yaml` 的话（训练期描述，不是测试期结论，不改文件）：信用价差可以沿用对称 k 0.20（略乐观约 0.05·H̄ ≈ 0.5 美元/组）；**不要**把用户校准里的"贷方 0.10"当成信用价差开仓的 k，它来自蝶。
- 放弃的是"垂直价差组合簿上存在 P-0019 式的权利金卖方让价"这个机制，在本数据里它即便存在也小于 0.3 美元/组。
