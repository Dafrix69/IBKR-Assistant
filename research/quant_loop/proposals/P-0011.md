## 机制

**命题**：做市商把“周五收盘 → 周一收盘”当作一块方差来定价，并在周一开盘时把周末积压的不确定性（周末新闻、亚欧盘的跳空在开盘一次性实现）**延续**到周一 0DTE 的隐含里；而周一上午实际走得比这个隐含安静。开盘后几个小时内，做市商看到“周末已经过去、上午很平”，把 0DTE 隐含重新校准下来，所以溢价集中在**周一上午入场**的期权上，到 14:00 入场时已经没有了。这是 Jones & Shemesh（2018, *JF*, “Option mispricing around nontrading periods”）“非交易期附近的期权错误定价”在每日到期时代的样子：他们发现期权收益在跨周末的持有期显著更低，解释为市场对休市期方差的错误处理（按日历时间而非交易时间摊方差），不是风险补偿。每日到期把“周末”拆成了周五 1DTE 和周一 0DTE 两张合约，错误定价不一定只在周五收盘那张上，也会落在周一 0DTE 开盘时的报价上（做市商的隐含模型带着“周末刚过、波动应当偏高”的先验进入周一）。

**谁在付钱**：周一开盘买 0DTE 期权的一方——周末积累了观点、开盘就想表达的散户与方向交易者（周一开盘的 0DTE 买盘量），以及在周末对冲缺口后补对冲的机构；做市商因为需求偏买方而抬高上午的隐含，自己则在上午卖出、在下午随隐含回落而获利。

**为什么没被套利掉**：(1) 单天噪声极大：0DTE 铁蝶单日盈亏标准差约 1000 美元量级，而周一一年只有约 50 次，溢价即便有 10%（约 2–3 个跨式点），一年的累计期望也在两三个标准误之内，任何一年都可能为负，资本有限的卖方无法据此放大；(2) 收这笔钱要在周一上午持有空 gamma 跨过几个小时，周一上午若周末消息被延迟消化（如 2024-08-05）会有尾部；(3) 星期效应是公开知识，但大部分卖方在 13:00 之后进场（winrate_study 已示 0DTE 卖方偏好下午），上午这段被少数人拿，没有被系统性挤平。

**为什么溢价在周一上午而不在 14:00（回答 cross.md 的 Mon@14:00 不成立）**：隐含不是固定的，它每分钟按做市商对剩余时间方差的看法重定价。机制说的是“周一开盘时带入了过量的周末先验”；随着上午实际走得平，做市商在 10:00–14:00 之间逐步把它降下来，到 14:00 剩下的 2 小时已按当天实际的节奏定价，于是 14:00 入场看不到溢价。这给出三个**可以单独否定**的价格 / 分段预言（全部只用价格与现货路径，不用盈亏）：

- **预言 V（主，回答 14:00 问题）**：休市后首日，10:00 → 14:00 的 0DTE ATM 跨式**隐含方差下调** D = 1 − (I₁₄/I₁₀)² 大于对照日；并且在**控制上午实际走幅**后仍大于（回归 D = a + b·m + c·PNT，m = |S₁₄ − S₁₀| / I₁₀；预言 c > 0）。控制 m 是必要的：平静的上午在任何一天都会让隐含回落（实现 → 隐含的反馈），只有在同样的上午走幅下周一下调得更多，才是“开盘带入了多余先验”而不是“周一碰巧平静”。
- **预言 S（分段）**：上午段 x_m = |S₁₄ − S₁₀| / √(I₁₀² − I₁₄²) 在休市后首日**低于**对照日；下午段 x_a = |settle − S₁₄| / I₁₄ 与对照日**无差**（|差| < 0.05）。若下午段也明显低，那周一的溢价是全天的水平效应，“14:00 已重新校准”的说法就错了。
- **预言 L（开盘水平）**：休市后首日 09:35 的 I/S 相对前收 VIX 的归一化水平 (I₀₉₃₅/S) / (VIX_prev/100/√252) 高于对照日。若周一开盘隐含**不**更高，那 x 低是“周一实际走得少”而非“定价多”，机制降级为实际波动的星期效应（仍可交易，但不是 Jones–Shemesh）。

**最强的竞争解释（必须先排除）**：**周一没有 08:30 的数据发布**。CPI、NFP、PCE 都落在周二到周五，FOMC 落在周三；step2 显示 NFP / PCE 的 09:35 ratio 1.10 / 1.17。P-0010 的对照“其余 1.053”含这些日子。所以本提案的主对照是**非休市后、且非 CPI / NFP / PCE / FOMC 的日子**，并设闸门：主差值（对非事件对照）若小于“对全部非 PNT 日”差值的一半，机制改判为“无事件的上午”，撤回。另一个已知的反向离群是**周四上午**（step2 全样本 1.116 / 1.136），它会拉高“其余日”的均值；我把五个星期全部单列报告，并用周二对周三做安慰剂。

## 信号（入场那一分钟已知）

- **PNT（post-non-trading，处理组）**：交易日 d，calendar 中前一个交易日 p 满足 (d − p) ≥ 2 个日历天。即周一（周五 → 周一 = 3 天）、长假后的周二、周中假日后的那一天。全部在 d 的开盘前已知。纯周一单列报告。
- **对照组**：非 PNT 且非 CPI / NFP / PCE / FOMC 的交易日。
- 两组都剔除：半天、无 0DTE；**PNT 也剔除同日 CPI / NFP / PCE / FOMC**（主口径；含事件版只报告）。
- 入场时刻 t = 10:00（主），S = `spot.parquet` 10:00 的 `spot`；10:30 只报告，09:35 只作历史对照。
- 不用 VIX、I 水平、星期以外的任何东西过滤；I 三分位只用于闸门分层。

## 结构

- **0DTE 铁蝶（卖方）**：卖 K call、卖 K put，买 K + w call、买 K − w put，1 组 / 天，持到结算（`calendar.settle`），现金交割，无出场成本。
- K = 10:00 chain 中离 S 最近的行权价（平局取低）；I = K 档 C_mid + P_mid（`flag_bad` 行不用）。
- w = 离 2 × I 最近的 5 点倍数（|w − 2I| 相等时取窄，比较加 1e-9 容差，P-0008 教训）；最小 10。
- 跳过：四腿任一缺档或 `flag_bad`、短腿 bid ≤ 0、或任一腿 ask − bid > 2.0 点（翅腿 bid = 0 允许）。
- 成交：每腿 px = mid ± k·(ask − bid)/2（买加卖减），k = 0.20；费用每腿 max(佣金档, 1.00) + 交易所费档 + 0.14 + 0.04028（config.yaml 校准值，与 P-0009 / P-0010 同实现）；乘数 100。另报 k 0 / k 0.5。
- 赔付：结算时空跨式内在值 min(|settle − K|, w) 的点数 × 100。
- 选这个结构而不是周五收盘 1DTE：P-0010 的 16:15 收盘 NBBO 有未排除的报价伪影（P 集中在点差 / I 高半），且翅膀在那里净成本 −70 / 晚；周一 10:00 用盘中分钟报价，成交可信度与基准同一来源。**周五收盘 1DTE 空铁蝶只报告**（沿用 P-0010 定义，按测试期跑一次，不进判定）。

## 主检验与判定口径

- x = |settle − S₁₀| / I₁₀（标度无关，先比 x 再比盈亏：PNT 的 I 若更高，2×I 的翅膀就机械地更宽，盈亏不能直接比）。
- **G_x = mean x(PNT) − mean x(对照)**，日重抽样 95% 区间（10 000 次，两组各自重抽）。
- **EV_PNT** = PNT 日铁蝶盈亏均值（k 0.20）；**ΔEV = EV_PNT − EV_对照**。
- 预言 V：c（OLS，HC1 标准误）与原始 D 差；预言 S：x_m、x_a 差；预言 L：归一化开盘水平差。
- 安慰剂（唯一一种）：**周二 vs 周三**（均非 PNT、非事件），同口径 G_x 与 ΔEV。
- 报告：五个星期各自的 x、EV；10:30 同口径；含事件版；纯周一；按年；I₁₀/S 训练期三分位；settle − S₁₀ 符号两半；去 PNT 最好 5 天；k 0 / 0.5；与基准 A（同日 14:00 规则）日盈亏相关。

### 机制核对：三条价格预言里一条半不支持，必须照实写

1. **预言 L 反了**：PNT 开盘的归一化隐含**低于**对照（−0.015，约 −3%，区间几乎不含 0），10:00 的 I 中位也更低（21.05 对 22.35）。做市商**已经**把周一定价得更便宜，只是还不够便宜——x 低来自“周一 / 休市后实际走得更少”，而不是“开盘带入了多余的周末先验”。按规格自己的话，机制降级为**日内实际波动的星期（休市后）季节性被部分低估**，Jones–Shemesh 的“错误摊派周末方差”在开盘价格上看不到。
2. **预言 S 的下午段不成立**：x_a 差 −0.133（< −0.10 线），PNT 的下午段**也**实现得少。所以“到 14:00 已被重新校准”这个对 cross.md Mon@14:00 的解释，在训练期就是错的：训练期周一 14:00 同样有效。
3. 预言 V 方向对但弱：控制上午走幅后 c +0.014（t 1.4），原始 +0.023。

**那 cross.md 的 Mon@14:00 为什么不成立？** 更诚实的回答是：不是机制在 14:00 消失，而是**测试期**周一下午变差了。用 step2 全样本表粗算（与“污染申报”同法，口径近似）：全样本周一 14:00 0.904，训练期 PNT 下午段 0.831（约 127 天）→ 测试期周一 14:00 约 1.02；全样本其他日 14:00 约 0.925，训练期对照 0.964 → 测试期其他日约 0.88。即测试期周一下午**比**其他日更差。cross.md Mon@14:00 训 +5.0pp / 测 −4.1pp 的翻转就是这件事；Mon@13:00 测试期仍 +5.7pp 但期望只有 +42。同法粗算 10:30：测试期周一约 0.92、其他日约 0.99，差约 −0.07（09:35 约 −0.06）。由于 x₉₃₅ / x₁₀₃₀ 本身是“入场到结算”，这已经把测试期下午的反转算进去了——**10:00 入场的测试期 G_x 由此推测约 −0.05 ~ −0.07，与预注册中心 −0.05 一致**；但盈亏（翅宽固定 2×I、尾部决定 EV）不能由此推出。

### 周四：把 PNT 当日历噪声的最强理由

星期一行 G_x −0.201，周四 **+0.253**，量级相同、方向相反；周四在 step2 全样本里同样离群（1.116 / 1.136）。每个星期约 120 天、x 标准差约 0.7，单个星期的标准误约 0.065，周一与周四都在 3–4 个标准误。我降级后的机制（休市后实际波动季节性）**对周四没有任何预言**，所以“五个星期里本来就有两个各偏 3 个标准误的格子”是对 PNT 最强的现存反驳。预注册的安慰剂周二 − 周三（−0.061）是从两个安静的星期里取的，**低估了星期之间的真实离散**；我不改安慰剂（已预注册），但验证人应把周四 +0.253 当作“按星期切分本身能制造多大的差”的另一参照。

### 结论与申请

闸门 0 条触发，按预注册**申请测试期一次**。但我对它的定位改为：**一个被训练期确认、测试期已被部分推知、机制解释在训练期就有一半不成立的日历效应**。规格前面写的 PASS 条件（G_x < 0、EV_PNT > 0、ΔEV > 0、c > 0）不改。预言 L、S 已在训练期与规格的机制叙述冲突，这一点不因测试期结果而撤销：即使测试期 PASS，也只能记为“休市后首日上午卖 0DTE 波动有边际（日历 / 实际波动季节性）”，**不能**记为 Jones–Shemesh 机制得到证实。另：c > 0 不是漏洞——若测试期 G_x、EV_PNT、ΔEV 三条成立而 c ≤ 0，按规格记为“有日历效应、无所述机制”，判 **FAIL**。
