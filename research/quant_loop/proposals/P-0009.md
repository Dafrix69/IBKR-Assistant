## 机制

**要预言的量**：同一天、同一种选点规则（收 3–4 点、15 宽），14:00 入场的价差比 10:30 入场的价差“卖得更贵”，即单位风险的风险中性损失与实际损失之差更大。

**我押的命题（H）**：0DTE 的方差溢价（风险中性方差 − 实际方差，按剩余方差归一化）**越接近到期越厚**。原因有三：(1) 到期前最后两小时 gamma ∝ 1/√τ 爆炸，做市商单位方差的库存风险最大，按风险厌恶收更高的单位方差价（Bollen & Whaley 2004 的“净买压 + 做市商对冲成本”在 0DTE 上的时间版本）；(2) 下午的 0DTE 需求以彩票型买家和收盘前对冲为主，他们为“最后一段的凸性”付费，对价格不敏感；(3) 15:50 MOC 失衡与收盘集合竞价是离散跳跃，做市商对它保守定价。10:30 的价差持有期里有午盘低波段（11:30–13:30 实际方差最低），但 10:30 报价中“剩余方差”由早盘高波动与全天平均主导，单位方差溢价摊薄；14:00 的价差只承担最后两小时，溢价最集中。

谁在付钱：下午买 0DTE 价外期权的人（彩票型多头与收盘前保护买家）。卖方在 14:00 卖出、持到结算，收的是这段集中溢价。

为什么没被套利掉：(1) 卖临近到期的 gamma 每单位资本的跳跃 / 钉住风险最大，资本与回撤约束让卖方供给有限；(2) 效应是“单位方差的价”，换算到单笔价差只是每天十几到几十美元，被单日 ±1000 美元的噪声淹没；(3) 机构卖方（备兑、0DTE 收入型基金）在固定时点（多为上午）卖出，不在下午补位。

**能单独否定它的预言**：如果 H 是“单位方差溢价随时间上升”，那它对**两侧**都成立——bull put（收 3–4 点、15 宽）从 10:30 挪到 14:00 也应该更好。**竞争解释“下午漂移”只能让一侧变好、另一侧变差**（V-0005：下午向上漂时 bear call 早进场更吃亏、bull put 早进场更占便宜，反之亦然）。所以：call 侧与 put 侧的时段增量必须**同号且都为正**；并且 call 侧在 settle − F 下行月、put 侧在上行月（各自“漂移帮倒忙”的那一段）仍须为正。

**其余竞争解释**：
- **I 水平影子**：同一天两时点比较，日间 I 水平已经配对；仍按 10:30 的 I 三分位分层报告并设闸门。
- **选点规则跟着时间漂移**（P-0004）：收 3–4 点在 10:30 与 14:00 对应的“距离 / I”不同；不含盈亏的主检验 D 是在各自短腿处的风险中性 vs 实际概率差，已按各自价格归一化，不依赖距离；另报短腿距离 / I 的分布。
- **成本**：14:00 的价外腿点差比 10:30 窄（期权更便宜），成本差会单独贡献一部分；主检验 D 不含成本，盈亏线含校准成本。

## 信号（入场那一分钟已知）

无日间信号。规则是“入场时点 = 14:00 而不是 10:30”。每个时点 t ∈ {10:30, 12:00, 13:00, 14:00}：
- `S_t` = `spot.parquet` t 分钟现货；`F_t` = 同行 `parity_F`（只用于分段标签）；`I_t` = 离 S_t 最近 5 点行权价的 C + P mid（只用于分层与报告）。
- 报价 = `chain_{D}.parquet` 中 `ts == t` 且 `flag_bad == False` 的行。

## 结构

- **bear call（主）**：卖 C(K)，买 C(K + 15)，K ≥ S_t。候选 K 为 5 点网格上满足：两腿都在、都不是 `flag_bad`、**每腿 ask − bid ≤ 2.0 点**、**价差 mid 信用 = mid C(K) − mid C(K+15) ∈ [3.0, 4.0]**；取信用离 3.5 最近者，平局取更高 K（更远）。没有候选 → 该时点当天不交易。
- **bull put（机制检验用，不是交易建议）**：卖 P(K)，买 P(K − 15)，K ≤ S_t，同样的过滤与选点（平局取更低 K）。
- 成交：每腿 `mid ± 0.20 × (ask − bid)/2`（卖腿减、买腿加）；费用按 `config.yaml`：佣金分档且每腿最低 1 美元、交易所费分档、0.14 附加费、0.04028 监管清算；只计开仓（持到结算无平仓费）。同时算 k 0.5、k 0。
- 每天每个时点每侧 1 组。
- 样本：训练期、非半天、有 0DTE。**FOMC 日从主样本剔除**（14:00 = 声明时刻，那是定时跳跃，不是 H 讲的到期溢价）；含 FOMC 的结果只报告。**不**跳过前日 ≤ −1%（那是蝶的规则；winrate_study 显示大跌次日 bear call 没有变差），只报告该子集。
- **配对**：主比较只用 10:30 与 14:00 **两个时点都有候选**的日子（每侧各自配对）。

## 出场

## 主检验（不含盈亏）

在短腿处取 5 点“斜坡”：call 侧 `ramp = clip(settle − K, 0, 5) / 5`，其风险中性价格 `q = (mid C(K) − mid C(K+5)) / 5`；put 侧 `ramp = clip(K − settle, 0, 5) / 5`，`q = (mid P(K) − mid P(K−5)) / 5`。`d_t = q_t − ramp_t`（> 0 = 短腿那一段被卖贵了）。若 K+5（或 K−5）缺档或坏报价，该日该侧的 D 不计（盈亏仍计）。

- **D_call = mean(d_14 − d_10:30)**（call 侧配对日）；**D_put** 同理；**D_2 = (D_call + D_put) / 2**。H 预言三者都 > 0。
- 辅助 **G**（不含成本的毛边际 / 宽度）：`g_t = (mid 信用 − 到期赔付) / 15`，G_call、G_put、G_2 同样配对相减。只报告，进闸门 5。
- 单调性（报告 + 闸门 6）：12:00、13:00 的 d 相对 10:30 的配对差。

## 盈亏检验（符号线）

- **Δ_call** = mean(pnl_14 − pnl_10:30)，call 侧配对日，美元，k 0.20；同时报 k 0.5、k 0、各自胜率、各自未配对的全部日子的期望。
