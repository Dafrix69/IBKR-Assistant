## 1. 机制

### 1.1 价格事实
每笔近平值 0DTE 组合成交都有一个 Π 买方和一个 Π 卖方（持有 Π = 卖铁蝶 = 买 1:2:1 蝶 = 近平值短 gamma、长翅膀）。若组合成交价相对腿中间价系统性偏向 Π 买方一侧 D > 0，则不论谁主动，Π 买方平均比腿 mid 多付 D、Π 卖方多收 D。不签号，只量水平。

### 1.2 谁在付钱、为什么没被套利掉（同 P-0018 §1.2，不改）
- 付钱的：0DTE 近平值组合簿上持续单边的 Π 买方需求——卖铁蝶收权利金 / 买便宜平值蝶赌钉住的终端用户和系统化下午开蝶程序（包括本项目的基准 A）。
- 收钱的：组合簿（Cboe COB / COA）上的流动性提供者，接的是 Π 的反面（近平值长 gamma、短翅膀），承担最后几小时的库存、钉住 / 跳空风险；按需求定价（Gârleanu, Pedersen & Poteshman 2009），单边净需求使组合簿的清算价向需求方偏移。
- 没被套利掉：组合簿与腿簿是两本簿；把组合簿的偏移套回腿簿要在腿簿逐腿成交，四腿半点差合计约 26–28 美元/组，比 D（约 2 美元/组）大一个数量级，0DTE 腿险大。D 留在腿点差的无套利带内。
- 对谁有意义：持到结算的开仓（基准 A、P-0013 的空铁蝶）是 Π 买方；快速离场 / 止损 / 跟单止损是 Π 卖方。对称 k 低估开仓成本、高估提前平仓成本。

### 1.3 这次的反驳链（三件事都要成立，任一不成立 = 放弃）
D = (成交价 − 自带 mid) + (自带 mid − chain 插值) = D_own + F。

1. **D > 0，两段同正**（价格事实存在且稳定）。
2. **新安慰剂 P_own（§3.3）**：同一时段、同一条腿上的**单腿成交价 − 它自带的 NBBO mid**，按 Π 权重合成。它和 D_own 是同一种比较（成交价对成交时刻的腿 NBBO），是"苹果对苹果"的一对：如果 Π 方向的偏移是"腿簿上普遍的价位倾斜"（翅膀单腿总被买在 mid 之上、身体总被卖在 mid 之下之类），P_own 会和 D_own 同量级；组合簿机制预言 P_own ≈ 0 而 D_own ≈ D。
   - 预先回应显然的质疑："单腿成交价 − 自带 mid ≈ 0 几乎是构造出来的"——对买卖平衡的单腿流的确如此，**这正是要点**：同一种报价参照下，腿簿没有 Π 倾斜，组合簿有 +2 美元/组。安慰剂要排除的是"D 是腿簿共有的性质"，不是"单腿成交价有没有噪声"。它不能排除"chain 参照本身错"，那由第 3 条管。
3. **F（§3.4，公平性检查）**：组合成交那一刻的"自带 mid − chain 插值"。P-0018 §5 写死的担心是"偏移可能来自 chain mid 作为参照的系统误差 / 组合成交时点的报价抽样"——那就是 F。|F| 远小于 D 才能说 D 不是报价抽样偏差，D 与 D_own 讲的是同一件事。
4. **±1 秒邻近报价（§3.5，回答 P-0018 §7.3 的问题）**：组合成交是否集中在腿报价短暂偏移的瞬间。用组合成交前后各 1 秒内同一条腿上其他成交自带的 NBBO 做第三份参照。读法规则写在 §3.5，训练期闸门见 §5。

只报告、不判：按张数、时段、结构（预期仍无张数梯度）。

## 3. 测量（美元/组 = 点 × 100）

### 3.1 Π 与参照（同 P-0018）
g：铁蝶 (+1, −1, −1, +1) 对 (K−w P, K P, K C, K+w C)；蝶 (+1, −2, +1)。Π_trade = Σ gᵢ·pxᵢ；Π_own = Σ gᵢ·(bidᵢ + askᵢ)/2（成交自带）；Π_ref = (1 − u)·Σ gᵢ·mid_chain(m) + u·Σ gᵢ·mid_chain(m+1)，m = floor(t)，u = (t − m)/60 秒。

### 3.2 主量（不改）
Dᵢ = (Π_trade − Π_ref)·100。日值 = 当日 Dᵢ 的 10% 双侧截尾均值；D = 日值的 10% 截尾均值；区间 = 对日 bootstrap 10,000 次截尾均值的 2.5 / 97.5 分位（种子 19）。分段：训练期 2024-10-30 → 2025-04-30 / 2025-05-01 → 2025-10-31；测试期 2025-11-01 → 2026-04-30 / 2026-05-01 → 结束。
同口径另报 D_own = (Π_trade − Π_own)·100（具名共报量，不判）。

### 3.3 安慰剂 P_own（唯一一种）
- 单腿成交 = 条件码**不在** 130/131/134/137/144，自带 bid > 0、ask > bid、price > 0。
- 每条单腿成交 j：ℓ_j = price − (bid + ask)/2（点，用它自己那一行的 NBBO）。
- 每笔合格组合成交 c（时刻 t、腿 i、权重 g）：ℓ̄ᵢ = 腿 i 在 [floor15(t), floor15(t) + 15 分钟) 窗内全部单腿 ℓ_j 的均值；任一腿窗内无单腿成交 → 该笔不进安慰剂。P_own(c) = Σ gᵢ·ℓ̄ᵢ·100。
- 日值、截尾、bootstrap 同主量。判据：|P_own| < D/2（点估计）。

### 3.4 公平性检查 F
F(c) = (Π_own − Π_ref)·100，逐笔直接算（不是 D − D_own 的截尾均值相减），日值、截尾、bootstrap 同主量。判据：**|F| < D/4**（取绝对值：负的 F 同样说明组合成交时点的报价与分钟参照不一致）。

### 3.5 ±1 秒邻近报价（回答 P-0018 §7.3）
- 对每笔组合成交的每条腿，在同一（行权价, 权利）上找**不在同一毫秒**的其他成交：pre = [t − 1 s, t) 内最后一笔，post = (t, t + 1 s] 内第一笔；取它们各自自带 NBBO 的 mid。两组邻居分别做：
  - (a) 单腿成交（非组合码）；
  - (b) 组合码成交（别的组合单在同一条腿上的那一腿）。
- 每条腿 pre 与 post 都要有，Π_nb = Σ gᵢ·(mid_preᵢ + mid_postᵢ)/2；任一腿缺 → 该笔不进该组。
- 三个量（每组，日级截尾同主量）：A = (Π_own − Π_nb)·100（组合成交那一刻的报价相对前后 1 秒是否偏离）；B = (Π_nb − Π_ref)·100（这组邻居本身是否与 chain 一致）；F_cov = 同一覆盖子集上的 F。另报覆盖率、覆盖子集上的 D 与 D_nb = (Π_trade − Π_nb)·100。
- 漂移：P-0018 的分钟内 Π 平均漂移约 0.015 点/分钟，±1 秒约 0.03 美元/组，忽略。
- **读法规则（先写死）**：一组邻居要"能定罪"，它自己必须与 chain 一致（|B| < D/4），且 |A| ≥ D/4 → 判定"组合成交集中在腿报价短暂偏移的瞬间"。两组都与 chain 不一致 → 本检查不能下结论，以 F 为答案。理由：P-0018 §7.3 已知单腿成交时刻的自带报价相对 chain 有 +0.4 ~ +5.2 美元/张的抽样偏移，(a) 组很可能自己就不与 chain 一致；拿一份有偏的邻居去比，A 会机械地很大而组合成交并无瞬时偏移。
- 只报告：±5 秒同口径（两组）；单腿成交自身的同一检查（单腿 own mid − 同腿 ±1 秒他笔 mid 均值，按距离 5 档 × 权利，美元/张）；报价年龄（trade_timestamp − quote_timestamp）在组合腿与单腿上的中位 / p90，以及单腿"自带 mid − chain 插值"按报价年龄分档（< 5 ms、5–50 ms、50–500 ms、0.5–5 s、≥ 5 s）。最后两项用来解释 P-0018 旧安慰剂为什么失败：若单腿偏移随报价年龄变化，它是数据来源的性质，不是市场状态。

### 3.6 只报告（同 P-0018）

## 8. 结论（提案人）

**训练期五条闸门全过，申请测试期（只跑一次，按 §5.2 四条判）。**

- 价格事实 D（+2.45 美元/组）在训练期由三份参照共同支持：chain 插值、成交自带 NBBO（+2.27）、±1 s 组合码邻居（覆盖子集上 +4.12 对 D +4.19）。单腿成交相对自带报价不向 Π 方向偏（+0.01），所以偏移是组合簿专有的；组合成交时刻的自带报价与分钟参照只差 +0.24、与前后 1 秒同腿报价只差 −0.03，所以 D 不是组合成交时点的报价抽样。
- 训练期非盲的部分：D、D_own、各分层的方向与量级（P-0017 / P-0018）；P_own ≈ 0 可由已知分档推得。证据只能来自测试期。
- **最不确定的一点（看过训练期之后才看清的）**：F 是一个稳定的小正数（+0.24 [+0.16, +0.32]，两段 +0.22 / +0.26），而闸门 4 是相对 D 的（|F| < D/4）。若 F 在测试期保持约 +0.24，它实际上要求测试期 D ≳ +1.0；§4 预期区间的下半段（+0.5 ~ +1.0，P-0013 式的逐年收窄可能落到这里）会在 D 显著为正、P_own 干净的情况下因闸门 4 判 FAIL——那不是 D 消失，而是 F 与 D 的比例。§4 / §5 不改，按原样判；§6 写的“两组邻居都与 chain 不一致”这一担心已被训练期数据解决（(b) 组一致）。
