# P-0001 国债票息拍卖日（13:00 ET）的跳跃风险：拍卖日不在 13:00 开蝶，等结果出来再开

范围: A（SPX 0DTE 日内蝶式）

状态: 规格 v1，**预期部分写于任何训练期数字之前**（见文末"写作顺序"）。训练期证据一节在预期写定之后补入。

## 机制

美国财政部的票息国债拍卖（2y / 3y / 5y / 7y / 10y / 20y / 30y，以及 TIPS）竞争性投标在 **13:00 ET 截止**，结果在 13:01–13:03 公布。拍卖结果（尾部 tail / 认购倍数 / 间接投标占比）是一个**定时、在入场前已知会发生、但方向和幅度未知**的跳跃源，落在 13:00 入场蝶的持有窗口的头几分钟里。2023–2024 年多次长端拍卖"尾部"直接打出了 SPX 下午的趋势（例：2023-11-09 的 30 年期拍卖）。

谁在付这笔钱、为什么没被套利掉：

- 0DTE ATM 跨式的定价靠做市商的日内波动率时钟（intraday vol clock）。标准时钟里标记的定时事件是 FOMC / CPI / NFP 这类 08:30、10:00、14:00 的数据；**13:00 的票息拍卖是债市的事件，不是股指期权做市商通常标记的事件**，每月 8–9 个拍卖日里大多数只造成 1–3 点的瞬时抖动，但分布的尾巴（流拍 / 大尾部）很肥。
- 蝶是空 gamma 结构，对未被定价的跳跃的损失是凸的（移动越大亏得越多），而跨式价格对波动率是线性的；如果做市商只按"平均日"的时钟给 13:00–14:00 这一小时定价，那么 13:00 在拍卖日开蝶的人就是在**免费承担**那个跳跃。付钱的是 13:00 开蝶的人自己（这是避免成为付钱方的提案，不是向别人收钱的提案）。
- 为什么没被套利掉：边际小（一小时的跳跃方差），只对**恰好在 13:00 入场、持到结算**的结构有意义，而大多数 0DTE 参与者不是在 13:00 定时入场的。

**这个机制可以被单独反驳**：如果 13:00 的 ATM 跨式在拍卖日相对 14:00 的跨式更贵（做市商已经把这一小时的额外方差算进去了），或者拍卖日 13:00–13:10 的 SPX 实际移动并不比非拍卖日大，机制就不成立。

与账本里已否定机制的区别：账本否定的是入场因子（墙、GEX、动量、曲面、持仓、跨资产、日历中的 FOMC/CPI/NFP/PCE 前后日、opex、月末、星期）和离场规则。**票息拍卖日**不在任何一族的因子清单里（cross 族的事件只有 FOMC/CPI/NFP/PCE 的前一日 / 后一日，没有国债拍卖），而且它不是"预测收盘落点"的因子，是"避开窗口内一个定时跳跃"的时机规则。它和星期因子有重叠的风险（拍卖集中在周二到周四，30 年期在周四），所以预先登记按星期分层的检验（见下）。

## 信号

在入场那一分钟已知的只有：**今天 13:00 是否有票息拍卖截止**（财政部按季度提前公布拍卖日程；FiscalData 的 `auctions_query` 数据集里 `security_type ∈ {Note, Bond}` 且 `closing_time_comp == "01:00 PM"` 的 `auction_date`）。

- 含：2y / 3y / 5y / 7y / 10y / 20y / 30y 的新发与重开，TIPS（也是 13:00 截止）。
- 不含：浮息票据 FRN（11:30 截止）、所有 Bill（11:30 / 13:00 以前，且对股指没有影响）。
- **拍卖结果（bid-to-cover、high yield、tail）在 13:00 入场时不可用，任何 ≤ 13:02 的入场只能用"有 / 无"这个标志**。13:10 入场时结果已公布（treasurydirect.gov 13:01–13:03 发布），但本提案在 13:10 入场**也不用结果**，只用"已经过去了"这个事实。

公式：`auction_day(D) = 1[D ∈ {auction_date : security_type ∈ {Note,Bond}, closing_time_comp = 01:00 PM}]`。

## 结构

基准 A 的规则不变，只改入场时点的分配：

- 非拍卖日：**13:00** 入场，ATM put 蝶，翅宽在 20/25/30/50/75 里取 `width / implied` 最接近 2 的一档（implied = 入场分钟 ATM 跨式中间价），跳过 `spx_ret_prev ≤ −1%` 的日子，剔半天。每天 1 组。
- 拍卖日：**13:10** 入场，其余同上（翅宽按 13:10 的隐含重选）。
- 对照变体（预先登记，用于判断机制而不是选最好的）：V2 拍卖日改 14:00 入场；V3 拍卖日不开。

## 出场

持到结算（官方收盘价 = `calendar.settle`）。不提前离场。

## 预先声明的预期（写于任何数字之前）

样本量现实：训练期约 620 个整日里拍卖日约 230 天、非拍卖日约 390 天；230 天的胜率 95% 区间约 ±6 个百分点。**小于 6 个百分点的效应在训练期测不出来**，所以下面的区间都宽。

机制诊断（先于盈亏）：

- D1：训练期 SPX `|spot(13:10) − spot(13:00)|` 的中位数，拍卖日 ÷ 非拍卖日。预期 **1.3–2.0×**；若 < 1.15× 则跳跃不存在，机制失败。
- D2：训练期 `implied(13:00) / implied(14:00)`（同一天两个时点的 ATM 跨式之比；纯 √T 缩放给 √(180/120) ≈ 1.22）。拍卖日减非拍卖日的差：预期 **< +0.02**（做市商没有单独定价这一小时）。若 ≥ +0.04，说明已被定价，我预期盈亏差会接近零、提案大概率失败——这个判断在看数据前写下。
- D3：按星期（周二 / 周三 / 周四各自）和剔除 FOMC/CPI/NFP/PCE 当日之后，D1 的比值应保持 > 1.15×；只在周四成立则视为星期影子，放弃。

训练期盈亏（13:00 基准规则，k 0.20 + 每腿最低 1 美元）：

- 拍卖日 vs 非拍卖日：胜率 **低 3–8 个百分点**，期望 **低 40–120 美元/组**。
- 拍卖日 13:10 入场 vs 同日 13:00 入场：期望高 20–80 美元/组。

测试期（验证人判定用）：

- 机制检验（主判据）：测试期拍卖日 13:00 蝶比非拍卖日 13:00 蝶 **胜率低 ≥ 2 个百分点且期望低 ≥ 20 美元**，方向与训练期一致。两条都不满足 → 机制被否定。
- 策略 vs **13:00 全天候规则**（扣掉"13:00 本来就比 14:00 好"这部分）：胜率 **+1 到 +3 个百分点**，期望 **+15 到 +50 美元/组**。期望增量 < +10 美元 → 放弃。
- 策略 vs 基准 A（14:00，61.0% / +100）：胜率 +2 到 +6 个百分点，期望 +40 到 +100 美元/组。**这个对比里大约 +2.6 个百分点 / +46 美元来自已知的"13:00 比 14:00 期望高"，不是本机制的功劳**；验证人请以上一条为准。
- 夏普：不单独预期；按天的 pnl 标准差大约 400–600 美元，增量不会改变夏普的量级。
- 诚实的算术：如果拍卖日只差 X 个百分点，全样本增量最多 0.37·X；要达到协议的 +3 个百分点门槛，拍卖日得差 8 个百分点以上。**我不预期能到 8**，所以本提案对"全样本 +3pp"门槛的预期是**达不到**，它的价值在于 EV 增量和机制本身是否成立。

## 已知反证

- `winrate_study.md`：13:00 入场本身胜率低于 14:00（52.2% 对 55.6%，全样本 25 宽），但期望更高；基准规则下测试期 13:00 为 63.6% / +146，14:00 为 62.4% / +110。本提案的增量必须和 13:00 全天候比。

- `winrate_study.md`"不该开的日子"：周四中午前 34% / −163（稳）——那是 09:35–12:00 的事，拍卖在 13:00，不是同一个窗口；但 30 年期拍卖在周四，分层检验必须单独看周四。
- 文献上定时宏观事件的隐含波动通常**被高估**（事件方差风险溢价为正），这和本机制方向相反；我押的是"13:00 拍卖不在股指做市商的事件清单上"，D2 就是检验这一点。

### 对照预期，如实判

- D1 **成立**（1.33）；D2 **勉强成立**（+0.016，低 VIX 组已定价）；D3 **部分失败**（周四不成立，周三最强）。

- "拍卖日 13:10 入场比 13:00 期望高 20–80 美元"：**失败**（−119 对 −105）。等结果出来再开并没有把钱拿回来，**所以"13:01 的跳跃没被定价"这个窄机制被我自己的训练期数据否定了**。拍卖日差的是整个下午（13:00、13:10、14:00 入场都差），不是头十分钟。
- V1 对 13:00 全天候：+0.4 个百分点 / −5 美元，**低于放弃线（+10 美元）**。

### 提案人的结论（给验证人）

1. 按协议，预期写定后不改。本提案的主判据（测试期拍卖日 13:00 蝶比非拍卖日差 ≥ 2pp 且 ≥ 20 美元）训练期支持；**主结构 V1 训练期已经不及格**，我预期它在测试期也不及格。验证人可以只测主判据和 V1，不必替我找补。
2. 训练期剩下的东西是另一个、更弱的机制："**票息拍卖日的整个下午对 0DTE 蝶不利**"（可能的解释：拍卖后一级交易商在下午分销新券、利率在下午持续重定价；这是猜测，没有检验）。它在训练期对应 V3（不开拍卖日，60.4% / +75，比 14:00 基准 +2.2pp / +13 美元），但：(a) 没有预注册；(b) 2024 年差距为零，2023 独撑；(c) 周三反向。**我不把 V3 作为本提案的策略提交**；若要测它，应当作新编号、重新写预期，并先解释 2024 为什么消失。
3. 最该被验证人检查的泄漏点：拍卖日历来自 2026-11-01 拉取的 FiscalData 全量表，含"已发生"的拍卖；财政部的日程提前一个季度公布，所以 2022–2024 的每个拍卖日在当天 13:00 之前都已知，但验证人应抽查几个日期对照当季日程 PDF（例如 2023-11-09 的 30 年期）。
4. 多重比较：3 个策略变体 + 27 个切片；主判据是预注册的一个格子，不是从切片里挑的。
5. **最不确定的一点**：2024 年 13:00 的拍卖日差距为零，D2 的低 VIX 组已经显示这一小时被定价（+0.038），13:10 等待在非拍卖日赚 +20、在拍卖日亏 −14——三件事合起来和"2023 年底几次大尾部之后市场开始给拍卖定价"相容。如果是这样，测试期（2024-11 起）会什么都看不到，账本应记"效应 2022–23 存在、2024 起消失"，而不是"从未存在"。
