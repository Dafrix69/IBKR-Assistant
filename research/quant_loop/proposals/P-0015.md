## 0. 来源与非盲声明
P-0014 §7.3（跑完判定格后的诊断）列出训练期固定腿台阶最大的 10 天，其中 8 天是 14:00 的纪要 / 褐皮书发布日。**所以本提案的价格方向在训练期不是盲的**：训练期证据只能算一致性检查，判定靠测试期（P-0014 训练期撤回，没有碰测试期；原文误写为“V-0014”，跑数后勘误，不涉及任何预期或闸门）。P-0014 只看了台阶最大的 10 天，没有按完整日历算过事件日均值、对照、按年和置换；本提案把这些在跑数前固定。

## 1. 机制

### 1.1 主张
美联储在固定日程的 14:00 ET 发布 FOMC 会议纪要（会后约 3 周）和褐皮书（会前约 2 周）。发布时刻已知、内容未知，SPX 在 14:00:00 可能跳一下。0DTE 近平值期权的做市商在发布前后面对：
1. **跳跃风险**：发布那一秒挂着的报价可能被比他快的人按发布后的价格吃掉（逆向选择）。
2. **库存风险**：0DTE 平值 gamma 最大，几秒内的跳动对库存的影响最大。

理性的对策是在发布**前一刻**撤单或加宽，发布后等价格稳定、重新定价后再收窄。P-0014 的整点固定腿剖面显示 14:00 起点差抬一个台阶、到 14:10 还没回去，与“预先撤单 + 发布后重新定价的不确定期”一致。

**谁在付钱**：在发布那一刻（14:00:0x）准时吃单的人——包括基准 A 这种按整点调度的系统和散户——付的是做市商承担发布跳跃的风险补偿。**为什么没被套利掉**：这不是套利，是流动性的事件时段价格；做市商加宽是理性的，拥挤者因调度默认值不挪时间。挪到发布前几分钟就避开，但不会消除它。

### 1.2 为什么是 13:55（固定，不扫描）
- 机制要求入场在做市商**预先**加宽之前；P-0014 固定 14:00 腿的剖面在 −5 … −1 分钟是平的（0.237–0.241），台阶从 0 分钟开始，所以 −5 分钟（13:55）在预先加宽之外，且给人工 / 程序 5 分钟工作时间（限价组合单在 0DTE 上通常几十秒到一两分钟成交）。
- 13:55 与 14:00 入场承担**同一个**发布风险（快照口径见 1.4），二者盈亏差只有 5 分钟走势 + 重选 K/w 的噪声，均值应 ≈ 0；所以规则可以只按价格判。
- 不试 13:50、13:58 等别的分钟。14:10（发布后）只作次要对照、只报告：它避开发布风险，但这是另一个问题（“是否卖发布风险”），本数据测不出（见 §3.4）。

### 1.3 机制可被单独反驳
- 若事件日 13:55 固定腿到 14:00 / 14:01 的台阶**减去同年同星期非事件日的同一台阶**（D_step）≤ 0 或区间含 0 → 事件日没有特有的点差抬升，机制不成立。
- 若事件日 13:55 的 H 已经比对照日宽（预先加宽在 13:55 之前就开始），节省会变小；单独报告。
- 若训练期效应只来自一年或一类事件（P-0001 教训：拍卖日效应集中在 2023），按年三段同号是闸门；纪要 / 褐皮书分开只报告（预期纪要更强：纪要可改变利率路径预期，褐皮书是定性的地区经济描述，市场反应一般更小）。

### 1.4 快照口径（从 P-0014 §1.3 继承，未核实）
`quote_1m` 的 14:00 行按 ThetaData 区间报价通常口径为“该时刻（含之前最后一条）的 NBBO”。若它在发布前一瞬，“14:00 入场”承担发布风险、点差已被预先加宽；若在发布后，14:00 入场的信息集与 13:55 不同（卖在跳动之后）。不去解决；事件日 13:50–14:15 的固定腿剖面与 `spot.parquet` 路径作为描述只报告，让读者看到台阶和跳动落在哪一分钟。

### 1.5 与账本的关系
- **不是星期选日**（账本已关闭 PNT / 按星期选日）：规则由美联储公开日历触发；事件几乎全是周三（训练期 1 个周二：2023-11-21，感恩节前），所以**对照组 = 同年、同星期的非事件日**，主统计量是星期内的差中差，任何“周三效应”按构造抵消。置换只在（年 × 星期）层内打乱事件标签。
- P-0001（拍卖日 13:00，FAIL）：同类“日程事件日改入场时点”，但那是按盈亏 / 胜率判、效应集中在 2023、与星期重叠。本提案只按点差判、对照同星期、按年同号是闸门。
- P-0014（整点拥挤，训练期撤回）：否定的是“任何整点都加宽”；本提案只主张“有日程发布的 14:00”加宽，P-0014 自己的诊断指向这里（非盲，见 §0）。
- P-0013（PASS）：结构选择（铁蝶），与本提案正交。本提案用铁蝶。
- FOMC 声明日（14:00 声明 + 14:30 记者会）剔除：它们在 14:00 被点差上限删光（V-0013），机制相同但量级大一个数量级，混进来会主导均值。只在稳健性里报告“含 FOMC”。

## 2. 信号（入场那一分钟已知）
- **事件日历**：`src/proposer/P-0015_events.csv`，2026-11-01 从 federalreserve.gov 抓取后固定（纪要 = `fomccalendars.htm` 的 “Minutes: Released …”；褐皮书 = `publications/beige-book-default.htm`、`beige-book-archive.htm`、`beigebook2022.htm` … `beigebook2025.htm` 上的 `BeigeBook_YYYYMMDD.pdf` 文件名），覆盖 2022-05 → 2026-10，共 72 个（训练期 40：纪要 20、褐皮书 20；测试期 32：16 + 16）。两类都在 14:00 ET 发布。事件日 = 当天在该表里。全部事件在开盘前多周就已公布，入场时已知。
- **基准日**：非半天、`has_0dte`、`spx_ret_prev` > −1%、非 FOMC 声明日（`calendar.fomc`）。脚本断言事件日与 FOMC 声明日不重合。训练期 2024-07-03 纪要是半天，自动剔除。
- **对照日**：基准日中非事件日，与事件日同年、同星期（Tue / Wed）。
- **时点 t 的选择**（与基准 A / P-0013 / P-0014 相同）：S = `spot.parquet` 在 t 的值；K = 当分钟有报价的行权价中离 S 最近的一档；I = C(K).mid + P(K).mid；w = {20, 25, 30, 50, 75} 里 |w / I − 2| 最小，平局（容差 1e-9）取窄。结构：空铁蝶（K−w P 买、K P 卖、K C 卖、K+w C 买），1 组 1 张。
- **报价**：chain 当分钟 NBBO，`flag_bad` 不用，ask > bid，bid ≥ 0；**点差上限**：任一腿 ask − bid > 2.0 点 → 该分钟丢弃；另报 1.0。
- **成本**：k = 0.20（`config.yaml` 校准值），买 = mid + k·半点差、卖 = mid − k·半点差；每腿费用 `max(佣金 × 张数, 1.00) + 张数 × (交易所 0.36/0.45 + 0.14 + 0.04028)`，佣金按权利金 < 0.05 → 0.25、< 0.10 → 0.50、其余 0.65。执行成本 E = k·H·100 + fee（美元），H = 四腿半点差之和（点）。

## 3. 统计量与规则

### 3.1 机制统计量（固定腿）
在 13:55 选定 (K, w) 并**固定这四条腿**，取 13:50 … 14:15 每分钟的 H（缺腿或超上限的分钟留空）。
- 台阶 step = mean H(14:00, 14:01) − mean H(13:55 … 13:59)（点；两边各至少 1 分钟有值）。
- D_step = 事件日 step − 其（年 × 星期）层对照日 step 的均值，对事件日取平均（点；× 20 = 美元，k 0.20）。
- 预先加宽 P_w = 事件日 H(13:55) − 层对照均值（点）。

### 3.2 规则 R（判定用）
事件日的基准 A 铁蝶从 14:00 挪到 **13:55**，13:55 重新选 K、w。
- G_ev = E(14:00) − E(13:55)，事件日均值（美元/事件日；各自 K、w；只含执行成本）。要求两个分钟都过点差上限且腿齐全（对称条件），报告因此丢掉的事件日及其在两个分钟各自的 H。
- 差中差 DiD = G_ev − 层对照 G_ctrl（逐事件日减其层对照均值后平均）。它区分“事件日特有”与“13:55 一般更便宜”（P-0014 的全天候 13:55–13:59 比 14:00 便宜约 0.2–0.3 美元，已知）。
- 安慰剂（唯一一种）：每个事件日**前一周同星期**那天（若它本身是事件 / FOMC / 半天 / 非基准日则跳过）当作伪事件，算同样的 DiD：伪事件日的 G 减去其（年 × 星期）层对照均值，对照池 = 同层非事件日去掉全部伪事件日本身。
- 分层置换：在（年 × 星期）层内打乱事件标签 5,000 次，DiD 的单侧 p。
- 按天 bootstrap 2,000 次给区间（事件日重采样；DiD 时对照层均值视为固定）。

### 3.3 出场
持到结算（赔付按 `calendar.settle`），不提前离场。

### 3.4 盈亏（单独预注册，只报告 + 一条闸门）
功效声明：训练期约 38 个事件日、单日盈亏标准差 500–1,500 美元 → 事件日均值的标准误约 100–250 美元；“事件日开不开”这个问题本数据**只能发现灾难**，不能给方向。
- ΔPnL = pnl(13:55) − pnl(14:00)（同一事件日，各自 K、w，持到结算，k 0.20，含费）。预期均值 ≈ G_ev，单日噪声几百美元。
- x = |settle − S| / I 在 13:55：事件日 − 层对照（无量纲，功效好于美元，半宽仍约 ±0.2）。
- 事件日基准 A（14:00）pnl 对层对照 pnl；14:10 入场的 E、pnl 对 13:55（次要对照）。
- 事件日 13:50–14:15 的 spot 路径（|S(t) − S(13:55)| 的均值）对层对照：发布跳动落在哪一分钟。

## 附录（不占编号）：张数与费用结构（算术）
每腿费用 = max(0.65 × n, 1.00) + n × (0.36 或 0.45 + 0.14 + 0.04028)。n = 1 时佣金按 1.00 计（最低佣金咬住，每腿多付 0.35）；n ≥ 2 时 0.65 × n ≥ 1.30 > 1.00，最低佣金不再约束，佣金严格线性。所以：
- 四腿铁蝶 1 张：佣金 4.00 美元；2 张：5.20（每张 2.60）。三腿 put 蝶（中间腿 2 张）1 组：1.00 + 1.30 + 1.00 = 3.30；2 组：1.30 + 2.60 + 1.30 = 5.20。
- 即 P-0013 的 Δfee −0.62 美元（铁蝶比 put 蝶多付的费用）在 1 组时存在，2 组起为 0（铁蝶 4 × 0.65n 对 put 蝶 4 × 0.65n，交易所费按权利金分档的差除外，量级几分钱）。点差项按张数线性，所以铁蝶对 put 蝶的节省 ≈ n × 4.3 美元（V-0013 模型值，实测约其 55–75%）。
- 本提案的 G_ev 在两个时点结构相同，费用差只来自权利金跨过 1.00 / 0.05 / 0.10 分档，n 张时节省 ≈ n × k·ΔH·100。
