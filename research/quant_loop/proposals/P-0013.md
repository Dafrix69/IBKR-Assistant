# P-0013 同一赔付选最便宜的结构（铁蝶 / put 蝶 / call 蝶）与整数行权价点差：只用价格判定的执行成本
范围: A
状态: 第 1–6 节（机制、信号、结构、预先声明的预期、失败线、变体计划）写于训练期回测之前（2026-11-01），跑数后没有改；第 7 节以后是跑完补写的。

## 1. 机制

### (a) 等价结构
同一天、同一中心 K、同一翅宽 w、同一到期（SPXW 0DTE，欧式，现金结算，当天无利息 / 股息差），下面四种组合在结算时的赔付都是 max(0, w − |S_T − K|)，相差的只是一个常数：

| 结构 | 腿（+ 买 / − 卖） | 含实值腿 |
|---|---|---|
| put 蝶 | +P(K−w) −2P(K) +P(K+w) | P(K+w) 深实值 w 点 |
| call 蝶 | +C(K−w) −2C(K) +C(K+w) | C(K−w) 深实值 w 点 |
| 空铁蝶（借记口径 = w − 收入） | +P(K−w) −P(K) −C(K) +C(K+w) | 只有 K 处那一条腿实值 ≤ 2.5 点 |
| 反铁蝶（借记口径 = 支出 − w） | +C(K−w) −C(K) −P(K) +P(K+w) | 两条深实值腿 |

平价（C − P = F − K，0DTE 不贴现）保证四者的**理论中间价相同**。所以成交借记的差只能来自三项：
1. **Δmid**：各腿中间价不满足平价的部分。理论上为 0；系统性不为 0 说明某些腿（通常是深实值腿）的中间价是陈旧 / 不对称挂单造成的报价伪影，**不是可交易的钱**，只作报价质量诊断，不进 PASS 判据。
2. **Δ(k·H)**：H = Σ 张数 × 半点差。深实值 SPX 0DTE 期权的 NBBO 系统性更宽：做市商挂实值期权要承担接近 1 的 delta 对冲，客户流量集中在虚值，竞争的报价方少。put 蝶和 call 蝶各带一条 w 点深的实值腿，铁蝶没有。
3. **Δfee**：按校准费率，1 张时 IBKR 每腿最低 1 美元，铁蝶 4 条腿各 1 张（佣金 4 × 1.00），put / call 蝶中间腿 2 张（1.30），佣金铁蝶多 0.70；交易所费按权利金分档（< 1 点 0.36，否则 0.45），铁蝶的两条翅膀是便宜的虚值腿，可省回一部分。

**谁在付这笔钱**：没有人。这不是“市场定价错误”，而是**避免付给做市商的点差**：基准 A 用 put 蝶，等于每天为一条深实值腿多付 k × 它的半点差。它没有被“套利掉”是因为它本来就不是套利机会——深实值腿宽是做市商对冲成本的合理补偿，只是对一个只要赔付形状的交易者来说，这个补偿可以绕开。
**上限与反驳路径**：这笔节省在模型里 = k × ΔH − Δfee，**上限由 k 决定**。如果组合单在 Cboe COB 上的成交价跟各腿 NBBO 宽度无关（例如做市商对等价组合给同一个价），真实节省就是 −Δfee（铁蝶反而贵 0.7 美元左右）。校准表里蝶的 k 中位是 0.00（15 笔）、全部组合 0.20（21 笔）；本提案按协议用 0.20，但这是最大的不确定性。能真正反驳它的办法只有实盘交替下两种结构比有效 k，报价数据给不了。

### (a') 可预测的那一部分：call 蝶 vs put 蝶随 sign(S − K) 翻转
设 d = S − K（入场现货减中心，|d| ≤ 2.5）。put 蝶的实值腿 P(K+w) 深 w − d，call 蝶的实值腿 C(K−w) 深 w + d。d > 0 时 put 蝶的实值腿更浅、call 蝶的更深，所以 cost_call − cost_put 在 d > 0 时应大于 d < 0 时。另外偏斜：C(K−w) 经平价对应 P(K−w)，下方虚值 put 隐含更高、点差更宽，所以预计平均而言 call 蝶比 put 蝶贵。这是不依赖结算的、按年可检验的方向预言，也是本提案里**测试期没看过**的一部分。

### (b) 整数行权价的点差
SPX 的持仓量和成交在 25 / 50 / 100 的整数倍行权价上集中（人的锚定习惯、机构的标准化下单、各类指数产品）。更多的成交量 → 更多做市商在这些行权价上竞争 → 同样价内外程度下 NBBO 更窄。若成立，现货落在两档之间、较远那档是 25 的整数倍时，把蝶中心放在整数档可以省点差。但挪中心会改变赔付（≤ 5 点偏心），那部分只能用结算判断，单日噪声几百美元，**不进 PASS 判据，单独报告**。
与已否定的“整数关”（winrate_study §整数大关、账本第一条）区别：那是把整数关当作落点 / 反弹的胜率与期望检验；这里只问点差宽度，不问现货会不会停在整数关。

### 为什么不是旧东西的变体
- winrate_study §3 在**全样本**（含测试期）报告过 “iron fly 胜率一样，k 0.5 时期望更高（14:00 / 25：+34 对 +17）”。所以 **“铁蝶比 put 蝶便宜”的方向在测试期已被看过**，不是盲测。本提案在这一点上只检验幅度（校准 k 0.20 + 每腿 1 美元最低佣金下是否仍为正、是多少）。盲的部分是 (a') 的翻转、call 蝶的位置和 (b)。
- 账本中所有 FAIL / 撤回都是“选日 / 选时 / 挪中心 / 选翅宽”的盈亏类机制；本提案不改变赔付（(a)），或把赔付改变单独报告（(b)）。

## 2. 信号（入场那一分钟已知）
- 时点 t：主格 14:00；描述性网格 10:00–13:59 每分钟。
- S = spot.parquet 在 t 的值；K = 当分钟有报价的行权价里离 S 最近的一档（与 winrate_study 一致）；d = S − K。
- I = C(K).mid + P(K).mid；w = {20, 25, 30, 50, 75} 里 w / I 最接近 2 的那一档，平局（容差 1e-9）取窄的。
- 基准日：非半天、spx_ret_prev > −1%、当天有 0DTE。FOMC 日保留（基准 A 不剔），另报剔除后。
- 报价：chain 当分钟 NBBO，flag_bad 的腿不用；**点差上限**：任一腿 ask − bid > 2.0 点，当分钟四种结构全部丢弃（配对一致）；另报 1.0 点上限。
- 成交：买 = mid + k × 半点差，卖 = mid − k × 半点差，k = 0.20；费用按自写函数 `max(0.65 × 张数, 1.00) + 张数 × (交易所 0.36/0.45 + 0.14 + 0.04028)`，佣金分档 < 0.05 → 0.25、< 0.10 → 0.50、其余 0.65（与 config.yaml 一致，加每腿最低 1 美元）。1 组 1 张。
- 执行成本 E = (k·H)·100 + fee（美元）；成交借记 = mid·100 + E。

## 12. 已知反证与局限
- **铁蝶 > put 蝶的方向不是盲测**：winrate_study §3 在含测试期的全样本里报告过（k 0.5 时 +34 对 +17）。本提案在这一点上的新内容只有：校准 k 0.20 + 每腿最低佣金下的幅度（+5.8 美元/天，k 0 时 −0.6）、三项拆分（中间价贡献为 0）、按年稳定。它在测试期几乎必然仍为正（只要实值腿点差比虚值腿宽），所以**主判据的功效高但信息量低**；真正有信息的是 T（盲）和 M（盲）。
- **最大不确定性**：k 是否随腿的 NBBO 宽度按比例变化。校准表里蝶的 k 中位 0.00（15 笔，全是窄翅虚值蝶）；如果真实组合单对 put 蝶和铁蝶给同样的绝对滑点，G_a 的 +6.40 点差项就不存在，只剩 −0.62 的费用差。M 是唯一能在数据里检验这一点的东西；最终答案要靠实盘交替下两种结构比有效 k。
- 不改赔付，所以与账本里所有选日 / 选时 / 挪中心的 FAIL 不同族；与基准 A 的比较就是 +G_a / 天（约为基准 A 测试期 +100 美元/天的 5–6%），对胜率的影响 = 每天成本降 0.058 点，几乎不动胜率。
- **费用差只在 1 张时存在**：2 张起每腿最低 1 美元不再约束（put 蝶 1.30 + 2.60 + 1.30 = 铁蝶 4 × 1.30），每张 G_a 趋近 k·ΔH ≈ +6.4。本提案按 1 张判，验证人做张数敏感性时别把这当成差异。
