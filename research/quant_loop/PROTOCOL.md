# 量化策略提案—验证循环：协议

两个角色，一本账。**提案人**（`quant-proposer`）只看训练期数据，写策略规格；**验证人**（`quant-validator`）独立重做、拿测试期打分、记账。两者不共享代码，不共享结论，只共享这份协议、数据字典和账本。

## 范围

- **A. SPX 0DTE 日内蝶式 / 信用价差**：数据齐全（见下）。
- **B. 科技小盘股超短线**（ALAB APLD AXTI CLSK CRDO IREN LITE NBIS NVTS OKLO QBTS QUBT RKLB SNDK WOLF，2024-10-31 起）：本地只有**每日 OI 和日终期权报告**，没有股票分钟线、没有期权盘中报价。超短线策略先用日频数据做“隔夜 / 日内方向 + 期权结构”层面的假设；要分钟线得先用 `research/spx_fly/src/fetch_spx_tws.py` 的做法从 TWS 拉（每标的约 105 周 × 12 秒，16 个标的约 5 小时）。提案里要写明需要什么数据，没有的标“待拉取”。

## 防过拟合的硬规则

1. **时间墙**：训练期 `date < 2024-11-01`，测试期 `>= 2024-11-01`。提案人的任何脚本必须在读数据后第一步就过滤训练期；验证人审脚本时第一件事就是查这一行。小盘股数据从 2024-10-31 起，训练 / 测试改为 `< 2025-11-01` / `>= 2025-11-01`，并在提案里注明样本只有约 12 个月测试。
2. **一次测试**：每个假设在账本里拿一个编号，验证人只在测试期跑一次。失败的假设不能换参数再交；要再交必须是新的机制、新的编号，并在提案里引用旧编号说明为什么不同。
3. **提案先写预测再看数**：提案人在写规格时必须先写“我预期测试期胜率 / 期望 / 夏普在什么区间，低于多少算失败”，验证人按这个判。
4. **独立实现**：验证人不运行提案人的脚本做结论，只读它查泄漏，自己从数据字典重写。两者数字对不上 → 先查谁错，查清前不出结论。
5. **成本按校准值**：`research/spx_fly/config.yaml` 的 `fills` 段（k 0.20，每腿最低佣金 1 美元）。提案人用更乐观的假设 = 直接驳回。
6. **多重比较账**：提案人报告自己试了多少个变体才选出这一个；验证人按 5% × 变体数算运气预期，并做 Bonferroni 或置换检验。
7. **基准**：A 类的基准是 `winrate_study.md` 的规则（14:00 入场、翅宽 ≈ 2 × 隐含、跳过前日 ≤ −1%，测试期 61.0% / +100 美元 / 439 天）。新策略要和它比增量，不是和零比。B 类基准 = 同期买入持有该篮子（等权）。

## 提案规格（`proposals/<id>.md`，一个假设一份）

```
# P-0001 <一句话标题>
范围: A | B
机制: 为什么这个边际应该存在（谁在付钱、为什么没被套利掉）。不写机制的提案不收。
信号: 入场那一分钟 / 那一天已知的变量，精确到公式。
结构: 合约、宽度、方向、仓位（每天固定 1 组或按风险）。
出场: 规则。默认持到结算 / 收盘；要提前离场必须给理由（已知提前离场普遍压低期望）。
训练期证据: 表格（n、胜率、期望、按年），脚本路径，变体数。
预先声明的预期: 测试期胜率区间、期望区间、失败线。
需要的数据: 已有 / 待拉取。
已知反证: 引用账本或 winrate_study / mining 里和它相关的否定结果，说明为什么这次不同。
```

## 验证报告（`validations/<id>.md`）

```
# V-0001 对 P-0001
泄漏审查: 逐条（时间墙、未来数据、成交假设、半天、坏报价）。
独立实现: 脚本路径，和提案训练期数字的对照（差异 > 2 个百分点要解释）。
测试期结果: n、胜率 + Wilson 区间、期望 + bootstrap 区间、按年、最大回撤、和基准的增量。
稳健性: 相邻参数（±1 档）的结果；换成 k 0.5；去掉最好的 5 天。
多重比较: 变体数 → 运气预期 → 调整后是否仍显著。
判定: PASS / FAIL / REVISE（REVISE 只用于实现有误，不用于“再调调”）。
账本更新: 一行。
```

## 补充（2026-11-08，第 23 轮起）：可能性评估，与 B-pools 范围

### 一、可能性评估（每个提案都要）

**测之前给先验，测之后给后验，两个都记进账本。** 原有的 PASS / FAIL 规则不变，后验是加上去的一栏；真要拿钱做，要求 PASS **且**后验上界 ≥ 50 %。

**先验由主会话（评估人）按下表给，在该提案任何训练期证据算出来之前写进提案顶部；提案人只交材料，不给自己打分。验证人审评估是否照表执行。**

提案人交的材料（提案里「可能性评估材料」一节，每条带出处）：
- E1 机制：谁在付钱、为什么没被套利掉。
- E2 外部证据：原始文献（作者、年份、期刊、样本、效应大小），发表之后至少一篇独立复现（样本是否在发表之后、效应是否衰减；McLean & Pontiff 2016 的发表后衰减约 1/3 作参考），有没有小盘 / 高波动名字上的证据。
- E3 成本比 R = 文献里的毛效应（换算成本研究的单位：每笔占正股 %，或每笔占权利金 %）÷ 本研究的单笔成本（k 0.5 来回；期权按 V-0021/22 实测的半点差，事前池上 k0 与 k0.5 之差约 0.1–0.2 % 正股 / 笔；正股按假设单边 10 bp，另报 25 bp 敏感性与盈亏平衡成本）。**毛效应只能取自文献，不能取自本研究的数据。**
- E4 本研究已有的相关证据：账本里相关的 FAIL（编号）、已看过的描述性结果（如 `call_spread_edge/out/diag_cond.txt`：原 15 只训练期按 IV/RV、期限结构、偏度、ret5、IV 分三档的卖方对冲结果）。
- E5 数据可行性：只用本地日终数据能否无前视地算出信号；缺的标「待拉取」。

先验档位（只用 5 % / 15 % / 30 % / 50 % 四档，不给小数）：

| 条件 | 档位 |
|---|---|
| E1 说不出谁付钱 | 5 % |
| E1 有，E2 只有原始文献 | 15 % |
| E1 有，E2 有发表后的独立复现 | 30 % |
| E1 有，E2 有发表后复现，且在小盘 / 高波动名字上也成立 | 50 % |

然后逐条下调（每条降一档，最低 5 %）：R < 2（R < 1 直接 5 %）；账本里有同机制的 FAIL；E4 里已看过的描述性结果方向相反。

**闸门**：先验 < 15 % 的不测；每轮最多测 4 个，按「先验 × 若为真时的 k 0.5 期望」排序取前 4；该轮的 Bonferroni 按实测个数 m 算（97.5 % → 1 − 0.05/m 双侧）。闸门在看任何候选之前写死（本节即是）。

**后验**：p = 测试期主判据 k 0.5 的单侧周块 bootstrap P(均值 ≤ 0)。贝叶斯因子上界 BF = 1 / (−e · p · ln p)（p < 1/e，否则 BF = 1；Sellke, Bayarri & Berger 2001）。后验几率上界 = 先验几率 × BF。这是**上界**（对假设最有利的情形），记作「后验 ≤ x %」。例：先验 30 % 需 p ≤ 0.05 才到 50 %；先验 15 % 需 p ≤ 0.006。**勘误（2026-11-08，第 24 轮）**：后一个算错了。到 50 % 所需单侧 p：先验 5 % → 0.0034，15 % → 0.016，30 % → 0.054。

**校准**：账本每轮末尾记一行「本轮各档先验个数 / PASS 个数」，积累起来检查打分是否偏乐观。

- **事件**：上一常规收盘 C 之后，盘后（同日 16:00–20:00 ET）或盘前（下一交易日 04:00–09:30 ET）第一根收盘价 ≥ 1.05 × C 的 5 分钟 TRADES K 线 = 触发；每个名字每个反应日最多一个事件；反应日 = 触发之后的第一个常规交易日。

- **对照**：反应日官方收盘（收盘集合竞价，不扣成本，申报为对规则不利的简化）。每个事件 r = 卖价 / 反应日收盘 − 1，r > 0 = 纪律赢。

- **统计**：事件等权；按 ISO 周的平稳块 bootstrap（平均 4 周，10 000 次）；单侧 p 用于后验。
- **PASS 默认口径**：k 0.5 均值 > 0 且 95 % 区间不含 0；k 1 均值 > 0；2023、2024 两池各自 > 0；有 ≥ 3 个事件的名字里过半为正；去掉 r 最大的 5 个事件后仍 > 0。报告项：财报事件（从期权 IV 骤降推断，`lit_dossier.md` J 节）与非财报事件分开、盘后与盘前触发分开、涨幅分档（5–10 %、10–20 %、> 20 %）、60 分钟版本、反应日开盘价相对卖价。
