# V-0004 对 P-0004（轻量审计，训练期撤回）

范围：提案人按预注册闸门 W1 / W3 / W4 在训练期撤回，未申请测试期。本审计**不跑测试期**（`calendar`、`spot` 读入后第一步过滤 `< 2024-11-01`，chain 按文件名 `>= 2024-11-01` 不打开），只做泄漏审查、撤回依据的独立复现，以及 P3 诊断按同桶数 / 分位分桶的重做。

## 判定：WITHDRAWN（训练期撤回），撤回成立

依据（训练期，我的独立实现）：W1 高 I 三分位 Δ **−2.7**（提案 −2.8），按规格字面实现为 −5.5，去掉 FOMC 日 −3.7，三种口径都为负；W3 2022 年 Δ **−4.5**（提案 −4.4），三种口径都为负。W1、W3 两条就足以撤回。

但要写准两点：

1. 所有 Δ 的区间都跨零（全期 −1.7 [−6.2, +2.8]）。撤回的含义是“训练期没有证据表明隐含锚优于权利金锚”，**不是**“证明了权利金锚更好”。
2. **W4 在同桶数下不成立。** 提案的 3 : 1 是 5 桶对 4 桶的比较。改成同一批候选、两个变量都按分位切 4 桶时，信用比更平的是 2 / 4 格；切 5 桶时是 0 / 4 格。按天 bootstrap，“信用比在 ≥ 3 格更平”的概率只有 0.19–0.26，每格差值的区间都跨零。P3 在这个样本量下分不出 H_I 和 H_Q，不能当作“信用比才是锚”的证据。

## 泄漏审查

1. **时间墙**：`P-0004_build.py` 读入后第一步过滤：`calendar` 一行，`spot` 一行，chain 按文件名 `d >= TRAIN_END: continue`（测试期文件不打开），最后再 `assert`。`P-0004_analyze.py` 对 cand、days、calendar、winrate_panel 各过滤一行。m（0.15 / 0.41 / 0.05 / 0.32）和 I 三分位切点只来自训练期。**通过。**
2. **未来数据**：
   - build 只读 `calendar` 的 `half_day`。`grep settle` 只在 docstring 里出现，`cand.parquet` / `days.parquet` 的列里也没有 settle、loss、pnl。结算价第一次出现是在 analyze 里算结果的时候。
   - **m 只来自信号**：我用自己的权利金锚选点重算每格 dist_I 中位数，得 0.154 / 0.411 / 0.048 / 0.321，四舍五入后与规格一致。按 I 三分位的中位数（−0.03 / 0.14 / 0.27 等）和“信用在 [3,4]”的占比（82 / 68 / 83 / 75%）也与“写规格前看过的东西”逐格一致。m 是在被评估的同一批训练日上估出来的，但只用了信用、I、距离，不涉及结果，可以接受。
   - spot 用 `spot.parquet` 14:00（= 13:59 K 线收盘），I 用 14:00 chain 快照，结算用 `calendar.settle`，没用 16:00 快照，剔除半天，不用 OI 和成交流。
   - 附注（不算泄漏）：FOMC 日 14:00 正是公布时刻，那一分钟 chain 与 13:59 spot 可能不同步（例如 2022-12-14 的 4045P 离现货 4 点，mid 却是 30.25）。去掉 FOMC 日（20 天）后结论不变（见下表）。
   
   **通过。**
3. **成交与成本**：k 0.20；费用按 `config.yaml` 分档，加每腿最低 1 美元、交易所费 0.36 / 0.45、0.14、0.04028，与配置一致；按腿 NBBO 算 H；成交在 14:00 快照（与基准 A 同口径），持到结算，无止损止盈。费用档按腿 mid 取，不按成交价取，影响可忽略。k 0.5 另报。**通过。**
4. **预期是否先于结果**：预期区间、失败线和 W1–W4 都写得明确，结果一节如实报告全部闸门。W2 字面上没触发，提案人也没有借此保留提案。文件时间：build 19:53，analyze 与表 19:59，规格 20:01（单个 md，没法从文件系统独立证实“先写预期”）。提案人自己承认读过全样本的 `spread_credit_scan`，属于软污染，但不影响撤回。**通过（不可独立证实）。**
5. **与账本的关系**：不挑日子、不挑分钟、不改组数，不是 P-0001 / 0002 / 0003 的变体。与 `spread_study`、`spread_credit_scan` 相关，提案已引用。**通过。**

**实现上的小问题（不改变结论）**：规格写“候选短腿：同侧所有行权价”，build 却加了一个 `−15 ≤ d ≤ 90` 点的距离窗。另外，`idxmin` 在两个行权价离 3.5 一样近时（如 3.25 / 3.75）按行序取第一个。少数日子的 14:00 快照有两类缺陷，两个锚在这些日子会落到离谱的位置：(a) **缺档**：行权价中间空缺，或 ATM 只有一侧报价。例如 2022-05-03 的 bull put 15 宽；2024-06-21 ATM 5460P 缺报价，提案剔除了这一天。(b) **公布时刻的超宽报价**：2022-12-14（FOMC）的 4045P bid 24.5 / ask 36.0、4030P 18.2 / 35.0，价差 11–17 点。它们没有被 `flag_bad` 标记，因为 spread / mid < 1。信用随行权价变得不单调（离现货 4 点处 3.65，99 点处 3.60），“离 3.5 最近”在这种日子没有意义，单是 0.2·H 就要 3 点左右。距离窗恰好挡掉了一部分。这是数据缺陷，不是有利于哪一方的选择。

## P3 重做：哪个锚让期望表跨 I 三分位更平

提案的表是 dist_I 5 桶、信用比 4 桶，每桶覆盖的候选集合也不同，所以极差的均值不可比。

我的做法：
- 候选取两个变量范围的交集，dist_I ∈ [−0.2, 0.8] 且信用 / 宽度 ∈ [0.15, 0.55]，两个锚用同一批候选；
- 每格内两个变量都按分位切成同样的桶数；
- 保留提案的口径：桶内先按天平均、每个三分位至少 30 天、指标为各桶跨 I 三分位极差的均值；
- 按天 bootstrap 300 次（每次重切分位），对“信用比极差 − dist_I 极差”取区间，负值表示信用比更平。

| 格 | 4 桶：dist_I / 信用比 | 差 [95%] | 5 桶：dist_I / 信用比 | 差 [95%] |
|---|---|---|---|---|
| bear call 10 | 46.3 / 65.9 | +19.6 [−18.8, +46.5] | 48.9 / 64.6 | +15.7 [−29.1, +55.9] |
| bear call 15 | 66.8 / 85.5 | +18.7 [−52.5, +62.0] | 73.0 / 75.4 | +2.4 [−83.3, +60.4] |
| bull put 10 | 36.1 / 27.7 | −8.5 [−37.6, +25.2] | 42.6 / 65.0 | +22.4 [−26.2, +54.5] |
| bull put 15 | 60.4 / 58.3 | −2.1 [−47.3, +59.4] | 49.2 / 82.2 | +33.0 [−52.7, +79.0] |
| **信用比更平的格数** | | **2 / 4** | | **0 / 4** |
| bootstrap P(信用比在 ≥ 3 格更平) | | 0.26 | | 0.19 |

几点说明：
- 同桶数下，规格字面口径和距离窗口径的 P3 数字相同，因为交集已经把候选限制在 dist_I ∈ [−0.2, 0.8]。
- 用提案的固定边界（5 对 4 桶）在我的候选上重算，仍是 3 / 4 偏向信用比，所以我复现了他的数字。差别来自桶数，不是来自实现。
- 去掉 FOMC 日：4 桶 1 / 4，5 桶 0 / 4。

**结论**：W4 在同桶数、按分位分桶下**不触发**（2 / 4 与 0 / 4，都低于 3 / 4）。每格差值的区间都跨零，宽度 ±50 美元左右；三个均值各自的标准误约 25 美元，单靠噪声就能产生 30–80 美元的极差。P3 在这个样本量下不能区分 H_I 和 H_Q。撤回仍然成立，靠的是 W1 和 W3；账本里不应写“W4：信用比是锚”。

## 稳健性 / 多重比较

未进测试期，不适用。k 0.5 和去 FOMC 日下，全期 Δ 和高 I Δ 都保持负号。提案报 8 个变体，0 个显著，与约 0.4 个的运气预期相符。本审计另做了 2 个口径（规格字面、去 FOMC）和 2 种 P3 分桶，只用于判断撤回依据是否稳、措辞是否准，不用于判定，也都没有显著结果。

## 给提案人的反馈

撤回理由 W1、W3 复现无误，而且不随口径变化。但 W4 是 5 桶对 4 桶的假象：同桶数分位分桶下信用比只在 2 / 4 或 0 / 4 格更平，bootstrap 区间全部跨零，所以训练期**没有**说明“信用比才是锚”，只是说明隐含锚没有带来增量。另外 chain 缺档日和 FOMC 14:00 快照会让固定权利金的选点跳到离谱的行权价，下一个价差提案应该先加两道过滤：(1) 缺档过滤，短腿到 ATM 之间不缺档、ATM 两侧都有报价；(2) 点差上限，例如任一腿半点差超过 mid 的一定比例或绝对值就跳过，或者 FOMC 等公布日不在公布那一分钟入场。如果要做 10:30 的锚问题，第 (1) 条更重要，因为那里候选更远、缺档更多。
