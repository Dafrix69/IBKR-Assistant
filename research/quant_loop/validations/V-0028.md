# V-0028 对 P-0028（基准 A：14:00 空铁蝶、翅宽 ≈ 2 × ATM 跨式、前日 ≤ −1 % 不开、持到结算；A-hist 第一次样本外检验）

## 5. 多重比较与后验
- 变体数 1（提案 §7.7），m = 2（本轮 P-0028、P-0029），Bonferroni 97.5 % 区间 [−262.4, −53.4]。5 % × 2 = 0.1 个运气 PASS 的预期。变体数 < 10，不做置换检验。
- 基准增量：A-hist 范围按 PROTOCOL 与 0 比；P-0028 本身就是基准 A，没有另外的增量可算。
- 单侧 p = P(k0.5 均值 ≤ 0) = **0.9999** > 1/e → BF 上界 = 1 → **后验上界 ≤ 5 %**（= 先验）。

## 7. 读法表（字面套用）

- 「**k 0 均值 ≤ 0**」行适用：k0 −118.4，95 % [−213.9, −34.8]。读作「**边际不存在**」：在中间价上就不赚，基准 A 在 2022–26 的结果是那个年代特有的，或是挑规则的幸存偏差。
- 「结算离 14:00 现货的距离 / I 的均值 ≥ 1」行适用：1.058。读作「**机制被否定**」：14:00 的跨式在那个年代没有被卖贵，与盈亏无关。
- 年份行（「2020 ≤ 0、2021 > 0」与「2020 > 0、2021 ≤ 0」）都不适用：两年都 ≤ 0。
- 月末行不适用：其余日子也为负。
- 这不是功效不足的「方向一致、没有证明」。结果在负侧显著（k0 与 k0.5 的 97.5 % 区间上界都 < 0），信息量大，方向与外部证据一致（Vilkov 2020–21 买蝶毛 −55 美元 / 组）。

## 8. 判定

**FAIL**（PASS 表 #1–#7 全不满足）。基准 A 第一次碰到规则被选出之前的数据，在中间价上就显著为负。

**给提案人的信息**：
- 2020-01 → 2022-04 的 14:00 0DTE 跨式平均**便宜**于到收盘的实际移动（|Δ| / I 1.06）。
- 亏损遍布三段年份、五个星期、三档隐含，隐含越高亏得越多。成本只占小头（k0 −118 → k0.5 −151）。
- 「14:00 卖 ATM 方差」在 2022 年后为正，更像是 0DTE 零售买盘扩张后的年代现象，不是稳定溢价。
- 以后任何以基准 A 为底座的 A 类提案，都应把「基准 A 本身没有样本外证据、在 2020–22 显著为负」写进已知反证。
- 铁蝶比 put 蝶每组省 41 美元（k0.5），是本次唯一在样本外重现的结论（P-0013 的执行层面）。
