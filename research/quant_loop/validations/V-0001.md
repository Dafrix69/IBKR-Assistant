# V-0001 对 P-0001

（本节写于测试期运行之前，2026-11-01；测试期跑完后在下方追加结果，本节不改。）

## 测试期预注册（运行一次，指标列死）

脚本 `research/quant_loop/src/validator/V-0001_auction.py`，`build --period test` + `analyze --period test` 各跑一次。成本一律 k 0.20 + 每腿最低佣金 1 美元（config.yaml `fills`），基准 A 另报账本口径（k 0.25、不含最低佣金）以便和 61.0% / +100 对照。

1. **主判据（提案人预注册，不分层）**：13:00 规则蝶（翅宽 w/implied 最接近 2，跳过前日 ≤ −1%，剔半天），拍卖日 vs 非拍卖日：各自 n、胜率 + Wilson 95%、期望 + bootstrap 95%；差值的 bootstrap 95%；置换检验（打乱拍卖标签 1000 次，按星期分层 = 主；不分层 = 参考），单侧。**机制成立 = 胜率差 ≤ −2pp 且 期望差 ≤ −20 美元，且按星期分层的置换 p < 0.05**；只满足幅度不满足显著 = "方向一致但不显著"。
2. **V1（策略）** 对 13:00 全天候（同一天集：13:00、13:10、14:00 都有成交的日子）：胜率差、逐日期望差 + bootstrap 95%；提案人放弃线 = 期望增量 < +10 美元。V1 对基准 A（14:00 同规则同天集，自算）：胜率差、期望差。V1 增量置换检验（分层，1000 次）。
3. V2、V3 只作参考；**V3 未预注册**，任何结果都不进判定。
4. 机制诊断：D1（|spot 13:10 − 13:00| 中位数比，对照 12:00、14:00 窗口，按星期、剔事件日）；D2（implied 13:00 / 14:00 的拍卖日减非拍卖日）。提案人的自否线：D1 < 1.15×；D2 ≥ +0.04。
5. 按年（2024-11/12、2025、2026）：主判据两组、V1、13:00、14:00、V3。
6. 最大回撤（逐日累计）：V1、13:00 全天候、14:00。
7. 稳健性：入场 12:50 / 13:10（±1 档）；翅宽目标 1.5 / 2.5；跳过阈 −0.5% / −1.5%；k 0.5；去掉 5 个最差拍卖日（最利于假设的 5 天）；去掉最好 5 天；V1 同样做 k 0.5、目标 1.5/2.5、去掉增量最大的 5 天。
8. 多重比较：3 个策略变体 + 27 个诊断切片 = 30 → 运气预期 1.5 个；用置换检验（≥ 10 个变体）；另报 Bonferroni（主判据 + 3 个变体 = 4 个预注册检验，α = 0.0125）。

**判定规则**（协议）：PASS 需要策略（V1）测试期对基准增量 ≥ +3pp（或期望显著高于基准）、按年同向、稳健性不翻转、多重比较调整后仍显著；任一不满足 = FAIL。主判据的结果单独记入账本（机制层面的结论）。

## 判定：FAIL

策略 V1 对 13:00 全天候 −20 美元/天（提案人放弃线 +10），对基准 A +2.5pp（门槛 +3pp）且期望差不显著；主判据只过了胜率一半（−3.4pp），期望差 −5 美元（门槛 −20），置换 p = 0.64；提案人自己的 D1 自否线（< 1.15×）也被触发（1.12×）。

## 泄漏审查

1. **时间墙**：提案脚本在读 `winrate_panel`、`calendar`、`spot` 后第一行就过滤 `< 2024-11-01`；13:10 路径先读 chain 再按文件名日期返回空（读了但没用，效果合规，写法应改成读前判断）。VIX 三分位切点只来自训练期。训练期规格数字都来自训练期。**通过。**
2. **未来数据**：
   - 拍卖日历是 2026-11-01 拉的全量表，但用的只是"今天 13:00 有没有票息拍卖"。我从 FiscalData 重拉（2042 行），用 `announcemt_date` 逐行核对：保留的 446 行公告日都早于拍卖日 4–8 天（中位 6 天）；抽查 2023-11-09 30 年期：公告 2023-11-01；2022-07-11/12/13 与 TreasuryDirect 一致。季度再融资时还会提前公布暂定日程，所以 13:00 前已知。**通过，两处修正：**
     - (a) **2022-07-14**（"1-Year 10-Month" 再开，发行额 2500 万美元，当天公告、无中标收益率）不是事前可知的市场拍卖，提案人的 csv 把它算作拍卖日。我剔除了（训练期 1 天，不影响数字）。
     - (b) FiscalData 有约一周的发布延迟：**2026-10-26（2 年）、10-27（5 年）、10-29（7 年）** 不在表里，提案人的 csv 也没有；TreasuryDirect 的 `auctioned` 接口有这三条（公告日 10-22）。我已并入，否则测试期 3 个拍卖日会被当成非拍卖日。
     - 拍卖日的定义（`security_type ∈ {Note, Bond}` 且 13:00 截止）与提案一致，439 天与提案 csv 逐日相同（修正前）。
   - `spx_ret_prev` = `settle.pct_change().shift(1)`（前一日收益），`vix_prev_close` 前收，`spot(t)` = t−1 分钟 K 线收盘，结算用官方收盘价，不用 16:00 快照，半天剔除。**通过。**
3. **成交与成本**：提案人用面板的 k 0 / k 0.25 线性插值到 k 0.20（盈亏对 k 线性，正确），费按腿中间价分档，每腿最低佣金按固定 `2×(1.00−0.65)` 补；两处小瑕疵：翼腿权利金 < 0.10 时最低佣金补差应为 0.50 / 0.75；13:10 路径的补差拿"含交易所费的全腿费"和 1.00 比，永远为 0，13:10 每组少算约 0.70 美元。都是亚美元级，不改变任何结论。各腿按 NBBO 中间价 ± k×半点差，持到结算，无止损止盈。**通过。**
4. **预期先于结果**：预期、失败线、主判据在规格里写得明确；训练期一节如实写了 V1 不及格、13:10 等待失败、D3 周四失败、2024 年差距为零，不像事后改过。切片 27 是第一轮后补的，提案人已自报。**通过。**
5. **与账本的关系**：账本否定的日历因子是 FOMC/CPI/NFP/PCE 前后日、opex、月末、星期；国债拍卖不在其中，不是已 FAIL 机制的变体。和星期高度重叠（拍卖集中周二到周四），提案人预注册了 D3。**通过。**

## 测试期结果（2024-11-01 → 2026-10-29，一次）

基准 A 账本口径复现：439 天 / 61.05% / +99.9（账本 61.0% / +100），天集一致。

**主判据（13:00 规则，拍卖日 vs 非拍卖日）**

| | n | 胜率 [Wilson 95%] | 期望 [bootstrap 95%] |
|---|---|---|---|
| 拍卖日 | 164 | 61.0% [53.3, 68.1] | +161 [−8, +333] |
| 非拍卖日 | 275 | 64.4% [58.5, 69.8] | +166 [+27, +307] |
| 差 | | **−3.4pp** [−12.6, +6.0] | **−5 美元** [−220, +211] |

置换 p（单侧，1000 次）：按星期分层 胜率 0.67 / 期望 0.64；不分层 0.27 / 0.49。胜率差过了 −2pp，期望差没过 −20 美元，两者都远不显著。**机制未被确认。**

提案原文“两条都不满足 → 机制被否定”可以读成“满足一条就算成立”。我预注册的是两条都要满足；即使按宽松读法，结果仍然不成立：分层置换 p 0.64，胜率差的 bootstrap 区间 [−12.6, +6.0] 跨零，D1 1.12× 也触发了提案人自己定的 1.15× 失败线。两种读法判定相同。

**策略（同一天集 439 天，k 0.20 + 最低佣金）**

| 方案 | 胜率 [Wilson] | 期望 [bootstrap] | 最大回撤 | 对 13:00 逐日增量 [95%] | 对 14:00 胜率 / 期望增量 [95%] |
|---|---|---|---|---|---|
| 13:00 全天候 | 63.1% [58.5, 67.5] | +164 [+55, +270] | 11 381 | — | +2.1pp / +62 [−37, +154] |
| 14:00 基准 A 规则 | 61.1% [56.4, 65.5] | +103 [+6, +203] | 11 699 | −62 | — |
| **V1** 拍卖日 13:10 | 63.6% [59.0, 67.9] | +144 [+34, +251] | 9 919 | **+0.5pp / −20 [−55, +15]** | **+2.5pp / +41 [−58, +136]** |

V1 增量置换 p（分层）= 0.55。V1 相对基准 A 的 +2.5pp / +41 几乎全部来自"13:00 比 14:00 好"（13:00 全天候本身就 +2.1pp / +62），本机制的贡献是 −20 美元/天。

**按年**（V1 对 13:00 逐日增量）：2024-11/12（34 天）+39，2025（218 天）−46，2026（187 天）−1。**不同向。** 主判据按年：2024 拍卖 53.8% / −42 对 52.4% / −54；2025 58.8% / +227 对 68.1% / +261；2026 64.8% / +123 对 62.1% / +93（拍卖日反而更好）。

**机制诊断**：D1 = 1.12×（3.30 / 2.94），**低于提案人自己的 1.15× 失败线**；对照 12:00 窗口也是 1.12×，即拍卖日 13:00 之后并不比同日中午更跳；13:00→13:30 比值 0.88。D2 = +0.001（拍卖 1.261 / 非拍卖 1.260）。按星期 D1：周二 1.68、周三 1.27、周四 0.97、周一 0.80。

## 稳健性

主判据（胜率差 / 期望差）：入场 12:50 −2.3pp / **+55**；13:10 **+1.1pp** / −24；翅宽目标 1.5 −0.7pp / −3；2.5 −4.7pp / **+31**；跳过阈 −0.5% −4.3pp / −32；−1.5% −2.4pp / **+38**；k 0.5 −3.6pp / −6；去掉 5 个最差拍卖日 −1.5pp / **+86**；去掉最好 5 天 −3.1pp / +21。**期望差的符号在相邻参数上来回翻**，胜率差在 13:10 也翻正。

V1 对 13:00：k 0.5 +0.7pp / −20；目标 1.5 / 2.5：−20 / −22；去掉增量最大的 5 天 −38。一致为负，即"等到 13:10 再开"在测试期稳定地不赚钱。

## 多重比较

3 个策略变体 + 27 个诊断切片 = 30 → 5% 水平运气预期 1.5 个。测试期没有一项预注册检验达到 p < 0.05（主判据分层 p 0.64、V1 增量 p 0.55、V1 对基准 A 的期望差 bootstrap 区间含 0），Bonferroni（4 个预注册检验，α 0.0125）下更不显著。无需调整即为不显著。

## 判定

**FAIL。** 不满足的条款：
- 策略增量：V1 对 13:00 全天候 −20 美元/天（< 提案人 +10 放弃线）；对基准 A +2.5pp（< +3pp）、期望差 +41 [−58, +136] 不显著，且这部分来自入场时点而非本机制。
- 按年不同向（+39 / −46 / −1）。
- 多重比较 / 置换：主判据与 V1 增量都远不显著。
- 机制层：主判据期望差 −5 美元（未达 −20），D1 1.12× 触发提案人自否线，D2 ≈ 0。

**给提案人的信息**：训练期"拍卖日 13:00 蝶差 9pp / 168 美元"在测试期缩到 −3.4pp / −5 美元，且训练期本身按星期分层的置换 p 已经只有 0.08、集中在 2023 年——更像 2023 年一段利率主导行情加周二 / 周四的星期影子，而不是一个持续的"拍卖跳跃未定价"。13:01 的跳跃在测试期只剩 1.12×，和同日 12:00 一样大。V3（拍卖日不开）在测试期每笔与非拍卖日持平，按天反而少赚约 60 美元，**不建议以新编号重交 V3 式"避开拍卖日"**；如果还想做国债维度，应换成用拍卖**结果**（13:10 已知的尾部 / 认购倍数）做条件的新机制，并先证明它和星期无关。
