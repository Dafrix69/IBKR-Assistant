## 4. 机制价格预言（只报告）

- **预言 V（c > 0）**：测试期 c +0.035，t 2.9，两期同号（训练 t 1.4）。这是本提案唯一在测试期站得住的东西：控制上午走幅后，休市后首日 10:00 → 14:00 的 0DTE 隐含方差多降约 3.5 个百分点。限定三条：(1) t 2.9 的原始双侧 p ≈ 0.004，按与 G_x / ΔEV 相同的 52 变体调整后约 0.2，不显著，且提案人已要求不给显著性加分；(2) c 未做按年与去极端日检验（属于测试期二次查看，本报告不补做）；(3) 它是盯市路径量，不是结算盈亏。
- **预言 L 两期都反**（−0.015 / −0.016）：开盘归一化隐含在 PNT 更低，不是更高。做市商没有“带入多余的周末先验”。
- **预言 S**：测试期下午段 x_a +0.050（在 ±0.08 的预期内），上午段 x_m −0.049，均不显著；训练期下午段 −0.133。两期不一致，不能支持“溢价在上午、14:00 已重新校准”。

c 显著而 x / 盈亏不显著的组合，合理的读法是：PNT 日隐含在日内回落得更快（开盘定价对“周一上午会多安静”略有高估，随后修正），但持到结算的铁蝶吃的是 10:00 → 结算的实际走幅对 10:00 隐含，c 只说明路径上的盯市，不是结算盈亏。c 不能被持有到结算的结构变现；若要用，须是“10:00 开、14:00 前后按盯市平”的新假设（提前离场在本研究里普遍压低期望，须单独立号，不在本编号内调参）。

## 5. 独立意见

1. **这是什么**：即使按提案人口径 PASS，测到的也是“休市后首日实际波动季节性”，不是定价错误：预言 L 两期都显示 PNT 开盘隐含已经更便宜，x 差训练期 −0.255、测试期 −0.080，回归约 70%，且测试期的方向与量级在跑之前已由 step2 推出。它与 cross.md Mon@14:00 的“训练有、测试没有”是同一现象的第二次样本外缩水。
2. **对用户的可操作含义**：用户 10:00 后入场、蝶 20–30 宽。本规格的翅宽中位 50（测试期 I₁₀ 中位 26），是用户习惯的两倍，盈亏结论不能直接搬。按 x 换算（事后描述，非预注册）：|settle − S₁₀| ≤ 12.5 点（25 宽蝶身体内）的比例 PNT 32.4% 对对照 26.0%（+6.4pp，z ≈ 1.2；训练期 48.0% 对 31.6%）；≤ 0.6·I₁₀ 为 40.0% 对 36.5%。结论：**没有证据支持“周一 / 假后上午多开或加仓窄蝶”**；对基准 A 胜率 −7.7pp、同日相关 −0.06、叠加后夏普变低。若用户本来就会在周一上午开蝶，测试期数据也没说周一比别的日子更差——只是不更好到可以区分。
3. **周四**：按“星期切分噪声”的参照对待，不当作要反向交易的信号。周四训练 +0.253 → 测试 +0.059，周一 −0.201 → −0.112，二者对称地向零缩，是同一种回归。任何“按星期选日”的后续提案都应以五个星期的离散度（训练期约 ±0.25，测试期约 ±0.1）作为噪声基线，而不是只拿周二 − 周三这一对安静的星期做安慰剂。
