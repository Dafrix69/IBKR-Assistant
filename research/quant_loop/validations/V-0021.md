# V-0021 对 P-0021（小盘股「正股换 call」：Δ×100 股换一张约 3 周 Δ≈0.35 的 call，静态对冲）

验证人：quant-validator（独立实现），2026-11-06。范围 B。判定标准 = P-0021 §5（不是 agent 说明里的“+3 个百分点”）；对冲后期权盈亏的基准是 0。

## 0. 测试期跑之前列死的指标（写于测试期 build 之前，未改）

测试期 = 入场 ≥ 2025-11-01、到期 ≤ 数据末日（2026-11-05）。一次 build（`P-0021_build.py test`）把 Δ {0.15, 0.25, 0.35, 0.50} × k {0, 0.5, 1} × {静态, 每日对冲} 全部算进一张表 `src/validator/V-0021_tables/trades_test.parquet`，build 脚本在表已存在时拒绝再跑；之后所有数字都从这张表算（`P-0021_report.py test`、`P-0021_stats.py test`），没有再 build。

推断口径（P-0021 §5，不改）：按入场 ISO 周排序，平稳块 bootstrap（几何块长均值 8 周，环绕），10000 次，seed 21；每次重抽 = 抽到各周全部交易 pnl 合计 ÷ 笔数（按笔加权）。报 2.5/97.5 与 Bonferroni（2 个提案）1.25/98.75。

判定用（§5 原文）：
1. Δ0.35、k 0.5 静态每笔均值 > 0；
2. 同上 95% 区间不含 0，且 97.5%（Bonferroni）区间不含 0；
3. Δ0.35、k 1.0 静态均值 > 0。
→ 三条全满足 = PASS，否则 FAIL。

解读用（§5“预先写定的解读”）：Δ0.35、k 0.5 **每日对冲**版均值与 95% 区间（同一口径）。静态 > 0 而每日 ≤ 0 或区间含 0 → “收益来自趋势延续（动量敞口），不是期权定价偏低”；两者都 > 0 且每日区间不含 0 → 才可说“期权低估向上尾部”。

报告项（不进判定）：n、胜率 + Wilson 95%、中位数、去两端 2% 均值、为正的股票数、去掉贡献最大的一只、相邻档 Δ0.25 / Δ0.50（k 0.5）、k 0 / 0.5 / 1、去掉最好的 5 周（按周合计）、去掉最好的 5 笔、按股票、按季度、上 / 下半段（2026-05-01 分）、最大回撤（按周平均 pnl 累计）、佣金敏感性（$0.65/张 + $0.0035/股；1 手 $1 最低）、静态 − 每日分解、周内日收益打乱检验（1000 次）、周块符号翻转、流动性（半点差/中间价、当日成交量、Δ0.10–0.60 区 bid = 0 比例）、同期等权持有篮子。ETF 盲检（SPY/QQQ/IWM）单独一节，只报告。

事后补做的报告项（不在上面清单内，看过测试期结果后加的，只用于解释、不进判定）：按持有期涨跌五档分桶的静态 / 每日均值表（第 4 节“收益结构”）。

**静态 − 每日 分解与路径打乱检验**（只报告）：测试期静态 − 每日 = +0.498（对冲路径项 +0.445、成本项 +0.053；训练期 +1.447）。在每笔交易内把日收益顺序打乱 1000 次（S0、S_T、到期赔付、静态盈亏都不变；IV 路径和时间网格保持原日期，这是近似），打乱后的“静态 − 每日”中位数 −0.011，实际 +0.498，单侧 p < 0.001（训练期 +0.466 对 +1.447，p < 0.001）。即静态版相对每日版的多出部分确实来自收益的先后顺序（3 周终值方差大于日方差之和 = 正自相关 / 趋势），这与提案“趋势”的说法一致；但它在测试期只够把一个负的每日对冲结果（−0.11）抬到不显著的 +0.39。

## 5. 多重比较

提案申报训练期看过约 250 个格子 → 5% 下运气预期约 12.5 个“显著”格（相邻 Δ / k 档高度相关，这是上限）。训练期本格 §5 口径 bootstrap 均值 ≤ 0 的比例 0.004，若按 250 次 Bonferroni 需 < 0.0002，训练期证据本身扛不住 250 个变体的校正。测试期是单一预注册规则，按 §5 用 2 个提案的 Bonferroni：97.5% 区间 [−1.23, +2.15] 含 0。agent 说明要求变体 ≥ 10 时“打乱日期标签”做置换：本规则每周都交易、没有择时信号，打乱日期标签不构成有意义的零假设，所以改做上面的周内收益打乱（检验机制）与周块符号翻转（检验均值，p 0.30），两者都只作报告。结论不受影响：未调整时就不显著。

## 6. 流动性、容量、幸存者偏差（B 类）

- 选中的 Δ0.35 合约（测试期）：半点差 / 中间价中位数 0.086（75 分位 0.141），全点差占正股价中位 0.81%；k 0.5 相对中间价每笔成本 0.285% of S0——与测试期静态均值（+0.387%）同一量级。WOLF 0.19、AXTI 0.16 最差。训练期中位 0.060。
- 入场当天该合约成交量中位 36 张，8.3% 为 0；按当日成交量 10% 算，中位只能放约 4 张/只/周。Δ0.10–0.60 区报价 bid = 0 的比例测试期 4.2%（训练期 15.6%）。
- 幸存者偏差：15 只是 2026-10 事后按“涨得多的科技小盘”挑的。训练期等权持有约 +598%（QBTS +3396%、QUBT +1392%），训练期的边际很可能部分来自“挑的就是涨过的”。测试期这批股票分化（10/15 下跌），静态版仍未显著；即便过关也不能外推到池外。这一点进一步压低训练期结果的可信度。

## 8. 判定：**FAIL**

不满足的是 §5 第二行：Δ0.35、k 0.5 静态均值 +0.387%，95% 区间 [−1.06, +1.90] 含 0（Bonferroni 97.5% [−1.23, +2.15] 同样含 0）。另外：去两端 2% 后为负（只靠尾部）、去掉最好 5 周后显著为负、26Q3 反向、最大回撤翻倍。每日对冲版 −0.111 [−0.48, +0.25]，按 §5 预先写定的解读，测试期点估计的那点正数是趋势 / 终值波动敞口，不是期权便宜。实现没有 bug（静态逐位复现、每日差异已查清），不适用 REVISE。

给提案人的信息：
- 训练期本格的每日对冲版就已经区间含 0（+0.34 [−0.21, +0.94]），提案自己的解读规则在训练期就已指向“不是期权便宜”。
- 静态版的盈亏是 3 周终值的 V 形（≈ 长跨式）：测试期两侧尾部都赚（> +20% 合计 +1210、≤ −20% +617），上侧被 +5~+20% 的 −889 抵掉大半，净贡献下侧略大于上侧——不是单边押涨；它押的是“3 周终值波动 > 日波动之和”（路径打乱检验两段都 p < 0.001），这一点是真的，但量太小，抵不过小盘股期权的点差（k 0.5 ≈ 0.29% of S0）。
- 如果要继续，应该把“3 周方差比（3 周已实现 / 日已实现之和）”当作明确的机制、在**事前定义**的小盘股池上提；卖方那边（每日对冲按中间价 +0.17、扣成本后为负）同样没有余量。
