## 3. 机械偏差的解释是否成立：签号来源 × 起点参照交叉矩阵

终点 chain floor(t)+τ，同格对冲、日级截尾均值（美元/组）。四种参照：own = 成交自带四腿 NBBO；interp = chain floor(t) 与 floor(t)+1 按秒插值；ch_0 = chain floor(t)；prior = 每条腿在该毫秒之前最后一笔他笔成交自带的 NBBO（年龄中位 3.6 秒，p90 25 秒）。

| 签号 \ 起点（τ = 5 / τ = 15） | own | interp | ch_0 | prior |
|---|---|---|---|---|
| **own** | **+4.92 / +5.91**（判定） | −0.45 [−0.85, −0.04] / +0.47 [−0.12, +1.06] | −1.13 [−1.54, −0.71] / −0.16 [−0.75, +0.48] | +0.59 / +1.64（prior ≤ 2 秒：+1.53 @5） |
| **interp** | **−8.99 [−9.73, −8.27] / −8.89** | +0.63 / +0.61（共用） | +1.31 [+0.63, +1.99] / +1.29（interp 含 ch_0，非独立） | −9.08 / −9.01 |
| **ch_0** | −5.74 / −8.70 | +0.17 / −2.87（非独立） | **+7.30 / +4.26**（共用） | −5.20 / −8.05 |
| **prior** | +0.22 / +0.66 | −0.25 / +0.17 | −0.22 / +0.17 | **+18.07 / +18.72**（共用） |

终点换成逐笔 asof 报价（t+τ 每腿最后一笔的自带 NBBO）结论不变：own/own +5.15 / +5.68，own/interp −0.22 / +0.35，own/ch_0 −0.86 / −0.31，interp/own −10.07 / −8.69。

读法：
- **镜像成立，解释站得住**。签号用 own、起点用 own → +4.9；签号换成独立的 interp、起点仍用 own → **−9.0**（区间远离 0），符号翻转、量级更大（不对称是因为成交价贴着自带 NBBO 定价——own 参照的 k 最小，§4——签号来自 interp 时，own 与 interp 的整段差都流进签号，而不只是超过一跳的那部分）。偏差跟着“签号与起点是否共用同一份报价”走，不跟着“谁是主动方”走。
- **偏差是普遍的，不是 own 独有的**：只要签号与起点共用一个参照，就出现大的假正值——ch_0 / ch_0 +7.3、prior / prior +18.1（prior 最陈旧，噪声最大，假冲击最大）。量级随参照相对成交时刻的噪声单调放大，和按 |偏离| 分档的 −3.6 / −7.1 / −26.7 是同一个签名。
- **自带报价的位移不是陈旧，是瞬时的、与签号同源的**：全样本自带报价年龄中位 0.024 秒；签号用 own 时，own − prior（prior 年龄 ≤ 2 秒）= −3.50 美元/组——成交那一毫秒的四腿 NBBO 相对几秒前的报价朝成交价的反方向偏了，随后回到 chain 水平。按 own 签号时这个位移是按构造挑出来的（选择效应），所以这份数据分不清“自带报价在跳”还是“分钟参照在那一刻偏了”哪一边是噪声；对结论不重要。对“挂单价在成交之前就定了”的用户，这段跳动不是成本；提案人对 §1.3 的自我纠正正确。
- **interp 起点吸收了一部分走势**：s·u·(ch_1 − ch_0) 的对冲均值 −0.66 [−0.83, −0.50]，约等于 I'_5（−1.13）与 interp 起点（−0.45）之差 −0.68（截尾均值不严格可加）。

**“独立参照下 markout 在 ±0.5 美元内”是否站得住：只部分站得住。** 签号与起点独立、起点不早于成交的干净格（own×interp、own×ch_0、prior×own/interp/ch_0）在 τ = 5 取 **−1.13 … +0.22**，τ = 15 取 **−0.16 … +0.66**。±0.5 只在 own×interp（提案人选的那一格）和 prior 签号的几格成立；起点用 ch_0 时 5 分钟是 −1.13 [−1.54, −0.71]，区间不含 0（其中约 −0.66 是 interp 与 ch_0 之间的分钟内走势）。起点用 prior（平均老 3.6 秒，含成交前那几秒的走势，不是干净的成交后漂移）的 own×prior 格为 +0.59 / +1.64（≤ 2 秒 +1.53 @5），单列、不进区间。准确说法：**独立参照下，近平值组合成交后 5–15 分钟的 mid 漂移在 −1.1 ~ +0.7 美元/组之间，符号随参照变化，没有一致为正的逆向选择；判定口径的 +4.9 不存在。** “k 0.20 不需要为此加项”成立。“对被动方有利”同样不能读出来。

## 4. 对 V-0013 有效 k（各自腿口径）的影响

V-0013 的 k_own 是无条件的绝对偏离 |成交价 − 自带 mid| / H，不签号，所以本提案的**方向性**偏差不进入它。但它含同一份噪声，口径要写清。本样本（铁蝶，|K − S| ≤ 5、09:45–15:30，H̄ 0.248 点）：

| 参照 | k 均值 / 中位 | |滑点| 均值 / 中位（美元/组） | |滑点| > 10 美元 |
|---|---|---|---|
| own（V-0013 各自腿） | 0.238 / 0.200 | 5.66 / 5.00 | 8.4% |
| interp | 0.333 / 0.231 | 7.77 / 5.10 | 23.0% |
| ch_0（回测用的那份分钟快照） | 0.479 / 0.300 | 11.04 / 7.50 | 30.3% |

- 按 own 签号为“≥ 1 跳”的铁蝶成交（122,538 笔），换成 interp 后同号 44.5%、反号 13.4%、落进 1 跳以内 42.1%：**“偏离 ≥ 1 跳”这件事依赖参照——约一半在独立的分钟参照下不是 ≥ 1 跳**。interp 本身是更噪的参照（k 更大），所以不能把分歧全记在自带报价头上；能说的是 V-0013 |滑点| 尾部的大小与参照绑定。
- 分侧 k_own（只看签号成交）：s = +1 0.358、s = −1 0.336，用户一侧（卖铁蝶 = 买 Π）没有显著高于另一侧。
- 结论（一句）：**V-0013 的 k_own 0.246 / 0.200 不受方向偏差影响，与 config k 0.20 仍可比（用户的校准 k 也是相对成交时刻的 TWS 自带 mid，含同一份跳动）；换成与成交时刻无关的分钟参照，绝对 k 升到中位 0.23–0.30 / 均值 0.33–0.48，但多出来的是参照噪声（对称、均值为 0），不是成本，回测的期望不需要改 k。** 需要加在 V-0013 注记里的只有：|滑点| > 0.10 的 8.1% 尾部依赖参照，约一半在独立分钟参照下落回 1 跳以内。

## 5. 方法教训

用成交自带的四腿 NBBO 既签号又当起点，会产生约 +5 美元/组的假冲击（铁蝶 / 蝶，0DTE 近平值）；签号来源换成独立参照后同一起点给出 −9，是镜像；任何参照（chain 分钟快照 +7.3、陈旧 asof +18）与签号共用都会出现同样的假正值，量级随该参照的噪声放大；格内打乱签号的置换零分布对它完全不敏感。**签号与起点 / 终点必须来自两份独立的报价，并且要同时报“反过来”的那一格，看是否镜像。**
