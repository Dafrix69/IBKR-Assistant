## 3. 提案人的诊断与验证人的补充检查

提案人的诊断：单腿成交时刻自带 NBBO mid 比 chain 插值高 +0.4 ~ +5.2 美元/张（我复现：身体 call +3.03、put +5.16，51–85 档 +0.42 / +0.99，逐位一致），成交价贴着自带 mid（价 − 自带 mid：|K−S| ≤ 15 call −0.03、put −0.08 美元/张），身体权重大，所以 Π 合成为负。验证人做了四项提案人没做的检查，全部 09:45–15:30、训练期、美元/张、日级截尾均值（`stats_out.txt`、`extra_out.txt`）：

**(A) 同一合约前后 1 秒的报价（“成交瞬间是否短暂上抬”）**。对每笔单腿成交取同一合约前一个 / 后一个不同毫秒的任意成交行（≤ 1 秒）的自带 NBBO：

| 档 | 自带 − 前一条 | 自带 − 后一条 | 前一条 − chain 插值 | 后一条 − chain 插值 |
|---|---|---|---|---|
| 身体 C / P | −0.12 / −0.12 | +0.12 / +0.10 | +4.31 / +7.59 | +4.18 / +7.41 |
| 16–30 C / P | −0.10 / −0.09 | +0.05 / +0.04 | +1.73 / +4.06 | +1.62 / +3.92 |
| 51–85 C / P | −0.06 / −0.09 | −0.04 / −0.05 | +0.50 / +1.89 | +0.49 / +1.81 |

单腿成交时刻的 NBBO 与前后 1 秒内的报价相差 ≤ 0.12 美元/张，**没有秒级尖峰**；前后报价相对 chain 插值同样高（有邻居的子样本更忙，所以更高）。“成交那一瞬间报价被抬了一下”被排除。

**(B) chain 在自己的采样时刻是否有偏**。只取 t ∈ [m, m + 0.5 秒) 的行（V-0015：chain 第 m 行 ≈ 这半秒的 NBBO），自带 mid − chain 第 m 行（不插值）：单腿 −0.28 ~ +0.11、组合腿 −0.14 ~ +0.57。**chain 快照本身没有 +3 ~ +5 的偏差。**

**(C) 固定 chain 行：同一合约同一分钟里同时有单腿和组合腿成交**（每天约 700–1,700 个合约分钟/档）：自带 − 插值 单腿 / 组合腿 / 差：身体 C +0.52 / −0.13 / +0.65，身体 P +1.17 / +0.89 / +0.29，其余档差 −0.38 ~ +0.29。同一分钟里两类成交看到的 NBBO 相对 chain 几乎一样，**两份 NBBO 来源在任何成交时刻都一致，差的是“哪些分钟”**。

**(D) 按该合约该分钟的单腿成交笔数分档**（|K−S| ≤ 15）：

| 每分钟单腿笔数 | 1–5 | 6–20 | 21–100 | > 100 |
|---|---|---|---|---|
| call 自带 − 插值（笔数占比） | +0.46（0.6%） | −0.70（6.7%） | +0.39（55.5%） | **+8.50（37.2%）** |
| put | +0.53（0.8%） | −0.63（8.8%） | +1.41（60.6%） | **+15.68（29.8%）** |

整个 +3 / +5 几乎全部来自**单腿成交爆发的分钟**（> 100 笔/分钟，占三到四成的笔数）。另：按报价年龄分档，最新鲜的报价（< 100 毫秒，占 89%）偏离最大，1–10 秒的旧报价接近 0 或为负——“自带报价陈旧所以偏高”被排除；条件码 18 / 125 / 95 同号（125 最大）。

**判断**：提案人的读法（“单腿成交时刻自带 NBBO 比 chain 插值高、是抽样偏差，不是 chain 整体错位”）**成立，而且可以说得更具体**：这是**成交时点选择**，时间尺度在秒到一分钟之间——单腿成交扎堆发生在腿 mid 偏离分钟端点线性路径向上的分钟里（call 与 put 同号、put 更大、随权利金变大；具体是分钟内冲高回落还是波动率尖峰是**推测**，本审计没有检验），chain 两端点的线性插值看不到这段偏离；既不是成交瞬间的秒级尖峰（A），也不是 chain 快照偏差（B、C）。

需要限定提案人的一处表述：§7.3 说“两份 NBBO 来源在组合成交时刻一致”，直接证据只在识别出的近平值组合的 **Π 层面**（自带 − 插值 +0.24）。我的逐腿表里 M 行是**全部多腿条件码的腿行**（含竖价差、鹰式、远行权价组合，不只是识别出的近平值铁蝶 / 蝶），它们逐腿也为正（身体 call +0.56、put +3.23，16–30 档 +0.60 / +1.70）；这与 Π 层面的 +0.24 不是同一批成交，不能相互推算。结论只到这里：识别组合的 Π 自带 − 插值很小；D_own（同毫秒自带 NBBO）+2.27 与 D 一致，不依赖这一点。

**对 D 本身意味着什么**：D 的主要证据应当是 D_own（成交价对**同一毫秒**的腿 NBBO，不受分钟内插值误差影响），+2.27 [+2.19, +2.36]，两段 +2.38 / +2.18；chain 插值只是一个更粗的旁证。D 这个价格事实在训练期稳定，本审计**没有否定**它。

## 4. 给 P-0019（公平安慰剂）的设计约束

- 安慰剂必须与主量**同一份、同一时刻的参照**：单腿成交价 − 它自带的 NBBO mid，按 Π 权重合成（各腿“价 − 自带 mid”在训练期 −0.09 ~ +0.03 美元/张，合成后量级 ≤ Σ|g|·0.09 ≈ 0.36 美元/组）；主量同样用 D_own。不能再拿 chain 插值去比两类在分钟内时点构成不同的成交。
- 这个口径的训练期值已被看过（≈ 0），所以只能在测试期盲判，提案里要申报。
- 这是公平但**偏弱**的零：单腿成交（码 18 / 125）几乎都成交在自带 mid 上、净主动 ≈ −0.01，它接近 0 几乎是构造使然。P-0019 要同时报告单腿与组合成交的主动方构成（≥ ask / ≤ bid / mid 的比例），免得把“安慰剂 ≈ 0”误当成有区分力的检验。
- 若仍想保留 chain 插值作旁证，安慰剂要在**同一合约同一分钟**内配对（检查 C 的做法），或按分钟活跃度分层（检查 D）。
- 经济量级仍然只有约 2 美元/组（基准 A 期望的约 2%），即便 PASS 也只是成交模型的方向修正，不是边际。
