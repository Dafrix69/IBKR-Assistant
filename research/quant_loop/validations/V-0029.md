## 7. 读法表（字面套用）

- 「**k 0 均值 ≤ 0**」行适用（−73.3）：「**边际不存在**」。
- 下一行「k0 ≤ 0 且『结算 − 14:00 现货』均值 > 0 且信用 / 15 > 赔付 / 15 不成立」**字面适用**：漂移 +0.91 > 0，信用 0.231 < 赔付 0.277。读作「主要是漂移，溢价是否存在这段数据分不出」。
  - 验证人加注（不改判）：漂移只解释约四成（去掉后 k0 仍 −46）。2022-01…04 漂移为负却仍亏，所以「主要是漂移」这个读法偏宽。
- 「k0 ≤ 0 且漂移 ≤ 0」行不适用（全段漂移 > 0）。
- 「**k 0.5 均值 < 0 且 95 % 区间上界 < 0**」行适用（上界 −23.7）：「**A-hist 上显著为负**：用户的规格在 2022 年以前的市场结构里是亏的」。这是本次检验唯一有功效的结论，结论成立。
- 年份行都不适用（2020、2021 都 ≤ 0）。月末行不适用。

## 8. 判定

**FAIL**（PASS 表七条全不满足；负侧显著）。

**给提案人的信息**：
- 用户的 14:00、15 宽、收 3–4 点 bear call 在 2020-01 → 2022-04 的中间价上就亏（k0 −73），扣当年点差后 −90 / 天。
- 亏损集中在高波动段（2020 −157、2022-01…04 −95）。平静的 2021 信用 ≈ 赔付，扣成本后 −11。
- 下午上涨漂移只解释约四成；更大的部分是那个年代下午的实际振幅大于 3–4 点信用所隐含的。
- 规则天然偏向高隐含日交易：低 I 三分位 59 % 的日子被跳过，高 I 只跳过 7 %。在 A-hist 上，偏向的正是亏钱的日子。
