### 0.2 推断（§5 原样）

按入场 ISO 周排序，平稳块 bootstrap（几何块长均值 8 周，环绕），10000 次，seed 21；每次重抽统计量 = 抽到各周全部单子 pnl 合计 ÷ 笔数。报 2.5 / 97.5 与 Bonferroni（2 个提案）1.25 / 98.75。

### 0.3 判定（每池、2024 训练 / 测试段、两个合并各给一个）

§5 原文三条：(1) 静态 Δ0.35 k0.5 均值 > 0；(2) 其 95% 区间与 Bonferroni 97.5% 区间都不含 0；(3) 静态 Δ0.35 k1 均值 > 0。全部满足 = PASS，否则 FAIL。
各池判定之间**不做跨池校正**；复核的主判定是主合并。7 个池里有零星单池 PASS 不足以推翻合并结论（每池单侧 1.25% 的偶然通过概率，7 个池至少一个偶然通过约 8%）。

### 0.4 解读检验（§5「预先写定的解读」）

每日对冲 Δ0.35 k0.5 均值与 95% 区间。静态 > 0 而每日 ≤ 0 或区间含 0 → 「动量 / 终值波动敞口，不是期权便宜」；两者都 > 0 且每日区间不含 0 → 才可说「期权低估向上尾部」。

### 0.5 报告项（每池、两段、两个合并，不进判定）

1. n、胜率 + Wilson 95%、中位数、去两端 2% 均值（静态 Δ0.35 k0.5）。
2. 为正的股票数：数目 / 总数和比例（§5 的 ≥ 9/15 换成 ≥ 60%、≤ 7/15 换成 ≤ 46.7%，只报不判）。合并里按代码计（同一代码在多个池合一）。
3. 去掉贡献最大的一只（按 pnl 合计；合并里按代码，另报按「代码 × 池」）后的均值。
4. 去掉最好的 5 周（按周 pnl 合计）后的均值与 95% 区间（静态与每日）。
5. 相邻档 Δ0.25 / Δ0.50（k 0.5，静态）是否与 Δ0.35 同号；Δ0.15 只报数。
6. k 0 / 0.5 / 1（静态与每日）。
7. 前后半段（每池按窗口中点分；合并按池）。
8. 最大回撤（按周平均 pnl 累计）。
9. 敏感性：融资 / 计息的 r 改为 0（选合约仍按 4.3% 的规则不变），只报静态 Δ0.35 k0.5——2019–2021 实际短端利率远低于 4.3%，卖股所得按 4.3% 计息对策略有利。佣金 $0.65/张（开仓 + 价内到期再一次）+ $0.0035/股。
10. 流动性：选中合约半点差 / 中间价中位数、当日成交量中位数与 0 成交比例、Δ0.10–0.60 区报价 bid = 0 的比例。
11. 剔除计数（按原因：无文件、不能结算、缺陷跨越、DTE 无合约、无 |Δ−0.35| ≤ 0.05 的合约、其他根代码行数）。
12. 背景：同期等权持有本池（窗口首日收盘 → 窗口末日或最后数据日收盘），只作背景。
13. 已知不建模、写明方向：派息股卖股要付股息（忽略 → 偏有利）；借券成本（GME/AMC 等，「少持 h0 股」框架不计 → 偏有利）。
