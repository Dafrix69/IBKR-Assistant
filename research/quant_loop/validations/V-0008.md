# V-0008 对 P-0008（轻量审计，训练期撤回）

范围：提案人按预注册撤回闸门（7 条全部触发）在训练期撤回，未申请测试期。本审计**不跑测试期**。`calendar`、`spot`、`vix_term_1d`、`vix_1d` 读入后第一步过滤 `< 2024-11-01`，chain 只对训练期日子打开并再按 `ts` 过滤，结果表再过滤一次。只做四件事：泄漏审查、撤回依据的独立复现、判断“L 档下午 x 更大”是不是 P-0006 那条线、记账。

## 判定：WITHDRAWN（训练期撤回）。撤回成立；“L 档 x 更大”不是 P-0006 的低隐含水平效应，而是高 I 三分位里一个只有 25 天的小格上的噪声，均值差由其中 3 天主导

撤回依据我独立复现了。577 个有效日的 K0、I、s、w15、w3 以及 1.5×、3× 两只蝶的盈亏都与提案的 `days_all.csv` 逐日一致（最大差 1e−12 美元）。2× 蝶和基准 B 分别在 7 天和 4 天不同，这些都是平局日（见泄漏审查第 3 条）。M_c / M_t / M_x 全期、按年、按 I 三分位、按已走幅度、按 settle − F 分段，**每一格都与提案相同（到小数点后三位）**。唯一的差别是 7 天的 w2（m = 2 正好平局，见泄漏审查第 3 条），它让 Δ 从 −24.8 变成 −24.5，不影响任何结论。7 条闸门全部触发，我核对过。

第 3 项的结论（详见“独立意见”）：

- s 与 x 在整个训练期**没有关系**。Spearman(s, x) 为 −0.009；在三个 I 三分位内分别是 +0.06 / +0.01 / −0.02。x 对 s 回归并控制 log I 后，s 的系数是 **+0.07 [−0.80, +0.90]**，再控制 log FE 后是 +0.07，三年的符号分别为 + / − / +。
- 提案报的 M_x −0.082 几乎全部来自**高 I 三分位**（−0.230，L 档只有 25 天，档内 Spearman(s, x) −0.015）。低 I 三分位是 +0.012，中 I 三分位是 −0.028。去掉高 I × L 格里 x 最大的 3 天（2024-08-30 x 3.31、2022-12-22 x 2.88、2022-07-05 x 2.21，三天都是下午大涨），该格 M_x 变成 **+0.010**。
- 高 I × L 格的 25 天分布在 2022 / 2023 / 2024 = 11 / 3 / 11，**不在 2023–2024 的平静期**。P-0006 那条未证实的线在**低 I 三分位**（I ≤ 10.6）。在低 I 三分位里，s 分不开 x：L / M / H 档的 x 均值是 0.998 / 0.841 / 1.010，档内 M_x 为 +0.012。
- 所以这两件事所在的格子互不重叠，“L 档 x 更大”也不是 I 水平的影子：在高 I 三分位里，x 对 log I（或 log I 加 log FE、log VIX 前收）回归后取残差，H − L 仍是 −0.23 ~ −0.25，说明控制 I 并没有让它消失。它消失只靠去掉 3 天。**结论是：这是小格加离群值，不归入 P-0006，也不另立一条“未证实”的线。**

## 独立意见：“L 档下午 x 更大，在高 I 三分位最明显”是不是 P-0006 那条线

P-0006 留下的未证实线是：**低 I 三分位（I ≤ 10.6）里，FE 低（0DTE 隐含相对 VIX 低）的日子，下午实际走幅超出定价**。这是一个水平效应，也就是 `iv_over_vix` 的影子。要把 P-0008 的现象归入这条线，至少要满足两点之一：它出现在同一个低 I 格；或者控制 I / FE 之后，它表现为“定价偏低 → x 偏大”。我逐条检查：

1. **所在的格不同。** x 按 I 三分位 × s 档的均值如下：低 I 为 L 0.998 / M 0.841 / H 1.010，中 I 为 0.980 / 1.102 / 0.951，高 I 为 1.044 / 0.822 / 0.814。只有高 I 格里 L 明显大于 H。在低 I 格，s 分不开 x（M_x +0.012）。P-0006 的水平效应在本样本里确实存在，但看的是 FE 而不是 s：低 I 三分位内，FE 低的一半 x 为 1.033，高的一半为 0.873。
2. **年份不对。** 提案说“s 低的日子多在 2023–2024 的平静期”，这对整个 L 档成立（19 / 74 / 78），但对产生这个效应的高 I × L 格不成立：那里是 11 / 3 / 11，2023 年只有 3 天。高 I 格的按年 M_x 为 2022 −0.185、2023 −0.013、2024 −0.398。
3. **控制 I 和 FE 后它没有消失，所以也不是 I 的影子；但它也不是 s 与 x 之间的关系。** 在高 I 格里，x 对 log I、log FE、log VIX 前收回归，取残差后 H − L 仍为 −0.23 ~ −0.25。高 I 格里 L 档的平均 I 比 H 档低（17.3 对 19.2），但 x 对 I 在该格内的 Spearman 为 +0.006，几乎为零，所以这个 I 差解释不了 x 的差。另一方面，全样本 Spearman(s, x) 为 −0.009，各 I 三分位内 |ρ| ≤ 0.06；x 对 s 和 log I 回归时，s 的系数为 +0.07 [−0.80, +0.90]。“L 档 x 更大”只出现在“档均值”这个统计量上，秩相关和回归都看不到。
4. **离群值。** 高 I × L 格 25 天里，x 最大的 3 天是 2024-08-30（3.31）、2022-12-22（2.88）和 2022-07-05（2.21），三天都是 14:00 之后单边大涨。去掉 1 / 3 / 5 天后，该格 M_x 依次为 −0.135 / +0.010 / +0.090。两档的中心质量 P(x ≤ 0.5) 都是 0.36；P(x > 1.5) 为 L 0.20、H 0.16，差别在 25 天里只相当于 1 天。中位数也是 L 0.925 对 H 0.713，同方向差 0.21，但 25 天的中位数标准误约 0.2，档内 Spearman(s, x) 为 −0.015。所以这一格没有秩关系，均值差由 3 天主导。这 3 天也是交互 I1 反号的主要来源：3 倍宽翅 put 蝶在远离中心向上结算时会亏掉全部成本，于是 D3|L 被压低。去掉这 3 天后 I1 从 −66 变为 −45，仍然反号。可见 M_x 的反向和 I1 的反向来自同一批日子，不是两条独立的证据。

**判断：不是同一现象。** 它不在 P-0006 的低 I 格，不在平静年份，与 I 和 FE 都无关，只是 25 天小格上的噪声，均值差由其中 3 天主导。账本的写法是：**“训练期 s 与 x 无关（秩相关和控制 I 后的回归都为零）；原始档均值的反向只出现在高 I × L 这个 25 天的小格，由 3 个下午大涨日主导（中位差 0.21，在约一个标准误内），不归入 P-0006 的未证实线，也不构成新的未证实线。”** 不复活这个提案，也不接受反向规则（L 1.5 倍 / H 3 倍）：那是看了训练期结果之后再定的方向；它在盈亏上的点估计为正，靠的正是同样那几天。
