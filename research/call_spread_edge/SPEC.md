# 从「卖 call 垂直价差」出发找正期望 —— 研究规格

写于 2026-11-06，**在看任何对冲后 / 条件化结果之前**。之后的改动写在文末并注明原因。

## 出发点（已知，不再重复检验）
`research/call_overlay/`：15 只小盘股上，不对冲地卖 call 垂直（当周、2–4 周；delta 0.25 或平值；2×/1× 止损；75% 止盈）在全部 600+ 个组合里没有一个过关。
那里的亏损混在一起的是三样东西：**方向**（样本期大涨，空 call 价差是空头敞口）、**期权本身贵不贵**（方差溢价）、**成交成本**（小盘股期权点差）。
这项研究先把三样拆开，再只在「期权本身确实贵」的地方建策略。

## 已经看过的数据（申报）
- 小盘股 2024-10-31 … 2026-10-29：看过**不对冲** call 价差的全样本盈亏、按年、按股票。没有看过对冲后的盈亏、IV 与已实现波动的关系、put 侧。
- SPY / QQQ / IWM：**完全没看过**。

## 时间墙
- 训练期 `date < 2025-11-01`，测试期 `date >= 2025-11-01`（约 12 个月）。所有发现、选参数只用训练期。
- 每个脚本读数据后第一步按 `PERIOD` 过滤；测试期只在规则冻结（写进本文件「冻结的规则」一节）之后跑一次。
- 测试期由独立的验证人（`quant-validator` agent）自己重写实现、只跑一次，按这里写定的通过标准判。

## 数据
- ThetaData `greeks_eod`（日终 NBBO，`underlying_price` = 收盘价）。小盘股 15 只 2024-10-31 起；SPY/QQQ/IWM 2023-01-27 起（下载还在往前补，研究只用 2023-01-27 起）。
- IV 与 delta 自己从中间价用 BS 反推（r = 4.3%，ETF 不扣股息，ETF 只用 call 时提前行权忽略）。文件里的 delta 不用。

## 标的分工（开工前定，2026-11-06）
- **发现集 = 15 只小盘股的训练期**（2024-10-31 … 2025-10-31，约 52 个周一入场 / 只）。第一、二阶段只碰这一段。
- **SPY / QQQ / IWM 整体封存**，第一、二阶段一行都不读。到第三阶段，它们的**全部历史**（2023-01-27 起，约 3.8 年）都是盲检。
- 冻结规则时必须先写明：这条规则预期在 ETF 上也成立吗（机制是否通用）。写了「是」，ETF 盲检就是通过标准的一部分；写了「否」，ETF 结果只报告。

## 第一阶段：诊断（只训练期）
问题：**在这些标的上卖 call（或 put）本身有没有溢价，在哪个行权价、哪个期限？**
- 每周第一个交易日收盘，对当周到期（2–6 天）和约 3 周到期（14–28 天，取最接近 21 天）两档，按 delta 取 call 0.50 / 0.35 / 0.25 / 0.15 / 0.10，put −0.50 / −0.25 / −0.10。
- 卖 1 张，持到到期按内在价值结算；每天收盘按 BS delta（当天中间价反推的 IV，缺报价沿用前一天 IV）用正股做 delta 对冲。
  另算一个**静态对冲**版本：只在入场时按 delta 买入正股，持到到期不调整（贴近用户已经持股、不愿天天调仓的做法）。
- 成本：期权入场按中间价让 k × 半个点差，k ∈ {0, 0.5}；到期不付平仓成本；正股调仓按成交额收 5 bp（小盘股）/ 1 bp（ETF）。
- 输出：每格（标的组 × 期限 × delta）对冲后盈亏占正股市值 % 与占权利金 %，周块 bootstrap 区间（块 8 周），按标的、按半年拆开。
- 同时记录入场时 ATM IV、下一个到期日的 ATM IV（前后月比值是唯一能事前看到财报的代理）、过去 20 日已实现波动 RV20、call 25Δ 与 ATM 的 IV 差（偏斜）、5 日涨跌，供第二阶段条件化。
- 每格同时报均值、中位数、去掉两端各 2% 后的均值（一只股票一周的大涨会主导均值）。
- 样本量提醒：每格约 15 × 52 = 780 笔、52 个周块；挑「8 个 delta 里最贵的一档」本身就是 8 个变体，第二阶段要计入变体数。

## 第二阶段：候选（只训练期，提出时就写机制）
以下是开工前想到的方向，诊断后可以删、改、加，但每一条进第三阶段前都要写清楚机制、规则、训练期证据、变体数：
- H1 **方差溢价择时**（Goyal–Saretto 2009：IV 高于历史波动越多，卖期权的收益越高）：只在 ATM IV / RV20 处于训练期高三分位时卖。
- H2 **对冲后的 overlay**：用户本来就持股。卖 call 价差的同时多买「价差 delta × 100」股，让总敞口不变，只赚期权的溢价，不再用方向去换权利金。
- H3 **卖贵的那一档**：按诊断出的「哪个 delta 最贵」决定短腿、「哪个最便宜」决定长腿（可能是反过来的借方价差）。
- H4 **大涨之后**：5 日涨幅极端时 call IV 抬高、短期回吐（小盘股），卖 call 价差。
- H5 **ETF 侧**：不在发现阶段做（封存），只作为第三阶段的盲检。

## 通过标准（第三阶段，测试期，写定）
- 主判据：k = 0.5、含对冲成本，测试期每笔平均盈亏 > 0，且周块 bootstrap 95% 区间不含 0；
- 同时 k = 1 时平均值 > 0（对手价也不亏）；
- 冻结时写明「ETF 上也应成立」的规则：SPY / QQQ / IWM 全历史（盲检）同样 k = 0.5 均值 > 0。
- 多重比较：测试期跑几条规则就报几条，按 Bonferroni（α = 0.05 / 条数）再报一次。
- 不过关的写成「没证明有效」，不换参数再测。
