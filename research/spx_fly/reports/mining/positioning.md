# 因子族 positioning：持仓结构（OI）与 GEX 轮廓

脚本 `src/mining/positioning.py`；表 `reports/mining/positioning_tables/`。目标：put_fly、翅宽 25/30、13:00 与 14:00 入场，持到结算，胜率 = pnl>0（k=0.25 含费）。训练期 `date < 2024-11-01`（621 天 / 2481 行），测试期（494 天 / 1969 行）；剔除半天。全样本基准胜率训练 54.0%、测试 56.9%；期望训练 +10、测试 +69 美元/笔。

## 1. 一句话结论

**没有找到能叠在基准规则上的持仓结构因子。** 38 个因子里 15 个单变量两期成立（置换零假设下平均只有 2.5 个，p=0.00，所以结构本身是真的），但它们几乎全是同一件事的不同写法——「现货处 GEX 为正 / 零 gamma 在下方 / put-call OI 低 / OI 重心在现货下方」，训练期两两 Spearman 多在 0.8–0.97；而这件事与隐含水平（|ρ| 0.3–0.6）和当日已走幅度（ρ 0.45–0.78）高度相关。叠到基准（14:00、翅宽≈2×隐含、跳过前日 ≤−1%）上，76 个（因子, 变体）里只有 4 个两期同号且测试期 ≥+3pp，置换零假设下平均 2.5 个、p=0.23，与运气无法区分；其中 max pain 距现货与 ±50 OI 不对称两项的增量在按「当日已走幅度」分层后消失，是日内动量的影子。

## 2. 试过的因子

所有因子都在入场那一分钟已知：OI 用 D 日文件（= D−1 收盘），OI 日变化 = D 文件 − D−1 文件；GEX 用 D−1 收盘 NBBO 反解的 IV（与 `gex_daily` 同一套 `src/gex.py` 求解器），到期时间按入场时刻缩短（从前一交易日 16:00 到入场时刻的实际小时数，周一与假日后按日历算），在入场现货 S 处重算，并在 S×(1±1%) 处重算以取斜率与曲率；当天到期的 AM 结算 SPX 从所有「全到期」口径里剔掉。全到期的集中度 / 重心 / put-call 只用现货 ±10% 内的行权价；局部口径用 ±50 点。SPY/QQQ 现货取 TWS 1 分钟 K 线在入场前一分钟的收盘。

置换检验：把因子面板按交易日整体打乱（所有因子一起、13:00/14:00 配对不拆）200 次，重做单变量筛与增量检验。单变量「成立」数：观察 15，零假设均值 2.52、95 分位 7，p=0.000；增量「有价值」数：观察 4，零假设均值 2.48、95 分位 7，p=0.235。也就是说单变量层面的结构是真的（但它是一簇而不是 15 个独立发现，且与隐含和日内走势相关），增量层面的 4 个命中与随机无法区分。注意置换把交易日独立打乱，拆掉了 GEX 符号、零 gamma 距离这类慢变量的自相关，真实的零假设下「跨时间切分仍成立」的个数会比这里的均值略多。

## 6. 与前面研究的关系、局限

- `winrate_study.md` 已经报告过「距零 gamma」「总 GEX」「0DTE GEX」单变量成立、叠在按隐含定翅宽之后没有增量；本次在入场现货处重算 GEX、加上 OI 日变化、max pain、梯度、ETF 对照，结论一样。
- GEX 符号这一簇在控制隐含的三组内仍同向（4.1 表），说明它不完全是隐含的影子；但基准规则里的「跳过前日 ≤ −1%」和按隐含选翅宽已经吃掉了它的大部分（4.2 表增量 +1～+2pp）。
- IV 用 D−1 收盘、到期时间缩到入场时刻，没有用入场时刻的 0DTE 实时报价重解 IV，所以 0DTE 的 gamma 量级只是近似；GEX 符号假定做市商多 call 空 put（见 `src/gex.py` 开头）。

- 基准规则测试期的 n / 胜率 / 期望与 `winrate_study.md` 的 439 / 61.0% / +100 一致；训练期 n 与那里的 504 不同（本文 543），来自上游面板日期范围 / 标签合并的差异，未追。
