# 因子族 flow：0DTE 期权成交流的微观结构

脚本 `src/mining/flow.py`，表 `reports/mining/flow_tables/`。全部数字来自 `flow_tables/summary.md` 与各 csv，未手改。

## 1. 一句话结论

**没有找到样本外站得住的成交流因子。** 30 个因子里有 7 个按单变量门槛"成立"，但其中 4 个（行权价集中度 hhi_day / hhi_60、有效点差 eff_abs_60、ATM 跨式相对点差 straddle_spread_rel）与 ATM 隐含的 Spearman 相关在 0.70–0.96，是"今天波动低"的影子，叠加到按隐含选翅宽的基准上增量为 0；只有净主动量 30 分钟加速度 accel30 在增量检验里两期同号（训练 +3.0pp、测试 +4.0pp，期望 +144 / +82 美元），但它测试期的 Spearman ρ = 0.015（p = 0.64）、13:00 入场的五分位曲线在测试期反向，150 次检验里预期约 7.5 个假阳性，不能当作证据。成交流对入场后 60 分钟的现货方向与幅度均无预测力（4 个连续目标全部 0 个成立）。

## 2. 样本与数据

- 数据：`data/raw/SPXW/trade_quote_dte0/`，501 个文件，2024-10-30 → 2026-10-29；剔除 5 个半天（2024-11-29、2024-12-24、2025-07-03、2025-11-28、2025-12-24），用了 496 天、992 个"日×入场"行。
- **切分与别的族不同**：训练 `date < 2025-11-01`（249 天），测试 `>= 2025-11-01`（247 天）。面板行（日×入场×翅宽 25/30）训练 994 / 测试 983。别的族训练约 620 天、测试约 500 天，本族样本约为其 40%/50%，每格的 Wilson 区间宽约 ±8pp。分年表里 2024 只有 11–12 月。
- 只读 10 列：`strike, right, trade_timestamp, condition, size, price, bid, ask, bid_size, ask_size`；`ProcessPoolExecutor(6)`，全量 1 分 25 秒。
- 主动方向：先剔除条件码 130/131/134/137/144（组合腿，占原始行 **35.9%**，日间 26.5%–46.4%）；剩余行里 NBBO 无效（ask ≤ 0 或 bid ≥ ask）的只有 0.02%，不分类；价 ≥ ask 记买（占 46.7%）、≤ bid 记卖（47.6%），其余约 5.7% 在点差内不分类。净主动量比 = (买 − 卖)/(买 + 卖)。条件码 125（抽样 2025-01-06 一天约 8% 行）不在 BRIEF 的剔除表里，照 BRIEF 保留。
- 现货用 `spot.parquet` 在入场分钟的值；ATM 跨式报价（两个因子）用 `chain_*.parquet` 在入场分钟的快照而不是成交附带的 NBBO（后者可能是陈旧报价）。
- 入场后 60 分钟现货变动 `ret60 = spot(t+60) − spot(t)`（点），另算 `|ret60| / implied`。

## 3. 试过的因子（30 个；t = 入场时刻，所有成交取 trade_timestamp < t）

| 因子 | 定义 | 为什么有道理 |
|---|---|---|
| nf_call_25_day | 自开盘至 t，\|K−spot\|≤25 的 call 净主动量比 | ATM call 的方向性需求 |
| nf_put_25_day | 同上，put | ATM put 的方向性需求（对冲 / 投机） |
| nf_call_50_day / nf_put_50_day | 带宽放宽到 ±50 | 同上 |
| nf_call_25_60 / nf_put_25_60 | t 前 60 分钟，±25 的 call / put 净主动量比 | 近期而非全天 |
| nf_all_60 | t 前 60 分钟，全部行权价两侧合计净主动量比 | 整体买压 / 卖压 |
| accel30 | (净主动量[t−30,t) − 净主动量[t−60,t−30)) / 成交量[t−60,t) | 净主动量的 30 分钟加速度 |
| accel60 | (净主动量[t−60,t) − 净主动量[t−120,t−60)) / 成交量[t−120,t) | 60 分钟尺度 |
| big50_share_day / big100_share_day | 自开盘至 t，单笔 size ≥ 50 / ≥ 100 的张数占比 | 机构大单活跃度 |
| big50_net_day / big50_net_60 | size ≥ 50 成交的净主动量比（全天 / 近 60 分钟） | 大单净方向 |
| frag_day / frag_60 | 成交笔数 / 成交张数（全天 / 近 60 分钟） | 碎单程度 |
| hhi_day / hhi_60 | 成交张数按行权价的 Herfindahl（全天 / 近 60 分钟） | 成交是否集中在少数行权价 |
| centroid_day / centroid_60 | \|K−spot\|≤100 内成交量加权平均行权价 − spot（点） | 成交重心相对现货的偏移 |
| pc_ratio_60 | t 前 60 分钟 put 张数 / call 张数 | 对冲 / 恐慌需求 |
| pc_ratio_chg | pc_ratio_60 / 自开盘至 t 的 put/call 比 | 相对当日均值的变化 |
| eff_60 / eff_call_60 / eff_put_60 | t 前 60 分钟可分类成交的 (price−mid)/半点差 张数加权均值（买方付出为正） | 买方急迫度 |
| eff_abs_60 | t 前 60 分钟 2·\|price−mid\| 张数加权均值（点） | 实际付出的有效点差 |
| nprem_put_50_60 / nprem_call_50_60 | t 前 60 分钟 ±50 的 put / call 净主动**成交额**比（price×size） | 按金额而非张数 |
| vol_accel | t 前 60 分钟每分钟张数 / 开盘至 t 每分钟张数 | 活跃度加速 |
| straddle_imb | t 时刻 ATM call 与 put 的 (bid_size−ask_size)/(bid_size+ask_size) 均值（chain 快照） | ATM 跨式报价簿失衡 |
| straddle_spread_rel | t 时刻 ATM call+put 点差之和 / 中间价之和（chain 快照） | ATM 跨式相对点差 |

## 6. 多重比较账

- 因子 30 个 × 目标 4 个（win、pnl、ret60、|ret60|/implied）= 120 次单变量检验，再加 30 次增量检验，共 **150 次**；5% 水平下预期假阳性约 **7.5 个**。
- 单变量 win 成立 7 个（其中 4 个是隐含影子，剩 3 个）；pnl / ret60 / |ret60|/implied 成立 0 个；增量通过 1 个（accel30）。扣掉隐含影子后的 4 个"阳性"少于 7.5 的预期，与全是运气一致。
- 没有搜参数：每个因子只有一个窗口（30/60/120 分钟）、一个带宽（±25/±50/±100）、一个大单阈值（50/100），叠加规则统一为"剔除不利的两个训练五分位"，没有试别的切点。drift 门槛 30 行、增量最小 50 天是在看到结果之后加的（为了把 frag_*/big*_share 的漂移标出来），不影响 accel30 的结论。
